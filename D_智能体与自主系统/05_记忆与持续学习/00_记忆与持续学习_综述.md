# 记忆与持续学习

记忆保存当前状态、长期知识、经历与技能；持续学习改变策略或参数，使系统在新任务中适应而不过度遗忘旧能力。二者共同构成 Agent 从"每次从零开始"走向"经验可积累、能力可迭代"的适应层。

## 概念边界

- **RAG** 是外部知识增强，不等同于个人经验记忆（详见 [[../06_Agent工程系统/03_RAG与检索增强/00_RAG系统|D-06 RAG系统]]）；长期写入必须验证来源、权限、时效和冲突。
- **反思**改变的是行为策略（提示/记忆），语言层面总结，成本低、已可行；**持续学习**改变的是模型权重，梯度更新，成本高、仍是瓶颈。反思是持续学习的"轻量级替代"。
- **经验层自我改进**（技能库、工作流修改）低成本且可回滚；**参数层自我改进**（再训练、RL）能力潜力更大但风险也更高，需要固定基准、沙箱、回归测试与人工审批。
