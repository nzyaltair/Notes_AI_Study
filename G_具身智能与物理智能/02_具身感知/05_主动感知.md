# 主动感知

## 一句话理解

主动感知将行动用于获得信息：移动相机消除遮挡、绕到背面确认把手、轻推判断物体是否可动。它选择的不是即时任务奖励最大的动作，而是能降低关键不确定性且风险可控的动作。

## 概述

被动感知假设"看就够"，主动感知认为"看本身是行动"。当感知信息不足（遮挡、低置信度、传感器冲突）时，主动感知通过移动视角、改变光照、试探接触或请求协助来获取信息。它是感知-行动循环的核心机制，也是与静态视觉系统最本质的区别。

## 发展历史

- **1980s**：Aloimonos 提出"主动视觉"（Active Vision），强调用观察者运动解决视觉不适定问题。
- **1990s-2000s**：Next-Best-View (NBV) 规划用于三维重建；主动感知与探索进入机器人导航。
- **2010s**：信息论方法（信息增益、互信息）成为主动感知的形式化框架；RL 驱动的主动感知（主动目标识别）出现。
- **2020s**：主动感知与 LLM/VLM 结合（语言引导的信息获取）；交互感知（Interactive Perception）强调通过物理交互改变观测。

## 核心概念

| 概念 | 定义 | 用途 |
|---|---|---|
| 信息增益 | 观测后不确定性减少量 | 选择观测动作 |
| 后验熵 | 状态分布的不确定性 | 量化"不知道多少" |
| Next-Best-View | 下一个最优视角 | 重建、识别 |
| 主动触觉 | 主动接触获取局部信息 | 材质、力、几何 |
| 交互感知 | 行动改变环境以理解环境 | 推断隐藏属性 |
| 探索-利用 | 获取信息 vs 完成任务 | 决策权衡 |

## 技术原理

### 形式化：把感知当决策

主动感知可形式化为 POMDP 中的信息获取问题。信念状态 \(b(s)\) 的后验熵衡量不确定性：

$$H(b_t)=-\sum_s b_t(s)\ln b_t(s)$$

选择动作 \(a\) 的预期信息增益（Expected Information Gain, EIG）：

$$\text{EIG}(a)=\mathbb E_{o\sim p(o\mid a,b)}\left[H(b)-\mathbb E_{s'\sim b'}[H(b'_{a,o})]\right]$$

实践中完全求解 EIG 计算量大，常采用近似：

1. **规则触发**：位姿置信度低于阈值、目标被遮挡、传感器冲突、动作预测风险高时触发重新观察。
2. **启发式 NBV**：选择能看到最多未观察表面/对象的视角。
3. **学习式价值函数**：用 RL 学习"看哪里最有价值"。

### 主动视觉动作

| 动作类型 | 解决的问题 | 例子 |
|---|---|---|
| 视角移动 | 遮挡、视差 | 绕到物体侧面 |
| 接近观察 | 分辨率不足 | 靠近确认细节 |
| 光照调整 | 反光、阴影 | 改变光源位置 |
| 试探接触 | 推断隐藏属性 | 轻推判断可动性 |
| 工具辅助 | 视线不可达 | 使用镜面、探针 |

### 主动触觉与交互感知

- **主动触觉**：主动接触获取局部几何、材质、温度与力信息，弥补视觉在遮挡和反光下的不足。
- **交互感知**：通过推、碰、抬、摇等行动改变物体状态以推断属性（是否空心、是否可动、重心位置）。Bohg et al. (2017) 系统化了这一方向。

### 安全约束

主动感知应受到安全边界约束；未知环境中的"探索"不能等同于无约束试错：

- 试探力限制在安全阈值内。
- 探索动作不破坏物体或环境。
- 高风险信息获取（如深入狭窄空间）需先评估风险收益。

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| NBV 规划 | 最大化新表面覆盖 | 三维重建 |
| 信息增益优化 | 最大化 EIG | 目标识别 |
| RL 主动视觉 | 学习观察策略 | 遮挡目标识别 |
| 不确定性驱动 | 触发式重新观察 | 抓取前验证 |
| LLM 指导感知 | 语言建议看哪里 | 长程任务 |
| 主动触觉 | 试探获取接触信息 | 灵巧操作 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 信息增益框架 | 形式化、可计算 | EIG 计算昂贵 |
| 规则触发 | 简单、可解释 | 规则覆盖不全 |
| 学习式策略 | 自适应、泛化 | 需要训练数据 |
| 交互感知 | 获取视觉不可得信息 | 有物理风险 |

## 应用场景

- 抓取前验证：绕到背面确认把手、确认物体是否可动。
- 三维重建：NBV 规划覆盖场景。
- 家居任务：找不到物体时移动搜索。
- 灵巧操作：接触试探判断抓取策略。

## 前沿发展

- **主动感知 + 大模型**：LLM/VLM 指导"先看哪里、再试什么"。
- **预测编码主动感知**：以预测误差驱动观察（世界模型告诉我们哪里不确定）。
- **主动-被动融合**：主动探索与被动观测的统一学习。
- **多机器人主动感知**：多机器人协作覆盖大场景。

## 常见问题

- **探索 ≠ 无约束试错**：信息获取必须受安全边界约束。
- **信息增益 ≠ 任务成功**：最大化信息不一定最大化任务成功率，需权衡。
- **主动 ≠ 永远移动**：观测成本高时，保持稳定视角可能更优。
