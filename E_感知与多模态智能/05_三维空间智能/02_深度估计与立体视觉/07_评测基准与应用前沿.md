# 深度估计评测基准与应用前沿

## 一句话理解

深度估计评测的核心不是寻找一个“总冠军”分数，而是在明确深度定义、尺度对齐方式、相机设置、距离范围与系统约束后，验证模型是否在目标场景中可靠地支持测量、避障、重建或交互。

## 先明确评测对象

同为“深度预测”，下列任务不可混用排行榜：

| 任务 | 输出 | 是否可做米制评测 | 常见误区 |
|:---|:---|:---|:---|
| 相对深度 | 排序、仿射不变深度 | 不直接可做 | 先做 scale-and-shift 对齐后，把分数当测距能力 |
| 单目度量深度 | 每像素米制距离 | 可以 | 忽略相机内参、最大深度截断与训练域 |
| 双目视差 | 像素视差 | 由标定可转米制 | 忽略基线与远距误差放大 |
| MVS 重建 | 多视图深度/点云 | 可以 | 只看新视角渲染，不看几何准确性 |
| 深度补全 | RGB + 稀疏米制深度 | 可以 | 忽略投影遮挡和传感器时间/外参误差 |
| 视频深度 | 时序深度 + 可选位姿 | 可以，但需时序指标 | 单帧指标好却存在严重闪烁 |

## 常用指标

设真值为 \(D\)、预测为 \(\hat D\)，有效像素数为 \(N\)：

\[
\text{AbsRel}=\frac1N\sum_i\frac{|D_i-\hat D_i|}{D_i},\qquad
\text{RMSE}=\sqrt{\frac1N\sum_i(D_i-\hat D_i)^2}
\]

\[
\delta_k=\frac1N\left|\left\{i:\max\left(\frac{D_i}{\hat D_i},\frac{\hat D_i}{D_i}\right)<1.25^k\right\}\right|
\]

| 指标 | 含义 | 适用提醒 |
|:---|:---|:---|
| AbsRel | 相对误差平均值，越低越好 | 近距小深度会有较大权重；须说明尺度对齐 |
| SqRel | 平方相对误差 | 对大误差更敏感 |
| RMSE / RMSE-log | 绝对/对数均方根误差 | RMSE 强调远距大误差；单位和截断范围不可省略 |
| \(\delta_1,\delta_2,\delta_3\) | 倍数阈值内比例 | 易读但不能显示长尾灾难性失败 |
| EPE / Bad-pixel | 视差端点误差/错误像素率 | 双目立体匹配常用，需报告阈值 |
| iRMSE / iMAE | 逆深度误差 | 常用于 KITTI，强调近距离结构 |
| 时序一致性 | 重投影误差、闪烁、尺度漂移 | 视频任务必须额外报告 |

## 主要数据集与基准

| 数据集 | 场景与传感器 | 适用任务 | 注意事项 |
|:---|:---|:---|:---|
| KITTI Depth / Stereo | 城市驾驶；双目 + LiDAR | 单目米制、双目、补全 | 区分 Eigen split 与官方测试；深度上限和稀疏 LiDAR 投影影响结果 |
| NYU Depth V2 | 室内；Kinect RGB-D | 室内单目/度量深度 | Kinect 噪声、缺洞与固定相机特征会影响泛化结论 |
| Middlebury | 高质量室内双目/结构光真值 | 双目匹配 | 大视差、遮挡和高分辨率；以 Bad-pixel/EPE 为主 |
| ETH3D | 室内外高精度多视图/激光 | 双目、MVS、泛化 | 图像高分辨率，真实纹理/视角挑战较强 |
| ScanNet | 大规模室内 RGB-D/重建 | 室内几何、MVS、语义 | 传感器轨迹和室内域偏差 |
| DIODE | 室内外多样场景 | 跨域单目深度 | 适合检验室内外泛化 |
| DA-2K | 多域相对深度评测 | 零样本相对深度 | 适合基础模型，不替代米制评测 |
| TUM RGB-D | 室内 RGB-D 序列 | SLAM/VIO、视频深度 | 更适合跟踪与轨迹，而非仅单帧深度 |

## 建议的严谨评测流程

1. **写清任务合同**：相对还是米制？单帧还是视频？是否给相机内参、稀疏深度或位姿？
2. **固定协议**：官方划分、裁剪、有效像素掩膜、最大深度、输入分辨率和尺度对齐方式必须公开。
3. **分层报告**：按室内/室外、距离段、静态/动态、材质和光照条件拆分结果，避免平均分掩盖长尾风险。
4. **检查几何而非仅像素**：查看点云、平面法线、物体边缘和障碍物最近距离错误；针对双目检查左右一致性。
5. **评估系统代价**：报告端到端延迟、吞吐、显存、功耗、模型大小与传感器/标定开销。
6. **做失效压力测试**：夜晚、逆光、雨雾、反射/透明物、弱纹理、大/小视差、运动物体、镜头污渍与域外场景。

## 主动深度、几何定位与尺度锚定

深度网络不是唯一的距离来源。工程系统常以主动传感器或已知几何作为尺度锚定，并明确其可观测范围：

| 技术 | 直接输出 | 适用条件 | 主要局限 |
|:---|:---|:---|:---|
| 结构光 | 稠密米制深度 | 近距离、受控室内 | 环境红外、反光/透明表面和遮挡会降低可靠性 |
| ToF / RGB-D | 稠密或半稠密米制深度 | 室内交互、机器人近场 | 多径、飞行时间噪声、强光与量程限制 |
| LiDAR | 稀疏至中等稠密的米制点 | 户外测距、自动驾驶 | 点云稀疏、遮挡、雨雾/反射材质及成本 |
| 雷达 | 稀疏距离与速度 | 全天候冗余 | 角分辨率低、多径和杂波，需要与视觉融合 |
| PnP | 已知 3D 点/物体相对相机的位姿 | 有标志物、CAD 模型或可靠 2D–3D 对应 | **不产生稠密深度图**；结果受对应与模型误差支配 |

主动传感器的“毫米级精度”只能在特定量程、反射率、曝光和标定条件下成立，不能作为无条件的系统承诺。对于安全任务，应把其量测方差、无效深度和传感器健康状态显式送入后续融合与规划模块。

## 部署与安全

- **优化**：先以目标分辨率测端到端基线，再使用 FP16/INT8、TensorRT/ONNX Runtime、蒸馏或剪枝；量化后必须复测长尾场景，不应只测平均吞吐。
- **融合**：相机、LiDAR、雷达和 IMU 的时间同步与外参标定往往比更换一个模型更能改善实际可靠性。
- **不确定性**：输出置信度、有效深度掩膜与失效告警；规划系统应把低置信度区域按风险而非“无障碍”处理。
- **模型与性能声明**：吞吐量受模型变体、输入分辨率、批大小、预处理、硬件、驱动和推理引擎影响。应复现实测配置，不把第三方报告中的单一 FPS 或对齐后指标迁移为通用结论。
- **安全与隐私**：自动驾驶、机器人等安全关键用途需有冗余传感器和独立验证链路；摄像头数据还需遵守隐私、数据治理与适用法规。

## 研究前沿

1. **通用几何基础模型**：从相对深度扩展到米制深度、法线、相机内参、点云和不确定性的一体化预测。
2. **生成式几何**：扩散模型把大规模生成先验迁移到稠密几何，但需要解决效率和物理一致性。
3. **长时序、动态 4D**：在场景变化、相机运动和动态物体中维护一致的结构与尺度。
4. **主动感知与提示**：用可控相机运动、稀疏 LiDAR、雷达、语言或几何提示消除病态性。
5. **从分数到可靠性**：面向任务的置信度、失效检测、跨域压力测试和功能安全评估将成为部署门槛。
