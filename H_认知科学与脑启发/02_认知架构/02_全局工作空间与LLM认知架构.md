# 全局工作空间与 LLM 认知架构

## 一句话理解

全局工作空间理论将“可被多个专门过程访问的信息”作为认知整合的核心；它可启发 AI 中的共享状态与任务调度，但不能据此断言 Transformer 或 LLM 已具有意识。

## 全局工作空间的功能假设

1. 多个专门过程并行处理局部信息。
2. 竞争或注意机制选择当前最相关的内容。
3. 被选内容进入容量受限的工作空间，并向记忆、规划、语言和行动模块广播。
4. 广播结果改变后续处理，从而形成跨模块协调。

## 与 LLM Agent 的可检验映射

| 工作空间功能 | 可能的 AI 实现 | 应评测的能力 |
|---|---|---|
| 竞争与选择 | 检索排序、注意路由、任务优先级 | 是否减少无关上下文与错误调用 |
| 共享广播 | 显式任务状态、黑板、结构化 scratchpad | 模块是否使用一致状态 |
| 容量限制 | 上下文预算、摘要、状态压缩 | 长程任务中是否保持关键信息 |
| 控制切换 | 调度器、规划—执行循环 | 是否能及时重规划与停止 |

Transformer 的注意力是张量运算中的加权信息聚合；认知注意与工作空间则是功能、资源与行为层的理论。两者可以相关，但不应视为同义。
