# 模型与生成式AI安全综述

## 领域定义

本方向覆盖训练数据、模型参数、输入输出和生成式应用的攻击面。传统对抗机器学习仍重要，但在生成式系统中必须同时处理提示、检索内容、工具接口和供应链风险。

## 为什么会出现

生成式模型（LLM、VLM、扩散模型）与判别式模型相比，攻击面发生了根本变化：
- 自然语言既是输入也是指令，**指令与数据天然混杂**
- 模型具备复杂推理能力，使攻击者能通过多步话术绕过护栏
- 工具调用将生成式输出转化为真实世界行动

传统的"模型准确率"不足以描述安全性；需要专门研究攻击链和防御纵深。

## 发展历史

| 阶段 | 重点 | 代表工作 |
|---|---|---|
| 传统对抗ML (2013–) | 图像分类器的对抗样本 | FGSM、PGD、认证防御 |
| NLP对抗 (2019–) | 文本对抗扰动、后门攻击 | TextFooler (2020)、BadNL (2021) |
| 大模型越狱 (2022–) | 提示注入、角色扮演越狱 | "越狱"成为公共研究领域 |
| 生成式AI系统安全 (2023–) | 间接注入、Agent攻击、多模态注入 | OWASP LLM Top 10 (2023)、HarmBench (2024) |

## 核心问题

1. **提示安全**：攻击者如何利用自然语言绕过安全约束？如何防御？
2. **训练安全**：训练/微调数据如何被污染以植入后门或偏差？
3. **知识可靠性**：生成式模型如何产生幻觉？如何检测和缓解？
4. **隐私**：训练数据中的敏感信息如何被提取？
5. **模型资产安全**：模型权重和能力如何被复制、滥用或窃取？

## 防御原则：纵深防御

```text
不可信内容 → 来源标记/风险分类 → 上下文隔离 → 模型推理
                                                   ↓
用户响应 ← 输出审核/脱敏 ← 策略引擎 ← 工具请求校验
```

单一护栏无法解决指令与数据混杂等架构性问题；安全性来自多层控制的叠加。

## 当前发展状态

- **自动红队**（AutoDAN、PAIR、GCG等）使越狱攻击的发现和迭代效率大幅提升
- **间接提示注入**成为 RAG 和 Agent 系统的主要安全威胁
- **多模态攻击**（图像/音频中嵌入指令）随多模态模型普及而实用化
- **HarmBench**（2024）提供了统一的越狱评测框架，包含400+ 行为类别
