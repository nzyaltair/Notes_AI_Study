# 具身感知综述

## 一句话理解

具身感知的目标是估计**支持下一步行动的状态**，而非孤立识别类别。它融合视觉、深度、触觉、本体与语言，维护对象位姿、关系、可供性与不确定性，并在信息不足时主动改变视角或试探。

## 概述

具身感知与静态计算机视觉的核心区别：静态 CV 追求"识别这张图里有什么"，具身感知追求"根据当前观测，我现在能做什么、下一步该观测什么"。感知输出必须带坐标系、时间戳和置信度，供规划、世界模型与安全层使用。

## 发展历史

- **1980s-1990s**：机器视觉以几何和特征为主（立体匹配、特征点），感知服务于定位与导航。
- **2000s-2010s**：SLAM 成熟（ORB-SLAM, LSD-SLAM），语义 SLAM 出现；深度学习进入检测与分割（YOLO, Mask R-CNN）。
- **2015-2020**：6D 位姿估计（PoseCNN, DenseFusion）、3D 场景理解（点云深度学习）成为操作感知的基础。
- **2020s**：多模态大模型（CLIP, PaLM-E）带来开放词汇感知；主动感知、可供性学习与交互感知（Interactive Perception）重新兴起；NeRF/3DGS 进入场景表示。

## 核心问题

1. **为行动感知**：感知输出必须支撑抓取、导航、装配等具体行动，而非仅做类别分类。
2. **部分可观测**：遮挡、反光、透明材质、触觉只在接触后出现——状态估计必须显式处理不确定性。
3. **多模态融合**：视觉、深度、触觉、本体、语言在不同坐标系、采样率、噪声模型下融合。
4. **主动获取信息**：信息不足时主动移动相机、试探或请求协助，而非被动等待。

## 技术演进路线

| 时期 | 感知范式 | 代表方法 |
|---|---|---|
| 几何时代 | 特征点 + 立体匹配 | SIFT, ICP |
| SLAM 时代 | 定位 + 建图 | ORB-SLAM, LSD-SLAM |
| 深度时代 | 检测/分割/位姿 | YOLO, Mask R-CNN, PoseCNN |
| 语义时代 | 语义 SLAM + 场景图 | 3D Scene Graph |
| 大模型时代 | 开放词汇 + 多模态 | CLIP, PaLM-E, SAM |
| 行动时代 | 可供性 + 主动感知 | Affordance Learning, NBV |

## 前沿发展

- **开放词汇感知**：SAM + CLIP 组合实现开放词汇分割与查询。
- **交互感知（Interactive Perception）**：通过行动改变观测来理解物体（推、碰、抬）。
- **触觉-视觉联合**：从视觉预测触觉属性，从触觉推断几何。
- **世界模型感知**：用预测误差驱动感知更新（预测编码思想）。
- **主动感知与大模型**：LLM/VLM 指导信息获取策略（问哪里、看哪里、试哪里）。
