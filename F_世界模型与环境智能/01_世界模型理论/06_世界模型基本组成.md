# 世界模型基本组成

## 一句话理解

完整的世界模型系统通常不是单一神经网络，而是围绕状态、动力学、观测、奖励、行动与规划接口组合的模块集合，每个模块承担可单独校验的职责。

## 模块清单

1. **状态表示**：融合历史观测，形成 belief/latent state（见 [[../../02_世界表示学习/01_状态表示|状态表示]]）。
2. **环境动力学**：预测行动条件下的下一状态和不确定性（见 [[03_Latent_Dynamics_Model|潜在动力学模型]]）。
3. **观测模型**：生成或对齐相机、语言、触觉等观测；判别式表征 vs 生成式重建是主要取舍。
4. **奖励与风险模型**：估计目标达成、代价和终止概率。
5. **行动模型**：表示离散工具调用、连续控制或层级技能，并编码动作延迟与执行噪声。
6. **长期预测机制**：记忆、层级时间尺度、滚动校正和多步训练。
7. **规划接口**：MPC、MCTS、轨迹采样或策略优化，把预测转成行动。

## 训练与推理流程

```text
训练：真实轨迹 → 联合优化（重建/特征损失 + 动力学损失 + 奖励损失 + KL/先验约束）
推理：观测 → 状态估计 → 多步想象 → 规划/策略 → 执行 → 反馈校正
```

## 架构选择

- **端到端模型**：减少手工接口，梯度可贯穿全局，但难以诊断，组件错误定位困难。
- **模块化模型**：能单独校验物理、奖励和安全组件，接口清晰、可替换，但可能引入接口信息损失。

高风险具身系统通常需保留可观测、可校准的约束与验证层，采用"模块化主干 + 端到端细调"的混合方案。

## 常见设计错误

- 只优化一步预测，忽略多步一致性。
- 奖励/风险模型与动力学模型耦合过紧，无法独立校准。
- 缺少不确定性通道，规划器无法区分"确定"与"猜测"。
