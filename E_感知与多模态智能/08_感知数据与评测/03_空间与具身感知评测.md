# 空间与具身感知评测

## 一句话理解

空间与具身感知评测衡量感知系统在三维空间和机器人场景中的能力——从 KITTI 自动驾驶到 ScanNet 室内场景，从 Habitat 导航到 RLBench 操作，它定义了空间感知的研究目标和进度度量。

## 概述

空间与具身感知评测（Spatial and Embodied Perception Benchmarks）覆盖了三维视觉、SLAM、点云理解、导航和机器人操作等任务。与 2D 视觉评测不同，空间评测需要同时考虑几何精度、语义准确性和闭环效果。

## 核心空间基准

| 基准 | 任务 | 规模 | 指标 |
|:---|:---|:---|:---|
| KITTI | 3D 检测/跟踪/深度 | 约 15K 帧 | mAP, ATE, RMSE |
| ScanNet | 3D 场景理解 | 1.5K 场景 | mIoU, ACC |
| nuScenes | 自动驾驶感知 | 1.4M 帧/23 类 | NDS, mAP |
| Waymo Open | 自动驾驶感知 | 1K 场景 | mAP, mAPH |
| NYU Depth v2 | 深度估计 | 1.4K 图 | RMSE, δ |
| ModelNet/ShapeNet | 3D 分类 | 40/55 类 | ACC |

## 核心具身基准

| 基准 | 任务 | 环境 | 指标 |
|:---|:---|:---|:---|
| Habitat | 导航 | 3D 室内场景 | SPL, 成功率 |
| Matterport3D | 导航 | 90 建筑 | SPL, 成功率 |
| RLBench | 操作 | 仿真 | 成功率 |
| MetaWorld | 操作 | 仿真 | 成功率 |
| RoboSuite | 操作 | 仿真 | 成功率 |
| CALVIN | 长程操作 | 仿真 | 完成率 |

## 闭环评测的重要性

与开环评测（仅检测 mAP）不同，具身感知评测需要闭环评估：

```
感知 → 决策 → 行动 → 新观测 → 感知（更新）
```

闭环评测指标（如导航 SPL、操作成功率）更能反映感知系统的实际效果。
