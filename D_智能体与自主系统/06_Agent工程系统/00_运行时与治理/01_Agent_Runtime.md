# Agent Runtime

Runtime 是执行自主闭环的基础设施：它管理 Agent Loop、状态、任务、事件、工具、预算和恢复，使长任务不依赖一次超长模型调用。

## Agent Loop

```text
加载检查点 → 观察/状态估计 → 决策或规划 → 策略与权限检查
→ 调用工具 → 记录事件/Trace → 校验结果 → 完成、重试、重规划或暂停
```

## 关键能力

| 能力 | 要求 |
|---|---|
| 状态管理 | 区分会话、任务、环境与记忆状态；支持检查点和幂等恢复 |
| 调度 | 处理队列、优先级、并发、超时、取消与资源配额 |
| 事件驱动 | 工具回调、长任务完成、人工输入和外部变更可触发继续执行 |
| 工具运行 | 输入校验、最小权限、隔离、重试和补偿事务 |
| 人机协作 | 对风险动作、歧义和低置信度提供升级与接管接口 |

工作流适用于预定义路径；Runtime 也必须支持状态驱动的动态分支。所有可恢复决策都需要持久化，而不是只保留在上下文窗口。
