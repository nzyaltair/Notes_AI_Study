# MLOps 综述

MLOps 管理数据、代码、实验、模型和部署的生命周期，使机器学习变更可复现、可审批、可回滚。

## 生命周期

```text
数据版本 → 实验追踪 → 模型注册 → CI/CT → 发布部署 → 监控反馈 → 再训练
```

各阶段的治理要点：

| 阶段 | 核心目标 | 关键门禁 |
|:---|:---|:---|
| 生命周期与版本管理 | 维护数据/代码/特征/配置/模型/服务之间的血缘 | 不可变工件、审批状态、变更记录、退役策略 |
| 实验与模型注册 | 参数、指标、工件追踪；模型标记为可部署资产 | 可复现检查、回滚验证、风险说明 |
| CI/CD/CT | 自动化构建、发布与再训练 | 评测、人工审批、影子流量、回滚演练 |
| 模型部署与发布 | 将注册模型与运行时一起交付 | schema/性能/权限/镜像签名验证 |
| 监控与反馈 | 覆盖系统/数据/模型/业务四层 | 报警绑定负责人、阈值、runbook、升级路径 |
| 成本治理 | 训练/存储/推理/网络成本归因 | 预算、配额、单位任务成本、容量预测 |
| 安全与合规 | 供应链、访问控制、密钥、审计、数据权限 | 安全检查纳入 CI/CD 门禁 |
