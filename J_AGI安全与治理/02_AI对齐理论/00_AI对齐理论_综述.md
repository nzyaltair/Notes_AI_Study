# AI对齐理论

对齐研究如何使系统的训练目标、学习到的偏好、部署时行为与人类意图保持一致。它与可靠性、安全工程相互支撑，但不能互相替代。

## 对齐链

```text
人类意图 → 可表达规范 → 偏好/反馈数据 → 训练目标 → 模型策略 → 部署行为
```

链上每一步均会损失信息：人类偏好不完整，标注有偏差，代理目标可被投机，部署环境也会改变。对齐因此是持续测量、纠偏与限制能力的过程，而不是一次微调。
