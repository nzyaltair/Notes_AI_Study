# Transformer 扩展与推理接口

Transformer 的工程化扩展要区分**结构设计**与**服务系统实现**。本目录关注结构为何影响训练和推理；缓存调度、连续批处理、分离式推理与部署运行时见 [[../../../09_模型压缩与高效推理/00_大模型推理与优化_综述|高效推理]] 和 K 工程板块。

- **FlashAttention**：通过 IO 感知分块计算保持精确注意力结果，降低显存访问开销。
- **KV Cache / GQA / MLA**：以缓存和键值共享/压缩降低解码带宽与显存成本。
- **推测解码与多 token 预测**：以候选生成和验证减少主模型串行解码负担。
- **并行性**：张量、流水线、专家并行支持训练与大规模推理，但属于系统层。

这些设计说明：模型能力、模型容量与可服务性必须协同考虑。
