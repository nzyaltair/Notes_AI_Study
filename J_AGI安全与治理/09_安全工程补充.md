# 安全工程补充

## 模型供应链安全

- **权重完整性验证**：校验权重文件的哈希值，防止篡改
- **供应链 SBOM**：记录模型的所有依赖、组件、来源
- **第三方模型审计**：使用前评估模型的安全性和可信度
- **模型签名**：用数字签名验证权重来源

## 训练与数据投毒防护

- **数据投毒检测**：检测训练数据中的恶意样本
- **训练过程监控**：监控训练损失、梯度异常
- **鲁棒训练**：对抗训练、数据增强
- **后门检测**：检测模型中的后门触发器

## 权重泄露与模型窃取

- **模型访问控制**：限制模型权重访问权限
- **模型水印**：在模型中嵌入不可移除的水印
- **API 安全**：防止通过 API 提取模型信息
- **模型混淆**：对模型进行混淆保护

## AI 代码供应链风险

- **代码依赖审计**：审查第三方代码库的安全风险
- **沙箱执行**：在隔离环境中执行 AI 生成的代码
- **代码签名**：验证 AI 生成代码的完整性
- **安全扫描**：自动扫描 AI 生成代码的漏洞

## 多模态攻击与跨模态注入

- **视觉对抗攻击**：对图像输入添加不可察觉的扰动
- **音频对抗攻击**：对语音输入添加干扰
- **跨模态注入**：通过一个模态向另一个模态注入恶意指令
- **多模态红队测试**：针对多模态场景的对抗测试

## Agent 身份与权限管理

- **Agent 身份认证**：确认 Agent 的身份
- **权限委托**：Agent 的权限从用户继承
- **操作审计**：记录 Agent 的所有操作
- **会话隔离**：不同 Agent 会话的数据隔离

## 行为漂移与线上监控

- **行为基线建立**：记录 Agent 的正常行为模式
- **异常检测**：检测偏离基线的行为
- **漂移告警**：行为漂移超过阈值时触发告警
- **自动回滚**：检测到异常时自动回滚到安全版本

## 安全 Case 与审计门禁

- **安全 Case 文档化**：记录安全事件、影响、修复
- **审计门禁**：高风险操作需要审计通过
- **合规检查**：定期检查安全合规状态
- **事件分级**：按影响范围分级处理

## 事件分级与责任边界

| 级别 | 描述 | 响应时间 | 升级路径 |
|------|------|---------|---------|
| P0 | 系统瘫痪/数据泄露 | 立即 | 全团队 + 管理层 |
| P1 | 核心功能异常 | 1 小时 | 核心团队 |
| P2 | 非核心功能异常 | 8 小时 | 值班团队 |
| P3 | 小问题/优化建议 | 下一个迭代 | 正常工单流程 |
