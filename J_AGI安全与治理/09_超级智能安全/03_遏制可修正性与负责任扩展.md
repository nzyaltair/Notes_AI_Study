# 遏制、可修正性与负责任扩展

遏制（containment）通过限制接口、资源、网络、复制与行动范围降低危险能力外溢；可修正性确保人类能修改目标、暂停系统或撤销访问；负责任扩展（如 RSP 思路）则将能力阈值、安全评测和部署决策绑定。

| 层级 | 措施 |
|---|---|
| 能力 | 分阶段训练与发布、危险能力评测、最小化暴露 |
| 接口 | 沙箱、网络隔离、工具白名单、配额 |
| 控制 | 人类批准、独立关机、密钥撤销、事务回滚 |
| 治理 | 预定义阈值、外部审查、事故通报、暂停条件 |

没有单一“盒子”能确保高能力系统安全。有效策略需要技术隔离、组织纪律、可验证证据和跨机构协调共同作用；同时评估隔离措施是否会因运维、供应链或人类绕过而失效。
