# 协作、竞争与任务分配

协作的关键是把可分解目标分配给能力互补的主体，并将局部结果整合为可验证的整体。竞争与博弈用于建模资源冲突、谈判和对抗环境。

## 机制

- **合同网/拍卖**：任务发布、竞标、授标、执行、验收；适合动态负载与显式能力标签。
- **协同规划**：共享目标与约束，协调子计划的资源、时序与依赖。
- **集中训练、分散执行（CTDE）**：MARL 中训练时可见额外信息，部署时各 Agent 只用局部观察。
- **博弈与机制设计**：处理竞争、谈判、激励相容和联盟形成。

任务分配应以可验证交付物而非角色名称为单位；对于高度耦合的任务，拆分可能增加通信成本并降低质量。
