# 持续学习与 Agent 对齐接口

## 一句话理解

模型后训练可以通过版本化适配、回放和回归评测减缓能力退化，但开放环境中的长期目标、工具权限和动作风险必须由 Agent 运行时与安全机制共同约束。

## 两类接口

| 接口 | 训练侧职责 | 系统侧职责 |
|---|---|---|
| 持续适配 | 数据增量、适配器隔离、回放、遗忘监测 | 数据版本、灰度发布、回滚与回归评测 |
| Agent 行为 | 指令、偏好与拒答边界 | 权限最小化、动作审计、停止条件、异常回退 |

## 关键边界

- 参数更新会引入遗忘、漂移和评测污染；每次适配应保留基座能力、安全和领域能力的回归集。
- 偏好对齐塑造默认输出，却不能单独保证长程目标一致性、工具调用正确性或环境安全。
- Agent 的记忆和反馈数据也可能成为数据投毒、提示注入和目标漂移的入口。
