# 空间推理与场景记忆

## 一句话理解

空间推理与场景记忆研究如何将三维感知组织为可查询、可推理的结构化场景知识——从"哪里有物体"到"物体之间的关系"，是空间智能从感知走向认知的关键。

## 概述

空间推理（Spatial Reasoning）和场景记忆（Scene Memory）关注如何从三维感知数据中提取、维护和推理关于场景的结构化信息。核心是将"几何"（点云/网格）升级为"知识"（场景图/语义地图）。

## 核心方法

| 方法 | 原理 | 代表 | 特点 |
|:---|:---|:---|:---|
| 场景图 | 物体为节点，关系为边 | Scene Graph, 3D Scene Graph | 结构化，可推理 |
| 语义地图 | 语义标签+几何地图 | Semantic SLAM, Neural Map | 可导航，可查询 |
| 拓扑地图 | 节点=位置，边=可达性 | 拓扑 SLAM | 抽象，高效 |
| 空间记忆 | 持久化空间状态 | Neural Scene Memory | 长期维护 |

## 关键挑战

- **对象关系**：物体之间的空间关系（上、下、左、右、内、外）的推理
- **动态更新**：场景变化时如何更新空间记忆
- **长期一致性**：长时间跨度的空间状态维护
- **可供性推理**：从几何推断功能（这个面可以坐吗？）
