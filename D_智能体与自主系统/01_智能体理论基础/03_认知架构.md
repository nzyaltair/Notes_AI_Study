# 认知架构

认知架构按功能分解智能，而非要求每层各用一个模型：感知解释输入；工作记忆保存当前状态；长期记忆保存知识与技能；审议模块负责推理、规划与决策；执行控制监测动作；元认知评估不确定性与错误。

每个接口应可检查：证据、状态假设、计划前置条件、动作副作用和失败归因分别记录。SOAR、ACT-R 等经典架构强调这一闭环；LLM Agent 应继承功能分工，而不是只拉长上下文。

References: Laird, *The Soar Cognitive Architecture*; Sumers et al., *Cognitive Architectures for Language Agents*.
