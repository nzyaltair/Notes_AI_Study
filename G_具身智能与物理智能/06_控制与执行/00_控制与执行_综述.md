# 控制与执行综述

## 一句话理解

控制与执行负责把目标、轨迹或学习策略的短动作块可靠映射为真实物理行动。它以反馈、约束、实时性和安全为第一原则——模型可以提议动作，但"做到"是控制层的事。

## 概述

控制与执行是具身智能的"运动系统"：高层规划/策略生成目标与动作块，控制层以高频稳定执行，安全层独立监督。具身系统的价值最终取决于它在真实世界的可靠性：时延、稳定性、接触安全和可审计性。

## 发展历史

- **1940s-1960s**：控制论（Wiener）与经典反馈控制（PID）奠定基础。
- **1960s-1970s**：状态空间方法与 LQR/LQG 最优控制成熟；Kalman 滤波用于状态估计。
- **1980s-1990s**：MPC 进入过程控制；阻抗控制（Hogan 1985）实现柔顺接触。
- **2000s-2010s**：MPC 进入机器人（步态、操作）；ROS 成为工程标准。
- **2020s**：学习型控制（RL、扩散策略、神经 MPC）与经典控制分层协作；人形全身控制（WBC + MPC + RL）成为研究焦点。

## 核心问题

1. **稳定跟踪**：在扰动和模型误差下跟踪轨迹。
2. **约束满足**：碰撞、力矩、速度、工作空间约束。
3. **接触安全**：硬接触必须由力控和独立安全层管理。
4. **实时性**：控制循环抖动直接转化为轨迹误差。
5. **学习与经典融合**：学习策略与反馈/MPC 的分层协作。

## 技术演进路线

| 时期 | 范式 | 代表 |
|---|---|---|
| 经典控制 | 频域反馈 | PID, Nyquist |
| 状态空间 | 最优调节 | LQR, LQG, Kalman |
| 预测控制 | 约束优化 | MPC, MPPI |
| 接触控制 | 柔顺力控 | 阻抗/导纳控制 |
| 学习控制 | 数据驱动策略 | RL, 扩散策略 |
| 混合架构 | 学习提议 + 控制执行 | Neural MPC, Residual |

## 前沿发展

- **学习型 MPC**：解析约束 + 神经残差。
- **RL + WBC 融合**：人形机器人的统一全身控制。
- **安全 RL**：约束策略优化与安全层。
- **高频推理**：模型推理与控制频率的差距缩小。
- **可证明安全**：控制障碍函数（CBF）等安全保证方法。
