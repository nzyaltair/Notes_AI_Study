# 感知智能综述

> **定位**：E 是 AGI 的感知能力层，研究系统如何把图像、视频、声音、空间与语言条件转化为可供推理、预测和行动使用的状态表示。

## 能力链

```text
原始信号 → 表征学习 → 任务理解 → 时空/空间建模 → 多模态状态 → 行动接口
```

感知不等于分类或检测。面向 AGI，感知系统还要维护时序连续性、空间关系、跨模态证据与不确定性，并为后续系统提供可查询、可更新的世界状态。

## 板块边界

- **E 感知**：信号、表示、理解任务、空间/时空状态和观测接口。
- **C 基础模型**：预训练范式、规模化训练、视觉/多模态基础模型谱系。参见 [[C_基础模型与通用智能/03_视觉基础模型/00_视觉基础模型_综述|视觉基础模型]]、[[C_基础模型与通用智能/04_多模态基础模型/00_多模态基础模型_综述|多模态基础模型]]。
- **D 智能体**：规划、记忆、工具调用与任务编排。参见 [[D_智能体与自主系统/02_Agent理论/00_Agent理论_综述|Agent 理论]]。
- **F 世界模型**：环境动态、预测与想象。
- **G 具身智能**：机器人执行、控制与 VLA 策略。参见 [[G_具身智能与物理智能/02_具身感知/00_具身感知_综述|具身感知]]。

## AGI 闭环

```text
Perception (E) → World Model (F) → Agent (D) → Action (G) → 新观测 (E)
```

E 的关键产物不是最终决策，而是带有语义、时间、空间和置信度的观测状态；它既是世界模型的输入，也是 Agent 决策和具身执行的共同接口。
