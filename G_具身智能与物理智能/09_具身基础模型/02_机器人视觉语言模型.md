# 机器人视觉语言模型

## 一句话理解

机器人 VLM 将开放词汇识别、属性理解、指令消歧和场景问答用于行动前状态构建——它特别适合"找红色杯子""判断哪个抽屉可打开"等语义任务，但不应承担精确操作的全部责任。

## 概述

机器人视觉语言模型（Robot VLM）把视觉语言模型的语义能力带入具身系统：理解开放指令、识别未知类别、推理空间关系、回答场景问题。它不是直接输出动作的策略，而是为规划与技能选择提供语义状态。机器人 VLM 是 VLA 的感知基础，也是人机交互的接口。

## 发展历史

- **2021-2022**：CLIP 开放词汇识别进入机器人；Flamingo 类多模态模型展示少样本视觉问答。
- **2023**：PaLM-E 把 LLM 与具身观测结合（embodied LLM）；LLaVA 开源多模态模型普及。
- **2024-2025**：机器人专用 VLM 涌现（RT 系列感知头、OpenVLA 内部 VLM）；VLM 用于任务核验、失败诊断与主动感知。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 开放词汇 | 识别任意类别 | 长尾物体 |
| 指代消歧 | 解析"那个红色的" | 语言落地 |
| 场景问答 | 回答环境问题 | 状态构建 |
| 属性理解 | 颜色/材质/状态 | 任务约束 |
| 空间关系 | 相对位置推理 | 导航/操作 |
| 核验能力 | 判断任务完成 | 闭环核验 |

## 技术原理

### 机器人与通用 VLM 的区别

| 维度 | 通用 VLM | 机器人 VLM |
|---|---|---|
| 输入 | 单图/多图 | 时序观测 + 本体状态 |
| 输出 | 文本 | 结构化状态/约束 |
| 目标 | 问答 | 支撑行动 |
| 关键能力 | 常识 | 指代 + 空间 + 落地 |

### 在具身系统中的角色

```text
用户指令 + 多模态观测 → 机器人 VLM
→ 对象指代（"红色杯子"→ 实例 ID）
→ 属性/关系（"哪个抽屉可打开"）
→ 场景问答（"杯子里还有牛奶吗"）
→ 状态构建 → 规划/技能选择 → 执行
```

### 落地约束

VLM 输出的对象指代须接入 3D 位姿、可供性、可达性与碰撞验证；低置信度和语言歧义应触发主动感知或澄清：

- **指代 → 3D 定位**：语言指代必须落到具体位姿。
- **语义 → 物理验证**："可打开"必须检查把手、轴与可达性。
- **低置信处理**：不确定时重新观察或询问。

## 关键方法与模型

| 模型 | 年份 | 贡献 | 机器人应用 |
|---|---|---|---|
| CLIP | 2021 | 开放词汇视觉 | 指代、属性 |
| PaLM-E | 2023 | 具身多模态 LLM | 任务推理 |
| LLaVA | 2023 | 开源 VLM | 感知基础 |
| RT-2 | 2023 | VLM→动作 | VLA |
| 3D VLM | 2023- | 3D 场景问答 | 空间推理 |
| OpenVLA 视觉 | 2024 | 开源 VLA 感知 | 指代落地 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 语义泛化 | 开放词汇 | 精确几何弱 |
| 常识推理 | 任务理解 | 幻觉 |
| 交互性 | 自然语言接口 | 时延 |
| 组合性 | 新指令组合 | 物理验证缺失 |

## 应用场景

- 家居任务：找物、判断状态、核验完成。
- 服务机器人：自然语言交互。
- 操作前状态构建：抓取目标选择。
- 失败诊断：解释失败原因。

## 前沿发展

- **3D VLM**：3D 场景上的开放词汇问答。
- **VLM 核验**：任务完成度自动判断。
- **VLM 主动感知**：语言指导"看哪里"。
- **时序 VLM**：视频理解支撑长程任务。
- **VLM + 世界模型**：语义与预测结合。

## 常见问题

- **让 VLM 承担精确操作**：语义 ≠ 厘米级位姿。
- **忽略低置信处理**：必须触发主动感知或澄清。
- **把 VQA 当任务能力**：场景问答 ≠ 行动能力。
