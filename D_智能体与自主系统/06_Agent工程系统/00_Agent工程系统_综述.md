# Agent 工程系统 Overview

## 领域定义

Agent 工程系统研究如何将"感知-决策-行动"的自主闭环，转化为可运行、可观测、可评测、可治理的软件产品。它是连接 Agent 理论（[[../01_智能体理论基础/00_智能体理论基础_综述|理性主体、BDI、认知架构]]）与实际落地系统之间的工程层，覆盖系统架构、主流框架、运行时、工具接口、任务编排、检索增强、评测可观测性与安全治理。

工作流（Workflow）与 Agent Loop 是两种互补的执行范式：工作流适合控制流已知、步骤确定的任务（DAG 编排）；Agent Loop 由 LLM 根据新的观察动态决定下一步行动，适合开放式、不确定步数的任务。生产系统通常将二者组合——用工作流搭建可靠骨架，在关键节点嵌入 Agent 循环处理不确定性。

## 为什么会出现

2022 年 ChatGPT 发布后，开发者发现单轮问答无法完成"预订机票""调试代码""调研报告"等多步骤任务。ReAct（Yao et al., 2022）等研究证明，LLM 可以通过"思考-行动-观察"循环自主使用工具、修正计划。但从研究原型到生产系统之间存在巨大工程鸿沟：如何管理长期状态、如何安全地授权工具调用、如何评估非确定性输出、如何控制成本和延迟——这些问题催生了独立的 Agent 工程学科。

## 发展历史

| 时间 | 里程碑 | 意义 |
|:---|:---|:---|
| 2022.10 | ReAct 论文 | 提出"推理+行动"交替循环，成为 Agent 范式基石 |
| 2022-2023 | LangChain 发布 | 首个通用 LLM 应用开发框架，封装 Chain/Agent/Memory |
| 2023.03 | AutoGPT / BabyAGI | 首批自主 Agent 实验，暴露长程任务的可靠性问题 |
| 2023.06 | OpenAI Function Calling | 结构化工具调用成为标准接口，替代脆弱的文本解析 |
| 2023.11 | AutoGen / CrewAI | 多智能体协作框架兴起 |
| 2024.01 | LangGraph | 用状态图显式建模 Agent 控制流，替代隐式黑盒链 |
| 2024.11 | Anthropic 发布 MCP | 标准化工具/上下文协议，成为跨厂商互操作标准 |
| 2025 | Agent 生产化元年 | 运行时治理、评测体系、安全护栏成为工程重点 |

## 核心问题

1. **控制流设计**：如何在确定性工作流与自适应 Agent 循环之间权衡？
2. **状态与记忆管理**：长任务如何持久化状态、如何检索历史经验？
3. **工具接口标准化**：Agent 如何安全、可靠地调用外部工具与数据源？
4. **知识增强**：如何用 RAG 弥补参数化知识的局限与幻觉问题？
5. **可观测与评测**：非确定性系统如何衡量质量、定位失败原因？
6. **安全与权限**：如何防御 Prompt Injection，约束 Agent 的行动边界？

## 技术演进路线

```
提示工程（单轮问答）
  → ReAct 循环（推理+行动+观察）
    → Function Calling（结构化工具调用）
      → Agent 框架化（LangChain/AutoGen）
        → 图化编排（LangGraph 显式状态机）
          → 协议标准化（MCP）
            → 多智能体协作（CrewAI/AutoGen）
              → 生产治理（运行时、评测、安全护栏）
```

## 重要分支

- **系统与框架**：Agent 核心循环与主流开发框架
- **运行时与治理**：状态管理、调度、监控、安全审计
- **工具调用与协议**：Function Calling、MCP
- **工作流与编排**：任务级流程设计与系统级自动化
- **检索增强（RAG）**：为 Agent 提供外部知识
- **评测与可观测性**：LLM-as-Judge、Tracing、指标体系
- **提示工程与结构化输出**：Agent 行为设计的基础手段
- **安全**：Prompt Injection 防御、权限控制

## 当前发展状态

- **框架从"链式"走向"图化"**：LangGraph 等以显式状态机取代黑盒 Chain，提升可控性与可调试性
- **协议标准化加速**：MCP 已成为工具/上下文接入的事实标准，被 OpenAI、Google 等主流厂商采纳
- **评测成为落地瓶颈**：非确定性输出的质量评估仍缺乏统一标准，LLM-as-Judge 是当前主流方案但存在偏差
- **安全治理从可选项变为必需项**：Prompt Injection、越权工具调用等风险推动护栏机制标准化

## 未来趋势

- **Agent 操作系统化**：运行时、权限、调度、记忆逐渐收敛为类操作系统的基础设施
- **多智能体协作规模化**：从单 Agent 工具调用走向多 Agent 分工协作的复杂系统
- **端到端可观测性**：Trace、评测、成本、安全审计融合为统一的 LLMOps/AgentOps 平台，详见 [[../../K_AI工程化/06_LLMOps与AgentOps/00_LLMOps与AgentOps综述|K-06 LLMOps 与 AgentOps]]
- **自我改进闭环**：Agent 通过反思与经验积累持续优化自身策略，见 [[../05_记忆与持续学习/00_记忆与持续学习_综述|D-05 记忆与持续学习]]
