# 表示学习综述：如何让机器理解世界

## 一句话理解

表示学习研究如何将原始数据转化为有利于下游任务的特征表示——几乎所有现代 AI 的核心突破（词嵌入、预训练模型、对比学习、多模态对齐）本质上都是表示学习的进步，"学到好的表示"是智能的必要条件。

## 1. 领域定义

表示学习（Representation Learning）是学习数据的有意义表示（特征、嵌入、编码），使后续任务更容易完成。它不是单一方法，而是一个贯穿所有 AI 系统的**横切关注点**。

### 核心问题

如何设计学习目标和架构，使得学到的表示具备：
- **判别性**：不同语义的输入有不同表示
- **不变性**：语义相同的输入有一致表示（对抗变换不变）
- **可组合性**：表示可以被组合和迁移
- **多尺度性**：从低级特征到高级语义的层级结构

## 2. 为什么表示学习是核心

- **特征工程 → 表示学习**：传统 ML 手工设计特征，深度学习自动学特征
- **预训练的本质**：Foundation Model 的核心价值就是学到了通用表示
- **迁移学习的基础**：好的表示从一个任务迁移到另一个任务
- **多模态的桥梁**：不同模态通过共享表示空间实现对齐
- **AGI 的前提**：通用智能需要通用的世界表示

## 3. 核心概念与方法

### 3.1 嵌入空间 (Embedding)

| 类型 | 映射 | 代表 |
|------|------|------|
| 词嵌入 | 词 → 向量 | Word2Vec, GloVe, FastText |
| 句子嵌入 | 句 → 向量 | Sentence-BERT, E5 |
| 图像嵌入 | 图 → 向量 | CLIP Image Encoder, DINO |
| 图嵌入 | 节点/图 → 向量 | DeepWalk, Node2Vec, GCN |
| 多模态嵌入 | 异构数据 → 共享空间 | CLIP, ImageBind |

### 3.2 表示质量评估

| 度量 | 含义 | 方法 |
|------|------|------|
| 线性可分性 | 表示是否线性可分 | 线性探测 (Linear Probe) |
| 对齐度 | 相似语义的表示是否接近 | CKA, SVCCA |
| 不变性 | 变换后表示是否稳定 | 不变性测试 |
| 解耦性 | 因素是否独立编码 | DCI, Beta-VAE |
| 紧凑性 | 信息密度 | 信息瓶颈 |

### 3.3 迁移学习范式

| 范式 | 描述 | 代表 |
|------|------|------|
| 特征提取 | 冻结预训练表示 | ImageNet 特征 |
| 微调 | 小学习率更新全部/部分参数 | LoRA, Adapter |
| 多任务学习 | 共享表示 + 任务头 | MT-DNN |
| 领域适应 | 源域 → 目标域表示对齐 | DANN, CORAL |

### 3.4 多模态表示对齐

- **对比对齐**：CLIP (Image-Text), ImageBind (多模态)
- **生成对齐**：LLaVA (视觉指令), Flamingo (交叉注意力)
- **联合嵌入**：JEPA (预测潜在表示而非像素)
- **模态融合**：早期/中期/晚期融合策略

### 3.5 解耦表示学习

- β-VAE：解耦潜在因素
- StyleGAN：风格与内容分离
- GroupVAE / FactorVAE：分组解耦
- 与因果表征学习的关系：解耦 ≠ 因果，但解耦是因果的必要条件

## 4. 发展历史

1. 2003：Word2Vec 之前的分布式表示
2. 2013：Word2Vec 证明词嵌入可学
3. 2014：自编码器 (VAE) 用于表示学习
4. 2018：BERT 证明大规模预训练学到通用表示
5. 2020：SimCLR/MoCo 对比学习视觉表示
6. 2021：CLIP 多模态对齐，DINO 自蒸馏表示
7. 2022：Foundation Model = 大规模表示学习
8. 2023-：多模态统一表示 (ImageBind, GPT-4V)

## 5. 与 AGI 的关系

- **通用表示 = 通用智能的前提**：AGI 必须对世界有统一的内部表示
- **多模态统一**：AGI 需要跨模态的统一表示空间
- **因果表示**：超越统计相关，学到因果相关的表示
- **持续学习的表示挑战**：如何在不破坏旧表示的情况下学习新表示

```
AGI 阶梯中的位置：

[语言模型] → CoT → Agent → 持续学习 → 奇点 → 具身智能
    ↑
表示学习是所有台阶的底层支撑：
语言模型 = 词表示学习
CoT = 推理过程表示
Agent = 状态-行动表示
具身 = 感知-运动表示
```

## 6. 学习路径

1. 理解词嵌入 (Word2Vec) 的分布式假设
2. 学习自编码器和 VAE 的潜空间表示
3. 理解对比学习的表示对齐（SimCLR → CLIP）
4. 研究迁移学习的表示迁移机制
5. 探索多模态表示对齐
6. 研究因果表征学习与解耦表示

## 7. 未来趋势

- 因果表征学习（超越统计表示）
- 统一多模态表示空间
- 世界模型的潜在表示（JEPA 路线）
- 面向持续学习的表示设计
- 表示学习的信息论理解
