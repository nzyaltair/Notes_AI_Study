# 预测准确性

## 一句话理解

预测准确性衡量模型对未来状态与观测的预测质量；单一点误差或单幅画质都不能代表预测能力，必须同时考察分布、校准与任务相关变量。

## 概述

预测是世界模型的基础能力，但"预测得准"有多种含义：点预测（MSE）可能被模糊均值掩盖；感知质量指标可能忽略动作效果；奖励预测与状态预测可能互相矛盾。评估必须与模型用途对齐。

## 指标体系

| 层面 | 指标/测试 | 说明 |
|---|---|---|
| 观测/状态 | 像素 MSE、PSNR | 简单但易被模糊平均掩盖 |
| 分布 | 概率 NLL、FVD | 检验对多模态未来的覆盖 |
| 对象/语义 | 对象位置、数量、属性误差 | 比像素更贴近决策 |
| 任务变量 | 奖励、终止、风险预测误差 | 直接关系规划质量 |
| 校准 | 可靠性曲线、ECE | 预测置信度应匹配真实准确率 |
| 行动条件 | 同状态不同动作的区分度 | 检验是否真的响应动作 |

## 关键原则

- **多模态未来**：应允许多个合理结果，而不是以单一真实轨迹惩罚所有替代未来（如扩散/采样模型评估需覆盖多样性）。
- **动作条件对比**：在相同初始状态改变动作，检查预测是否随之改变——这是区分"预测世界"与"生成无关视频"的关键测试。
- **闭环意义**：预测误差应结合下游规划收益解读（一步准 ≠ 闭环可用）。

## 常见误区

- 只报 FVD/PSNR：画质高不代表预测了正确的对象运动。
- 只用单一轨迹评估：掩盖对多模态未来的建模失败。
- 忽略校准：高置信错误预测比低置信正确预测更有害。
