# 群体智能与自组织：行为主义范式的优化与涌现

## 一句话理解

进化计算模拟自然选择进行全局搜索与优化，群体智能模拟社会性生物的协作涌现，二者共同构成了行为主义 AI 范式中"通过交互与选择产生智能"的核心路线，也是强化学习和多智能体系统的重要理论来源。

## 1. 领域定义

进化计算（Evolutionary Computation）和群体智能（Swarm Intelligence）是受生物进化和社会性动物行为启发的计算方法家族。前者通过选择、交叉、变异进行种群级优化；后者通过简单个体间的局部交互产生全局智能行为。它们属于 AI 三大范式中的**行为主义**：不依赖内部知识表示或学习权重，而是通过外部选择压力和交互产生适应性行为。

遗传算法、进化策略、CMA-ES 等进化计算方法详见 [[01_进化计算与开放性/01_遗传算法与进化策略|遗传算法与进化策略]]；本页聚焦群体智能与自组织涌现。

## 2. 为什么会出现

- 传统优化方法（梯度下降）需要可微目标函数
- 许多实际问题（组合优化、结构设计、策略搜索）不可微或高维
- 生物进化证明了"无智能过程可产生智能结果"
- 群体行为证明了"简单规则可涌现复杂智能"

## 3. 群体智能方法

| 方法 | 生物灵感 | 核心机制 |
|------|----------|----------|
| 粒子群优化（PSO） | 鸟群觅食 | 速度-位置更新 |
| 蚁群算法（ACO） | 蚂蚁信息素 | 信息素更新 + 概率选择 |
| 人工蜂群（ABC） | 蜜蜂采蜜 | 引领蜂-跟随蜂-侦查蜂 |
| 萤火虫算法 | 萤火虫闪烁 | 亮度吸引 |

## 4. 自组织系统

- **涌现（Emergence）**：简单规则产生复杂行为
- **元胞自动机**：局部规则 → 全局模式
- **人工生命**：数字环境中的进化模拟（详见 [[01_进化计算与开放性/02_神经进化_开放式学习与人工生命|神经进化、开放式学习与人工生命]]）

## 5. 发展历史

1. 1950s-60s：进化计算思想萌芽（Fogel, Rechenberg, Holland）
2. 1975：Holland 正式提出遗传算法
3. 1980s：蚁群、粒子群等群体智能方法涌现
4. 1990s：进化计算与机器学习开始结合
5. 2017：OpenAI ES 证明进化策略可用于 RL
6. 2020s：进化计算用于 LLM 超参搜索、NAS、模型优化

## 6. 与 AGI 的关系

- **行为主义范式核心**：进化与群体智能是"智能可从选择与交互中涌现"的直接体现
- **无梯度优化**：进化策略是强化学习的替代方案（OpenAI ES, PPO-ES 混合）
- **多智能体系统**：群体智能理论支撑多 Agent 协作
- **AutoML**：NAS 本质是搜索空间的进化
- **开放进化**：人工生命研究智能的涌现条件

## 7. 当前发展状态与未来趋势

- 进化策略在 RL 中作为无梯度替代方案有实际应用
- CMA-ES 是连续优化的强基线方法
- 群体智能主要用于组合优化和调度问题
- 与深度学习结合：进化 NAS、ES-RL、种群训练
- 未来：进化 + 深度学习的深度融合、大规模多智能体群体智能、开放式进化与 AGI、进化计算在 LLM 优化中的应用
