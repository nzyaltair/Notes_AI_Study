# 具身 Agent 综述：物理世界中的自主智能体

## 一句话理解

具身 Agent 是在物理世界中自主感知、规划、行动和学习的智能体——它将 LLM Agent 的推理能力与机器人的物理执行能力结合，是 AGI 阶梯最终阶段的实现形态。

## 1. 领域定义

具身 Agent = Agent 架构 + 物理载体 + 世界模型 + 持续学习

与虚拟 Agent 的区别：

| 维度 | 虚拟 Agent | 具身 Agent |
|------|-----------|-----------|
| 环境 | 数字/符号 | 物理世界 |
| 感知 | 文本/图像 | 多模态传感 |
| 行动 | API/代码 | 物理运动 |
| 反馈 | 即时 | 延迟/稀疏 |
| 安全 | 回滚可恢复 | 不可逆损伤 |
| 学习 | 提示/微调 | 持续学习 |

## 2. 核心架构

```
高级推理 (LLM/CoT)
    ↓ 任务分解
中级规划 (世界模型 + 搜索)
    ↓ 动作规划
低级控制 (MPC/Diffusion Policy)
    ↓ 关节执行
物理世界
    ↑ 传感反馈
多模态感知 (VLA)
```

## 3. 核心能力

### 3.1 自主探索

| 能力 | 描述 | 方法 |
|------|------|------|
| 好奇心驱动 | 主动探索未知区域 | 内在奖励 |
| 信息获取 | 主动感知以减少不确定性 | 贝叶斯主动学习 |
| 新物体发现 | 发现并理解新物体 | 开放世界识别 |
| 环境建图 | 构建环境地图 | SLAM + 语义 |

### 3.2 交互学习

| 方式 | 描述 | 代表 |
|------|------|------|
| 模仿学习 | 从人类演示学习 | BC, ACT |
| 语言指令 | 遵循自然语言指令 | SayCan, VLA |
| 物理交互 | 通过接触学习 | 触觉学习 |
| 人类反馈 | 从人类评价学习 | RLHF for Robotics |

### 3.3 开放世界能力

- 开放词汇识别：识别训练中未见过的物体
- 开放集操作：操作未见过的物体
- 零样本任务：执行未训练过的任务
- 组合泛化：组合已知技能完成新任务

## 4. 发展历史

1. 2022：SayCan 将 LLM 与机器人结合
2. 2023：RT-2 首个大规模 VLA 模型
3. 2024：Octo 开源通用策略；Figure AI 商业化
4. 2025：π₀ / π₀-mini 推出；人形机器人量产
5. 2026：具身 Agent 从原型走向应用

## 5. 与 AGI 的关系

- **AGI 阶梯6**：具身 Agent 是 AGI 的最终物理实现
- **持续学习的终极场景**：物理世界是持续学习最自然的环境
- **从虚拟到物理**：Agent + 物理载体 = 具身 Agent
- **社会影响**：具身 Agent 将改变劳动力市场

## 6. 学习路径

1. 理解 Agent 架构与具身系统的结合
2. 学习 VLA 模型（RT-2, Octo）
3. 研究自主探索与交互学习
4. 探索开放世界具身能力
5. 关注持续学习在具身场景的应用
