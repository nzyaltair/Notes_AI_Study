# Agent评测与运行时防护

Agent 评测必须测量完整轨迹：是否识别不可信内容、是否选择合适工具、是否遵守权限、是否在不确定时暂停，以及失败后能否恢复。

## 场景维度

- 工具参数注入、跨工具链攻击和权限提升。
- 恶意网页/邮件/文档造成的间接提示注入。
- 记忆投毒、租户隔离和敏感数据外泄。
- 长程任务的目标漂移、循环调用、预算耗尽与副作用。
- 多 Agent 通信伪造、委派链与冲突解决。

## 运行时防护

```text
策略监控 → 调用前检查 → 受限执行 → 结果验证 → 轨迹审计 → 异常熔断/人工接管
```

监控信号包括：异常工具序列、敏感资源访问、拒绝后反复尝试、预算/时长突增、记忆写入异常和执行结果偏离计划。熔断机制必须由独立服务触发，并提供暂停、撤销凭据、回滚事务、通知责任人和保全证据的流程。

## 指标

除任务成功率外，跟踪：越权行动率、攻击成功率、敏感数据暴露率、无效工具调用、人工接管延迟、可回滚率和安全误拒率。任何单一“安全分”都不足以代表 Agent 的运行风险。
