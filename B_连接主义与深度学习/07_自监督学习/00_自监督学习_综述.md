# 自监督学习综述：从数据自身获取监督信号

## 一句话理解

自监督学习从无标注数据中自动构造监督信号（如预测被掩码的部分、区分不同视角），是现代大规模预训练的基础范式，也是解决数据标注瓶颈的核心路径。

## 1. 领域定义

自监督学习（Self-Supervised Learning, SSL）是一类无需人工标注、从数据自身结构中构造前置任务（pretext task）进行表征学习的方法。它不是无监督学习的子集，而是利用数据内在的监督信号，兼具规模优势和语义质量。

与监督学习、无监督学习的关系：

| 方法 | 监督信号 | 数据规模 | 表征质量 |
|------|----------|----------|----------|
| 监督学习 | 人工标注 | 受限 | 高（任务相关） |
| 无监督学习 | 无 | 大 | 低（缺乏语义引导） |
| 自监督学习 | 数据自身构造 | 大 | 高（语义丰富） |

## 2. 为什么会出现

- **标注成本**：ImageNet 标注耗时数年，LLM 训练数据无法人工标注
- **数据规模**：互联网数据量远超人工标注能力
- **表征通用性**：监督学习表征受限于特定任务，SSL 学到更通用表征
- **GPT/BLIP 的基础**：语言模型预测下一个 token 本质就是自监督

## 3. 核心范式

### 3.1 对比学习（Contrastive Learning）

核心思想：相似样本拉近，不相似样本推远。

- SimCLR：数据增强 + 同一实例不同视角为正对
- MoCo v1/v2/v3：动量编码器 + 队列负样本
- BYOL：无需负对的师生网络
- CLIP：图像-文本对比对齐

### 3.2 掩码预测（Masked Prediction）

核心思想：预测被遮掩的数据部分。

- MAE（Masked Autoencoder）：掩码图像 patch 预测
- BEiT：掩码视觉 token 预测
- BERT：掩码语言模型
- GPT 系列：下一个 token 预测

### 3.3 其他范式

- 自蒸馏（DINO/DINOv2）：师生架构，无需负对
- 非对比学习（Barlow Twins/VICReg）：冗余消除
- 时空预测（视频预测、物理预测）

## 4. 发展历史

1. 2018：BERT 将掩码语言模型推向主流
2. 2020：SimCLR/MoCo 开创视觉对比学习
3. 2021：BYOL/DINO 突破对负对的依赖；MAE 开创视觉掩码预测
4. 2022：DINOv2 证明视觉自监督可达通用表征
5. 2023-：自监督成为多模态和 LLM 预训练标准范式

## 5. 重要分支

| 分支 | 代表方法 | 核心思想 |
|------|----------|----------|
| 对比学习 | SimCLR, MoCo, CLIP | 正负对距离优化 |
| 掩码预测 | MAE, BEiT, BERT | 重建被掩码内容 |
| 自蒸馏 | DINO, DINOv2 | 师生网络一致性 |
| 非对比 | Barlow Twins, VICReg | 冗余消除/方差-协方差 |

## 6. 与 AGI 的关系

- 自监督是 LLM 预训练的基础（next-token prediction 即自监督）
- 持续学习需要自监督来处理无标注流数据
- 通用表征是 AGI 感知能力的前提
- 在 AGI 阶梯中，自监督是语言模型和持续学习两个台阶的底层支撑

## 7. 学习路径

1. 理解对比损失（InfoNCE/NT-Xent）
2. 从 SimCLR 入手理解对比学习
3. 学习 MAE 理解掩码预测
4. 理解 BYOL/DINO 为何不需要负对
5. 研究 CLIP 的跨模态对比学习
6. 探索自监督在 LLM 预训练中的角色

## 8. 当前发展状态

- 视觉自监督表征已接近甚至超过监督预训练
- 语言模型的自监督预训练已成为标准范式
- 多模态自监督（图像-文本-视频-音频）正在快速发展
- 自监督 + 合成数据是未来方向

## 9. 未来趋势

- 更高效的自监督目标函数
- 自监督 + 强化学习结合
- 视频和 3D 自监督
- 面向持续学习的自监督
- 自监督世界模型
