# 记忆目标与多智能体安全

长期记忆让 Agent 积累偏好、事实和经验，也带来持久化污染、跨租户泄露和目标漂移。多 Agent 系统则增加委派、通信和责任链风险。

## 记忆安全

- **写入门禁**：区分短期缓存、可验证事实、用户偏好和策略；不可信内容不得直接升级为长期记忆。
- **来源与时效**：每条记忆记录来源、权限、置信度、创建/过期时间和适用范围。
- **检索最小化**：按用户、任务和授权范围过滤，避免把无关敏感记忆注入上下文。
- **投毒检测**：监测异常写入频率、重复指令、策略冲突和记忆引发的行为突变。
- **可删除与回滚**：支持审计、修订、过期和用户数据删除。

## 目标漂移与委派

复杂任务会经历计划分解、子 Agent 委派、重试和自我反思。每一步都可能放大原始目标偏差。要求：任务范围和预算随委派传递；子 Agent 不继承超出任务需要的权限；禁止隐式再委派或权限提升；聚合器必须能解释最终行动由谁、基于何种证据提出。

## 多智能体风险

| 风险 | 控制 |
|---|---|
| 通信注入/伪造 | 身份认证、结构化协议、消息来源与完整性校验 |
| 共谋或反馈放大 | 独立评估、异质化角色、资源和预算限制 |
| 责任扩散 | 指定行动 owner，保留端到端因果链 |
| 竞争资源抢占 | 配额、调度策略、冲突仲裁 |

多 Agent 不应被视为天然更可靠；冗余只有在独立性和可审计性得到保证时才有安全价值。
