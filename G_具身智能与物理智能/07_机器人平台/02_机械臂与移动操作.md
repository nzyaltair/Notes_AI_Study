# 机械臂与移动操作

## 一句话理解

固定基座机械臂适合精密、重复且可围栏保护的操作；移动操作机器人将导航与抓取结合，面向仓储、家居和巡检——移动操作的难点是导航终点与操作位姿的耦合。

## 概述

机械臂是最成熟、部署最广的机器人平台。固定基座机械臂解决单点操作问题；移动操作（Mobile Manipulation）把移动能力与操作能力结合，是仓储、家居、巡检等真实场景的主力平台。移动操作的核心难点不是单点能力，而是移动与操作的耦合规划。

## 发展历史

- **1961**：Unimate 首台工业机械臂。
- **1970s-1990s**：工业机械臂普及（焊接、喷涂）；协作概念萌芽。
- **2000s**：协作机械臂（UR 2008, KUKA iiwa 2013）与人机共享空间。
- **2010s**：移动操作研究平台（PR2, Fetch, Stretch）；Amazon Picking Challenge 推动抓取与放置。
- **2020s**：移动操作 + 学习策略（VLA 部署平台）；低成本平台（Stretch, HSR）推动研究民主化。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 协作机器人 | 与人共享空间的安全机械臂 | 人机协作 |
| 移动操作 | 移动 + 操作联合任务 | 大范围任务 |
| 基座-臂耦合 | 基座位姿与臂可达性关系 | 移动操作核心 |
| 末端执行器 | 夹爪/吸盘/灵巧手 | 任务适配 |
| 安全力限制 | 协作臂的力/速度限制 | 人机安全 |

## 技术原理

### 移动操作的耦合问题

移动操作的耦合在于：

- **基座位姿决定手臂可达性**：基座停错位置，臂够不到目标。
- **相机视角随基座变化**：感知条件受位置影响。
- **臂负载改变移动稳定性**：对轮式/足式基座都是约束。
- **导航终点必须是可操作位姿**：而非任意位置。

### 解耦 vs 联合规划

| 方法 | 流程 | 优势 | 局限 |
|---|---|---|---|
| 解耦 | 先导航到可操作区域，再操作 | 简单、模块化 | 可能多次调整位姿 |
| 联合规划 | 同时规划移动轨迹与操作 | 全局最优 | 计算复杂、状态维数高 |
| 可操作位姿搜索 | 搜索满足 IK 可达的基座位姿 | 面向任务 | 依赖逆解与碰撞检查 |

典型流程：

```text
任务目标 → 语义导航到候选可操作区域
→ 基座位姿搜索（IK 可达 + 无碰撞）
→ 视觉感知 → 抓取/放置 → 核验 → 下一任务
```

### 协作臂安全

协作机器人（ISO/TS 15066）的安全机制：

- **力/功率限制**：接触力限制在安全阈值。
- **速度限制**：接近人时减速。
- **安全监测**：安全等级监控。
- **空间共享**：工作空间与人重叠。

### 关键能力

固定基座与移动操作机器人的共同关键能力：

- 标定（手眼、基座、相机）。
- 抓取与放置（感知 + 规划 + 执行）。
- 语义导航（对象级目标导航）。
- 动态避障与碰撞检测。
- 视觉/触觉闭环。
- 人机安全协作。

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| MoveIt 2 | 运动规划 + IK + 碰撞 | 通用操作 |
| 可操作位姿搜索 | IK 可达位姿采样 | 移动操作 |
| 语义导航 | 对象级目标导航 | 家居/仓储 |
| TAMP | 任务-运动联合规划 | 复杂操作 |
| 学习抓取 | 数据驱动抓取 | 未知物体 |
| VLA 操作 | 语言条件操作 | 开放任务 |

## 优势与局限

| 平台 | 优势 | 局限 |
|---|---|---|
| 固定机械臂 | 精度、成本、稳定 | 工作空间受限 |
| 协作臂 | 人机共享 | 负载有限 |
| 移动操作 | 大范围、灵活 | 耦合复杂度、成本 |
| 低成本平台 (Stretch) | 研究民主化 | 负载、精度有限 |

## 应用场景

- 工业装配、焊接、喷涂。
- 仓储拣选、打包、上架。
- 家居整理、清洁、陪伴服务。
- 巡检 + 操作（开关阀门、读取仪表）。

- **VLA 移动操作**：语言指令驱动的导航 + 操作。

- **低成本平台规模化**：Stretch 类平台数据采集。
- **动态场景操作**：移动中抓取。

## 常见问题

- **把移动与操作分开优化**：耦合被忽略，任务失败。
- **忽略基座可达性**：导航到位但 IK 不可达。
- **协作臂安全当常规**：力限制失效即危险。
- **标定不完整**：手眼标定误差直接导致抓取失败。
