# 世界模型驱动智能体综述：预测未来，再选择行动

> Agent 的目标和工具能力不等于环境理解。世界模型为 Agent 提供行动后果预测，使其从“试一次看结果”升级为“先在内部比较方案，再安全执行”。

## 架构

```text
目标/指令 → 高层 Agent（分解、记忆、约束）
                       ↓
         世界状态 + 候选动作/子目标
                       ↓
      世界模型（预测回报、风险、不确定性）
                       ↓
  规划器（MPC / MCTS / 采样 / 策略） → 动作执行
                       ↑                   ↓
                  真实观测 ← 环境反馈与模型更新
```

## 设计原则

1. 高层计划与低层控制采用不同预测尺度。
2. 将风险和不确定性进入规划目标，不能只最大化预测回报。
3. 对工具、网页、代码和机器人环境，都要定义可观测状态、动作语义及反馈。
4. 让真实反馈随时否决模型想象，避免 Agent 在错误模拟中越走越远。
