# 无人机与空中机器人

## 一句话理解

无人机是高动态、欠驱动的具身平台，具备快速三维移动和高视角感知能力，但续航、载荷、风扰和安全约束严格。空中操作还会因机械臂反作用力显著耦合飞行稳定性。

## 概述

无人机（UAV）与空中机器人是具身智能中运动最动态、环境约束最特殊的一类：四旋翼欠驱动（只有 4 个推力输入控制 6 自由度）、快速响应、三维移动。它适合巡检、测绘、搜索救援等空中任务；空中操作（无人机 + 机械臂）则是前沿挑战，操作反作用力直接耦合飞行稳定性。

## 发展历史

- **2000s-2010s**：自主飞行技术成熟（PX4, DJI）；视觉惯性导航（VIO）用于无 GPS 环境。
- **2010s**：多旋翼避障、自主导航成熟（2013 年 IEEE 无人机竞速）；微型无人机研究兴起。
- **2020s**：无人机 + 机械臂空中操作（AVI 实验室、UT Austin）；无人机集群；学习型飞行控制与模拟器（Flightmare, AirSim）成熟。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 欠驱动 | 控制输入少于自由度 | 需要耦合控制 |
| 推力矢量 | 螺旋桨推力方向 | 位置/姿态控制 |
| 视觉惯性里程计 (VIO) | 相机+IMU 融合定位 | 无 GPS 定位 |
| 地理围栏 | 安全空域边界 | 安全约束 |
| 风扰 | 环境气流扰动 | 鲁棒控制挑战 |
| 空中操作 | 无人机 + 机械臂 | 反作用力耦合 |

## 技术原理

### 动力学与欠驱动

四旋翼动力学：4 个电机推力 \(T_i\) 控制 6 自由度（3 位置 + 3 姿态），欠驱动——通过姿态倾斜产生水平推力。位置控制由姿态级联控制实现：

```text
位置环 → 期望加速度 → 期望姿态 → 姿态环 → 电机指令
```

### 状态估计

- **VIO**：相机 + IMU 融合，估计位置与姿态（MSCKF, VINS-Mono）。
- **GPS + RTK**：室外高精度定位。
- **视觉 SLAM**：未知环境建图与定位。

### 飞行控制

| 方法 | 核心思想 | 适用 |
|---|---|---|
| 串级 PID | 位置-姿态级联 | 常规飞行 |
| MPC | 轨迹跟踪 + 约束 | 敏捷机动 |
| RL 飞行 | 学习机动策略 | 竞速、复杂机动 |
| 几何控制器 | SE(3) 位姿控制 | 大角度机动 |

### 空中操作

无人机 + 机械臂的挑战：

- **反作用力耦合**：机械臂运动改变质心与力矩，直接扰动飞行。
- **动态抓取**：高速接近、同步抓取。
- **载荷变化**：抓取后质量特性突变。
- **安全**：旋翼危险、坠落风险。

常用方法：自适应控制补偿反作用力、联合优化飞行动力学与操作动力学、视觉伺服抓取。

### 安全与合规

- 地理围栏与禁飞区。
- 传感器冗余（多 IMU、降落伞）。
- 低电量返航/降落。
- 法规合规（飞行许可、视觉线内）。

## 关键方法与模型

| 方法/平台 | 核心思想 | 适用 |
|---|---|---|
| VINS-Mono | 视觉惯性里程计 | 无 GPS 定位 |
| PX4/ArduPilot | 开源飞控 | 开发平台 |
| MPC 飞行 | 约束轨迹跟踪 | 敏捷机动 |
| RL 竞速 | 学习飞行策略 | 极限飞行 |
| Flightmare/AirSim | 飞行仿真 | 训练评测 |
| 空中操作臂 | 无人机 + 机械臂 | 操作任务 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 机动性 | 三维快速移动 | 载荷与续航 |
| 视角 | 高视角全局感知 | 近距离操作弱 |
| 环境适应 | 高空、危险区域 | 风扰、天气 |
| 安全性 | 无碰撞环境可行 | 坠落风险 |

## 应用场景

- 巡检：电力线、管道、光伏板、桥梁。
- 测绘：三维建图、农业监测。
- 搜索救援：灾后侦察、物资投递。
- 空中操作：抓取、放置（前沿）。
- 物流：末端配送（受限场景）。

## 前沿发展

- **无人机集群**：多机协同巡检、编队。
- **空中操作**：动态抓取、装配、维护。
- **自主决策**：长航时自主任务规划。
- **微型无人机**：狭小空间导航。
- **学习型飞行**：竞速与极限机动。

## 常见问题

- **用人形范式衡量无人机**：平台能力不同，任务匹配优先。
- **忽略风扰**：室外飞行必须建模风与湍流。
- **空中操作当地面操作**：反作用力耦合不可忽略。
- **忽略法规与安全**：飞行合规与地理围栏是部署前提。
