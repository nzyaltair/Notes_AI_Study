# 验证器与过程奖励模型

## 一句话理解

验证器评估候选答案或步骤可信度；过程奖励模型（PRM）将反馈下沉到中间步骤，可辅助搜索和训练，但可能奖励格式而非真实正确性。

ORM 只监督最终答案，信号稀疏；PRM 支持步骤级选择但标注昂贵且易被投机；可执行验证器客观可复现，却仅适用于有形式规范的任务。验证器需在对抗候选和分布外样本上独立评估。
