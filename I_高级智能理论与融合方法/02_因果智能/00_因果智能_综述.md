# 因果智能 综述

## 概述

因果智能（Causal Intelligence）是超越统计相关性、实现真正理解的核心能力。统计学习发现"什么和什么一起出现"，因果智能回答"为什么"和"如果...会怎样"。这是通向 AGI 不可绕过的方向。

## 核心概念

### 因果关系 vs 相关关系
- **相关**：X 与 Y 共同变化（观察性统计）
- **因果**：改变 X 会导致 Y 改变（干预性）
- "相关不等于因果"是统计学习的根本局限

### Judea Pearl 的因果阶梯 (Ladder of Causation)
```
Level 3: 反事实 (Counterfactual) — "如果当时...会怎样？"
    ↑
Level 2: 干预 (Intervention) — "如果我做X，会怎样？"
    ↑
Level 1: 关联 (Association) — "如果我观察到X，Y会怎样？"
```

当前深度学习主要在 Level 1，AGI 需要到达 Level 2-3。

## 主要研究方向

### 因果发现 (Causal Discovery)
- 从观测数据中发现因果结构
- PC 算法、FCI 算法
- 基于分数的方法（GES）
- 现代方法：NOTEARS（基于连续优化）、因果注意力

### 结构因果模型 (Structural Causal Model, SCM)
- 有向无环图 (DAG) 建模变量间因果关系
- 结构方程：$X_i = f_i(PA_i, U_i)$
- do-演算 (do-calculus)
- 干预与反事实的形式化

### 反事实推理 (Counterfactual Reasoning)
- "如果当时做了不同的选择，结果会怎样？"
- 三步过程：抽象 (Abduction) → 行动 (Action) → 预测 (Prediction)
- 在医疗、法律、政策评估中的应用

### 因果表示学习 (Causal Representation Learning)
- 从高维数据中发现因果变量
- 解耦表示与因果机制
- 独立因果机制 (ICM) 原则
- 因果特征学习

### 因果强化学习 (Causal RL)
- 基于因果模型的策略学习
- 因果探索与干预
- 奖励的因果推断
- 去混淆 (Deconfounding)

## 关键技术

### do-演算
- Pearl 的三条规则用于识别因果效应
- 从观察数据估计干预效果
- 后门准则、前门准则

### 因果推断方法
- 倾向得分匹配 (PSM)
- 工具变量 (IV)
- 双重差分 (DID)
- 回归断点设计 (RDD)

### 深度因果学习
- 因果生成模型
- 变分因果推断
- 基于神经网络的 SCM 参数化

## 与 AGI 的关联

因果智能是 AGI 的核心能力：
- **超越相关**：理解事物之间的真正因果机制
- **干预能力**：不只是预测，而是理解行动后果
- **反事实推理**：想象替代可能性，做出更优决策
- **可迁移性**：因果知识可跨域迁移，不依赖特定分布
- **与 Agent 结合**：Agent 需要因果理解才能真正规划行动

## 发展趋势

1. 大语言模型 + 因果推理：LLM 的因果知识利用
2. 因果世界模型：因果结构与深度学习融合
3. 因果 Agent：基于因果模型的自主决策
4. 因果表示学习：从像素到因果变量的自动发现
