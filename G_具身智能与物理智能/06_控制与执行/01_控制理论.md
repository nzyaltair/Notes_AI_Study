# 控制理论：从反馈到最优控制

## 一句话理解

控制理论研究如何为动态系统设计反馈输入，使状态跟踪目标并在扰动下保持稳定。它是具身控制与执行的理论前置——学习策略可以提议目标，但稳定地"做到"依赖控制理论。

## 概述

控制理论是机器人学的数学基石：动态系统建模、反馈设计、稳定性分析与约束优化。具身智能的学习模型需要控制层把高频、稳定、受约束的执行落到实处。理解控制理论是理解"为什么不能把策略输出直接接到电机"的关键。

## 发展历史

- **1868**：Maxwell 分析调速器稳定性，控制理论萌芽。
- **1930s-1940s**：频域方法（Nyquist, Bode）成熟；PID 整定（Ziegler-Nichols）。
- **1960s**：状态空间方法（Kalman 滤波 1960, LQR/LQG）；Pontryagin 最优控制。
- **1970s-1980s**：鲁棒控制（H∞）；模型预测控制（MPC）进入过程工业。
- **1990s-2000s**：MPC 进入机器人；阻抗控制（Hogan 1985）用于操作。
- **2010s-2020s**：学习型控制与经典控制融合；安全控制（CBF）与 RL 结合。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 反馈 | 用输出误差修正输入 | 稳定与跟踪的基础 |
| 稳定性 | 扰动后回到平衡 | 系统可用性的前提 |
| 可控性 | 能否通过输入到达任意状态 | 控制可行性 |
| 可观性 | 能否从观测推断状态 | 估计可行性 |
| 状态估计 | 从噪声观测估计状态 | 反馈的前提 |
| 最优控制 | 带代价函数的最优输入 | 性能指标 |
| 约束控制 | 满足状态/输入约束 | 实际系统必需 |

## 技术原理

### PID 控制

PID 是最广泛使用的反馈控制器：

$$u(t)=K_p e(t)+K_i\int_0^t e(\tau)d\tau+K_d\frac{de(t)}{dt}$$

- \(K_p\)：比例项，快速响应。
- \(K_i\)：积分项，消除稳态误差。
- \(K_d\)：微分项，抑制超调。

PID 不"理解任务"，但在毫秒尺度压制扰动和跟踪误差。整定方法：Ziegler-Nichols、继电整定、自整定。

### 状态空间与 LQR

线性系统状态空间描述：

$$\dot x=Ax+Bu,\qquad y=Cx$$

LQR 最小化二次代价：

$$J=\int_0^\infty (x^TQx+u^TRu)dt$$

解为状态反馈 \(u=-Kx\)，\(K=R^{-1}B^TP\)，\(P\) 由 Riccati 方程给出。LQG 在 LQR 基础上加入 Kalman 滤波器处理噪声。

### 状态估计

Kalman 滤波：线性高斯系统的最优递推估计，预测-更新两步：

$$\hat x_{t|t-1}=A\hat x_{t-1}+Bu_t,\qquad \hat x_t=\hat x_{t|t-1}+K_t(y_t-C\hat x_{t|t-1})$$

EKF/UKF 处理非线性；粒子滤波处理强非线性非高斯。

### MPC

MPC 在预测窗口内求解约束优化并只执行第一个动作：

$$\min_{u_{0:H-1}}\sum_{k=0}^{H-1}\ell(x_k,u_k)+\ell_T(x_H)\quad \text{s.t. } x_{k+1}=f(x_k,u_k),\ (x_k,u_k)\in\mathcal X\times\mathcal U$$

优势：显式处理约束、前瞻性。局限：需要模型、实时求解、对模型误差敏感。MPPI 用采样替代梯度求解，适合非光滑代价。

## 关键方法与模型

| 方向 | 关键方法 | 主要作用 |
|---|---|---|
| 经典控制 | PID、频域分析、Nyquist | 稳定跟踪与工程整定 |
| 状态空间 | 状态反馈、观测器、LQR/LQG | 最优调节 |
| 状态估计 | Kalman, EKF, UKF, 粒子滤波 | 噪声下状态估计 |
| 最优控制 | 动态规划、PMP、Riccati | 控制律设计 |
| 预测与鲁棒 | MPC, H∞, 自适应控制 | 约束与扰动 |

## 与学习方法的关系

强化学习以交互数据学习策略；控制理论利用模型、稳定性与约束结构设计控制律。实际机器人常采用"高层学习策略 + 低层反馈/MPC + 独立安全监督"的分层组合。

| 场景 | 优先使用 |
|---|---|
| 高频稳定控制 | 伺服、PID、WBC |
| 动态约束控制 | MPC |
| 复杂接触 | 阻抗/力控 |
| 感知-动作映射 | 学习策略 |

## 应用场景

- 关节伺服：位置/速度/力矩跟踪。
- 移动机器人：轨迹跟踪、避障。
- 四足/人形：平衡与全身控制（MPC + WBC）。
- 操作：柔顺接触（阻抗控制）。

- **学习型 MPC**：神经动力学 + 约束优化。
- **安全控制**：控制障碍函数（CBF）保证安全集不变。
- **RL 与最优控制统一**：两者的对偶关系被深入理解。
- **可微优化控制**：把 MPC 嵌入学习计算图。

## 常见问题

- **只调 PID 不看模型**：复杂系统需要模型与控制设计结合。
- **MPC 模型不准**：模型误差直接导致预测偏差。
- **忽略实时性**：求解时间超过控制周期则不可用。
- **学习替代控制**：学习策略不能保证稳定性与约束。
