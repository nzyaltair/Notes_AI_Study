# 跨模态对齐与连接器

## 一句话理解

跨模态对齐使不同信号可比较或交互；连接器把高维感知特征压缩后送入语言/生成主干，决定模型是否真正使用感知证据。

对比对齐学习共享嵌入；MLP 投影器成本低但容易成为瓶颈；Q-Former 用查询 token 选择特征；cross-attention 提供细粒度融合但成本较高。应通过遮挡、反事实配对和区域引用测试模型是否依赖真实证据。

## 连接器演进谱系（CS336 视角）

连接器（adapter/projector）负责把视觉编码器输出转换为语言模型输入，是 VLM 架构演进中最活跃的组件之一：

| 代际 | 方案 | 代表 | 特点 |
|---|---|---|---|
| 1 | 线性投影 $W$ | LLaVA (2023) | 最简单：视觉向量线性映射到 LM 嵌入空间 |
| 2 | 两层 MLP | LLaVA-1.5 (2023) | 少量非线性显著提升对齐质量 |
| 3 | 交叉注意力 + 2D 位置嵌入 | Qwen-VL (2023) | 视觉特征映射到固定尺寸（如 256 token），压缩序列长度 |
| 4 | 深度融合（注入残差流） | Qwen3-VL (2025) | 视觉 token 直接加入语言模型残差流——与"黑盒编码器输出向量序列"不同，视觉信息参与主干逐层计算 |

**参数规模直觉**：连接器与视觉塔参数量远小于语言主干（LLaVA：7B LM + 仅 72M 投影器；ViT 通常不到 10 亿参数）。原因在于视觉编码器执行的是**非常局部的操作**——只理解一个个小 patch，缺乏对世界知识的推理能力；模型的核心能力仍来自语言模型。这解释了为什么"冻结 LM、只训投影器"的对齐阶段是可行的。

## 分阶段训练：冻结策略的演进

VLM 普遍采用多阶段训练，通过逐步解冻组件控制训练稳定性（谁冻结、谁训练是各家主要差异）：

| 模型 | 阶段划分 |
|---|---|
| LLaVA（2 阶段） | ① **对齐阶段**：冻结视觉编码器 + LM，只训投影 $W$——随机初始化的 $W$ 输出根本不像自然语言 token 嵌入，必须先对齐到大致相同的嵌入空间；② 冻结视觉编码器，训 $W$ + LM（指令微调） |
| Qwen-VL（3 阶段） | ① 大规模低质数据（约 14 亿样本）：**冻结 LM**，训视觉编码器 + adapter；② 高质量任务数据（VQA、图表问答等）：训全部参数；③ 指令微调：冻结视觉编码器，训 adapter + LM |
| LLaVA-OneVision（3 阶段） | ① 对齐（只训投影器）；② 高质量偏知识数据；③ 下游任务示例——"不确定背后有什么特别原则"，本质是数据课程 |
| Qwen3-VL（4+3 阶段） | 预训练 4 阶段 + 后训练 3 阶段；上下文长度渐进训练 8K → 32K → 256K（大部分 token 集中在后两阶段）；后训练用长 CoT 数据做 SFT 与知识蒸馏，辅以 RL |

**共同模式**：先用海量粗数据对齐模态接口，再逐步用高质量数据解冻更多参数；越靠后的阶段越接近"后训练"性质（对齐人类意图、任务格式）。

## 对齐方法对比

| 方法 | 机制 | 优劣 |
|---|---|---|
| 对比对齐（CLIP/SigLIP） | 共享嵌入空间，余弦/点积比较 | 可大规模预训练、检索高效；细粒度交互弱 |
| MLP 投影 | 视觉特征线性/非线性变换后拼接进 token 序列 | 简单、成本低；可能成为信息瓶颈 |
| Q-Former | 查询 token 通过交叉注意力选择特征 | 固定 token 数、可学习选择；训练复杂 |
| 交叉注意力融合 | LM 层内对视觉 K/V 做注意力 | 细粒度融合；成本高 |
| 深度融合（残差流注入） | 多尺度视觉 token 注入主干多层 | 表达能力强；与主干耦合深、不易替换审计 |
