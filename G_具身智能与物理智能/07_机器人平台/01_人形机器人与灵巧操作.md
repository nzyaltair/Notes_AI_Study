# 人形机器人与灵巧操作

## 一句话理解

人形和灵巧手是具身智能最高目标也是最大挑战的载体：同时要求双足/多足平衡、多指协调、力控闭环、长程任务理解和人机安全共处。它不是"把机械臂装在腿上"，而是全身动态控制、多接触管理与高级认知的联合系统。

## 1. 为什么人形是硬问题

| 挑战 | 本质 | 与固定基座机械臂的差异 |
|---|---|---|
| 欠驱动与浮动基座 | 只能通过脚/手与环境的接触产生力 | 机械臂基座固定，不须考虑全局平衡 |
| 多接触管理 | 同时处理脚—地、手—物、身体—环境接触 | 机械臂通常单端接触 |
| 全身协调 | 移动 + 操作 + 平衡 + 感知必须同时规划 | 机械臂只需规划臂与末端 |
| 动态与跌倒恢复 | 高质心、快速运动时失稳风险大 | 固定基座无此问题 |
| 安全与可接受性 | 与人共处时必须温和、可预测 | 工业臂在围栏内，人形须出围栏 |
| 能耗与硬件 | 自主供电、散热、线缆和可靠性约束 | 固定供电和冷却 |

## 2. 全身控制（Whole-Body Control）

全身控制（WBC）在多接触、多任务优先级下同时规划全身关节运动：

$$\min_{\dot{\mathbf q}}\|J_{task}\dot{\mathbf q}-\mathbf v_{task}\|^2 \quad\text{s.t.}\quad\text{接触约束、关节限制、动力学}$$

常用框架（如 Hierarchical WBC）按优先级处理：保持平衡 > 避障 > 执行操作任务 > 姿态优化。对偶规划将 WBC 写为凸优化问题，可在 ms 级求解。

关键约束包括：脚与地面的摩擦锥、零力矩点（ZMP）/支撑多边形约束、关节力矩和速度限制、避免自碰撞、以及任务可达性。

## 3. 灵巧手与触觉操作

### 灵巧手架构

| 类型 | 代表 | 自由度 | 特点 |
|---|---|---|---|
| 欠驱动夹爪 | Robotiq 2F/3F | 1–3 | 简单可靠、适合工业 |
| 柔顺夹爪 | 软体/气动夹爪 | 连续 | 适应物体形状、力控温和 |
| 灵巧手 | Shadow Hand, LEAP Hand, Allegro | 16–20 | 可执行精细操作和多种抓取类型 |
| 仿人手 | 拟人肌腱驱动 | 20+ | 最接近人手、控制与感知最复杂 |

### 触觉感知

触觉提供接触位置、法向力、切向力/滑移、材质硬度和局部几何信息。常用传感器包括压阻/电容阵列、光学触觉（GelSight/DIGIT）、磁觉和力/力矩传感器。

触觉闭环典型流程：接近 → 初始接触检测 → 力控制夹紧 → 滑移检测 → 调整夹紧力 → 确认稳定抓取 → 抬升并复核。

当前瓶颈：传感器耐久性（反复接触后退化）、线缆与集成（高密度触觉需要大量信号线）、触觉表征学习（如何从触觉信号学习有用的操作策略），以及触觉数据采集成本。

### 在手操作（In-Hand Manipulation）

在手操作指不借助外部支撑，仅用手指重新调整物体位姿。它需要多指协调、接触模式切换和力控闭环，是灵巧操作的代表性难题。旋转笔、翻面、调整抓取姿态和插入钥匙都属于此类。

## 4. 移动操作（Mobile Manipulation）

移动操作 = 移动基座导航 + 机械臂操作，典型场景包括：在家中抓取散落物品、在仓库拣选、在工厂巡检与操作。

核心难点是**移动与操作的耦合**：基座位姿影响臂的可达性和相机视角；臂的运动改变质心和负载；规划需要联合优化。常用方法包括：先导航到可操作区域再执行操作（解耦），或联合规划移动轨迹和操作轨迹（耦合但计算量大）。

## 5. 代表系统与进展

| 系统 | 类型 | 特点 | 状态 |
|---|---|---|---|
| Atlas (Boston Dynamics) | 人形 | 动态跑跳、翻转 | 运动能力强，自主性有限 |
| Optimus (Tesla) | 人形 | 大批量制造目标 | 原型阶段 |
| Figure 02 | 人形 | 端到端操作 + 对话 | 早期部署 |
| Unitree H1/G1 | 人形 | RL 步态 + 操作 | 开源生态发展快 |
| Digit (Agility) | 人形 | 仓储物流定向 | 小规模部署 |
| Stretch (Hello Robot) | 移动操作 | 低成本、家居场景 | 研究/家居原型 |

人形/灵巧手领域的共同问题是：运动能力展示领先于自主智能能力；演示视频不代表日常可靠运行；硬件成本、耐久性和维护仍是瓶颈。

## 6. 研究前沿

- **全身操作**：用身体多部位（躯干、手臂、腿）协同接触和操作大/重物体。
- **触觉—视觉联合学习**：从视觉预测触觉属性，从触觉推断物体几何。
- **仿人运动学习**：从人类运动捕捉数据学习人形机器人步态和操作策略。
- **柔性物体操作**：布料、绳索、食物和软体对象的建模与操作仍是开放问题。
- **人机协作安全**：物理交互中的力控、意图预测和安全响应。
