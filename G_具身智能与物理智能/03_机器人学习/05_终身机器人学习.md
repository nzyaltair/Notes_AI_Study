# 终身机器人学习

## 一句话理解

终身学习要求机器人在长期运行中吸收新物体、新环境和用户偏好，同时避免灾难性遗忘和未经验证的能力退化——长期自主的核心是"适应而不遗忘、更新而不失控"。

## 概述

机器人部署不是一次性训练结束。真实环境持续变化：新物体、新房间、新用户偏好、硬件漂移。终身机器人学习（Lifelong Robot Learning）研究如何在长期运行中持续学习，同时保持旧能力不退化（不遗忘）、新能力可验证（不失控）。它综合了持续学习、在线适应和工程治理。

## 发展历史

- **1990s-2000s**：持续学习概念提出（Catastrophic Forgetting, McCloskey & Cohen 1989）；增量学习早期研究。
- **2010s**：深度持续学习方法成熟——EWC（2017）、Progressive Networks（2016）、Replay 方法；机器人领域出现终身 SLAM 与增量感知。
- **2020s**：终身机器人学习成为独立方向；大模型时代出现"世界知识 + 环境记忆"分离架构；基础模型 + 适配器持续更新成为主流路线。

## 核心概念

| 概念 | 定义 | 关键点 |
|---|---|---|
| 灾难性遗忘 | 学习新任务破坏旧任务能力 | 持续学习的核心难题 |
| 稳定-可塑困境 | 保持稳定 vs 快速适应 | 无法两全的基本矛盾 |
| 经验回放 | 重放旧数据巩固旧能力 | 简单有效 |
| 参数正则 | 惩罚对旧任务重要的参数变化 | EWC |
| 模块化/适配器 | 新任务新模块，旧模块不动 | 隔离遗忘 |
| 分布漂移 | 环境/数据分布随时间变化 | 触发重新学习 |
| 版本化与回滚 | 策略版本管理 | 工程保障 |

## 技术原理

### 持续学习方法

| 方法 | 核心思想 | 优势 | 局限 |
|---|---|---|---|
| 经验回放 (Replay) | 重放旧样本巩固 | 简单、有效 | 存储与隐私 |
| EWC | 惩罚旧任务重要参数 | 无存储 | 重要度估计偏差 |
| Progressive Nets | 新任务新网络列 | 不遗忘 | 参数增长 |
| 适配器/LoRA | 冻结主干 + 轻量适配 | 模块化、高效 | 适配器堆叠 |
| 知识蒸馏 | 旧模型指导新模型 | 无需旧数据 | 蒸馏损失 |

### 机器人的特殊性

机器人终身学习比纯软件持续学习更复杂：

1. **数据非独立同分布**：真实交互数据按时间顺序到达，场景相关。
2. **反馈延迟**：任务成功信号滞后且含噪声。
3. **安全约束**：更新策略可能带来危险行为。
4. **分布漂移**：环境、物体、用户偏好随时间变化。
5. **硬件退化**：执行器磨损改变动力学。

### 部署治理流程

机器人不应把每次在线交互立即写入生产策略；先记录、清洗、重放、评估，再在受限环境灰度验证：

```text
在线交互 → 数据记录 → 清洗与标注 → 离线评估（回放/仿真）
→ 候选策略 → 受限环境灰度验证 → 安全门禁 → 版本化部署
→ 监控与回滚
```

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| EWC | 参数重要度正则 | 任务序列 |
| Replay Buffer | 混合新旧数据训练 | 通用 |
| LoRA 适配器 | 参数高效微调 | 基础模型 |
| 技能库版本化 | 技能级增量 | 技能系统 |
| 场景记忆 | 环境级经验复用 | 长程部署 |
| 异常检测 | 监控能力退化 | 部署监控 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 长期适应 | 吸收新分布 | 遗忘风险 |
| 个性化 | 学习用户偏好 | 隐私与数据管理 |
| 持续改进 | 部署中提升 | 验证成本 |
| 模块化 | 隔离遗忘 | 参数增长 |

## 应用场景

- 家居机器人：学习新房间布局、用户习惯。
- 仓储机器人：新货物类型、新拣选策略。
- 人形机器人：新技能 + 旧技能保持。
- 服务机器人：新任务指令积累。

## 前沿发展

- **基础模型 + 持续适配**：VLA 主干冻结 + 环境适配器。
- **世界知识 vs 环境记忆分离**：通用知识存模型、场景知识存记忆。
- **无需重放的蒸馏**：避免存储旧数据。
- **终身世界模型**：环境持续更新的预测模型。
- **评测基准**：Lifelong Robot Learning Benchmarks 标准化。

## 常见问题

- **把在线学习当永久更新**：未经验证的在线更新可能退化和遗忘。
- **忽略分布漂移检测**：环境变了却不重新学习。
- **无回滚机制**：坏更新无法撤销。
- **只测新任务成功率**：必须同时报告旧任务保持率。
