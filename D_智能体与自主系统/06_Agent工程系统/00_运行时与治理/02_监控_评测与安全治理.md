# 监控、评测与安全治理

自主系统的质量不能只看最终回答。可观测性记录系统如何决策和行动；评测证明其在目标场景中表现；治理限制它在失败时造成的影响。

## Trace 与指标

一个 Trace 应关联：任务目标、模型/提示版本、状态变化、检索证据、计划、工具输入输出、权限判定、延迟、Token/费用和最终结果。核心指标包括任务成功率、步骤数、工具失败率、恢复率、风险拦截率、人工接管率、延迟与成本。

## 评测层次

1. 单工具与结构化输出测试。
2. 场景回放和模拟环境任务。
3. 长程端到端成功、恢复和资源评测。
4. 红队安全测试：提示注入、越权、数据泄露、危险副作用。
5. 生产在线监控与人工抽检。

治理采用最小权限、沙箱、审批阈值、预算、审计日志、敏感数据隔离和紧急停止。任何“自主”能力都不应绕过这些控制。
