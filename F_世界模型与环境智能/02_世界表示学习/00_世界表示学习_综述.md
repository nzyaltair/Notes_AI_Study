# 世界表示学习综述：把观测转化为可预测、可行动的状态

> 表示学习决定世界模型“看见什么”。好的世界表示应从原始信号中保留对象、关系、时间、可供性与不确定性，并丢弃对目标无关的偶然细节。

## 核心问题

同一环境可由像素、点云、语言、触觉和工具反馈观测。世界表示要将这些异构证据组织为状态 \(z_t\)，同时服务动力学预测与行动选择。

```text
多模态观测 → 对齐/融合 → 对象与空间状态 → 时序记忆 → 因果与可控变量
                                      ↓
                              预测、规划、控制
```

## 评价维度

| 维度 | 关键问题 |
|---|---|
| 可预测性 | 能否预测未来状态与观测？ |
| 可控性 | 能否分离动作可改变的因素？ |
| 几何与对象一致性 | 能否跨视角保持身份、关系和尺度？ |
| 任务效用 | 是否提升规划、控制和检索？ |
| 泛化与校准 | 面对新组合、遮挡和分布外情况是否可靠？ |
