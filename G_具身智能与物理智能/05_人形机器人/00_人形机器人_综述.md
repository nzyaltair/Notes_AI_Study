# 人形机器人综述：AGI 的终极物理载体

## 一句话理解

人形机器人是形态最接近人类的机器人——双足行走、灵巧操作、全身协调，它是 AGI 进入人类社会的最佳物理形态，也是当前最复杂、最具挑战性的具身智能方向。

## 1. 领域定义

人形机器人是具有类人形态（双足、双臂、灵巧手、头部）的机器人，目标是像人一样在人类环境中自主行动。

### 为什么是人形？

| 理由 | 说明 |
|------|------|
| 环境适配 | 人类环境为人体设计 |
| 工具使用 | 人形可直接使用人类工具 |
| 社交交互 | 人形更适合人机交互 |
| 任务通用性 | 形态通用 → 任务通用 |

## 2. 核心技术

### 2.1 双足行走

| 方法 | 特点 | 代表 |
|------|------|------|
| ZMP 控制 | 零矩点平衡 | Honda ASIMO |
| 模型预测控制 | MPC 优化步态 | Atlas |
| 强化学习 | 端到端学习行走 | Cassie, Unitree |
| 混合方法 | RL + 传统控制 | Tesla Optimus |

### 2.2 灵巧操作

| 方向 | 挑战 | 方法 |
|------|------|------|
| 抓取 | 物体多样性 | 抓取姿态采样 + 评估 |
| 旋转操作 | 长程操控 | RL + 仿真 |
| 双手协作 | 协调控制 | 双臂规划 + 力控 |
| 工具使用 | 未知工具 | VLA + affordance |

### 2.3 全身控制

- 全身运动规划：同时协调双腿+双臂+躯干
- 接触丰富的控制：多接触点平衡
- 动态运动：跑、跳、翻

### 2.4 代表产品

| 产品 | 公司 | 特点 |

| Optimus | Tesla | 大规模制造目标 |

## 3. 与 AGI 的关系

- **AGI 的物理载体**：人形机器人是 AGI 在物理世界的化身
- **具身 Agent**：人形 + AI 大脑 = 具身 Agent
- **终极阶段**：DeepSeek 路线中具身智能是 AGI 的最终阶段
- **社会影响**：人形机器人将深刻改变劳动力结构

```
AGI 阶梯定位：

语言模型 → CoT → Agent → 持续学习 → 奇点 → [具身智能]
                                               ↑
                              人形机器人是具身智能的
                              最佳物理形态
```
