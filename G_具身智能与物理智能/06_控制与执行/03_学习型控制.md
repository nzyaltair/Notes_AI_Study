# 学习型控制

## 一句话理解

学习型控制使用神经策略处理复杂感知和难建模动力学，但不应抛弃反馈与安全约束——最稳妥的架构是高层学习策略低频产生目标，低层 PID/MPC/阻抗控制高频执行。

## 概述

学习型控制（Learning-based Control）解决经典控制难以覆盖的问题：高维感知输入、复杂接触、难建模动力学。但学习模型无法提供稳定性保证与约束满足，因此核心问题是"学习与经典如何分工"：不是替代关系，而是互补关系。

## 发展历史

- **1990s**：神经网络控制萌芽（NN 逼近系统辨识、自适应控制）。
- **2010s**：深度 RL 进入机器人控制（DDPG 操作、PPO 运动）；端到端视觉运动策略。
- **2015-2020**：域随机化使仿真训练的策略可部署；残差控制（Residual Policy Learning）出现——经典策略 + 学习残差。
- **2020s**：扩散策略作为动作生成器；Neural MPC 将学习模型嵌入约束优化；人形全身 RL 控制成熟。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 神经控制 | 神经网络直接输出控制量 | 处理复杂映射 |
| 残差控制 | 经典控制 + 学习残差 | 安全 + 适应 |
| Neural MPC | 学习模型 + MPC 优化 | 约束 + 学习 |
| 行为克隆初始化 | 先用演示初始化 | 加速学习 |
| 安全盾 | 独立约束层 | 阻止危险动作 |
| 仿真-真机差距 | 训练分布与部署分布差异 | 核心挑战 |

## 技术原理

### 分工模式

| 方式 | 分工 | 代表 |
|---|---|---|
| Neural Controller | 从观测直接预测参考/控制量 | 端到端策略 |
| RL Control | 优化长期行为（平衡、接触、能耗） | PPO, SAC |
| Diffusion Policy | 生成多峰短动作序列 | 操作 |
| Neural MPC / Residual | 模型控制提供边界，网络补偿残差 | 稳定 + 适应 |

### 残差控制

残差策略学习（Residual Policy Learning）：

$$\pi_{total}(s)=\pi_{base}(s)+\pi_{residual}(s)$$

- 基线策略（如 PD 控制器、MPC）保证基本行为和安全。
- 残差策略从数据学习补偿模型误差和复杂动力学。

优势：安全性由基线保证、训练数据需求低、可解释。

### Neural MPC

Neural MPC 用学习模型替代解析模型：

$$\min_{u_{0:H-1}}\sum_{k}\ell(x_k,u_k)\quad \text{s.t. } x_{k+1}=f_\theta(x_k,u_k),\ (x_k,u_k)\in\mathcal X\times\mathcal U$$

- 学习动力学 \(f_\theta\) 覆盖复杂接触。
- MPC 优化保证约束满足。
- 风险：模型误差进入优化，需不确定性感知。

### 训练与部署

训练应模拟时延、传感噪声、执行误差和约束。部署分层：

```text
高层学习策略（低频，10-30 Hz）：感知、语义、任务目标
→ 中层规划/适配（IK、轨迹生成）
→ 低层控制器（高频，500 Hz-1 kHz）：PID/MPC/阻抗
→ 独立安全层：限幅、拒绝、急停
```

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| 端到端神经控制 | 观测→动作 | 简单映射 |
| PPO/SAC 控制 | 回报优化 | 动态平衡 |
| Diffusion Policy | 动作序列生成 | 操作 |
| Residual Policy | 经典 + 学习残差 | 安全关键 |
| Neural MPC | 学习模型 + 优化 | 约束操作 |
| 安全 RL (CPO) | 约束策略优化 | 受约束任务 |
| 自适应控制 | 在线参数估计 | 参数漂移 |

## 优势与局限

| 方法 | 优势 | 局限 |
|---|---|---|
| 端到端 | 免建模 | 无稳定性保证 |
| RL | 优化长期回报 | 样本、探索风险 |
| 残差 | 安全、数据高效 | 依赖基线质量 |
| Neural MPC | 约束 + 适应 | 模型误差敏感 |

## 应用场景

- 四足/人形动态运动：RL 步态 + 低层 WBC。
- 操作：扩散策略 + 阻抗控制。
- 装配：学习残差补偿模型误差。
- 无人机机动：学习动力学 + MPC。

## 常见问题

- **用学习替代反馈**：学习策略不能保证稳定性。
- **忽略训练模拟**：训练时没有时延/噪声，部署必失败。
- **残差过大**：残差策略应是小修正，不是主行为。
- **无安全层**：学习输出必须可被独立层拒绝。
