# 具身基础模型 综述

## 概述

具身基础模型（Embodied Foundation Models）是面向机器人与物理交互的基础模型，核心代表是视觉-语言-动作模型（Vision-Language-Action, VLA）。VLA 将视觉理解、语言指令和动作执行统一到一个模型中，是当前具身智能最重要的研究方向。

## 核心概念

### VLA 模型定义
- **Vision**：视觉感知环境状态
- **Language**：理解人类指令和任务描述
- **Action**：生成机器人控制动作
- 三者在同一模型中端到端统一

### 从 LLM 到 VLM 到 VLA
```
LLM (语言) → VLM (语言+视觉) → VLA (语言+视觉+动作) → 世界模型 + 动作模型
```

### 与传统机器人控制的区别
- 传统：模块化流水线（感知→规划→控制）
- VLA：端到端统一模型
- 传统：每个任务单独训练
- VLA：一个模型处理多种任务

## 主要模型系列

### 早期 VLA 模型
- **RT-1 (Robotics Transformer 1)**：Google, 2022
  - 首个大规模 VLA 模型
  - 语言条件策略学习
- **RT-2 (Robotics Transformer 2)**：Google, 2023
  - 基于视觉-语言模型的机器人策略
  - 知识迁移从网络数据到机器人

### 大规模 VLA
- **Octo**：开源通用机器人策略
- **OpenVLA**：开源 VLA 模型
- **π0 (Pi-Zero)**：Physical Intelligence, 2024
  - 流匹配 (Flow Matching) 动作生成
  - 通用机器人策略

### 机器人基础模型
- **RoboFlamingo**：基于 Flamingo 的机器人策略
- **GR-1**：视频预测+动作生成
- **3D-VLA**：3D 视觉-语言-动作

### 世界模型 + 动作模型
- **SuSIE**：子目标想象 + 执行
- **GenAug**：生成式数据增强
- **RoboDreamer**：视频世界模型驱动的规划

## 关键技术

### 动作表征
- 离散动作 token（VQ-VAE 编码）
- 连续动作（扩散/流匹配）
- 动作分块（Action Chunking）
- 相对 vs 绝对动作空间

### 训练策略
- 大规模预训练 + 机器人微调
- 互联网数据 → 机器人策略迁移
- 多任务多机器人训练
- 模拟数据 + 真实数据混合

### 数据工程
- Open X-Embodiment 数据集
- DROID 数据集
- 遥操作数据采集
- 合成数据生成

### 动作生成方法
- 自回归动作生成
- 扩散策略（Diffusion Policy）
- 流匹配（Flow Matching）
- 行为克隆 + 在线强化学习

## 与 AGI 的关联

VLA 是具身 AGI 的核心架构：
- **统一感知与行动**：一个模型从感知到执行
- **语言指令理解**：用自然语言控制机器人
- **跨任务泛化**：一个模型处理多种操作任务
- **知识迁移**：从互联网知识到物理世界行动

## 发展趋势

1. 更大规模 VLA：从数亿到数十亿参数
2. 通用机器人策略：一个模型适配多种机器人
3. 世界模型 + VLA：预测环境变化辅助决策
4. 长时序任务执行：VLA + 规划 + 记忆
5. Sim2Real 高效迁移
