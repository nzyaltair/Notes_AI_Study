# 视频基础模型

## 一句话理解

视频基础模型同时处理空间内容、事件顺序和长期一致性，连接视觉理解、生成与世界预测；视频生成逼真不等于掌握物理因果或动作后果。

时空 Transformer、掩码视频建模、视频生成和潜在状态预测是主要路径。关键挑战包括 token 成本、遮挡、镜头变化、身份/物理一致性和动作条件评测。
