# A 基础与范式：现代 AI 的前置理论层

> **定位**：A 不重复讲授深度学习、基础模型、强化学习、Agent、认知科学或 AI 工程；它提供理解这些方向所需的数学、优化、统计学习、概率推断与符号推理基础。

## 主线

```text
数学基础 → 优化理论 → 统计学习与传统机器学习
    ├→ 概率机器学习与贝叶斯智能
    └→ 符号主义 AI

A 的基础能力 → B 连接主义与深度学习 → C 基础模型
              → D 智能体与自主系统 → G 具身智能与物理智能
              → H 认知科学与脑启发 / I 高级智能理论 / K AI 工程化
```

## 跨板块学习建议

1. **现代模型主线**：数学 → 优化 → 机器学习 → B 深度学习 → C 基础模型。
2. **不确定性与决策主线**：概率统计 → 概率机器学习 → D 强化学习 → I 因果智能 → F 世界模型。
3. **推理与行动主线**：符号 AI → I 神经符号 → D Agent → G 具身控制。
4. **工程落地主线**：优化理论 → K 数据、训练、部署、MLOps 与评测。
