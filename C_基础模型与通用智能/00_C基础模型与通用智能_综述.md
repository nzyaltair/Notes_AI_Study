# C 基础模型与通用智能：能力形成层

## 一句话理解

本方向研究可复用模型能力如何从广泛数据、预训练目标、后训练与推理时计算中形成，并如何以表征、预测和动作接口服务于 Agent 与具身系统；它不等同于“已经实现通用智能”。

## 领域定义与边界

**基础模型（Foundation Model）**是在宽泛数据上以可扩展目标预训练，并能经提示、上下文、微调或工具增强适应多类下游任务的模型。其共同特征是预训练先验的复用，而非某个固定架构、模态或参数规模。

本方向处理模型层的能力形成与取舍：

- **包含**：预训练表征、语言/视觉/多模态模型、后训练与对齐、推理求解、模型效率、世界预测和动作条件模型。
- **不包含**：长期任务编排、记忆和工具治理（[[../D_智能体与自主系统/00_智能体与自主系统_综述|D 智能体与自主系统]]）；感知任务、数据集与评测细节（[[../E_感知与多模态智能/00_感知智能综述|E 感知与多模态智能]]）；物理控制和真机闭环（G）；部署运维（K）；安全治理（J）。

## 为什么会出现

早期机器学习通常针对单一任务、数据集和输出空间训练。自监督学习、Transformer 与规模化数据/计算使同一模型可先学习可迁移的统计结构，再以较低边际成本适应新任务。这个杠杆也会把数据偏差、鲁棒性缺陷和安全风险同步传递给下游系统，因此能力、评测和治理必须共同考虑。

## 能力形成链

```text
宽泛且受治理的数据 + 预测/对齐目标
                ↓
可迁移表征、生成先验与不确定性
                ↓
规模化预训练 → 适配与后训练
                ↓
候选生成 → 搜索/验证 → 测试时计算分配
                ↓
世界状态预测或动作条件策略
                ↓
Agent 的规划、工具、记忆与环境交互
```

该链表达依赖关系，不是通往 AGI 的线性“阶梯”：每一环都可能失效，并需要独立评测。

## 发展脉络

| 阶段 | 代表变化 | 长期意义 |
|---|---|---|
| 2013–2017 | 词向量、CNN/RNN 表征与迁移学习 | 证明预训练特征可复用 |
| 2017–2020 | Transformer、BERT/GPT、ViT、CLIP 与缩放规律 | 统一架构和自监督目标可在多任务迁移 |
| 2021–2022 | Foundation Model 概念、计算最优训练、指令对齐、扩散模型 | 从任务模型转向可适配模型与行为对齐 |
| 2023–2024 | 开源 LLM/VLM、长上下文、MoE、VLA、推理搜索 | 扩展模态、上下文和测试时求解能力 |
| 当前 | 推理训练、原生多模态、世界预测、效率协同 | 重点转向可靠性、数据质量、成本和真实环境泛化 |

## 评测与能力边界

不能由流畅输出、单一排行榜或展示案例推出“通用智能”。至少应分别测量：

1. **任务正确性与覆盖面**：分领域、分难度和分布外样本。
2. **校准、鲁棒性和安全行为**：置信度、提示注入、对抗与拒答边界。
3. **数据污染与可复现性**：训练—测试重叠、版本和评测协议。
4. **效率**：训练计算、测试时计算、延迟、吞吐和能耗。
5. **环境交互能力**：闭环成功率、恢复能力和安全约束。

统一评测方法论见 [[../K_AI工程化/07_AI评测体系/00_AI评测体系_综述|K AI 评测体系]]。
