# 安全生命周期与Safety Case

安全生命周期把风险控制嵌入开发与运营。Safety Case 是一组结构化主张、证据和论证：系统在给定用途、假设和边界内，风险已降至可接受水平。

## 生命周期

```text
用途界定 → 风险评估 → 安全需求 → 设计/训练 → 评测红队 → 发布门禁
   ↑                                                              ↓
复盘改进 ← 事故响应 ← 线上监控 ← 灰度部署与变更管理
```

证据可包括数据治理记录、威胁模型、评测结果、红队发现与修复、权限设计、监控告警、人工监督和演练记录。模型、工具、策略或用途更新后均应重新评估；上线不意味着安全工作结束。
