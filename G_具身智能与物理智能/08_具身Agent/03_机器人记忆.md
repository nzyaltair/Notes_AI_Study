# 机器人记忆

## 一句话理解

机器人记忆是具身 Agent 的长期状态：工作记忆支撑实时决策，空间记忆记录对象与地图，情景记忆复用经验，语义记忆提供常识——记忆必须带时间、来源和置信度，并支持更新与遗忘。

## 概述

记忆是具身 Agent 长程自主的核心组件。纯反应式策略无法完成"先放杯子、再拿牛奶、最后收拾台面"这类需要跨子任务状态的任务。机器人记忆研究如何组织、存储、更新和检索四类记忆（工作/空间/情景/语义），使 Agent 在长时间运行中保持一致、不重复、不遗忘、不信任过期信息。

## 发展历史

- **2000s-2010s**：语义地图（Semantic Map）作为空间记忆；机器人学中"记忆"主要停留在 SLAM 地图与状态估计。
- **2010s-2020s**：认知架构（Soar, ACT-R）中的记忆模型影响机器人设计；情景记忆进入机器人（经验复用、失败记忆）。
- **2020s**：LLM Agent 时代记忆成为热点——上下文记忆、向量检索记忆、情景记忆库；具身 Agent 的语义地图 + 经验记忆架构（SayCan, Voyager 类）。

## 记忆类型

| 类型 | 内容 | 更新频率 | 用途 |
|---|---|---|---|
| 工作记忆 | 当前目标、子任务、最新观测 | 每步更新 | 实时决策 |
| 空间记忆 | 对象、地图、关系与置信度 | 秒到分钟 | 定位、检索与导航 |
| 情景记忆 | 任务轨迹、失败、干预与结果 | 每次任务后 | 经验复用与恢复 |
| 语义记忆 | 物体常识、技能说明、规则 | 静态或缓慢 | 语言推理与规划 |

## 技术原理

### 工作记忆

- 内容：当前任务、子目标、最新感知状态。
- 机制：上下文窗口、短期缓冲。
- 挑战：容量限制、注意力选择（哪些信息进入工作记忆）。

### 空间记忆

空间记忆把几何与语义结合，支持"去厨房拿红色杯子"：

$$m_i=(\text{instance},{}^W\!T_i,\Sigma_i,\text{attributes},\text{relations},t_{last})$$

- 实现：语义地图、3D 场景图、向量记忆（语言特征）。
- 更新：物体被移动后必须更新；旧位置不能当作事实。
- 检索：语言查询 → 对象定位 → 导航/操作。

### 情景记忆

- 内容：过往任务的轨迹、成功/失败、人工干预、环境变化。
- 机制：经验库 + 检索（相似性、语言查询）。
- 用途：避免重复错误、复用成功策略、恢复时参考。

### 语义记忆

- 内容：物体常识（杯子的用途）、技能说明（open 技能的前置条件）、规则。
- 来源：预训练知识、规则库、经验总结。
- 机制：LLM 参数知识 + 显式知识库。

## 记忆管理原则

1. **时间戳**：每条记忆带时间，判断是否过期。
2. **来源与置信度**：区分"看到过""推断过""被告知"。
3. **更新机制**：新证据更新旧记忆，而非叠加矛盾。
4. **遗忘机制**：过期、低置信、无关记忆可遗忘。
5. **治理**：经验写入应经评估和版本治理，不能让一次异常交互污染长期行为。

## 记忆更新流程

```text
新观测 → 一致性检查（与旧记忆冲突？）
→ 更新对象状态/地图
→ 任务完成 → 情景记忆写入（成功/失败/干预）
→ 定期：过期清理、经验评估、语义总结
```

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| 语义地图 | 几何 + 语义标签 | 空间记忆 |
| 3D 场景图 | 对象关系图 | 长程任务 |
| 向量数据库 | 语言特征检索 | 情景/语义记忆 |
| LLM 上下文 | 工作记忆窗口 | 实时决策 |
| 经验库 | 任务结果存储 | 恢复与复用 |
| 记忆治理 | 版本化 + 评估 | 长期维护 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 长程一致性 | 跨子任务状态 | 更新成本 |
| 经验复用 | 避免重复错误 | 记忆污染风险 |
| 语言可查询 | 语义检索 | 精度不足 |
| 结构化 | 可验证 | 构建成本 |

## 应用场景

- 家居任务：跨房间找物、追踪进度。
- 服务机器人：记住用户偏好。
- 长程巡检：多轮任务状态保持。
- 人形操作：任务中记忆中间状态。

## 常见问题

- **把旧位置当事实**：物体被移动后，旧位置不能被当作事实。
- **记忆无治理**：一次异常交互污染长期行为。
- **只存不查**：记忆没有检索机制等于没有记忆。
- **无限累积**：必须有过期与遗忘机制。
