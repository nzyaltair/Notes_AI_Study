# 前沿综述与发展脉络

## 一句话理解

具身智能不是 2023 年凭空出现的热词，而是机器人学、认知科学、控制理论和深度学习数十年交叉积累的结果。了解脉络有助于判断哪些是真正的进步，哪些是周期性回潮。

## 1. 发展脉络

### 早期（1940s–1980s）：控制与行为主义

- 1948：Wiener 的控制论提出反馈闭环思想。
- 1961：Unimate 工业机器人进入生产线。
- 1966：SHAKEY 首次集成感知、搜索和规划。
- 1986：Brooks 的 Subsumption 架构强调行为分层和实时反应，反对"感知—规划—行动"的串行流水线。

这一阶段的争论——智能是否需要内部表征——在今日端到端 vs 模块化的辩论中仍有回响。

### 中期（1990s–2010s）：感知定位与学习

- 1990s–2000s：SLAM 使移动机器人能够在未知环境中定位和建图。
- 2005：DARPA Grand Challenge 推动自动驾驶系统集成。
- 2010s：深度学习进入机器人感知（目标检测、语义分割、6D 位姿估计），但控制层仍以经典方法为主。

### 近期（2020s）：大模型与具身智能融合

- 2022：SayCan/Inner Monologue 将 LLM 与机器人技能库结合，展示语言条件任务执行。
- 2023：RT-2 展示视觉—语言知识向机器人动作的迁移；PaLM-E 将多模态语言模型与具身观测结合。
- 2023：Open X-Embodiment 推动跨机器人数据规模化；Diffusion Policy 提出动作序列生成的扩散范式。
- 2024：OpenVLA 开源 VLA 训练与适配基线；人形机器人（Atlas、Optimus、Figure、Unitree）快速迭代；世界模型与视频预测应用于机器人规划。
- 2025–：通用操作策略、大规模真机评测、灵巧手操作和长程家居 Agent 成为竞争焦点。

## 2. 产业图景

| 层级 | 代表公司/机构 | 核心方向 |
|---|---|---|
| 基础模型 | Google DeepMind, NVIDIA, OpenAI | VLA、世界模型、仿真基础设施 |
| 人形硬件 | Tesla, Figure, Unitree, Boston Dynamics, 1X | 全身运动 + 操作 |
| 灵巧手/触觉 | Shadow, LEAP, GelSight, 机器人公司自研 | 触觉传感器 + 精细操作 |

| 家居/服务 | Hello Robot, 多家初创 | 家居操作与导航 |
| 自动驾驶 | Waymo, Tesla, 华为 | 特殊形式的具身智能（轮式） |

## 3. 当前开放问题

### 3.1 通用操作

- 如何在开放物体和场景上达到可靠的成功率？
- 如何统一不同机器人形态的动作空间和数据规范？
- 如何从少量演示泛化到新物体和新任务？

### 3.2 接触与柔性物体

- 如何鲁棒地处理摩擦、柔性、形变和不确定接触？
- 布料、绳索、液体和食物的操作仍是开放问题。
- 触觉—视觉联合学习如何降低对精确力控模型的依赖？

### 3.3 长程任务与恢复

- 超过 50 步的家居任务如何在真实环境可靠完成？
- 失败检测、归因和自动恢复如何系统化？
- 如何避免 Agent "忘记"已完成的子任务或忽略环境变化？

### 3.4 仿真—现实

- 柔性/接触的 sim-to-real 差距如何缩小？
- 真机数据的采集成本和覆盖范围如何平衡？
- 统一的仿真—真机评测基准何时出现？

### 3.5 安全与评测

- 如何定义和度量具身系统的"安全"？
- 统一的具身评测基准（覆盖任务、泛化、安全、鲁棒性）是否可能？
- 如何从演示视频和排行榜走向可复现的真机实验？

### 3.6 硬件瓶颈

- 灵巧手的成本、耐久性和集成如何突破？
- 人形机器人的能耗、可靠性和维护何时达到工业级？
- 触觉传感器的耐久性、密度和信号质量如何提升？

## 4. 研究趋势与判断

| 趋势 | 判断 | 误区 |
|---|---|---|
| VLA 规模化 | 必然方向，但不等于通用物理能力 | 以为参数规模自动解决精度和安全 |
| 世界模型 | 对规划和恢复有价值，但不是"真正的世界" | 混淆预测逼真度和物理正确性 |
| 人形机器人热潮 | 硬件快速迭代，但自主智能仍远 | 演示视频 ≠ 日常可靠运行 |
| 跨本体数据 | 高层语义迁移可行，低层动作仍需适配 | 忽略不同本体的物理约束差异 |
| 仿真至上 | 仿真对训练和评测必要但不够 | 仿真排行榜 ≠ 真机可靠性 |
| 端到端 vs 模块化 | 长期看是混合架构，不是二选一 | 任何一侧的极端都不够安全或泛化 |

## 5. 中国具身智能生态

中国在具身智能领域发展迅速：政策层面将具身智能列入重点方向；产业层面涌现人形机器人公司（优必选、智元、宇树等）；学术层面在操作学习、仿真平台和数据集上持续产出；开源层面 ManiSkill、RoboMIND 等项目推动社区发展。核心挑战仍在于真机数据的规模和质量、评测的标准化，以及从演示到工业级可靠性的跨越。
