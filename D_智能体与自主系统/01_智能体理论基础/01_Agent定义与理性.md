# Agent 定义与理性

## 一句话理解

智能体（Agent）是在观察历史、目标和约束下选择行动的系统——它区别于纯推理程序的关键在于**能通过行动改变环境状态**；理性不等于永远正确，而是在可用信息、计算预算与安全边界内最大化期望效用。

## 概述

一个数学题求解器可以展现复杂的推理链，但它不是智能体：它没有观察环境（输入是静态问题）、不能产生影响环境的行动（输出是答案，而非作用于外部世界的动作）、也没有从行动结果中学习的反馈通道。**智能体必须与环境交互**，这是一个根本性的区别。

智能体理论的任务就是回答三个问题：什么是 Agent？什么是理性？自主性如何定义？本笔记聚焦这三个问题的形式化答案，是 [[00_智能体理论基础_综述|智能体理论基础]] 的核心概念基础。

| 年代 | 里程碑 | 意义 |

## 核心概念

### Agent 的定义

**弱定义（Wooldridge & Jennings, 1995）**：一个 Agent 应具备以下属性的硬件或软件系统：
- **自主性（Autonomy）**：无需人类或其他系统的直接干预，能控制自身行动和内部状态
- **社会性（Social Ability）**：能通过某种通信语言与其他 Agent（包括人类）交互
- **反应性（Reactivity）**：能感知环境并对环境变化做出及时响应
- **主动性（Pro-activeness）**：不仅能对环境做出反应，还能主动展示目标导向的行为

**强定义**：在弱定义的基础上，Agent 还应具有信念、愿望、意图等认知属性（即 [[02_决策理论与BDI|BDI 模型]]）。

### 理性的形式化

Russell & Norvig 的理性 Agent 定义：**理性 Agent 选择能最大化其性能度量（performance measure）期望值的动作**，给定其感知历史和内置知识。形式化表示为：

$$ a^* = \arg\max_{a} \mathbb{E}[U(\text{outcome}) - C(\text{risk}, \text{resource}) \mid h_t] $$

其中：
- $h_t = (o_1, a_1, o_2, a_2, \ldots, o_t)$ 是观察-动作历史
- $U$ 是目标效用函数，衡量"多好地完成了任务"
- $C$ 是风险与资源成本函数，量化"这步动作的风险有多大"
- 期望在环境转移概率 $P(s_{t+1} \mid s_t, a_t)$ 和观察概率 $P(o_{t+1} \mid s_{t+1})$ 上计算

**理性 ≠ 完美**：理性 Agent 受限于可用信息（部分可观测）、计算能力（有限推理时间）和不确定性（随机环境），它在约束下做"最好"的选择，而非"理论上最优"的选择。

### 自主性

自主性不是二分的（是/否），而是连续的属性，体现在以下维度上逐步减少对人工指令的依赖：

| 自主程度 | 描述 | 示例 |
|:---|:---|:---|
| L0: 无自主 | 完全人工操作 | 直接执行每步指令 |
| L1: 辅助 | 辅助决策，但最终由人确认 | 自动补全 |
| L2: 条件自主 | 在限定范围内自主执行 | 触发式自动化 |
| L3: 部分自主 | 常规任务自主，异常时求助 | 客服 Agent（标准问题自主，复杂问题转人工） |
| L4: 高度自主 | 大部分任务自主，仅关键决策需审批 | 编程 Agent（大部分代码自主完成，关键变更需人工审核） |
| L5: 完全自主 | 无需人工干预 | 理论上的极限，目前无实际系统 |

## 技术原理

### Agent 类型谱系

| Agent 类型 | 状态 | 模型 | 目标 | 适用场景 |
|:---|:---|:---|:---|:---|
| 简单反射 Agent | 只有当前感知 | 无 | 无 | 简单反应式任务（恒温器） |
| 基于模型的 Agent | 维护内部状态 | 有世界模型 | 无 | 部分可观测环境（导航） |
| 目标导向 Agent | 维护内部状态 | 有世界模型 | 有显式目标 | 单目标规划（路径规划） |
| 效用导向 Agent | 维护内部状态 | 有世界模型 | 有效用函数 | 多目标权衡（资源分配） |
| 学习 Agent | 维护内部状态 | 可学习的世界模型 | 可学习的目标 | 适应新环境 |

### LLM Agent 的理性问题

LLM 作为 Agent 的"推理引擎"带来了新的理性问题：

1. **语言推理不等于理性决策**：LLM 可以生成看似合理的推理链，但推理过程可能包含系统性偏差，且模型无法保证在给定约束下做出真正最大化的选择
2. **信心不等于准确度**：LLM 可能在错误推理上充满信心，在正确推理上犹豫不决，缺乏理性 Agent 所需的不确定性量化
3. **长期目标维护困难**：LLM 的上下文窗口有限，在多步任务中容易"忘记"初始目标，偏离原有意图——这正是 BDI 中"意图承诺"问题的现代版本

## 关键方法与模型

| 方法/框架 | 核心思想 | 来源 |
|:---|:---|:---|
| 理性 Agent 定义 | 最大化期望效用 | Russell & Norvig, 1995 |
| Agent 弱/强定义 | 自主性、社会性、反应性、主动性 | Wooldridge & Jennings, 1995 |
| 有限理性 | 在计算和信息约束下做决策 | Simon, 1957 |
| 预期效用理论 | 在不确定性下做理性决策的数学框架 | von Neumann & Morgenstern, 1944 |

## 优势与局限

**优势**：Agent 定义和理性形式化提供了 AI 系统设计的理论指导——明确了"什么算好的决策"和"什么算自主行为"；理性 Agent 框架可以统一各种 AI 方法（搜索、规划、学习）在同一个目标函数下。

**局限**：经典理性定义假设 Agent 已知效用函数和环境转移概率，这在开放世界中往往不成立；理性 Agent 框架没有告诉我们应该如何"学会"理性——它定义目标，但不提供学习方法；LLM 与理性 Agent 之间存在鸿沟：LLM 的语言推理能力不等于理性决策能力。

## 应用场景

- **Agent 系统设计目标**：将理性定义为"最大化期望效用"为 Agent 系统提供了明确的设计目标
- **自主性分级**：自主性连续空间为设计人机协作系统提供了参考框架
- **Agent 评测**：理性 Agent 框架可指导 Agent 评估指标的设计（如任务成功率、效率、风险控制）

## 前沿发展

- **从理性到校准**：理性 Agent 要求效用最大化，校准 Agent 要求"知道自己的不确定性"——两者结合是现代 AI 安全的重要方向
- **可学习的理性**：通过强化学习从经验中学习"什么算好的决策"，而不是预先定义效用函数
- **LLM 作为理性 Agent 的评估**：如何评估 LLM Agent 是否"理性"——是否能在给定约束下做出期望效用最大化的决策，而非仅依赖语言流畅性

## 常见问题

**Q: 理性 Agent 和强化学习策略有什么区别？**
理性 Agent 是一个理论框架，定义"什么算好的决策"；强化学习策略是理性 Agent 的一种实现方式——通过最大化累积奖励来近似理性决策。两者在"最大化期望效用"上等价，但理性 Agent 的定义更一般，不限于强化学习。

**Q: LLM 是理性 Agent 吗？**
LLM 有语言推理能力，但缺乏理性 Agent 的关键要素：它没有稳定的目标函数、没有可靠的不确定性量化、没有从行动结果中学习的机制。LLM 可以成为 Agent 的"推理引擎"（如 ReAct 循环中的 Thought 生成），但整个系统需要额外组件（环境接口、记忆、学习机制）才能成为完整的理性 Agent。
