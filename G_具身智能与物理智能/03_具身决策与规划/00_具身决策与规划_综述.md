# 具身决策与规划综述：从意图到行动的桥梁

## 一句话理解

具身决策是将高级意图转化为可执行动作序列的过程——从"我想喝咖啡"到"走到厨房→打开柜子→拿出杯子→操作咖啡机"，具身规划需要同时考虑物理约束、时空顺序和任务依赖。

## 1. 领域定义

具身决策与规划研究机器人如何将高级目标分解为物理可执行的动作序列。与经典规划的不同在于：状态空间是连续的、动作有物理约束、需要感知-行动闭环。

### 决策层次

| 层级 | 时间尺度 | 内容 | 方法 |
|------|----------|------|------|
| 任务规划 | 秒-分钟 | 做什么任务，什么顺序 | LLM/Symbolic |
| 运动规划 | 毫秒-秒 | 怎么移动，路径 | RRT/PRM/MPC |
| 控制执行 | 毫秒 | 关节力矩/速度 | PID/阻抗 |

## 2. 核心方法

### 2.1 任务规划

| 方法 | 核心思想 | 代表 |
|------|----------|------|
| LLM 规划 | 自然语言任务分解 | SayCan, Inner Monologue |
| 符号规划 | PDDL/HTN 形式化 | Classic Task Planning |
| 混合规划 | LLM + 符号验证 | LLM + PDDL Planner |
| 代码规划 | 生成代码表示计划 | Code-as-Plan |

### 2.2 操作规划

| 问题 | 方法 | 挑战 |
|------|------|------|
| 抓取规划 | 抓取姿态采样 + 评估 | 多样性与鲁棒性 |
| 放置规划 | 稳定放置姿态搜索 | 物理约束 |
| 推/拉规划 | 非抓取操作 | 接触力学 |
| 铰接物体 | 关节操作规划 | 未知运动学 |

### 2.3 导航规划

| 方法 | 地图类型 | 特点 |
|------|----------|------|
| 全局规划 | 拓扑/语义图 | 长距离路径 |
| 局部规划 | 占据栅格 | 避障与动态 |
| 社交导航 | 行人模型 | 人机共存 |
| 语义导航 | 语言指令导航 | 语言到位置的映射 |

### 2.4 长程任务

- 任务链：多个子任务的串行/并行执行
- 错误恢复：子任务失败时的重规划
- SayCan 范式：LLM 规划 + affordance 验证

## 3. 与 AGI 的关系

- **Agent 的物理延伸**：规划是 Agent 在物理世界的行动方案
- **层次决策**：AGI 需要多层次的决策能力
- **世界模型的验证**：规划需要世界模型来预测行动后果
- **持续学习的场景**：长期操作中的经验积累

## 4. 学习路径

1. 理解经典任务规划 (PDDL)
2. 学习 LLM 驱动的任务规划 (SayCan)
3. 研究抓取和操作规划
4. 探索层次化规划架构
5. 研究长程任务的错误恢复
