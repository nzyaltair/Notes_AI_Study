# 反思与自我改进综述：Agent 如何从错误中学习

## 一句话理解

反思是 Agent 评估自身行动结果、识别错误并调整策略的能力——从简单的"再试一次"到系统性的"分析失败原因并改进策略"，反思是 Agent 从"执行器"进化为"学习者"的关键一步，也是迈向持续学习的过渡能力。

## 1. 领域定义

### 反思 (Reflection)

Agent 在执行任务后，回顾行动过程和结果，识别成功与失败的原因，形成经验教训存入记忆，以指导未来行动。

### 与持续学习的区别

| 维度 | 反思 | 持续学习 |
|------|------|----------|
| 改变层面 | 行为策略（提示/记忆） | 模型权重 |
| 学习方式 | 语言层面总结 | 梯度更新 |
| 持久性 | 会话内/记忆存储 | 永久权重变化 |
| 计算成本 | 低 | 高 |
| 当前可行性 | 已可行 | 仍为瓶颈 |

反思是持续学习的"轻量级替代"——在无法修改权重时，通过语言层面的经验积累来弥补。

## 2. 核心方法

### 2.1 基于反思的方法

| 方法 | 核心思想 | 代表 |
|------|----------|------|
| Reflexion | 语言反馈 + 自我评估 | Shinn et al. |
| Self-Refine | 迭代生成-批评-改进 | Madaan et al. |
| LATS | 树搜索 + 反思 | Zhou et al. |
| CRITIC | 外部工具验证 + 修正 | Gou et al. |
| Self-Correction | 自我纠错循环 | 上下文内修正 |

### 2.2 自我评估

| 能力 | 描述 | 挑战 |
|------|------|------|
| 结果评估 | 判断输出是否正确 | 需要判断标准 |
| 过程评估 | 判断推理过程是否合理 | 步级验证困难 |
| 置信度校准 | 评估自身确定性 | 过度自信 |
| 知识边界 | 知道自己不知道什么 | 盲区不可见 |

### 2.3 经验积累

| 机制 | 描述 | 实现 |
|------|------|------|
| 成功经验 | 记录成功策略 | Skill Library |
| 失败教训 | 记录失败原因 | 避免重复错误 |
| 策略模式 | 抽象可复用的行动模式 | 规则/提示模板 |
| 情景记忆 | 具体经历的存储 | 向量记忆 |

### 2.4 外部反馈

| 来源 | 特点 | 代表 |
|------|------|------|
| 人类反馈 | 最可靠但成本高 | RLHF |
| 工具验证 | 自动化但有限 | 代码执行、搜索验证 |
| 模型自评 | 低成本但可能不准 | Self-Critique |
| 环境反馈 | 任务信号但稀疏 | RL Reward |

## 3. 发展历史

1. 2023：Reflexion 提出语言反思框架
2. 2023：Self-Refine 迭代自改进
3. 2024：LATS 统一搜索与反思
4. 2024：过程奖励模型 (PRM) 训练反思能力
5. 2025-26：反思成为 Agent 标配能力

## 4. 与 AGI 的关系

- **持续学习的过渡**：反思是"无法改权重时的学习"
- **自我迭代的前提**：AI 必须能评估和改进自身
- **安全的保障**：反思能力让 Agent 能检测自身错误
- **元认知的体现**：反思本质上是元认知的实践

## 5. 学习路径

1. 理解 Reflexion 的语言反思框架
2. 学习 Self-Refine 的迭代改进
3. 研究自我评估与置信度校准
4. 探索反思 + 搜索的结合 (LATS)
5. 思考反思如何过渡到持续学习
