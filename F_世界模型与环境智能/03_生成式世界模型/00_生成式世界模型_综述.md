# 生成式世界模型综述：从逼真生成到可交互模拟

> 生成式世界模型以视频、3D、轨迹或多模态 token 的形式生成条件未来。它为数据合成、情景推演和交互训练提供高容量模拟器，但视觉逼真并不自动证明物理正确或可用于规划。

## 三条主线

1. [[01_视频世界模型\|视频世界模型]]：从历史视频、文本和动作生成未来视觉状态。
2. [[02_扩散世界模型\|扩散世界模型]]：利用去噪过程表达复杂、多模态未来分布。
3. [[03_交互式模拟器\|交互式模拟器]]：把用户/Agent 动作纳入生成循环，形成可控制训练环境。

## 能力链

```text
条件（观测、文本、动作、地图）
            ↓
空间/时间 token 或潜变量
            ↓
自回归、扩散或混合式未来生成
            ↓
物理/语义约束、动作响应与状态更新
            ↓
交互、规划、数据生成或训练
```

## 关键区分

- **开放环视频生成**：重点是视觉质量与时间连贯。
- **行动条件生成**：必须对同一状态下不同动作给出可区分、合理后果。
- **可交互世界模拟器**：要求持续状态、低延迟、可控规则、碰撞/任务约束与闭环评估。

生成模型可作为世界模型的观测预测器，但仍需与 [[../01_世界模型理论/00_世界模型理论_综述|动力学与规划]]、[[../07_世界模型评估与前沿/00_世界模型评估与前沿_综述|闭环评估]] 相结合。
