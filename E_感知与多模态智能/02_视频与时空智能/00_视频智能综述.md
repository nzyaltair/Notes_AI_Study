# 视频智能综述

视频智能把离散帧升级为连续环境观测：系统需要同时理解外观、运动、事件、轨迹和跨时间的状态变化。

## 任务层次

```text
视频表示 → 动作/事件理解 → 跟踪与时序定位 → 长视频记忆与时空推理
```

## 导航

- [[01_视频表示与理解]]：动作识别、时空特征、视频分割与多目标跟踪。
- [[02_时序定位与跟踪]]：检测-关联、身份一致性、动作定位和预测。
- [[03_时空推理与长视频记忆]]：事件因果、跨片段检索、长期状态。
- [[04_视频生成与世界预测接口]]：从视频生成到环境预测的边界；预测模型细节参见 F 世界模型。

视频生成的扩散与训练细节属于 [[C_基础模型与通用智能/04_多模态基础模型/00_多模态基础模型_综述|C 多模态基础模型]] 和 B 生成模型。本模块强调它作为连续感知、数据合成和世界预测观测接口的作用。
