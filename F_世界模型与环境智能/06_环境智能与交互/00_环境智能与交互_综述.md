# 环境智能与交互综述：在行动中学习世界

> 环境智能把静态模型变成持续闭环：系统观察环境、选择有信息价值或任务价值的动作、接受反馈、更新内部状态并适应新情境。

## 交互闭环

```text
观测 / 目标 → 状态估计 → 选择行动或查询
     ↑                              ↓
模型更新 ← 反馈、奖励、失败与人类校正 ← 环境接口
```

## 与 Agent / 具身的分工

D 关注 Agent 的架构和任务编排；G 关注物理载体与执行；F.06 聚焦“环境提供什么接口、智能体如何通过交互识别规律、如何把反馈更新为世界模型”。

## 核心原则

探索并非随机试错：它应平衡信息增益、任务收益、成本与安全。任何环境接口都应显式描述观测延迟、动作有效范围、奖励含义、终止条件、不可逆副作用和版本信息。
