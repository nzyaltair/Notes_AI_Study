# 多视角立体与深度补全

## 一句话理解

多视角立体（MVS）由多张已知或待估位姿的图片，以跨视角一致性恢复稠密场景几何；深度补全（Depth Completion）则将稀疏 LiDAR/雷达/RGB-D 深度和 RGB 图像融合，补成边缘清晰、尺度可靠的稠密深度图。

## 多视角立体（MVS）

### 基本问题

输入为 \(N\) 张具有内外参的图像 \(\{I_i,K_i,T_i\}\)。对于参考相机的每个像素和候选深度，MVS 把该点投影到源视图，比较其特征一致性，选择最符合多视图观测的深度。SfM 通常先提供相机位姿和稀疏点云，MVS 再稠密化几何。

### 平面扫描与代价体积

深度学习 MVS 的典型流程：

```text
SfM/已知位姿 + 多图像
  → 每图提取特征
  → 在候选深度平面上可微重投影（homography warp）
  → 聚合多视图特征，形成 3D cost volume
  → 3D CNN / Transformer 正则化
  → 深度回归、置信度过滤、深度图融合为点云/网格
```

MVSNet 以可微单应变换和方差聚合构造代价体积，是学习式 MVS 的里程碑。它在深度采样数、图像分辨率和显存间存在明显权衡。

### PatchMatch 与高效 MVS

PatchMatchNet 不再为每个像素建立完整均匀深度体积，而是在空间传播中迭代采样和优化少量深度假设。该路线以较低显存实现高分辨率重建，适合大场景和工程实践。CasMVSNet、Fast-MVSNet 等则通过 coarse-to-fine 级联缩小搜索范围。

| 方法族 | 深度假设 | 优势 | 局限 |
|:---|:---|:---|:---|
| MVSNet / R-MVSNet | 全局离散深度平面 | 表达直接、易端到端训练 | 显存和计算随深度采样增长 |
| CasMVSNet | 多阶段粗到细 | 高效缩窄范围 | 早期阶段错误会传播 |
| PatchMatchNet | 迭代随机采样/传播 | 高分辨率、低显存 | 对初始化、纹理和视角覆盖敏感 |
| 神经场/3DGS | 连续场或高斯集合优化 | 新视角质量高 | 与通用 MVS 深度评测目标不同 |

MVS 与 [[05_神经场与GaussianSplatting]] 关系紧密：后者也从多视图恢复场景，但优化目标常更偏向新视图合成，不能只凭渲染质量推断几何一定精确。

## 深度补全（Depth Completion）

### 输入与目标

设 RGB 图像为 \(I\)，稀疏或有孔洞深度为 \(D_s\)，目标是预测稠密米制深度 \(D\)。稀疏深度提供可靠尺度，RGB 提供物体边缘和纹理；关键是防止 RGB 的语义边界把错误深度“涂抹”到不连续处。

典型输入包括：

- 车载 LiDAR 投影：远距离、户外、稀疏且存在遮挡投影误差；
- RGB-D/ToF：室内相对稠密，但透明/反光表面或强光下存在缺失；
- 毫米波雷达：尺度和全天候性较好，但点极稀疏、噪声与多径显著。

### 代表方法

| 方法 | 思路 | 适用特点 |
|:---|:---|:---|
| GuideNet | RGB 引导的动态滤波/特征融合 | 通过图像结构补全深度 |
| NLSPN | 非局部空间传播网络 | 在可靠锚点之间学习传播邻域，改善边界 |
| PENet / KBNet | 几何卷积、可学习投影/融合 | 面向 KITTI 等 RGB-LiDAR 深度补全 |
| 雷达-相机单阶段融合（如 TacoDepth） | 以雷达点结构和层次特征融合 | 适合提升恶劣天气冗余，需处理噪声与多径 |
| 基础模型蒸馏式补全（如 DMD³C） | 将单目基础模型的细粒度先验蒸馏到补全网络 | 2025 年后基准中的新趋势，需在统一协议下比较 |

### 基准更新与阅读方式

KITTI 官方深度补全基准提供超过 9.3 万张与原始 LiDAR 扫描、RGB 图像对齐的深度图，并以 iRMSE、iMAE、RMSE、MAE 排行。其榜单已出现“蒸馏单目基础模型用于细粒度深度补全”的 DMD³C（CVPR 2025）等方法，说明单目基础模型正在成为多传感器几何任务的先验来源。

读取榜单时必须同步记录：输入是否使用 RGB、是否引入外部训练数据、深度密度插值策略、运行时硬件/语言，以及评价的是深度还是逆深度。不同设置的名次不能直接解释为算法本体的绝对优劣。

## 传感器融合原则

1. **先校准，后学习**：相机-LiDAR 外参、畸变、时间戳错位会表现为系统性深度边缘漂移，不能指望网络完全学习补偿。
2. **保留观测置信度**：稀疏点的反射强度、量测方差、遮挡状态应作为特征或筛选条件。
3. **区分早/中/晚融合**：早融合在输入层拼接，简单但对错位敏感；特征融合更灵活；后端图优化能保持物理可解释性。
4. **评估长尾失效**：雨雾、强日照、玻璃、黑色材质、运动物体和传感器污渍是关键压力场景。
