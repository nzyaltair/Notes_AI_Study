# 控制理论综述：从反馈到最优控制

## 一句话理解

控制理论研究如何在动态系统中通过反馈机制使系统行为达到期望目标——它是机器人、自动驾驶和具身智能的数学基础，也是 AGI 从"思考"走向"行动"的关键桥梁。

## 1. 领域定义

控制理论（Control Theory）是研究动态系统行为调控的数学分支。核心问题：给定一个动态系统，如何设计控制输入使系统状态沿着期望轨迹运动，并在受到扰动时保持稳定。

### 核心概念

| 概念 | 含义 | 数学表示 |
|------|------|----------|
| 状态 | 描述系统的内部变量 | x(t) |
| 控制 | 施加到系统的输入 | u(t) |
| 输出 | 可观测的系统量 | y(t) |
| 反馈 | 根据输出调整控制 | u = f(y) |
| 稳定性 | 扰动后回归平衡 | Lyapunov 稳定性 |

## 2. 为什么 AI 需要控制理论

- **具身智能**：机器人控制 = 控制理论的直接应用
- **自动驾驶**：路径跟踪、避障、车队控制
- **强化学习的关系**：RL 是"试错学习控制策略"，控制理论是"解析设计控制律"
- **最优性**：最优控制给出理论最优，RL 给出近似最优
- **安全约束**：控制理论提供硬约束保证（稳定性、安全集），RL 往往不能

## 3. 核心方法

### 3.1 经典控制

| 方法 | 核心思想 | 适用场景 |
|------|----------|----------|
| PID 控制 | 比例+积分+微分 | 工业控制标准 |
| 频域分析 | 传递函数 + Bode 图 | 线性时不变系统 |
| 根轨迹法 | 极点配置 | 系统稳定性设计 |
| 奈奎斯特判据 | 频域稳定性判据 | 反馈系统稳定性 |

### 3.2 现代控制（状态空间）

| 方法 | 核心思想 | 适用场景 |
|------|----------|----------|
| 状态反馈 | u = -Kx | 全状态可测 |
| 观测器设计 | 从输出估计状态 | 部分可测 |
| LQR | 线性二次调节器 | 线性系统最优控制 |
| LQG | LQR + 卡尔曼滤波 | 带噪声系统 |
| 极点配置 | 任意配置闭环极点 | 系统性能设计 |

### 3.3 最优控制

| 方法 | 核心思想 | 代表 |
|------|----------|------|
| 变分法 | 泛函极值 | Euler-Lagrange |
| 庞特里亚金最大值原理 | 最优控制的必要条件 | PMP |
| 动态规划 | Bellman 最优性原理 | HJB 方程 |
| LQR/LQG | 线性系统解析最优 | Riccati 方程 |

### 3.4 模型预测控制 (MPC)

核心思想：在每个时刻求解有限时域最优控制问题，只执行第一步，然后滚动优化。

- 线性 MPC：凸优化，实时可行
- 非线性 MPC (NMPC)：非凸，计算量大但更灵活
- 鲁棒 MPC：考虑模型不确定性的 MPC

### 3.5 卡尔曼滤波

| 变体 | 特点 | 适用场景 |
|------|------|----------|
| 标准 KF | 线性高斯 | 线性系统 |
| 扩展 KF (EKF) | 一阶泰勒线性化 | 弱非线性 |
| 无迹 KF (UKF) | 无迹变换 | 中等非线性 |
| 粒子滤波 | 蒙特卡洛采样 | 强非线性/非高斯 |

### 3.6 鲁棒控制与自适应控制

- H∞ 控制：最坏情况下的最优性能
- 滑模控制：不连续控制律，对匹配扰动不变
- 自适应控制：参数在线更新
- Model Reference Adaptive Control (MRAC)

## 4. 发展历史

1. 1868：Maxwell 调速器稳定性分析
2. 1932：Nyquist 稳定性判据
3. 1940s：Bode 图、PID 标准化
4. 1960：Kalman 滤波、状态空间法
5. 1960s：LQR、动态规划 (Bellman)
6. 1980s：H∞ 鲁棒控制、MPC 工业应用
7. 2000s：MPC 在汽车和机器人中的应用
8. 2010s：控制 + 深度学习融合（深度 RL、神经网络 MPC）
9. 2020s：学习型控制、Sim2Real、安全 RL

## 5. 与 AGI 的关系

- **具身智能的数学基础**：机器人控制需要控制理论
- **RL 的理论参照**：最优控制是 RL 的连续版本
- **安全保证**：控制理论可提供稳定性/安全性的硬保证
- **Sim2Real**：模型失配的鲁棒性是 Sim2Real 的核心挑战

```
AGI 阶梯中的位置：

语言模型 → CoT → Agent → 持续学习 → 奇点 → [具身智能]
                                               ↑
                              控制理论是具身智能的
                              数学基础和执行保障
```

## 6. 学习路径

1. 理解反馈控制的基本概念（PID）
2. 学习状态空间表示与 LQR
3. 理解卡尔曼滤波（状态估计）
4. 学习 MPC（滚动优化控制）
5. 研究最优控制与动态规划的关系
6. 探索控制 + 深度学习的融合

## 7. 未来趋势

- 学习型控制（Neural + MPC 混合）
- 安全 RL（控制理论约束 RL）
- 大模型驱动的控制策略
- 分层控制 + 高层规划
- Sim2Real 的鲁棒性保证
