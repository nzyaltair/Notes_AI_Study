# 全模态输入输出与评估

## 一句话理解

全模态输入输出与评估研究一个系统如何接收和产生文本、图像、音频、视频等多种模态的信息——核心问题是不同模态的编码、同步、融合和输出契约。

## 概述

全模态（Any-to-Any）感知系统需要处理多种输入和输出模态。与单模态系统不同，全模态系统必须解决模态间的编码差异、时间同步和融合策略。

## 核心问题

| 问题 | 说明 | 候选方案 |
|:---|:---|:---|
| 模态编码 | 不同模态如何统一编码 | 离散 token / 连续特征 / 混合 |
| 时间同步 | 不同采样率的模态如何对齐 | 时间戳 / 帧同步 |
| 融合策略 | 多模态信息如何组合 | 早期融合 / 交叉注意力 / 晚期融合 |
| 输出类型 | 理解和生成编码是否共享 | 解耦编码器 / 共享编码器 |
| 缺失处理 | 模态缺失时的推理策略 | 掩码 / 插补 / 鲁棒训练 |

## 输出契约

感知系统输出应包含：

| 维度 | 说明 |
|:---|:---|
| 语义标签 | 类别、属性、关系 |
| 空间坐标 | 位置、姿态、尺寸 |
| 时间戳 | 帧率、事件时间 |
| 置信度 | 不确定性量化、校准度 |
| 证据链 | 原始观测引用、可追溯性 |

## 当前状态

- GPT-4o 和 Gemini 展示了全模态交互的可行性
- 开源 Any-to-Any 模型仍在早期（NExT-GPT, AnyGPT）
- 模态对齐粒度仍是瓶颈
- 全模态评测体系缺失
