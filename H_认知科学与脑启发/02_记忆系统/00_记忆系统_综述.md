# 记忆系统 (Memory Systems)

> **定位**：认知科学视角下的记忆架构——从人类记忆系统的功能组织中汲取灵感，理解记忆在智能中的核心角色，为 AI 记忆系统设计提供认知基础。

---

## 一、记忆系统的认知科学视角

### 1.1 多存储模型 (Atkinson-Shiffrin)

```
感觉记忆 → 短期记忆(工作记忆) → 长期记忆
              ↑                      |
              └── 提取 ──────────────┘
```

### 1.2 长期记忆的分类

| 类型 | 描述 | 内容 | 持续时间 |
|------|------|------|----------|
| 情景记忆 | 个人经历 | 事件、时空情境 | 天~年 |
| 语义记忆 | 一般知识 | 概念、事实 | 年~终身 |
| 程序记忆 | 技能和习惯 | 动作序列 | 年~终身 |

### 1.3 工作记忆模型 (Baddeley)

```
中央执行系统
    ├── 语音环路（语言信息）
    ├── 视空间模板（视觉信息）
    └── 情景缓冲器（整合信息）
```

## 二、对 AI 系统的启示

### 2.1 从认知到AI的映射

| 认知记忆 | AI对应 | 实现方式 |
|----------|--------|----------|
| 工作记忆 | 上下文窗口 | Attention、KV-Cache |
| 情景记忆 | 向量存储 | RAG、向量数据库 |
| 语义记忆 | 参数记忆 | 模型权重 |
| 程序记忆 | 策略/技能 | 微调、LoRA |

### 2.2 记忆的编码、存储与提取

- **编码**：如何将经验转化为可存储的表示
- **存储**：如何组织记忆以支持高效检索
- **提取**：如何根据线索召回相关记忆
- **遗忘**：何时丢弃过时或不重要的记忆

### 2.3 记忆的一致性与干扰

- 前摄抑制与倒摄抑制
- 灾难性遗忘 (Catastrophic Forgetting)
- 记忆巩固 (Memory Consolidation)
- 知识编辑与更新
