# 世界模型基础 综述

## 概述

世界模型（World Models）是 AI 系统对物理世界内在表征的构建，使其能够预测环境状态变化、规划行动并理解因果关系。世界模型是 AGI 架构的核心候选——它连接感知、预测、规划、强化学习和机器人控制。

## 核心概念

### 世界模型的定义
- 对环境的内部模拟器：给定当前状态和动作，预测下一状态
- 支持反事实推理（What-if）
- 支持规划和决策

### 世界模型的层次
```
感知 → 表征 → 预测 → 规划 → 执行
```

### 与其他概念的关系
- 世界模型 vs 语言模型：语言是世界的投影，世界模型直接建模物理现实
- 世界模型 vs 模拟器：世界模型是学习得到的内部模型
- 世界模型 vs 心理模型：AI 的"心理模拟"

## 主要研究方向

### 基于RL的世界模型
- Ha & Schmidhuber (2018): 早期世界模型
- Dreamer 系列 (Dreamer, DreamerV2, DreamerV3)
- TD-MPC / TD-MPC2
- IRIS / Genie

### 基于视频生成的世界模型
- Sora 作为世界模拟器
- GAIA-1
- UniSim
- 视频预测模型（DVD-GAN, VideoGPT）

### 基于语言的世界模型
- LLM 作为世界模型
- 基于文本的环境模拟
- 世界知识与常识推理

### 3D/空间世界模型
- NeRF 作为场景表征
- 3D Gaussian Splatting
- 神经场景表征
- 占据网络 (Occupancy Networks)

## 关键技术

### 状态表征学习
- 潜变量模型 (VAE, VQ-VAE)
- 对比学习表征
- 离散表征 (VQ-VAE token)

### 转移模型 (Transition Model)
- 确定性 vs 随机性转移
- 动作条件预测
- 长期预测稳定性

### 奖励模型
- 从世界模型中学习奖励
- 想象中的策略学习 (Imagination-based Planning)

### 规划与搜索
- 在世界模型中搜索最优行动
- MCTS 在世界模型中的应用
- Model-Predictive Control (MPC)

## 与 AGI 的关联

世界模型是 AGI 架构的核心组件：
- **环境理解**：不只是模式匹配，而是理解物理规律
- **反事实推理**：理解"如果...会怎样"
- **规划能力**：在内心模拟行动后果
- **数据效率**：在世界模型中想象训练，减少真实交互

## 发展趋势

1. 统一世界模型：一个模型覆盖多种环境
2. 视频生成即世界模拟
3. 具身世界模型：与机器人控制结合
4. 因果世界模型：从相关到因果
