# 行动基础模型 (Action Foundation Model)

> **定位**：基础模型的"行动"维度——从语言(LM)、视觉(VM)、世界(WM)到行动(AM)，构成 Foundation Model 的完整图谱。行动基础模型是将感知与理解转化为物理行动的桥梁，是具身智能的核心模型层。

---

## 一、为什么需要行动基础模型

基础模型的演进路径：

```
LLM (语言) → VLM (视觉) → WFM (世界) → LAM/AFM (行动)
```

| 模型类型 | 输入 | 输出 | 核心能力 |
|----------|------|------|----------|
| LLM | 文本 | 文本 | 理解与生成 |
| VLM | 图像+文本 | 文本 | 视觉理解与描述 |
| WFM | 状态/视频 | 状态预测 | 世界模拟与预测 |
| AFM | 感知+指令 | 动作 | 感知到行动的转化 |

## 二、核心路线

### 2.1 VLA 模型 (Vision-Language-Action)

将视觉-语言模型与行动输出结合，是当前最具代表性的行动基础模型路线。

- **RT-2**：Google，将VLM输出映射为机器人动作token
- **Octo**：开源通用机器人策略模型
- **OpenVLA**：开源VLA模型
- **π0**：Physical Intelligence，流匹配策略

### 2.2 Action Tokenization

将连续动作空间离散化为token序列，使其可被Transformer处理。

- 动作分词与编码
- 动作vocab设计
- 连续动作回归 vs 离散动作分类

### 2.3 通用策略模型

跨任务、跨机器人、跨场景的通用行动策略。

- 大规模机器人数据预训练
- 多embodiment迁移
- 零样本/少样本任务泛化

### 2.4 行动表示学习

- 动作嵌入空间
- 行为克隆与模仿学习
- 离线强化学习策略

## 三、关键技术

### 3.1 训练范式

| 范式 | 方法 | 特点 |
|------|------|------|
| 行为克隆 | BC, Diffusion Policy | 从专家数据学习 |
| 离线RL | IQL, CQL | 从次优数据学习 |
| 在线RL | PPO, SAC | 与环境交互优化 |
| 模仿+RL混合 | RLHF for actions | 结合两者优势 |

### 3.2 数据工程

- **Open X-Embodiment**：跨机器人数据集
- **DROID**：大规模机器人操作数据
- **桥接数据**：互联网规模视频→行动理解

### 3.3 架构创新

- 流匹配策略 (Flow Matching Policy)
- 扩散策略 (Diffusion Policy)
- 自回归动作生成
- 动作chunk (ACT)
