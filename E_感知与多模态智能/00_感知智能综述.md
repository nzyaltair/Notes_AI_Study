# 感知智能综述

> **定位**：E 是 AGI 的感知能力层，研究系统如何将图像、视频、声音、空间与语言条件转化为可供推理、预测和行动使用的结构化状态表示。感知不是"看到"或"分类"——而是为认知系统提供可查询、可更新、带置信度的观测证据。

## 领域定义

感知智能（Perception Intelligence）研究如何从原始传感器信号中提取、组织、维护与推理关于环境的结构化信息。在 AGI 框架中，感知位于"观测 → 建模 → 规划 → 行动"闭环的入口：

- **输入**：像素、波形、点云、传感器读数等物理信号
- **输出**：带有语义、空间、时间与置信度的结构化状态（而非原始信号或单一标签）
- **核心能力**：识别、定位、跟踪、对齐、推理、更新

感知智能不等同于计算机视觉——它涵盖视觉、听觉、空间、多模态融合以及感知与行动的交互接口。

## 为什么会出现

感知智能作为独立研究领域出现，源于以下根本需求：

1. **从信号到符号的鸿沟**：传感器产生的是连续低层信号（像素、波形），而认知系统需要的是离散、语义化的高层状态（物体、事件、关系）。如何跨越这一鸿沟是感知智能的核心问题。

2. **感知不只是分类**：传统 CV 将感知简化为"识别物体"，但 AGI 系统需要的感知还包括：时序连续性（跟踪物体在时间中的状态变化）、空间几何（物体在三维世界中的位置与形状）、跨模态对齐（视觉证据与语言描述的对应关系）、不确定性量化（知道何时感知不可靠）。

3. **感知决定上层能力的上限**：世界模型依赖感知状态作为输入，Agent 决策依赖感知状态作为证据，具身执行依赖感知状态作为反馈。感知质量直接影响所有上层系统的可靠性。

## 核心问题

感知智能面临以下根本性问题：

1. **表示学习**：如何将高维传感器信号压缩为低维、可迁移、语义丰富的表示？
2. **跨模态对齐**：视觉、语言、音频、空间等不同模态如何映射到共享语义空间？
3. **时空一致性**：感知系统如何在时间维度维护连续状态，在空间维度保持几何一致性？
4. **开放世界泛化**：如何应对训练时未见过的新类别、新场景、新任务？
5. **不确定性量化**：感知系统何时应该"知道不知道"？
6. **主动感知**：系统如何选择最有信息量的观测位置以降低不确定性？
7. **感知-行动闭环**：感知如何为行动提供反馈，行动如何引导感知？

## 技术演进路线

```text
手工特征 (SIFT/HOG) 
    → 深度特征 (CNN) 
    → 预训练特征 (ViT/MAE) 
    → 视觉语言对齐 (CLIP) 
    → 视觉语言模型 (LLaVA/GPT-4o) 
    → 原生多模态 (Unified)
```

三条并行的技术演化线：

- **视觉理解**：分类 → 检测 → 分割 → 开放词汇 → 视觉 Grounding → 视觉推理
- **多模态对齐**：特征拼接 → 对比学习 → 桥接融合 → 原生统一架构
- **空间感知**：2D 图像 → 多视角几何 → 深度估计 → NeRF/3DGS → 可查询空间场景

## 当前发展状态

### 已取得的进展

- **VLM 达到实用的零样本视觉理解能力**：GPT-4o、Gemini、Claude 3.5 等模型在视觉问答、文档理解、图表分析等任务上已达到人类专家水平
- **开源 VLM 快速追赶**：Qwen2-VL、InternVL 2.0、LLaVA-NeXT 等开源模型在多个基准上接近商业模型
- **3D 感知进入实时阶段**：3D Gaussian Splatting 实现了实时新视角合成，NeRF 为动态场景提供了高质量表示
- **视频理解基础模型出现**：SAM 2、Video-LLaVA 等模型实现了视频级的开放世界理解
- **统一感知架构已现雏形**：GPT-4o、Gemini 等原生多模态模型展示了 All-in-One 的感知能力

### 仍存在的关键瓶颈

- **视觉幻觉远未解决**：模型频繁"看到"不存在的物体或关系，尤其在空间推理、精确计数任务上
- **细粒度感知不足**：小物体、精确位置、遮挡场景下的感知能力仍有限
- **长视频理解计算成本过高**：小时级视频的实时理解仍不可行
- **模态偏置问题**：语言先验常覆盖视觉证据，导致感知系统"说而非看"
- **感知评测滞后于模型发展**：现有基准难以衡量开放世界、闭环场景下的感知可靠性
- **不确定性量化缺失**：多数感知系统不输出置信度，无法为决策系统提供可靠信号

## 未来趋势

1. **原生多模态融合**：从"视觉编码器 + 桥接模块 + LLM"的拼装式架构走向端到端联合训练的统一架构，消除模态间的信息瓶颈。

2. **感知与生成的统一**：视觉理解模型与视觉生成模型正在融合——同一模型既能理解图像内容，也能生成图像/视频。Sora 已展示这一方向。

3. **主动感知与感知-行动闭环**：从被动接收传感器信号转向主动选择观测视角（如 NeRF 中的 next-best-view），由行动目标驱动感知过程。

4. **长时序感知**：从短片段（秒级）走向持续数小时甚至数天的感知系统，需要解决记忆、遗忘、状态更新的问题。

5. **感知不确定性量化与校准**：感知系统必须输出"我不知道"的置信度信号，而非总是给出最可能答案。

6. **具身感知**：与机器人平台深度融合，使感知系统理解物理可供性、物体交互和动态变化。

7. **感知评测从闭集到开放世界**：从固定类别准确率转向 OOD 检测、幻觉率、校准度、闭环成功率等更全面的评测体系。
