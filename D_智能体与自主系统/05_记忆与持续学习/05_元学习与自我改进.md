# 元学习与自我改进

元学习研究如何从任务分布中学习快速适应；自我改进则让 Agent 基于评估和反馈修改记忆、技能、策略或参数。

## 1. 元学习核心方法

| 类别 | 核心思想 | 代表方法 |
|------|----------|----------|
| 基于优化 | 学习优化器或初始化（MAML/优化式元学习学习易适应的初始化） | MAML, Reptile, LSTM优化器 |
| 基于度量 | 学习距离度量，用于少样本分类或检索所需的表示 | Prototypical, Matching, Relation |
| 基于模型 | 元学习模型架构 | HyperNetwork, Meta-LSTM |
| 基于记忆 | 外部记忆快速适配 | MANN, Meta-RNN |

## 2. 自我改进的两个层次

- **经验层自我改进**：通过反思、纠错、技能库和工作流修改实现，低成本且可回滚。改变外部记忆而非模型权重，易于审计。详见 [[06_反思与自我改进|反思与自我改进]]。
- **参数层自我改进**：通过再训练、RL 或持续学习实现（见 [[04_持续学习与终身学习|持续学习与终身学习]]），能力潜力更大，但须离线评测、版本控制和安全审核。

"Agent 自己生成代码/提示"不自动构成安全的自我改进。需要固定基准、沙箱、回归测试、资源上限和人类审批，防止优化代理指标而非真实目标。
