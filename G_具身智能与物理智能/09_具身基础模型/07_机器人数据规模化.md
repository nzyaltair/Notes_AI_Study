# 机器人数据规模化

## 一句话理解

机器人数据规模化同时追求数量、覆盖、质量和可复用接口。数据应包含任务语言、视觉/触觉/本体观测、动作及坐标系、频率、标定、环境状态、成功失败、恢复和安全事件。

## 概述

机器人数据规模化（Robot Data Scaling）是具身基础模型发展的瓶颈所在。与互联网文本/图像不同，机器人数据采集成本高、异构性强、动作标签难。数据规模化研究如何设计数据规范、扩大数据覆盖、保证数据质量、防止数据泄漏，并建立可复用的开源数据集生态。

## 发展历史

- **2015-2020**：单实验室遥操作数据集（RoboTurk）；仿真数据集（RLBench）。
- **2021-2022**：Bridge V2、DROID 等大规模操作数据集。
- **2023**：Open X-Embodiment 汇集 22 种机器人、多来源数据集，跨本体数据规模化成为共识。
- **2024-2025**：更大规模数据（千万级演示）、人形数据（遥操作 + 人类视频）、统一数据格式与评测基准。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 数据规范 | 记录字段与格式标准 | 可复用前提 |
| 数据覆盖 | 任务/场景/物体多样性 | 泛化基础 |
| 数据质量 | 动作-观测对齐与标签正确 | 学习上限 |
| 数据泄漏 | 训练/评测重叠 | 虚假泛化 |
| 跨本体数据 | 多平台数据 | 通用性 |
| 成功标签 | 任务成功定义 | 评测与训练 |
| 数据闭环 | 部署数据回流 | 持续改进 |

## 技术原理

### 数据规范：一条轨迹应记录什么

| 类别 | 应记录字段 | 常见遗漏 |
|---|---|---|
| 任务 | 文本指令、版本、任务 ID | 指令模板变化 |
| 视觉 | RGB/深度/点云、时间戳、相机参数 | 深度质量、丢帧 |
| 触觉/力 | 力/力矩、滑移、传感器 ID | 接触事件对齐 |
| 本体 | 关节角/速度/力矩、IMU | 实际执行 vs 策略输出 |
| 动作 | 命令值、坐标系、单位、频率 | 延迟、跟踪误差 |
| 环境 | 物体 ID/位姿、布局、光照 | 动态变化 |
| 元数据 | 标定版本、策略版本、操作者 | 失败/恢复/干预 |

**最大误区**：只保存成功的完美演示。失败、恢复、人工干预和边缘场景才是系统鲁棒性的关键数据。

### 数据来源与互补

| 来源 | 优势 | 局限 | 用途 |
|---|---|---|---|
| 遥操作 | 高质量、对齐 | 规模有限 | 策略训练 |
| 自主探索 | 覆盖长尾 | 质量参差 | 扩充覆盖 |
| 仿真 | 大规模、标注 | 差距 | 预训练 |
| 人类视频 | 语义丰富 | 无动作标签 | 预训练/先验 |

### 数据划分与泄漏

常见泄漏源：同一物体实例、同一场景不同角度、同一指令模板、同一天连续数据。

推荐按物体实例、场景、指令模板和时间切分，而非随机切帧。报告泛化能力时必须明确切分方式。

## 关键数据集与基准

| 数据集 | 覆盖范围 | 规模特点 |
|---|---|---|
| Open X-Embodiment | 22 种机器人 | 首个大规模跨本体 |
| DROID | 多机器人遥操作 | 开源、多样化 |
| Bridge V2 | 单臂桌面操作 | 高质量视觉-动作对 |
| RoboMIND | 多任务多场景 | 中国开源 |
| ManiSkill 演示 | GPU 并行仿真 | 无限生成 |
| RH20T | 人形/灵巧手 | 触觉多模态 |
| AgiBot World | 人形数据 | 大规模人形 |
| ARX 数据集 | 多源汇总 | 开源生态 |

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| 统一数据格式 | 跨源对齐 | 数据整合 |
| 数据清洗 | 过滤坏样本 | 质量保证 |
| 自动标注 | 语言/成功标签 | 规模扩展 |
| 失败数据扩充 | 记录失败恢复 | 鲁棒性 |
| 数据增广 | 视觉/物理随机化 | 泛化 |
| 主动采集 | 按分布缺口采集 | 覆盖 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 规模 | 大规模预训练 | 采集成本 |
| 覆盖 | 跨本体/场景 | 长尾仍缺 |
| 质量 | 规范统一 | 质量参差 |
| 生态 | 开源共享 | 标准不统一 |

## 前沿发展

- **千万级演示数据**：规模化竞赛。
- **统一数据格式**：跨源互操作标准。
- **自动标注**：LLM 生成任务语言。
- **合成 + 真机混合**：数据扩增。
- **数据评测标准**：泛化测量的统一。

## 常见问题

- **只统计成功演示**：失败与恢复是鲁棒性关键。
- **随机切帧**：导致物体/场景泄漏。
- **忽略元数据**：无法追溯与复用。
- **数据无治理**：版本、来源、许可不明。
