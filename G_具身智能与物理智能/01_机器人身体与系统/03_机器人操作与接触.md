# 机器人操作与接触：从抓取到物理交互

## 一句话理解

操作的目标不是移动末端，而是通过接触改变物体状态。抓取、推拉、插拔、开门和布料操作都涉及不确定摩擦、接触模式切换与力反馈——纯视觉开环策略在接触任务上必然脆弱。

## 概述

操作（Manipulation）是机器人学中与导航并列的核心问题。导航解决"到达某处"，操作解决"通过接触改变物体状态"。操作比导航更困难：它涉及力耦合、摩擦不确定、接触模式切换和柔性物体形变。理解操作的物理原理是理解为什么具身智能不能仅靠视觉语言模型的关键。

## 发展历史

- **1960s-1970s**：工业抓取器（夹爪、吸盘）用于结构化环境；Mason（1986）建立接触力学框架。
- **1980s**：抓取理论发展（力闭合、形闭合）；阻抗控制（Hogan 1985）和导纳控制提供柔顺接触。
- **1990s-2000s**：灵巧手（Stanford/JPL Hand, Barrett Hand, Shadow Hand）推动多指操作研究；触觉传感器（GelSight, BioTac）进入实验。
- **2010s**：深度学习进入抓取检测（Dex-Net, GG-CNN）；数据驱动抓取策略出现。
- **2020s**：RL 灵巧操作（OpenAI 解魔方）、扩散策略操作、VLA 操作成为主流；布料/柔性物体操作仍是开放问题。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 抓取稳定性 | 物体在扰动力下不滑移 | 决定能否安全移动物体 |
| 力闭合 (Force Closure) | 指尖力可抵抗任意方向扰动 | 抓取的充分条件 |
| 形闭合 (Form Closure) | 几何约束使物体完全固定 | 不依赖摩擦的抓取 |
| 接触模式 | 自由、滑动、固定、分离 | 接触状态切换决定策略 |
| 摩擦锥 | \(\lVert F_t\rVert \le \mu F_n\) | 接触力的可行域 |
| 柔顺控制 | 位置或力可顺应环境 | 吸收未知位姿误差 |

## 技术原理

### 抓取分析与规划

抓取规划回答"在哪里、用什么方式抓取物体使其稳定"：

1. **抓取候选生成**：基于几何（法向、曲率）或学习（GG-CNN, GraspNet）生成候选抓取位姿。
2. **稳定性分析**：力闭合测试验证指尖力能否抵抗重力、惯性和外部扰动。
3. **可达性检查**：IK 验证机器人能否到达候选抓取位姿。
4. **碰撞检查**：手臂、物体和环境的碰撞避免。
5. **执行与核验**：接近 → 接触检测 → 力控夹紧 → 滑移检测 → 抬升确认。

### 接触力学

接触力须满足非穿透和库仑摩擦约束：

$$F_n \ge 0, \qquad \lVert \mathbf{F}_t \rVert \le \mu F_n$$

多指抓取的力闭合条件：存在指尖力组合使物体在任意方向扰动下保持平衡。分析常用线性化摩擦锥（接触力在锥内）。

### 力控与阻抗控制

对装配、插拔、打磨等接触任务，纯位置控制会在位姿误差下产生过大接触力。阻抗控制让末端呈现期望的质量-阻尼-刚度关系：

$$M_d \ddot{\mathbf{e}} + D_d \dot{\mathbf{e}} + K_d \mathbf{e} = \mathbf{F}_{ext}$$

- \(M_d\)：期望惯性（决定响应快慢）。
- \(D_d\)：期望阻尼（抑制振荡）。
- \(K_d\)：期望刚度（"软硬"程度）。

"软"不是降低安全标准，而是用受控顺应性把未知接触误差转成可恢复的位移。

### 灵巧操作

在手操作（In-Hand Manipulation）指不借助外部支撑，仅用手指重新调整物体位姿：

- 需要多指协调、接触模式切换和力控闭环。
- 代表问题：旋转笔、翻面、调整抓取姿态、插入钥匙。
- 方法：RL（OpenAI 解魔方）、轨迹优化（接触-动力学规划）、模仿学习。

### 柔性物体操作

布料、绳索、液体和食物的操作是开放问题：

- 状态空间连续且高维（形变）。
- 感知困难（折叠状态的布料）。
- 接触模式复杂（多点、大变形）。
- 方法：简化模型（质点弹簧、有限元）、学习策略、视觉-触觉联合。

## 关键方法与模型

| 方法 | 核心思想 | 代表 | 适用 |
|---|---|---|---|
| 解析抓取规划 | 几何 + 力闭合 | Dex-Net | 已知物体 |
| 学习抓取检测 | 从深度图预测抓取 | GG-CNN, GraspNet | 未知物体 |
| 力/阻抗控制 | 顺应接触力 | Hogan (1985) | 装配、插拔 |
| RL 灵巧操作 | 策略学习多指协调 | OpenAI Rubik's Cube | 在手操作 |
| 扩散策略操作 | 动作序列生成 | Diffusion Policy | 通用操作 |
| 接触-动力学规划 | 联合优化接触和运动 | TraDopt | 接触模式切换 |

## 操作闭环

```text
对象/可供性感知 → 抓取候选生成 → 可达性与碰撞验证
→ 接近 → 接触检测 → 力/触觉闭环 → 结果核验与恢复
```

关键设计原则：
- 把可供性表示为"对该本体可执行的行动"，而不是物体类别标签。
- 记录接触事件、滑移、实际力和失败恢复，而非只保留成功轨迹。
- 对高风险操作设独立的力、速度与工作空间限制。

## 优势与局限

| 方法 | 优势 | 局限 |
|---|---|---|
| 解析抓取 | 可验证、稳定 | 需精确物体模型 |
| 学习抓取 | 泛化到新物体 | 抓取质量保证弱 |
| 阻抗控制 | 容忍位姿误差 | 需力感知和参数调节 |
| RL 操作 | 可学习复杂接触 | 样本量巨大、安全难保证 |
| 扩散策略 | 多模态动作分布 | 推理时延、安全约束 |

## 应用场景

- 工业装配：插装、螺丝拧紧、对位贴合。
- 仓储拣选：从货架抓取多样化商品。
- 家居操作：开门、倒水、折叠衣物。
- 灵巧操作：工具使用、精密组装。

- **触觉-视觉联合学习**：从视觉预测触觉属性，从触觉推断几何。
- **通用操作策略**：VLA + 扩散策略实现跨物体泛化操作。
