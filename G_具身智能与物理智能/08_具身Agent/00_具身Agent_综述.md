# 具身 Agent 综述

具身 Agent 将语言/多模态推理、世界模型、技能、控制和安全运行机制组合为可在物理世界中长期工作的自主体。它不是直接向电机输出 token 的 LLM，而是带有状态、记忆、验证、恢复和权限边界的闭环系统。
