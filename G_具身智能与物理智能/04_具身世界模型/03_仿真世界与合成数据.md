# 仿真世界与合成数据

## 一句话理解

仿真提供可并行交互、可控随机化与自动标注；真机暴露真实摩擦、时延、传感噪声和硬件非理想。二者必须组成数据与验证闭环，而不是"仿真替代真机"。

## 概述

仿真（Simulation）是具身智能的数据引擎与验证场：GPU 上可并行生成海量训练数据，自动获得完美标注，支持域随机化训练鲁棒策略。但仿真与真机存在系统性差距（sim-to-real gap），合成数据可扩展视觉和稀有失败样本，却不能替代真机接触验证。仿真世界与合成数据研究如何最大化仿真的价值、最小化其差距。

## 发展历史

- **1990s-2000s**：物理引擎（Bullet 2003, ODE, PhysX）成为游戏与机器人研究工具；Gazebo 作为机器人仿真器出现。
- **2010s**：MuJoCo（2012）成为 RL 标准环境；域随机化（Domain Randomization, 2017）解决 sim-to-real；Isaac Gym（2019）实现 GPU 并行训练。
- **2020s**：Isaac Sim/Lab 统一仿真与学习；ManiSkill、RoboMIND 等仿真基准规模化；可微物理引擎（Brax）与神经仿真兴起；数字孪生进入工业。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 物理引擎 | 数值求解动力学与接触 | 仿真的物理基础 |
| 域随机化 | 随机化物理/视觉参数 | 提升 sim-to-real 泛化 |
| 系统辨识 | 从真机日志估计参数 | 缩小仿真差距 |
| 合成数据 | 仿真生成的数据 | 标注免费、可扩展 |
| 数字孪生 | 真机系统的仿真镜像 | 验证与预测维护 |
| sim-to-real gap | 仿真与真机的行为差异 | 核心工程挑战 |
| 硬件在环 | 真实硬件 + 仿真环境 | 中间验证层 |

## 技术原理

### 主流物理引擎对比

| 引擎 | 特点 | 适用 |
|---|---|---|
| MuJoCo | 精确、可微、RL 标准 | 接触学习、RL 训练 |
| Isaac Sim/Lab | GPU 并行、仿真-学习一体 | 大规模并行训练 |
| Gazebo | ROS 集成成熟 | 系统级仿真 |
| Bullet | 开源、接触丰富 | 通用物理 |
| Brax | JAX 可微、超大规模并行 | 快速实验 |
| PhysX | NVIDIA 生态 | 渲染 + 物理 |

### 域随机化

域随机化在训练时随机化环境参数，让策略学会对差异鲁棒：

- **物理参数**：质量、摩擦、刚度、阻尼、执行器延迟。
- **视觉参数**：纹理、光照、相机噪声、曝光。
- **动态参数**：动作延迟、观测噪声、控制频率。

系统辨识用真机日志缩小随机范围：先估计真机参数分布，再在该分布上随机化，避免随机范围过大导致策略保守。

### 数字孪生

数字孪生不只是 3D 外观模型，还应持续校准几何、动力学、传感和控制时延：

```text
真机 → 传感器数据 → 参数辨识 → 仿真镜像 → 验证/预测 → 回传真机
```

数字孪生用于：策略灰度验证、故障预测、参数调整、演示数据生成。

### 合成数据生成

| 用途 | 方法 | 注意 |
|---|---|---|
| 视觉数据 | 渲染 RGB/深度 + 自动标注 | 材质与光照真实度 |
| 操作演示 | 脚本/规划器生成轨迹 | 分布与人类演示差异 |
| 失败样本 | 故意注入扰动 | 覆盖长尾失败 |
| 物理数据 | 仿真交互日志 | 物理参数校准 |

## 关键方法与模型

| 方法/工具 | 核心思想 | 用途 |
|---|---|---|
| Isaac Gym/Lab | GPU 并行 RL | 大规模训练 |
| ManiSkill | 接触式操作基准 | 评测与数据 |
| RoboMIND | 多任务仿真数据集 | 跨任务训练 |
| Domain Randomization | 参数随机化 | Sim2Real |
| Sim-to-Real 课程 | 难度递进迁移 | 平稳部署 |
| 硬件在环 (HIL) | 真硬件 + 虚拟环境 | 中间验证 |
| 系统辨识 | 日志估计参数 | 差距缩小 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 数据规模 | GPU 并行无限生成 | 分布偏差 |
| 标注质量 | 自动完美标注 | 标注≠真机标签 |
| 安全性 | 无物理风险探索 | 仿真探索行为迁移差 |
| 可重复性 | 实验可复现 | 真实随机性缺失 |
| 验证 | 快速迭代 | sim-to-real gap |

## 应用场景

- RL 训练：四足步态、操作策略、导航。
- 数据生成：大规模演示、失败样本、视觉数据。
- 评测基准：ManiSkill、RoboBench 等。
- 数字孪生：工业预测维护、策略灰度验证。
- 遥操作增强：仿真预演 + 真机执行。

## 前沿发展

- **生成式仿真**：扩散模型/NeRF 生成仿真场景。
- **可微物理规模化**：GPU 可微引擎支撑端到端学习。
- **仿真基础模型**：跨场景可交互仿真环境。
- **神经渲染仿真**：3DGS 渲染的真实感仿真场景。
- **仿真-真机闭环**：在线校准的持续数字孪生。

## 常见问题

- **仿真排行榜当真机能力**：必须真机验收。
- **域随机化过度**：随机范围过大导致策略保守。
- **忽略时延与传感模型**：仿真缺少真实时延/噪声。
- **合成数据不加校准**：分布偏差直接迁移。
