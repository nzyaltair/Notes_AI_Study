# 基础模型理论综述：从预训练到通用智能的架构

## 一句话理解

基础模型（Foundation Model）是大规模预训练+广泛适应的统一范式——它不再为单一任务设计模型，而是在海量数据上预训练一个通用表征，然后通过微调、提示或对齐适应到无数下游任务，是 AGI 路线的核心架构理念。

## 1. 领域定义

### 基础模型 (Foundation Model)

斯坦福 HAI 2021 年提出的概念：在大规模宽泛数据上训练的模型，可适应广泛的下游任务。核心特征：

- **同质性**：同一架构服务不同任务
- **涌现性**：规模增长带来质变能力
- **适应性**：微调、提示、上下文学习

### 与 LLM 的关系

LLM 是基础模型在语言领域的一个实例。基础模型的范畴更广：

```
Foundation Model
    ├── LLM (语言)
    ├── VLM (视觉-语言)
    ├── Video Model (视频)
    ├── Multimodal Foundation Model (多模态)
    ├── World Model (世界模拟)
    └── Robotics Foundation Model (具身)
```

## 2. 核心理论

### 2.1 Scaling Laws

| 定律 | 公式 | 含义 |
|------|------|------|
| Chinchilla Law | L(N,D) ≈ E + A/N^α + B/D^β | 损失随参数量和数据量幂律下降 |
| Kaplan Scaling | L(N) ∝ N^{-0.076} | 模型性能与参数量的幂律关系 |
| Emergent Abilities | 跨过阈值后能力突变 | 量变引起质变 |
| Data Scaling | L(D) ∝ D^{-0.095} | 数据量与性能的关系 |

关键发现：
- 模型大小、数据量、计算量三者需协同增长
- Chinchilla 证明之前大多数模型欠训练
- 计算最优：给定 FLOPs 预算，N 和 D 有最优比例

### 2.2 预训练范式

| 范式 | 目标函数 | 代表 |
|------|----------|------|
| 自回归 | P(x_t \| x_{<t}) | GPT 系列 |
| 掩码预测 | P(x_masked \| x_visible) | BERT, MAE |
| 对比学习 | 相似样本靠近 | CLIP, DINO |
| 去噪 | 去噪目标 | 扩散模型 |
| 联合嵌入预测 | 预测潜在表示 | JEPA |

### 2.3 涌现能力

规模增长带来的质变：

| 能力 | 涌现规模 | 含义 |
|------|----------|------|
| 上下文学习 | ~10B 参数 | 无需微调，从示例中学习 |
| 思维链推理 | ~100B 参数 | 多步推理能力涌现 |
| 指令遵循 | SFT + RLHF 后 | 遵循自然语言指令 |
| 代码生成 | 代码数据训练后 | 理解和生成程序 |
| 工具使用 | RLHF + 工具训练后 | 调用外部工具 |

### 2.4 适应方法

| 方法 | 参数量 | 成本 | 效果 |
|------|--------|------|------|
| 提示工程 (Prompt) | 0 | 极低 | 中 |
| 上下文学习 (ICL) | 0 | 低 | 中 |
| LoRA / Adapter | 0.1-1% | 低 | 高 |
| 全量微调 (SFT) | 100% | 高 | 最高 |
| RLHF / DPO | 100% + 奖励模型 | 极高 | 对齐后高 |

## 3. 多模态基础模型

| 模型类型 | 输入模态 | 输出模态 | 代表 |
|----------|----------|----------|------|
| VLM | 图+文 | 文 | LLaVA, GPT-4V |
| 视频模型 | 视频 | 视频/文 | Sora, GAIA-1 |
| 语音模型 | 语音 | 语音/文 | Whisper, Gemini |
| 统一多模态 | 图+文+音+视 | 多模态 | Gemini, GPT-4o |
| 具身基础模型 | 图+文+动作 | 动作 | RT-2, Octo |

## 4. 发展历史

1. 2018：BERT/GPT 开创预训练-微调范式
2. 2020：GPT-3 证明 Few-shot ICL，Scaling Laws
3. 2021：Stanford 提出 Foundation Model 概念
4. 2022：Chinchilla 修正 Scaling Laws；Stable Diffusion
5. 2023：GPT-4 多模态；LLaVA 开源 VLM
6. 2024：Sora 视频生成；RT-2 机器人基础模型
7. 2025-26：基础模型成为 AGI 路线核心共识

## 5. 与 AGI 的关系

- **AGI 的核心架构**：基础模型是 AGI 的"感知-理解"基础
- **AGI 阶梯1**：语言模型是基础模型在语言领域的实现
- **通用性来源**：预训练提供通用表示，微调/提示提供任务适应
- **当前局限**：基础模型 ≠ AGI，缺少持续学习、世界模型、规划能力

```
AGI 阶梯定位：

[基础模型] → CoT → Agent → 持续学习 → 奇点 → 具身智能
  ↑
基础模型是阶梯1（语言模型）的完整表述，
也是所有后续台阶的底层架构
```
