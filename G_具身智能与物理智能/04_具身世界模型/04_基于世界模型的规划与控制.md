# 基于世界模型的规划与控制

## 一句话理解

世界模型使机器人能在执行前"想象"多种动作的后果并选择最优者——模型预测控制（MPC）在有限时域内比较候选动作，执行时只下发首个动作并滚动重规划。

## 概述

世界模型的核心价值不在预测本身，而在支撑决策：比较技能候选、预判物体是否会倾倒、识别失败原因、选择重新观察还是重新抓取。基于世界模型的规划与控制研究如何把预测能力接入决策闭环，形成"想象-选择-执行-重规划"的滚动时域架构。

## 发展历史

- **1960s-1970s**：MPC 在过程控制中诞生（模型预测 + 滚动优化）。
- **1990s-2000s**：MPC 进入机器人（轨迹跟踪、约束控制）；概率模型（PILCO 2011）把学习模型用于 RL。
- **2018-2020**：World Models（Ha & Schmidhuber 2018）用潜空间想象训练控制器；Dreamer 系列实现基于想象模型的通用 RL。
- **2020s**：机器人世界模型用于操作规划与 Sim2Real；风险敏感 MPC 与不确定性感知规划成为安全关键方向。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 模型预测控制 (MPC) | 有限时域滚动优化 | 显式处理约束 |
| 滚动时域 (Receding Horizon) | 只执行首动作再重规划 | 闭环鲁棒性 |
| 想象规划 | 在模型内模拟动作后果 | 无需真实试错 |
| 不确定感知 | 把预测不确定性进入决策 | 安全关键 |
| 风险敏感 | 优化最坏情形/条件风险 | 高价值任务 |
| 模型预测路径积分 (MPPI) | 采样候选动作加权 | 无梯度 MPC |

## 技术原理

### MPC 形式化

模型预测控制在有限时域内最小化期望代价：

$$\min_{a_{t:t+H-1}}\mathbb E\left[\sum_{k=0}^{H-1}c(s_{t+k},a_{t+k})+c_T(s_{t+H})\right]$$

约束由动力学、碰撞、力、速度和风险阈值给出；执行时只下发第一个动作并重新观测（滚动时域闭环）。

### 从解析模型到学习模型

| 模型类型 | MPC 用法 | 优势 | 局限 |
|---|---|---|---|
| 解析模型 | 标准 MPC | 精确、可证明 | 覆盖范围窄 |
| 系统辨识模型 | 参数化 MPC | 适应真实动力学 | 参数估计偏差 |
| 神经动力学 | 学习式 MPC | 覆盖复杂接触 | 误差累积 |
| 潜空间模型 | Dreamer 式想象 | 高维观测 | 语义遗漏 |
| 视频预测模型 | 视觉想象规划 | 直观 | 物理正确性弱 |

### 想象规划（Imagination-based Planning）

学习世界模型后，在想象环境中规划：

```text
观测 → 编码 → 潜状态 z_t
→ 想象 rollout（模型内执行候选动作序列）
→ 价值/代价评估 → 选择最优 → 执行首动作 → 重规划
```

Dreamer 系列在潜空间想象中训练 actor-critic，实现稀疏奖励下的通用决策。

### 风险与不确定性

关键原则：预测的不确定性应进入代价或约束。

- **风险敏感目标**：优化条件风险 \(CVaR\) 而非期望。
- **不确定性下探**：高不确定区域选择更保守动作。
- **预测-观测一致性检查**：若观测与预测显著不符，更新状态、标记失败类型并重规划，而非继续盲执行。

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| 标准 MPC | 解析模型滚动优化 | 约束轨迹控制 |
| MPPI | 采样加权无梯度 | 复杂代价 |
| PILCO | 高斯过程动力学 | 样本高效 RL |
| Dreamer V1/V2/V3 | 潜空间想象 RL | 通用决策 |
| 学习式 MPC | 神经动力学 + 优化 | 操作任务 |
| 风险敏感 MPC | CVaR/最坏情形 | 安全关键 |
| 视频想象规划 | 生成未来帧选动作 | 操作规划 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 约束处理 | 显式处理碰撞/力矩 | 模型不准时失效 |
| 前瞻性 | 预判后果、规避风险 | 计算成本 |
| 数据效率 | 想象减少真实试错 | 想象与真实差距 |
| 可解释 | 可检查候选动作 | 接口复杂 |

## 应用场景

- 四足/人形运动：MPC + WBC 动态平衡。
- 操作规划：想象抓取后果、放置稳定性。
- 导航：预测障碍物运动轨迹。
- 长程任务：技能候选后果比较。
- 失败恢复：预测失败原因，选择恢复策略。

- **世界模型基础模型**：跨任务通用预测模型。
- **视频预测驱动操作**：生成未来帧评估动作。

- **安全世界模型**：保守预测支持安全决策。

## 常见问题

- **把预测当现实**：预测-观测不一致必须触发重规划。
- **忽略不确定性**：单一预测当事实危险。
- **约束放模型内**：碰撞、力矩、急停约束仍由独立安全层裁决。
- **长时域盲信**：滚动时域是标准做法，开环长执行危险。
