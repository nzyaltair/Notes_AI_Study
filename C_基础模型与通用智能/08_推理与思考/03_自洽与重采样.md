# 自洽与重采样

## 一句话理解

自洽通过采样多条推理路径并按答案聚合，降低单次解码偶然性；它以更多测试时计算换取稳定性，不能纠正系统性偏差或错误多数。

对同一问题采样 \(K\) 条轨迹后投票或经验证器选择。该策略需要正确候选有足够概率且错误路径不高度相关；温度提高多样性，也会降低单条质量。
