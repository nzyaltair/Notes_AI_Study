# 群体智能与多 Agent 社会模拟

## 一句话理解

群体智能研究多个有限主体如何通过局部信息、通信、市场或协作协议完成整体任务；多 Agent 社会模拟用同样的机制研究规范、分工、合作与竞争的涌现。

## 群体智能算法

| 算法 | 灵感来源 | 核心机制 | 典型应用 |
|---|---|---|---|
| 蚁群优化（ACO） | 蚁群觅食 | 信息素正反馈 + 蒸发 | 路径规划、组合优化 |
| 粒子群优化（PSO） | 鸟群/鱼群 | 个体最优 + 群体最优引导 | 连续优化 |
| 人工蜂群（ABC） | 蜜蜂采蜜 | 雇佣/观望/侦察三阶段 | 数值优化 |
| 细菌觅食优化 | 细菌趋化 | 化学趋性 + 繁殖 | 多峰优化 |

群体智能适合**不可微、非凸、分布式的优化问题**；其理论基础（何时收敛、收敛到何解）弱于梯度方法，工程上常作为黑盒优化器。

## 多 Agent 社会模拟

用 LLM 或经典 Agent 模拟人类社会交互，研究规范形成、分工演化、合作竞争与信息传播：

| 研究主题 | 典型问题 | 关键变量 |
|---|---|---|
| 规范形成 | 合作规范如何涌现与维持 | 惩罚机制、声誉系统 |
| 分工演化 | 角色如何分化 | 技能异质性、比较优势 |
| 合作与竞争 | 何时合作何时背叛 | 收益矩阵、记忆长度 |
| 信息传播 | 谣言/创新如何扩散 | 网络结构、个体影响力 |
| 市场与机制 | 价格、激励如何形成 | 拍卖、激励机制设计 |

## 关键设计变量

观测范围、通信协议、激励兼容性、身份与记忆、资源约束和治理规则。仿真结论依赖建模假设，不能直接外推到真实社会——Agent 的理性假设、同质性假设都会显著改变结果（对应 [[../../08_研究方法与证据评估/06_论文批判性阅读与证据等级]] 的外部效度判断）。

## LLM 多 Agent 的边界

LLM 驱动的多 Agent 模拟可生成丰富的语言交互，但需警惕：模型输出反映训练语料的社会偏见而非机制规律；"涌现的社会行为"可能只是 prompt 工程的结果。应以行为层面的可检验预测而非语言生动性作为评估标准。
