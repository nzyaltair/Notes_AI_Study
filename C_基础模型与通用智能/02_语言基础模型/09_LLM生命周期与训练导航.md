# LLM 生命周期与训练导航

LLM 的能力不是由单一模型文件产生，而是由完整生命周期共同塑造：

```text
数据治理 → Tokenization → 预训练 → 指令微调 → 偏好优化 →
推理时增强 → 推理服务与监控
```
