# 概率机器学习与贝叶斯智能综述：在不确定世界中做决策

## 一句话理解

概率机器学习将不确定性作为一等公民建模，贝叶斯智能从先验知识出发、通过观测数据不断更新信念——这是一条与纯连接主义不同的 AGI 路线：不追求最大似然的点估计，而是维护对世界的不确定性分布，使智能体能在信息不完整时仍然做出合理决策。

## 1. 领域定义

### 概率机器学习（Probabilistic ML）

以概率论为数学框架，将所有学习问题建模为概率推断问题。模型参数、预测结果、数据本身都有不确定性。

### 贝叶斯智能（Bayesian Intelligence）

从贝叶斯定理出发，将学习视为"先验 + 似然 → 后验"的信念更新过程。核心思想：**不是找到最好的答案，而是维护对所有可能答案的概率分布**。

### 与深度学习路线的对比

| 维度 | 深度学习路线 | 概率/贝叶斯路线 |
|------|-------------|----------------|
| 目标 | 点估计（最大似然） | 分布估计（后验分布） |
| 不确定性 | 忽略或事后估计 | 一等公民，内建建模 |
| 数据需求 | 大量数据 | 可融合先验，小数据友好 |
| 可解释性 | 黑箱 | 概率图可解释 |
| 持续学习 | 灾难性遗忘 | 天然支持贝叶斯更新 |
| 计算成本 | GPU 并行 | 推断计算昂贵 |

## 2. 为什么这是 AGI 的必要路线

- **现实世界本质不确定**：传感器噪声、不完整信息、对抗环境
- **小样本适应**：AGI 必须在少量数据下做决策，贝叶斯先验是关键
- **持续学习的数学基础**：贝叶斯更新天然支持持续学习——后验即新先验
- **安全与可靠性**：不确定性估计是 AI 安全的基础——"知道自己不知道什么"
- **主动学习**：知道哪里不确定，才能主动寻求信息

## 3. 核心方法

### 3.1 贝叶斯推断

| 方法 | 核心思想 | 适用场景 |
|------|----------|----------|
| 精确推断 | 直接计算后验 | 共轭先验 |
| MCMC | 马尔可夫链蒙特卡洛采样 | 通用但慢 |
| 变分推断 (VI) | 优化近似后验 | 大规模问题 |
| 拉普拉斯近似 | 高斯近似后验 | 局部近似 |
| SVGD | 非参数变分推断 | 灵活但计算量大 |

### 3.2 概率图模型

| 模型 | 结构 | 核心能力 |
|------|------|----------|
| 贝叶斯网络 (BN) | 有向无环图 | 因果关系建模 |
| 马尔可夫随机场 (MRF) | 无向图 | 联合分布建模 |
| 隐马尔可夫模型 (HMM) | 链式有向图 | 时序状态推断 |
| 条件随机场 (CRF) | 无向图+观测 | 序列标注 |
| 概率上下文无关文法 (PCFG) | 树结构 | 语法解析 |

### 3.3 高斯过程 (GP)

- 非参数贝叶斯方法：不假设函数形式，而是对函数空间建模
- 自动提供不确定性估计
- 高维大数据计算昂贵（O(n³)）
- 稀疏近似方法： inducing points, SVG

### 3.4 贝叶斯深度学习

| 方法 | 思路 | 代表 |
|------|------|------|
| 贝叶斯神经网络 | 权重是分布而非点 | Bayes by Backprop |
| MC Dropout | Dropout 等价于近似推断 | Gal & Ghahramani |
| 深度集成 | 多模型集成 ≈ 贝叶斯模型平均 | Lakshminarayanan et al. |
| SWAG | SGD 轨迹近似后验 | Wilson et al. |
| 深度高斯过程 | GP 的深度扩展 | Damianou & Lawrence |

### 3.5 不确定性估计

| 类型 | 含义 | 方法 |
|------|------|------|
| 认知不确定性 | 模型不知道（可减少） | 集成、贝叶斯 |
| 偶然不确定性 | 数据本身噪声（不可减少） | 异方差模型 |
| 预测不确定性 | 认知 + 偶然 | 总方差分解 |

### 3.6 主动学习与贝叶斯优化

- **主动学习 (Active Learning)**：模型主动选择最有信息量的样本标注
- **贝叶斯优化 (Bayesian Optimization)**：用 GP 建模目标函数，采集函数指导搜索
- 二者共享核心思想：**在不确定性最高的地方获取信息**

## 4. 发展历史

1. 1763：Bayes 定理发表
2. 1988：Pearl 概率推理获认可
3. 1990s：变分推断、MCMC 方法成熟
4. 2006：概率编程语言 (BUGS, Stan) 推广
5. 2015：变分自编码器 (VAE) 将变分推断与深度学习结合
6. 2017：贝叶斯深度学习复兴 (MC Dropout, Deep Ensembles)
7. 2020s：概率 ML 与 LLM 的结合（不确定性引导生成、概率编程 + LLM）

## 5. 与 AGI 的关系

- **持续学习的数学基础**：贝叶斯更新 = 后验 → 新先验，天然支持增量学习
- **不确定性感知决策**：AGI 必须知道"自己不知道什么"
- **小样本快速适应**：先验知识 + 少量观测 = 快速推理
- **因果推理的概率基础**：因果图 + 概率推断 = do-演算
- **AI 安全**：不确定性估计是可靠 AI 的基石

```
AGI 阶梯中的位置：

语言模型 → CoT → Agent → [持续学习] → 奇点 → 具身智能
                              ↑
                    贝叶斯更新是持续学习的
                    数学基础之一
```

## 6. 学习路径

1. 复习贝叶斯定理与共轭先验
2. 学习概率图模型（BN、MRF、HMM）
3. 理解变分推断与 MCMC 的区别
4. 学习高斯过程与贝叶斯优化
5. 研究贝叶斯深度学习（MC Dropout、Deep Ensembles）
6. 探索贝叶斯方法在持续学习中的应用

## 7. 未来趋势

- 可扩展贝叶斯推断（大规模数据）
- 贝叶斯持续学习
- 不确定性引导的主动探索
- 贝叶斯世界模型
