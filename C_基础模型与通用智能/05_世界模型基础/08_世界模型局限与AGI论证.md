# 世界模型局限与 AGI 论证

## 一句话理解

世界模型是连接感知、预测、规划和行动的重要组件，但能预测不蕴含理解因果、具备目标、能安全行动或已经达到 AGI。

视频逼真可能利用统计捷径，预测准确不识别干预，模拟环境存在 Sim2Real 风险，世界模型也不负责长期目标、记忆和工具组织。需要反事实、真实闭环、安全与长程 Agent 评测共同提供证据。
