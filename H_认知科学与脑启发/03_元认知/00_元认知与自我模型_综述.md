# 元认知与自我模型 综述

## 概述

元认知（Metacognition）是"对认知的认知"——系统监控、评估和调节自身认知过程的能力。自我模型（Self Model）是系统对自身状态、能力和局限的内部表征。二者共同构成 AGI 自我监控、自我改进和自我认识的基础。

## 核心概念

### 元认知
- **元认知知识**：对自身认知能力的了解（知道知道自己知道什么）
- **元认知监控**：实时追踪自身认知状态（自信度评估、错误检测）
- **元认知调控**：基于监控结果调整策略（选择推理深度、决定何时求助）

### 自我模型
- **自我表征**：系统对自身能力、知识和局限的内部模型
- **自我意识**：对自身状态和行动的觉察
- **自我改进**：基于自我模型识别弱点并主动改进

### 从元认知到 AGI
```
感知 → 认知 → 元认知 → 自我模型 → 自我改进 → AGI
```

## 主要研究方向

### 不确定性感知与校准
- 认知不确定性与偶然不确定性区分
- 置信度校准（Calibration）
- 不确定性估计方法（MC Dropout, Deep Ensembles, Conformal Prediction）
- "知道自己不知道什么"的能力

### 自我评估与反思
- 输出质量评估
- 答案正确性自我判断
- 推理链错误检测
- 自我一致性（Self-Consistency）

### 能力边界感知
- 知道自己能做什么、不能做什么
- 分布外检测（OOD Detection）
- 拒绝回答机制
- 主动求助策略

### 元学习（Learning to Learn）
- 学习如何更高效地学习
- 跨任务迁移学习策略
- MAML、ProtoNet 等方法
- 少样本学习的元策略

### 自我改进循环
- 自我评估 → 识别弱点 → 针对性学习 → 重新评估
- Constitutional AI 中的自我改进
- Self-Refine、Reflexion
- 经验积累与策略优化

## 关键技术

### 校准方法
- 温度缩放（Temperature Scaling）
- Platt Scaling
- 等渗回归（Isotonic Regression）
- 贝叶斯方法

### 元认知架构
- 监控模块：实时追踪推理质量
- 评估模块：判断输出可靠性
- 调控模块：选择最优策略
- 反馈循环：评估→调整→再评估

### 自我模型实现
- 基于训练的元知识：模型学习自身能力边界
- 基于推理的元判断：在推理时评估输出质量
- 混合方法：训练+推理结合

## 与 AGI 的关联

元认知与自我模型是 AGI 的关键能力：
- **自我监控**：实时了解自身认知状态
- **自我改进**：识别弱点并主动提升
- **可靠决策**：基于对自身能力的了解做决策
- **安全对齐**：知道自己能力的边界，避免过度自信

## 发展趋势

1. LLM 的元认知能力提升：自我评估与校准
2. 神经符号元认知：结合符号推理的自我监控
3. 持续元认知：在线监控与适应
4. 多层元认知：元认知的元认知
