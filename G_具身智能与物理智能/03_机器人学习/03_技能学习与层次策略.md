# 技能学习与层次策略

## 一句话理解

长程任务应分解为可验证技能，而非由一个低层策略输出数百步动作。技能是任务与动作之间的可复用单元，组合泛化的关键是明确的技能接口。

## 概述

单层策略难以完成长程任务：数百步的动作序列导致复合误差、难以监控失败、无法复用。层次策略（Hierarchical Policy）把任务分解为技能序列——每个技能是相对独立的行为单元（抓取、放置、开门），高层选择技能，低层执行技能。技能学习研究如何发现、表示、组合和泛化这些技能。

## 发展历史

- **1990s**：Options 框架（Sutton, Precup & Singh 1999）形式化层次 RL；运动原语（Dynamic Movement Primitives, DMP）出现。
- **2000s**：Hierarchical RL（HRL）理论发展（FeUdal Networks 的祖先）；技能发现（Skill Discovery）萌芽。
- **2010s**：选项学习、分层抽象成为主流；机器人技能库工程实践成熟（行为树 + 技能）。
- **2020s**：LLM 做高层任务分解 + 低层技能库执行（SayCan 2022）；技能库与 VLA 结合；基于大模型的技能发现与组合。

## 核心概念

| 概念 | 定义 | 关键点 |
|---|---|---|
| 技能/Option | \((I, \pi, \beta)\)：起始条件、内部策略、终止条件 | 可复用的行为单元 |
| 运动原语 (DMP) | 参数化节律/离散运动 | 生成平滑轨迹 |
| 层次策略 | 高层选技能，低层执行 | 时间抽象 |
| 技能库 | 技能的集合与索引 | 接口规范是关键 |
| 技能发现 | 从数据自动发现技能 | 无监督、内在动机 |
| 技能组合 | 序列/条件/循环组合 | 泛化的来源 |
| 行为树 | 任务编排结构 | 恢复骨架 |

## 技术原理

### 技能表示

| 表示 | 形式 | 优势 | 局限 |
|---|---|---|---|
| 运动原语 | 参数化轨迹 | 平滑、可调 | 表达力有限 |
| 目标条件策略 | \(\pi(a\mid o,g)\) | 通用、可组合 | 目标表示难 |
| 潜变量技能 | 潜在意图向量 | 自动发现 | 语义不可解释 |
| 语言技能 | 自然语言命名 | 可解释、可编排 | 语言落地难 |
| 动作片段 | 轨迹 chunk | 简单 | 复用性弱 |

### Option 形式化

技能可表示为 option：起始集合 \(I\)、内部策略 \(\pi\)、终止条件 \(\beta\)：

$$o=(I,\pi,\beta),\qquad I\subseteq S,\ \pi:S\to\Delta(A),\ \beta:S\to[0,1]$$

高层策略在技能间选择，技能执行到 \(\beta\) 为真时终止并返回结果。时间抽象使高层决策在更长时标上进行，降低长程任务的复杂度。

### 技能库与接口

技能库将 VLA/LLM 的语义泛化与规划器的可验证性、低层控制的稳定性连接起来。每个技能必须有明确接口：

```text
技能定义：名称、前置条件、后置条件、参数空间、失败模式
技能实现：规划、IL、RL、VLA 或混合策略
技能接口：输入（目标/对象/参数）→ 输出（成功/失败/部分完成）
```

`抓取(object)` 必须明确所需感知、可达条件、成功证据、超时与恢复路径。技能库应被视为可扩展、可替换的模块集合。

### 技能发现

- **内在动机**：以信息增益、预测误差为奖励发现新技能。
- **潜在空间聚类**：从动作数据聚类出行为单元。
- **任务无关预训练**：多种任务共享技能。
- **语言引导**：用语言标注技能语义。

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| Options | 时间抽象 RL | 层次决策 |
| DMP | 参数化运动原语 | 平滑轨迹 |
| FeUdal Networks | 高层-低层分解 | 长程 HRL |
| DIAYN | 内在动机技能发现 | 无监督技能 |
| SayCan | LLM 技能选择 + 可供性 | 语言任务 |
| 行为树 + 技能 | 编排框架 | 工程部署 |
| 技能库 + VLA | 语言条件技能 | 开放任务 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 可组合性 | 技能复用、任务泛化 | 接口设计成本 |
| 可验证性 | 技能级监控与恢复 | 依赖技能定义质量 |
| 样本效率 | 技能复用减少学习量 | 技能发现开销 |
| 可解释性 | 层次透明 | 高层语义与低层物理脱节 |

## 应用场景

- 家居任务："准备早餐"分解为取牛奶、倒牛奶、取麦片。
- 工业任务：抓取-搬运-装配流水线。
- 人形操作：移动 + 操作 + 恢复的组合。
- 长程导航 + 操作联合任务。

## 常见问题

- **技能粒度不当**：太粗无法复用，太细退化为单层策略。
- **接口不完整**：缺少前置条件/失败语义的技能无法可靠编排。
- **语义与物理脱节**：语言命名正确但动作不可行。
