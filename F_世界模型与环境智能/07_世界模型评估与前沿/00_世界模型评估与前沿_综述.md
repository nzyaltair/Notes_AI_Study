# 世界模型评估与前沿：以闭环效用检验“理解”

> 世界模型不能仅用画质或一步预测误差评价。真正的问题是：它是否在长程、物理、因果和分布外条件下可靠地支持行动，并能识别自己的边界。

## 评价框架

| 维度 | 核心问题 | 常见证据 |
|---|---|---|
| [[01_预测准确性\|预测准确性]] | 是否预测正确的未来分布？ | NLL、误差、校准、感知质量 |
| [[02_长程一致性\|长程一致性]] | 长时域是否保持身份、事件和状态？ | 多步 rollout、记忆和轨迹指标 |
| [[03_物理一致性\|物理一致性]] | 是否满足接触、重力、几何与守恒约束？ | 反事实物理测试、仿真验证 |
| [[04_因果理解\|因果理解]] | 是否响应干预、识别机制变化？ | action intervention、反事实任务 |
| [[05_泛化\|泛化]] | 是否适应新对象、组合、环境和任务？ | OOD、组合与跨域基准 |
| [[06_交互与任务能力\|交互与任务能力]] | 是否提高规划、控制与安全？ | 成功率、成本、风险、真人/现实验证 |

## 基准使用原则

基准应覆盖视频预测、机器人控制、导航、驾驶、游戏、工具环境和多智能体互动。不要把单一排行榜分数当作通用世界理解：应报告数据分布、动作覆盖、评价时域、模拟/现实差异和失败案例。

## 当前前沿与瓶颈

1. 长时域一致性与高效推理之间的矛盾。
2. 从相关视频统计到可干预物理/因果机制。
3. 多尺度、多模态状态的统一与可更新记忆。
4. 生成环境中的安全、偏见、版权和可控性。
5. 真实机器人与开放环境中的数据效率、Sim2Real 和持续学习。

世界模型的最终评价应回到闭环：它能否在有限真实试错与明确安全约束下，让智能体完成更可靠的新任务。
