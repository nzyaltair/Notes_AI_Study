# 语音与音频智能 综述

> **定位**：听觉感知将波形、频谱与声学事件转换为语言内容、说话人、情感、环境状态和可交互的音频表示——为多模态系统提供视觉之外的另一个关键感知通道。

## 领域定义

语音与音频智能研究如何从声学信号（波形、频谱）中提取语义信息（语音内容、说话人身份、情感状态）、环境信息（声事件、场景分类）以及可交互的音频表示。它是多模态感知中不可或缺的听觉通道。

## 核心问题

1. **声学-语义映射**：如何将连续的声学信号映射为离散的语义单元（音素、词、意图）？
2. **鲁棒性**：如何在噪声、混响、多说话人重叠等复杂声学环境下保持识别准确率？
3. **自监督声学表示**：如何像视觉领域的 MAE/DINO 一样，从大量无标签音频中学习通用声学表示？
4. **音视联合**：音频与视觉信息如何互补与对齐（如看口型听语音、定位声源）？
5. **语音生成与感知的统一**：识别（ASR）与生成（TTS）的共享表示是否可能？

## 技术演进路线

```text
传统声学模型 (GMM-HMM) 
    → 深度声学模型 (RNN-T/Listen Attend Spell) 
    → 端到端 ASR (RNN-T/Transformer) 
    → 自监督预训练 (wav2vec 2.0/HuBERT) 
    → 统一语音模型 (Whisper/USM) 
    → 语音语言模型 (SpeechGPT/SALM)
```

## 当前发展状态

- **自监督声学预训练已成熟**：wav2vec 2.0、HuBERT、WavLM 等自监督模型在大量无标签语音上学习通用声学表示
- **统一语音模型成为趋势**：Whisper 实现了多语言 ASR 的统一，USM 实现了多任务统一
- **语音 LLM 正在兴起**：SpeechGPT、SALM 等将 LLM 扩展到语音模态，实现端到端的语音对话
- **生成式语音质量接近人类**：VITS、NaturalSpeech 等神经声码器生成的语音在自然度上接近真人

## 前沿方向

- 语音理解与生成的统一架构（ASR + TTS + 语义理解）
- 语音基础模型的 Scaling Law
- 噪声鲁棒性与自监督适应
- 音视联合基础模型（视听协同感知）
- 语音情感与副语言信息的深度融合

## 学习路径

1. 信号处理基础 → 2. 声学特征提取 → 3. ASR 基础 → 4. 端到端 ASR → 5. 自监督声学表示 → 6. 语音生成 → 7. 音视联合学习
