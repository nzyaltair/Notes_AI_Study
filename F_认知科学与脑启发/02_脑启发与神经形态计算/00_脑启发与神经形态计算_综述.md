# 脑启发与神经形态计算综述：从大脑结构到新型计算范式

## 一句话理解

脑启发计算从大脑的运行原理中获取 AI 设计灵感，神经形态计算在硬件层面模拟大脑的脉冲信号处理——二者共同探索超越冯·诺依曼架构的智能计算范式，是 AGI 长远路线中可能带来范式突破的方向。

## 1. 领域定义

- **脑启发计算（Brain-Inspired Computing）**：从大脑的结构和功能原理中提取设计思想，应用于算法和系统设计
- **神经形态计算（Neuromorphic Computing）**：在硬件层面模拟生物神经元的脉冲信号处理机制
- **脉冲神经网络（Spiking Neural Network, SNN）**：使用离散时间脉冲进行信息传递的神经网络模型

## 2. 为什么需要这个方向

- 大脑功耗约 20W，GPT-4 训练功耗巨大——能效差距悬殊
- 大脑支持持续学习，ANN 容易遗忘——架构差异
- 大脑具备真正的通用智能，ANN 在特定任务间迁移困难
- 冯·诺依曼架构的内存墙问题越来越严重

## 3. 核心内容

### 3.1 脑启发计算

| 灵感来源 | AI 应用 | 例子 |
|----------|---------|------|
| 海马体快速记忆 | 少样本学习 | Memory-augmented Networks |
| 前额叶工作记忆 | 注意力与上下文 | Transformer 工作记忆类比 |
| 视觉皮层层级处理 | CNN 设计 | HMAX, Neocognitron |
| 多巴胺奖励信号 | 强化学习 | TD学习与多巴胺 |
| 小脑运动控制 | 精细运动控制 | 机器人控制策略 |

### 3.2 神经形态计算

| 平台 | 特点 | 状态 |
|------|------|------|
| Intel Loihi 2 | 可编程脉冲芯片 | 研究可用 |
| IBM TrueNorth | 百万神经元模拟 | 早期产品 |
| SpiNNaker | 大规模脉冲仿真 | 欧盟脑计划 |
| 清华天机芯 | 混合 ANN/SNN | 已发表 |

### 3.3 脉冲神经网络

| 特性 | ANN | SNN |
|------|-----|-----|
| 信号 | 连续值 | 离散脉冲 |
| 时间 | 无内在时间 | 内在时间动态 |
| 能耗 | 高 | 极低（理论上） |
| 训练 | 反向传播 | STDP / BPTT / 替代梯度 |
| 成熟度 | 工业级 | 研究阶段 |

## 4. 发展历史

1. 1943：McCulloch-Pitts 神经元模型（脉冲神经元雏形）
2. 1949：Hebb 学习规则
3. 1997：Maass 提出 SNN 第三代神经网络
4. 2005-：IBM/Intel 神经形态芯片
5. 2019：清华天机芯登上 Nature 封面
6. 2020s：SNN + 深度学习融合（Spiking Transformer）

## 5. 与 AGI 的关系

- **长线方向**：可能提供突破现有范式的计算架构
- **能效突破**：AGI 需要极高的能效比
- **持续学习**：SNN 的内在时间动态更接近生物持续学习
- **现实性**：当前仍处研究早期，不能替代主流路线，但值得关注

## 6. 学习路径

1. 理解生物神经元与脉冲信号
2. 学习 Hebb 学习与 STDP
3. 了解 SNN 的编码与训练方法
4. 研究神经形态芯片架构
5. 探索 SNN + ANN 混合架构
