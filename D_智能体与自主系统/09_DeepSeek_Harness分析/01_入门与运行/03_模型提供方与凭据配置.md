# 模型提供方与凭据配置

## 一句话理解

模型路由由提供方、协议、端点、凭据引用和模型能力共同决定；凭据只写入受保护存储，模型输入模态必须是对真实端点能力的准确声明。

## 配置模型

Web UI 的“设置 → 模型”可配置 DeepSeek、已安装目录提供方或自定义 OpenAI 兼容端点。模型变更在下一次请求生效，不要求重启。密钥保存后界面只收到脱敏描述符；凭据存于 `$DSH_HOME/.credentials.yaml`，设置文件保留引用而非明文。

## 自定义提供方的稳定标识

自定义配置至少包含小写 Provider ID、基础 URL、协议、凭据与模型。Provider ID 会被请求、会话默认值和凭据引用持久使用，不能把“改显示名”误当成安全重命名；需要改 ID 时，新建提供方并迁移后删除旧项。

## 模态声明

手动录入模型默认仅接受文本。视觉模型需声明 `input: [text, image]`；路由的 `defaultInput` 只是未被目录描述模型的回退，不会覆盖模型自己的 `input`。该声明是对端点的断言，不会主动验证端点是否真的支持图片。

## 排错思路

| 现象 | 优先检查 |
|---|---|
| `MISSING_CREDENTIAL` | 是否通过 UI 存密钥，或被引用环境变量是否存在 |
| `UNKNOWN_MODEL` | 提供方和模型 id 是否均已保存 |
| 获取模型返回 401 | 密钥；发现使用兼容的 `GET /models` |
| 图片发送前被拒绝 | 模型是否声明 `image` 输入 |
| 端点拒绝图片 | 删除错误的模态断言，并开启新会话避免历史附件重复参与请求 |
