# 双目立体匹配

## 一句话理解

双目立体匹配在完成相机校正后，为左图每个像素寻找右图的对应点；对应点的水平位移（视差）经三角测量转为米制深度，因此它用额外视角换取单目所缺失的尺度约束。

## 几何与前提

对于已校正的平行双目，极线为水平线，搜索从二维降为同一行的一维视差搜索：

\[
d(u,v)=u_L-u_R, \qquad Z(u,v)=\frac{fB}{d(u,v)}
\]

实际系统的前提包括：严格同步、内外参标定、立体校正、足够重叠视场与非零基线。深度不确定度近似满足 \(\sigma_Z\propto Z^2\sigma_d/(fB)\)，故远距离、小基线和低分辨率都会迅速恶化测距精度。

## 经典流水线

```text
标定与极线校正 → 特征/代价计算 → 代价聚合 → 视差优化
    → 左右一致性检查 → 遮挡填充 / 亚像素优化 → 深度与置信度
```

传统方法以 SAD/SSD、Census 或互信息构造匹配代价，再以 Semi-Global Matching（SGM）等路径优化平滑性。它们无需训练、易解释，仍常用于资源受限或可控工业场景。

## 深度学习范式

| 范式 | 机制 | 代表 | 优势与代价 |
|:---|:---|:---|:---|
| 2D 特征 + 3D 代价体积 | 枚举候选视差并正则化 | PSMNet、GANet | 几何显式，但显存随视差范围增大 |
| 可微 PatchMatch | 迭代采样少量候选 | DeepPruner、CREStereo | 降低全量代价体积成本 |
| 光流式迭代更新 | 相关体积 + GRU 反复修正视差 | RAFT-Stereo | 细致且强鲁棒，需权衡迭代次数 |
| 几何编码体积 | 多范围、多粒度几何特征 | IGEV、IGEV++ | 针对大视差、弱纹理和遮挡优化 |
| 泛化/无标定匹配 | 提升跨相机、跨域适配 | Stereo Anywhere 等 | 仍需严谨验证度量一致性 |

## RAFT-Stereo

RAFT-Stereo 将 RAFT 的“全对相关 + 循环更新”思想迁移到双目：从左右特征建立相关金字塔，通过 ConvGRU 不断更新视差。相比一次性回归，迭代过程能逐步聚焦难匹配区域，成为现代双目匹配的重要基线。

## IGEV 与 IGEV++

IGEV（Iterative Geometry Encoding Volume）以几何编码体积增强循环更新器。IGEV++（TPAMI 2025）进一步构建 **Multi-range Geometry Encoding Volumes (MGEV)**：

- 自适应 patch matching 兼顾大视差范围与困难区域；
- 多范围、不同粒度特征同时保留粗几何与细节；
- selective geometry feature fusion 自适应地融合这些特征；
- 再以 ConvGRU 迭代更新视差。

该工作报告在 Scene Flow 大视差范围及 Middlebury、ETH3D、KITTI 2012/2015 上达到强结果，并给出实时版本。它反映出当前前沿并非放弃代价体积，而是以更高效、更有选择性的几何表示处理病态区域。

## 遮挡与病态区域

| 区域 | 为什么失败 | 常见处理 |
|:---|:---|:---|
| 遮挡 | 一侧相机根本看不到对应像素 | 左右一致性检查、遮挡掩膜、单目先验补全 |
| 无纹理墙面 | 多个视差的外观代价相近 | 上下文/语义特征、平滑先验、几何体积 |
| 重复纹理 | 错误对应也有低代价 | 更大感受野、全局约束、置信度筛除 |
| 反光/透明物 | 光度一致性被破坏 | 偏振/主动传感器、多模态融合、失效检测 |
| 远距离 | 视差接近量化噪声 | 增大基线/焦距、提高分辨率、融合 LiDAR |

## 工程检查表

1. 先以棋盘格或专业标定板标定内参、畸变和外参，并在目标温度/焦距下复验。
2. 保证硬件同步；运动平台上的毫秒级时间差会引入显著视差错误。
3. 对输出做左-右一致性和置信度阈值过滤，而不是把所有像素直接交给避障模块。
4. 用目标距离区间的真实标尺评估，不能仅看近景的平均 EPE。
5. 远距、夜间、雨雾、低纹理路面优先规划传感器冗余。
