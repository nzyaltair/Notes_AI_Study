# 模板卡片规范

> 模型卡、论文卡、数据集卡、基准卡、事故卡的标准模板。用于统一记录各类知识对象。

## 模型卡

```yaml
---
type: model-card
model_name: "模型名称"
version: "1.0"
release_date: 2026-01-01
architecture: "架构描述（如 Transformer Decoder-only）"
parameters: "7B"
training_data: "训练数据描述"
context_length: "32K"
license: "MIT"
---
```

| 字段 | 必填 | 说明 |
|------|------|------|
| model_name | 是 | 模型名称 |
| version | 是 | 版本号 |
| release_date | 是 | 发布日期 |
| architecture | 是 | 架构描述 |
| parameters | 是 | 参数量 |
| training_data | 是 | 训练数据概要 |
| context_length | 是 | 最大上下文长度 |
| license | 是 | 许可证 |
| performance | 是 | 关键性能指标 |
| limitations | 否 | 已知局限 |
| references | 否 | 论文/文档链接 |

## 论文卡

```yaml
---
type: paper-card
title: "论文标题"
authors: ["作者1", "作者2"]
year: 2026
venue: "会议/期刊名"
core_contribution: "核心贡献一句话"
method: "方法简述"
key_results: "关键实验结果"
limitations: "局限"
code_url: "代码链接"
---
```

## 数据集卡

```yaml
---
type: dataset-card
name: "数据集名称"
version: "1.0"
size: "样本数量"
task: "任务类型"
languages: ["语言"]
annotation: "标注方式"
license: "许可证"
splits: "训练/验证/测试划分"
---
```

## 基准卡

```yaml
---
type: benchmark-card
name: "基准名称"
task: "评测任务"
metrics: ["指标1", "指标2"]
num_tasks: "子任务数量"
data_source: "数据来源"
leaderboard_url: "排行榜链接"
saturation_level: "饱和程度（低/中/高）"
---
```

## 事故卡

```yaml
---
type: incident-card
date: 2026-01-01
system: "受影响系统"
impact: "影响描述"

---
```
