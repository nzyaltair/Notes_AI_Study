# 数据工程与合成数据综述：AI 的新石油与炼油术

## 一句话理解

数据工程是 AI 系统的"供血系统"，合成数据是用 AI 生成训练数据的新范式——当互联网高质量数据趋于耗尽，合成数据可能成为 AGI 继续 Scaling 的关键燃料。

## 1. 领域定义

### 数据工程

AI 数据的全生命周期管理：采集、清洗、标注、增强、存储、版本管理和质量监控。

### 合成数据 (Synthetic Data)

通过程序或 AI 模型生成的、用于训练或评估的数据。不来自真实世界采集，而是有控制地生成。

## 2. 核心方法

### 2.1 数据构造

| 方法 | 描述 | 适用场景 |
|------|------|----------|
| 人工标注 | 人类标注数据 | 高质量小规模 |
| 弱监督 | 规则/启发式标注 | 大规模低成本 |
| 众包标注 | 分布式人工标注 | 中等规模 |
| AI 辅助标注 | AI 预标注 + 人工审核 | 高效标注 |
| 合成数据 | AI/程序生成 | 大规模特定场景 |

### 2.2 数据清洗

| 问题 | 方法 | 说明 |
|------|------|------|
| 重复数据 | 去重 (MinHash, SimHash) | 训练数据去重提升效率 |
| 标签噪声 | 噪声鲁棒训练 | 标签错误影响模型 |
| 低质量数据 | 过滤 (启发式 + 分类器) | 质量过滤提升训练效果 |
| 有害数据 | 安全过滤 | 毒性/偏见内容过滤 |
| PII | 隐私脱敏 | 个人信息去除 |

### 2.3 数据增强

| 类型 | 方法 | 适用模态 |
|------|------|----------|
| 几何变换 | 翻转/旋转/裁剪 | 图像 |
| 颜色变换 | 颜色抖动/灰度 | 图像 |
| 文本增强 | 同义词替换/回译 | 文本 |
| 混合增强 | MixUp/CutMix | 图像 |
| 生成增强 | 扩散模型生成 | 多模态 |

### 2.4 合成数据生成

| 方法 | 核心思想 | 代表 |
|------|----------|------|
| LLM 自生成 | 模型生成自己的训练数据 | Self-Instruct, Constitutional AI |
| 扩散模型生成 | 生成图像/视频训练数据 | Stable Diffusion 数据 |
| 3D 仿真生成 | 仿真环境生成机器人数据 | Isaac Sim, SAPIEN |
| 程序化生成 | 程序自动生成结构化数据 | 代码/数学/逻辑数据 |
| 数据蒸馏 | 强模型生成弱模型训练数据 | Knowledge Distillation |

### 2.5 合成数据的关键问题

| 问题 | 描述 | 挑战 |
|------|------|------|
| 质量保证 | 合成数据是否高质量 | 需要质量评估框架 |
| 多样性 | 是否覆盖足够分布 | 避免模式坍缩 |
| 模型坍缩 | 用 AI 数据训练 AI 会退化 | 递归训练质量下降 |
| 偏差放大 | 合成数据可能放大偏见 | 需要偏差校正 |
| 领域特定性 | 特定场景合成困难 | 医疗/法律等高门槛领域 |

## 3. 发展历史

1. 2010s：传统数据增强（翻转/裁剪/颜色）
2. 2023：Self-Instruct 用 LLM 生成指令数据
3. 2023：合成数据成为 LLM 训练标准做法
4. 2024：扩散模型生成视觉训练数据
5. 2024：模型坍缩问题引起关注
6. 2025-26：合成数据成为数据工程的核心方向

## 4. 与 AGI 的关系

- **数据瓶颈**：高质量互联网数据趋于耗尽，合成数据是突破口
- **持续学习的数据来源**：合成数据可按需生成
- **安全训练数据**：合成有害场景数据用于安全对齐
- **具身数据**：仿真生成机器人训练数据
- **评测数据**：合成评测基准

```
AGI 阶梯中的位置：

语言模型 → CoT → Agent → 持续学习 → 奇点 → 具身智能
             ↑                    ↑           ↑
        指令数据(合成)        需要流式数据    仿真数据(合成)
```
