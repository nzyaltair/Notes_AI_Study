# 持续学习与元学习综述：AGI 的当前最大瓶颈

## 一句话理解

持续学习解决"如何像人一样不断积累经验而不遗忘旧知识"，元学习解决"如何学会快速学习新任务"——二者共同构成 AGI 阶梯从 Agent 迈向自我迭代的核心瓶颈，也是目前全世界都还没有找到可靠方法的研究前沿。

## 1. 领域定义

### 持续学习（Continual / Lifelong Learning）

智能体在时间线上连续学习一系列任务，同时保持对旧任务的能力，不发生灾难性遗忘（catastrophic forgetting）。

### 元学习（Meta-Learning / Learning to Learn）

智能体从多个学习经历中提取"如何学习"的元知识，使其面对新任务时能用少量数据和步数快速适应。

### 二者关系

- 持续学习关注**时间维度的积累**（不遗忘）
- 元学习关注**效率维度的适应**（学得快）
- AGI 需要两者兼备：既持续积累，又快速适应

## 2. AGI 阶梯定位

```
语言模型 -> CoT -> Agent -> [持续学习] -> 奇点(自我迭代) -> 具身智能
                           当前最大瓶颈
```

梁文锋的判断：
- Agent 之后，**持续学习是下一个必须跨过的障碍**
- 持续学习不是一项技术，而是一个**问题**——可能需要多种技术来解决
- 全世界都还在摸索阶段，尚未找到 work 的方法
- 一旦解决持续学习，AI 能力将大幅提升，可以加速 AGI 研究本身

## 3. 持续学习核心问题

### 3.1 灾难性遗忘

神经网络学习新任务时覆盖旧知识，导致旧任务性能骤降。这是持续学习最根本的挑战。

### 3.2 主要方法

| 类别 | 核心思想 | 代表方法 |
|------|----------|----------|
| 正则化方法 | 限制重要参数的更新 | EWC, SI, MAS |
| 回放方法 | 重放旧数据/特征 | Experience Replay, GEM, A-GEM |
| 架构方法 | 为新任务扩展新模块 | Progressive Nets, PackNet, HAT |
| 动态架构 | 按需增减容量 | DGM, CNDPM |
| 基于提示 | 轻量任务适配 | L2P, DualPrompt |

### 3.3 评估指标

- 平均准确率（AA）
- 遗忘度（Forgetting Measure）
- 向前迁移（FWT）/ 向后迁移（BWT）

## 4. 元学习核心方法

| 类别 | 核心思想 | 代表方法 |
|------|----------|----------|
| 基于优化 | 学习优化器或初始化 | MAML, Reptile, LSTM优化器 |
| 基于度量 | 学习距离度量 | Prototypical, Matching, Relation |
| 基于模型 | 元学习模型架构 | HyperNetwork, Meta-LSTM |
| 基于记忆 | 外部记忆快速适配 | MANN, Meta-RNN |

## 5. 小样本学习

与元学习紧密相关：在只有少量样本的情况下学习新类别或新任务。

- Few-Shot Classification：5-way 1-shot / 5-shot
- 数据增强、生成模型辅助
- 与 LLM 的 in-context learning 形成有趣对比

## 6. 发展历史

1. 1990s：McCloskey & Cohen 发现多层感知机的灾难性遗忘
2. 2017：EWC（Kirkpatrick et al.）开创正则化持续学习
3. 2017：MAML（Finn et al.）开创元学习优化路线
4. 2019：GEM/A-GEM 引入梯度约束
5. 2022：L2P 将 prompt tuning 引入持续学习
6. 2025-26：持续学习成为 AGI 路线图的明确瓶颈

## 7. 与 AGI 的关系

- **Agent 的瓶颈**：当前 Agent 无法持续学习，每次从零开始
- **自我迭代的前提**：AI 必须能从经验中持续改进
- **人脑的参照**：人能持续学习2个月就上手新工作，AI 不能
- **与 LLM 的关系**：in-context learning 是一种"临时持续学习"，但不在权重层面

## 8. 学习路径

1. 理解灾难性遗忘问题
2. 学习 EWC（正则化路线）
3. 学习 Experience Replay（回放路线）
4. 学习 MAML（元学习路线）
5. 研究持续学习 + LLM 的最新进展
6. 思考持续学习的本质难点与可能突破

## 9. 未来趋势

- 持续学习 + LLM（权重层面的持续适应）
- 脑启发的持续学习机制
- 持续学习世界模型
- 开放世界持续学习
- 持续学习安全（避免持续学入有害知识）
