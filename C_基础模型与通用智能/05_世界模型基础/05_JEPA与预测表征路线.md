# JEPA 与预测表征路线

## 一句话理解

JEPA 在抽象表示空间预测目标而非重建每个像素，可为世界模型提供高效状态学习方式；它本身不包含动作、规划或因果干预的完整答案。

生成目标需覆盖观测细节和多模态分布，潜在预测可忽略不可预测纹理而聚焦稳定因素。走向世界模型还需加入时间与动作条件、多未来不确定性、长程一致性和规划增益评测。
