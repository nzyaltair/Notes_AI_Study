# 四足机器人

## 一句话理解

四足机器人以多足接触提供较强地形适应性，适合巡检、野外运输和危险环境。核心问题是浮动基座动力学、落足规划、接触切换、状态估计和跌倒恢复。

## 概述

四足机器人（Quadruped）是足式机器人的代表形态：四条腿提供静态与动态稳定，通过落足点选择适应崎岖地形。与轮式相比，四足能跨越台阶、碎石、沟壑；与人形相比，四足更稳定、成本更低、技术更成熟。它是学习型运动控制（RL + Sim2Real）最成功的落地平台之一。

## 发展历史

- **1980s**：Raibert 的平衡控制研究奠定动态足式运动理论（One-Legged Hopper）。
- **2000s-2010s**：BigDog（2005）、LS3、Spot（2015）展示野外运动能力；MIT Cheetah 系列展示高速动态运动。
- **2018-2020**：RL + 域随机化实现四足步态迁移（ANYmal, Unitree）；MPC + WBC 用于动态平衡。
- **2020s**：Unitree Go1/B2、ANYmal C 等商业平台成熟；学习型运动策略成为标配；四足 + 机械臂（ANYmal arm）出现。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 浮动基座 | 基座不固定，靠接触约束平衡 | 足式机器人共性 |
| 步态 | 腿的时序模式（walk, trot, gallop） | 速度/稳定权衡 |
| 落足规划 | 选择支撑脚落点 | 地形适应 |
| 接触模式 | 支撑相/摆动相切换 | 动态平衡 |
| ZMP/支撑多边形 | 零力矩点稳定性判据 | 静态稳定 |
| 跌倒恢复 | 从摔倒状态起身 | 长期自主 |
| 全身控制 (WBC) | 多任务优先级控制 | 稳定执行 |

## 技术原理

### 浮动基座动力学

四足机器人是浮动基座系统：身体不固定于地面，只能通过脚与地面的接触力保持平衡。动力学：

$$M(q)\ddot q + h(q,\dot q) = S^T\tau + J_c^T F_c$$

- \(S\) 选择被驱动关节。
- \(J_c^T F_c\) 是接触力（脚的支撑力）。

### 控制方法

| 方法 | 核心思想 | 优势 | 局限 |
|---|---|---|---|
| 静态步态规划 | 重心在支撑多边形内移动 | 简单稳定 | 慢 |
| 动态步态 | 质心在支撑多边形外仍平衡 | 快速 | 需要精确动力学 |
| MPC + WBC | 预测控制全身协调 | 约束 + 动态 | 计算成本 |
| RL 运动策略 | 学习步态策略 | 复杂地形泛化 | 安全验证 |
| 混合 | MPC/WBC 约束 + RL 残差 | 安全 + 适应 | 接口复杂 |

### RL 运动控制

RL 四足运动的标准管线：

1. 仿真中训练（Isaac Gym/Lab，GPU 并行）。
2. 域随机化（摩擦、地形、负载、传感延迟）。
3. 观测：本体状态 + 感知（地形高度、摩擦系数）。
4. 部署：有限真机微调 + 安全层。

### 落足规划

对崎岖地形，需要规划落足点：感知地形 → 评估支撑区域 → 选择落点 → 生成轨迹 → 执行。学习型方法从感知直接预测落点。

### 跌倒恢复

跌倒检测（姿态异常、接触意外）→ 蜷缩/调整 → 起身规划 → 恢复站立。长期自主的必要机制。

## 关键方法与模型

| 方法/平台 | 核心思想 | 适用 |
|---|---|---|
| Raibert 平衡 | 动态平衡基础理论 | 教学与基础 |
| MPC + WBC | 全身动态控制 | 动态步态 |
| RL 步态 | 学习型运动策略 | 复杂地形 |
| 域随机化 | 仿真训练迁移 | 部署 |
| ANYmal | 自主四足平台 | 工业巡检 |
| Unitree Go/B2 | 商业四足平台 | 研究/开发 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 地形适应 | 跨越台阶/碎石 | 能耗高于轮式 |
| 稳定性 | 四足冗余支撑 | 载荷有限 |
| 成熟度 | 商业平台成熟 | 成本仍高 |
| 学习落地 | RL 迁移成功 | 长程自主仍难 |

## 应用场景

- 工业巡检：管道、化工厂、变电站。
- 野外运输与搜索救援。
- 农业监测、测绘。
- 研究与教育平台。

## 前沿发展

- **四足 + 操作**：四足基座 + 机械臂（ANYmal arm, Unitree 机械臂）。
- **高速动态运动**：跳跃、翻滚、奔跑。
- **感知运动联合**：地形感知直接驱动落足。
- **长程自主**：多任务巡检 + 充电 + 数据回传。
- **人机协作**：四足在人群/工厂环境的安全运行。

## 常见问题

- **把 RL 当黑盒**：安全约束必须独立于策略。
- **只测仿真**：摩擦、地形、延迟差异必须在真机验证。
- **忽略能耗**：四足能耗高，续航是实际瓶颈。
- **忽略跌倒**：长期部署必须处理跌倒恢复。
