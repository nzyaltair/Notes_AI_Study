# 交互与任务能力

## 一句话理解

世界模型的实际价值通过闭环任务体现：它能否在真实（或接近真实的）环境中提升成功率、样本效率与安全性，是最终评价标准。

## 概述

离线预测、生成质量与物理一致性都是中间证据；最终要回答：把世界模型接入规划或策略后，Agent 是否真的做得更好、更安全、更高效？闭环评估正是检验这一点的环节。

## 评估维度

| 维度 | 指标 | 说明 |
|---|---|---|
| 任务成功率 | 完成率、平均回报 | 与 model-free、规则基线对比 |
| 样本效率 | 达到阈值所需交互数 | 世界模型的核心卖点 |
| 效率 | 规划延迟、能耗、计算预算 | 实时性约束 |
| 鲁棒性 | 扰动/噪声下性能保持 | 泛化到执行层 |
| 恢复能力 | 失败后的重试、纠错 | 交互中的闭环价值 |
| 安全性 | 风险违规率、约束违反、近失事件 | 高风险系统关键 |

## 评估原则

- **基线对比**：与模型自由策略、规则仿真或人工基线比较，避免自说自话。
- **模拟→现实**：报告现实迁移表现，仿真分数只是中间证据。
- **分位数与最坏情况**：平均回报不足以说明安全；报告最坏分位、近失事件、约束违反、人工接管次数。
- **置信度可用性**：模型是否在不确定时发出可用的风险信号。

## 常见误区

- 只报仿真平均回报：掩盖危险长尾。
- 只报成功率不报失败模式：无法定位模型缺陷。
- 用生成视频的"视觉连贯"替代任务结果：生成不等于决策收益。
