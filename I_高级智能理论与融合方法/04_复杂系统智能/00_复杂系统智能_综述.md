# 复杂系统智能 (Complex Systems Intelligence)

> **定位**：高级智能理论与融合方法的重要组成——从复杂系统科学视角理解智能的涌现性质，探索多尺度、非线性、自组织系统中的智能行为。

---

## 一、为什么需要复杂系统视角

智能本身是一种涌现现象——从简单规则中产生复杂行为：

```
简单规则 → 局部交互 → 涌现行为 → 系统智能
  (神经元)    (突触连接)   (认知功能)   (通用智能)
```

| 特性 | 描述 | 对AGI的启示 |
|------|------|-------------|
| 涌现 | 整体大于部分之和 | 智能可能从规模中涌现 |
| 自组织 | 无中心控制的全局秩序 | 去中心化智能架构 |
| 非线性 | 小扰动→大变化 | 训练中的相变与涌现 |
| 多尺度 | 不同层次有不同规律 | AGI的多层次理解 |
| 适应性 | 环境变化中维持功能 | 鲁棒与泛化的基础 |

## 二、核心主题

### 2.1 涌现与自组织

- 弱涌现 vs 强涌现

- 元胞自动机与规则涌现

- 小世界网络与脑网络

### 2.3 多尺度建模

- 分岔与相变
