# 具身智能与物理智能综述：从身体闭环到 Physical AGI

## 一句话理解

具身智能研究智能体如何借助身体在物理世界中**感知、预测、学习、规划、控制并持续适应**。机器人是身体与执行平台；Physical AGI 的核心则是将基础模型、世界模型、机器人学习和安全控制组织成可闭环改进的行动系统。

## 1. 从“Robot → AI”到“AI → Robot”

传统机器人学以本体、运动学、规划和控制为起点，再接入视觉与学习模块。现代 Physical AI 则以通用表征、语言理解和预测能力为上层入口，让它们通过技能、规划器和安全控制器落到不同机器人身体。

```text
语言目标 / 人类协作
        ↓
基础模型（VLM / VLA / 通用策略）
        ↓
具身 Agent（记忆、任务分解、恢复）
        ↓
世界模型（状态、后果、风险与不确定性预测）
        ↓
技能学习与规划（任务—运动—接触）
        ↓
控制与执行（MPC / 阻抗 / WBC / 安全监督）
        ↓
机器人身体与环境 ───────────→ 数据与经验闭环
        ↑
多模态具身感知（视觉、深度、触觉、本体、语言）
```

这不是单向流水线：每个动作会改变环境和观测；预测误差、失败恢复和人类干预会成为下一轮学习的数据。

## 2. 本知识体系的十个层次

| 目录 | 回答的问题 | 核心对象 |
|---|---|---|
| 01 机器人身体与系统 | 身体能做什么、如何可靠运行？ | 本体、运动学、接触、ROS 2 |
| 02 具身感知 | 为行动必须知道什么？ | 3D、空间、可供性、主动感知 |
| 03 机器人学习 | 如何从数据和交互中得到技能？ | IL、RL、自监督、终身学习、数据 |
| 04 具身世界模型 | 行动之后会发生什么？ | 物理预测、潜在状态、想象规划 |
| 05 具身规划与决策 | 在约束下先做什么、怎样做？ | TAMP、技能组合、长程决策 |
| 06 控制与执行 | 怎样稳定、安全地做到？ | 控制、学习控制、Sim2Real |
| 07 机器人平台 | 用什么身体进入哪些环境？ | 人形、机械臂、移动、四足、无人机 |
| 08 具身 Agent | 如何自主完成长程开放任务？ | 记忆、语言落地、恢复、协作 |
| 09 具身基础模型 | 如何规模化统一视觉、语言和动作？ | VLM、VLA、扩散策略、跨本体 |

## 3. 四个不可替代的核心瓶颈

1. **数据与接口**：真实机器人数据昂贵且异构；动作坐标系、控制频率、标定与成功标准不统一会直接破坏可扩展性。
2. **物理泛化**：互联网语义知识不能自动解决摩擦、遮挡、接触、时延和柔性物体。
3. **长程可靠性**：任务成功依赖记忆、状态更新、失败诊断与恢复，不是单次动作预测。
4. **安全与验证**：学习模型可提议行动，但碰撞、力矩、速度、工作空间和急停必须由独立层约束。

## 4. 典型系统分工

| 层级 | 最适合的机制 | 不应单独承担的工作 |
|---|---|---|
| VLM / LLM | 开放指令理解、对象语义、任务候选 | 毫秒级力控和碰撞安全 |
| 世界模型 | 后果比较、不确定性与重规划 | 代替真实接触验证 |
| IL / RL / VLA | 从数据学习技能和泛化策略 | 绕过硬约束直接驱动高风险硬件 |
| 经典规划 | 可达性、碰撞、任务前后置条件 | 从原始图像学习语义 |
| 控制器 | 高频稳定、接触顺应、动态平衡 | 解释开放语言意图 |
| 安全监督 | 限幅、拒绝危险命令、降级 | 依赖模型自我声明安全 |

可靠 Physical AI 通常是混合架构，而不是“端到端”与“模块化”的二选一。

## 5. 建议学习路径

1. **物理基础**：机器人身体与系统 → 具身感知 → 控制与执行。
2. **学习闭环**：模仿学习 → 强化学习 → 技能学习 → 数据工程与 Sim2Real。
3. **智能闭环**：空间状态 → 世界模型 → 任务与运动规划 → 具身 Agent。
4. **前沿路线**：机器人基础模型 → VLA → 跨本体学习 → 长程自主与终身学习。
