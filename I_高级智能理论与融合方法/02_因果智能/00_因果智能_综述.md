# 因果智能综述

> **核心命题**：因果智能以显式或隐式机制模型回答"改变什么会发生什么"与"若当时不同会怎样"，而不止拟合观察数据中的相关性。

## 因果阶梯

| 层级 | 问题形式 | 所需能力 |
|---|---|---|
| 关联 | 看到 X 时 Y 如何？ | 统计预测 |
| 干预 | 做 `do(X)` 会怎样？ | 混杂控制、机制假设 |
| 反事实 | 同一事件中，若未做 X 会怎样？ | 个体层机制与证据 |

## 发展历史

| 阶段 | 代表工作 | 关键贡献 |
|---|---|---|
| 1920s-1950s | Wright 路径分析、Neyman-Rubin 潜在结果 | 因果关系的统计与实验基础 |
| 1980s-2000s | Pearl 因果图、do-演算、SCM | 建立"关联-干预-反事实"三层因果阶梯 |
| 2010s | 因果发现算法、Double ML | 从观测数据中估计因果效应的方法学成熟 |
| 2020s | 因果表示学习、因果 RL、LLM 因果推理 | 因果与机器学习/大模型的深度结合 |

## 与 AGI 的关系

因果模型为规划、迁移和安全干预提供机制性假设；但"相关不等于因果"也意味着因果结论不能只由模型语言表达或观察拟合得出。必须陈述识别假设、数据来源、干预可行性与不确定性。
