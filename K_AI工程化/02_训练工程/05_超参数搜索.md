# 超参数搜索

## 一句话理解

通过受控实验在学习率、batch size、优化器配置等超参数空间中寻找最优组合，以系统化方法替代手工试错。

## 概述

超参数对模型训练效果的影响巨大——学习率偏差一个数量级就可能导致训练完全失败。大模型训练成本极高，无法像传统 ML 那样进行大规模网格搜索，因此需要更高效的搜索策略。

本笔记回答的核心问题：
- 哪些超参数最关键？影响如何？
- 大模型场景下如何高效搜索？
- 如何保证搜索结果的可复现性和可迁移性？

## 发展历史

| 时间 | 里程碑 | 意义 |
|---|---|---|
| 2012 | Grid Search 普遍使用 | 传统 ML 标准方法 |

## 核心概念

### 超参数分类

| 类别 | 超参数 | 敏感度 |
|---|---|---|
| 优化器 | 学习率、weight decay、beta1/beta2 | 极高 |
| 批量 | batch size、梯度累积步数 | 高 |
| 调度 | warmup steps、衰减策略 | 高 |
| 正则 | dropout、label smoothing | 中 |
| 模型结构 | 层数、宽度、注意力头数 | 高（但通常固定） |
| 数据 | 序列长度、采样策略、数据配比 | 中-高 |

### 学习率的重要性

学习率是最关键的超参数。过大导致发散，过小导致收敛缓慢或陷入局部最优。

经验法则（基于 Scaling Laws）：

$$\text{LR}_{\text{opt}} \propto \text{batch\_size}^{0.5} \text{（线性缩放法则，近似）}$$

实际中大 batch 训练使用更大学习率，但缩放并非严格线性。

## 技术原理

### 搜索方法

#### 网格搜索（Grid Search）

穷举所有超参数组合。适用于低维空间（2-3 个超参数），但在高维空间效率极差。

#### 随机搜索（Random Search）

在超参数空间中随机采样。比网格搜索更高效——因为不是所有超参数都同样重要，随机搜索有更高概率探索关键维度。

#### 贝叶斯优化（Bayesian Optimization）

构建超参数到目标值的代理模型（如 Gaussian Process），通过采集函数（如 EI、UCB）选择下一个评估点。每次评估后更新代理模型。

- 优点：样本效率高，适合昂贵评估
- 代价：代理模型在高维空间可能不准确
- 工具：Optuna、Ray Tune、SigOpt

#### Hyperband / ASHA

结合随机搜索和早停机制。先以少量资源训练多个配置，淘汰表现差的，对幸存者分配更多资源继续训练。

- Hyperband：多轮 bracket 调度
- ASHA（Async Successive Halving）：异步版本，更适合分布式

### 大模型搜索策略

大模型不应直接做全局搜索，而采用分阶段策略：

1. **小模型筛选**：在 1/10 参数量的小模型上搜索超参数
2. **Scaling Law 迁移**：利用 Scaling Laws 将超参数从大模型迁移
3. **目标规模复验**：在目标规模做少量验证实验
4. **敏感度分析**：对关键超参数做 ±20% 扰动，确认稳定性

### 优化目标

搜索目标不应仅是最低 loss，而应综合考虑：

| 目标 | 权重 | 说明 |
|---|---|---|
| 验证 loss | 高 | 模型质量 |
| 训练稳定性 | 高 | 无 loss spike、无发散 |
| 训练成本 | 中 | GPU 时 |
| 推理约束 | 中 | 模型大小、延迟限制 |

## 关键方法与模型

### Scaling Laws 指导的超参数迁移

Kaplan et al. (2020) 的 Scaling Laws 表明，最优学习率、batch size 等超参数可按幂律关系从大模型迁移到小模型。这为"小模型搜索 + 大模型复验"提供了理论基础。

### MuP（Maximal Update Parameterization）

Yang et al. (2022) 提出的参数化方案，使超参数（特别是学习率）在不同模型规模间可迁移。核心思想是通过调整初始化和学习率缩放，使每一层的激活值范数在不同宽度下保持稳定。

## 优势与局限

### 优势

- 系统化方法避免人为偏见
- 可量化超参数影响和交互
- 结合早停可控制搜索成本

### 局限

- 大模型搜索成本仍然很高
- 超参数可能与数据分布耦合，换数据需重新搜索
- 搜索结果受随机种子影响，需多次验证

## 应用场景

- 预训练：小模型筛选 + Scaling Law 迁移
- 微调：重点搜索学习率和 LoRA rank
- RLHF/DPO：需搜索的额外超参数包括 β、KL 系数等

## 常见问题

- **大模型能直接做随机搜索吗？**：不建议。一次 full-scale training 的成本可能高达数十万美元。应先在小模型上搜索，再在目标规模复验。
- **学习率应该用多少？**：取决于模型大小和 batch size。175B 模型典型值为 1e-4 到 6e-4（BF16 训练），7B 模型约为 3e-4 到 6e-4。
- **batch size 越大越好吗？**：不是。超过临界 batch size 后，训练效率下降。临界 batch size 与模型大小和任务有关，可通过梯度噪声尺度估计。
