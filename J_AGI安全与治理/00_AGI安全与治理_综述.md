# AGI安全与治理综述

> **定位**：本板块研究如何让具备生成、推理、工具调用、记忆和持续行动能力的人工智能系统，在设计、训练、部署与治理全生命周期中保持可靠、可控、可审计，并符合人类利益。

## 1. 范围与分层

AGI 安全不是单一的“内容过滤”问题，而是从模型到社会系统的连续风险链：

```text
模型与数据层 → 生成式模型层 → Agent 执行层 → 组织与社会层 → 长期能力风险
鲁棒/隐私        注入/幻觉        工具/记忆/目标       公平/法规/问责       控制/遏制/监督
```

- **Safety / Security**：系统在故障、攻击和分布变化下仍安全可靠。
- **Alignment**：系统优化的目标、偏好和实际行为与人类意图相符。
- **Assurance**：以评测、红队、监控和安全论证证明风险被持续控制。
- **Governance**：以组织制度、标准、法规和国际协调分配责任并约束高风险能力。

## 3. 全生命周期安全闭环

```text
风险建模 → 安全设计 → 数据/训练控制 → 对齐与验证
    ↑                                      ↓
治理与问责 ← 事故响应 ← 线上监控 ← 灰度部署与红队
```

这一区分避免两种误区：把“训练阶段的偏好对齐”当作完整安全保证，或把“部署阶段的护栏”当作解决目标错配的替代品。两者必须与权限边界、评测证据和治理机制共同工作。

## 4. 学习路径

1. 从 [[01_AI安全基础理论/00_AI安全基础理论_综述]] 建立风险、失效模式与控制问题的共同语言。
2. 学习 [[02_AI对齐理论/00_AI对齐理论_综述]] 和 [[04_可解释与可控/00_可解释与可控_综述]]，理解训练信号与行为证据的局限。
3. 进入模型攻防与 [[05_Agent安全/00_Agent安全_综述]]，将攻击面扩展到工具、权限、外部内容和长期记忆。
4. 以 [[06_安全评测与安全工程/00_安全评测与安全工程_综述]] 建立工程化验证能力，再学习责任 AI 与治理。
5. 最后阅读 [[09_超级智能安全/00_超级智能安全_综述]]，并始终区分可证实的当前风险与条件性的长期风险。

## 5. 与其他板块的边界

- **C 基础模型**讲能力、训练和推理；J 评估这些能力如何带来风险并提出控制要求。
- **D 智能体**讲 Agent 的架构、规划、记忆和运行时；J 的 Agent 安全讲其权限、隔离、攻击、验证和问责。
- **G 具身智能**讲感知与行动；J 关注现实世界行动的安全约束、失效降级与人类接管。
- **I 高级智能理论**讨论能力上限和自我改进；J 将其转换为对齐、控制与治理问题。
