# 潜在动力学模型

## 一句话理解

潜在动力学模型先从高维观测学习紧凑状态，再在该潜空间预测未来，把"视觉上像什么"的问题转为"对行动会产生什么后果"的问题。

## 概述

直接预测像素容易把容量花在背景、纹理等无关细节上。潜在动力学学习状态 \(z_t\) 后只预测对控制重要的信息，同时支撑长时域想象，是 Dreamer 等想象式 RL 的骨干。

## 典型结构

```text
观测 o_t → 编码器 → 后验状态 q(z_t|o_≤t)
动作 a_t ─────────────────────────────→ 转移 p(z_t+1|z_t,a_t)
潜状态 z_t → 解码器/奖励头/价值头 → 重建、回报和终止预测
```

## RSSM：随机循环状态空间模型

RSSM（PlaNet 提出）将循环确定性状态用于记忆，将随机变量用于多模态未来：

\[
h_t=f(h_{t-1},s_{t-1},a_{t-1}),\qquad s_t\sim p(s_t\mid h_t)
\]

- **确定性部分** \(h_t\)：累积历史上下文，保证长程信息不丢失。
- **随机部分** \(s_t\)：表征无法由历史唯一确定的未来（多模态、随机转移）。
- 训练联合优化观测/特征重建、奖励预测、KL 正则与多步一致损失；后验与先验之间的 KL 控制状态包含的信息量。

## 设计要点

- **连续或离散潜变量**：连续状态平滑，离散 token 更易与 Transformer 和生成模型结合（DreamerV2 用离散潜变量在 Atari 上大幅提升）。
- **一步或多步损失**：只优化一步会导致长期漂移；多步训练更贴近规划需求。
- **动作条件与控制频率**：动作语义、延迟和执行噪声必须进入模型。
- **不确定性**：模型集成、概率输出或扩散轨迹可表示多种未来。

## 评判

低重建误差不是充分证据。优先检查潜状态是否能预测奖励、可分辨可控因素、支持长时域想象，并提升真实闭环任务表现。

## 常见问题

- **状态混叠（state aliasing）**：不同真实状态映射到同一潜状态，导致预测失效——通常需要更强的记忆或更大的随机容量。
- **表示塌缩**：KL 项过强使随机状态携带信息过少；需要调平衡后验/先验。
- **生成式重建 vs 判别式表征**：重建损失训练可解释、但浪费容量；判别/对比损失高效、但可能丢失任务变量。
