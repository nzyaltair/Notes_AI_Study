# 物理与空间世界模型

## 一句话理解

物理与空间世界模型应将物体、几何、接触、视角和动力学组织为可预测状态；图像逼真或文本常识都不能保证可达性、碰撞和守恒约束正确。

2D 视频 latent 数据丰富却有遮挡/视角歧义；3D 场显式表达空间但采集与计算更昂贵；对象关系图有利组合规划却依赖可靠感知；神经—物理混合模型引入先验也面临模型失配。
