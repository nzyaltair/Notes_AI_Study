# 世界模型能力链：表征、预测、规划与交互

世界模型学习环境状态及其随动作演化的内部表示：\(z_{t+1}\sim p_\theta(z_{t+1}\mid z_t,a_t)\)。其价值不在生成逼真的画面本身，而在于支持预测、反事实比较、规划与数据高效学习。

| 层次 | 关注点 | 代表路线 |
|---|---|---|
| 表征 | 压缩与保留可控状态 | 潜变量、token、联合嵌入预测（JEPA） |
| 动力学 | 状态/视频如何随动作演化 | RSSM、Dreamer、视频预测 |
| 生成与仿真 | 多样未来与环境样本 | 生成式视频、环境模拟 |
| 规划接口 | 在想象轨迹中选行动 | MPC、搜索、策略优化 |

世界模型并不自动拥有因果干预能力；因果结构与反事实方法见 [[../../I_高级智能理论与融合方法/02_因果智能/00_因果智能_综述|因果智能]]。环境学习见 [[../../F_世界模型与环境智能/01_世界模型理论/00_世界模型理论_综述|F 世界模型理论]]，物理执行见 [[../../G_具身智能与物理智能/06_控制与执行/00_控制与执行_综述|G 控制与执行]]。
