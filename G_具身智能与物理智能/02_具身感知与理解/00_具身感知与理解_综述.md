# 具身感知与理解综述：从感知到行动的表示

## 一句话理解

具身感知不仅是"看到世界"，更是"理解世界以支持行动"——视觉-语言-动作 (VLA) 模型将视觉理解、语言指令和动作执行统一在一个端到端框架中，是具身智能从"看"到"做"的关键桥梁。

## 1. 领域定义

具身感知是将原始传感器数据转化为可供决策使用的环境理解和物体表示的过程。与纯视觉识别不同，具身感知强调**行动导向**：感知的目的是支持行动，而不仅仅是识别。

### 核心特点

| 特点 | 描述 | 与纯视觉的区别 |
|------|------|----------------|
| 行动导向 | 感知服务于行动 | 纯视觉只关注识别 |
| 主动感知 | 移动以获取更好视角 | 被动接收图像 |
| 多模态融合 | 视觉+语言+触觉+本体 | 通常只处理视觉 |
| 时序连续 | 持续的感知流 | 单帧或短视频 |
| 3D 理解 | 需要 3D 空间推理 | 2D 图像理解 |

## 2. 核心方法

### 2.1 视觉-语言-动作模型 (VLA)

| 模型 | 架构 | 特点 |
|------|------|------|
| RT-2 | PaLI-X + 动作 Token | 首个大规模 VLA |
| Octo | Transformer + 动作头 | 开源通用策略 |
| OpenVLA | LLaVA + 动作解码 | 开源可微调 |
| π₀ | VLM + Flow Matching | 物理智能路线 |
| GR-2 | 视频 + 动作生成 | 生成式路线 |

### 2.2 3D 场景理解

| 方法 | 核心思想 | 代表 |
|------|----------|------|
| 点云处理 | 直接处理3D点 | PointNet, PointNet++ |
| 3D 重建 | 从2D重建3D | NeRF, 3DGS |
| 场景图 | 物体关系图 | 3D Scene Graph |
| 语义地图 | 带语义的3D地图 | ConceptGraphs, NLMap |

### 2.3 空间智能

- 空间推理：物体间的空间关系
- 导航地图：拓扑图、语义图、占据栅格
- 场景流：动态场景的运动估计

## 3. 与 AGI 的关系

- **具身智能的感知入口**：感知是具身 Agent 行动的前提
- **VLA = Foundation Model 的具身版**：统一感知、理解和行动
- **世界模型的感知层**：3D 场景理解是世界模型的基础
- **Sim2Real 的感知差距**：仿真与真实的感知差异

## 4. 学习路径

1. 理解具身感知与纯视觉的区别
2. 学习 VLA 模型架构（RT-2, Octo）
3. 研究 3D 场景理解方法
4. 探索主动感知与信息获取
5. 研究 Sim2Real 的感知适应
