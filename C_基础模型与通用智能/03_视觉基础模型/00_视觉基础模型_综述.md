# 视觉基础模型 综述

## 概述

视觉基础模型（Vision Foundation Models）是大规模预训练的视觉模型，能够在广泛的视觉任务上实现强大的泛化能力。从语言基础模型到视觉基础模型的扩展，是通向多模态 AGI 的关键一步。

## 核心概念

### 视觉基础模型的定义
- 在大规模图像/视频数据上预训练的视觉模型
- 具备跨任务、跨域的视觉理解与生成能力
- 可通过微调或提示适配下游任务

### 与语言基础模型的关键差异
- 视觉信号的连续性 vs 语言的离散性
- 空间结构 vs 序列结构
- 标注成本与自监督策略差异

## 主要模型系列

### 视觉 Transformer 系列
- ViT (Vision Transformer)
- DeiT (Data-efficient Image Transformer)
- Swin Transformer
- SigLIP / EVA-CLIP

### 自监督视觉预训练
- MAE (Masked Autoencoder)
- DINO / DINOv2
- BEiT / BEiT v3
- SimCLR / MoCo 系列

### 视觉-语言预训练
- CLIP (Contrastive Language-Image Pre-training)
- ALIGN
- SigLIP
- EVA-CLIP

### 视频基础模型
- 视频MAE (VideoMAE)
- InternVideo
- 视频生成基础模型（Sora, Gen-2）

## 关键技术

### 分词策略
- 图像分块 (Patch Embedding)
- 视觉 Token 化
- 视觉词汇学习

### 预训练目标
- 掩码图像建模 (MIM)
- 对比学习
- 图文对比对齐
- 重建与生成

### 规模化训练
- 大规模视觉数据集（LAION, DataComp）
- 视觉 Scaling Laws
- 高效训练策略

## 与 AGI 的关联

视觉基础模型是 AGI 感知能力的核心载体：
- **环境感知**：理解物理世界的视觉信号
- **空间智能**：从视觉中构建三维空间理解
- **多模态对齐**：视觉与语言的统一表征
- **具身智能基础**：机器人的视觉感知能力

## 发展趋势

1. 统一视觉架构：检测、分割、生成一体化
2. 视觉 Scaling Laws：更大的数据与模型
3. 视频基础模型：从静态到动态理解
4. 3D 视觉基础模型：NeRF/Gaussian Splatting 与预训练结合
