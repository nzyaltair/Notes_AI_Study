# 视觉语言预训练接口

## 一句话理解

视觉语言预训练把图像与文本映射到可比较或可交互的空间，为零样本检索、分类和视觉语言模型提供接口，但不保证细粒度空间理解。

双塔对比模型适合检索与零样本分类；投影器、Q-Former 与 cross-attention 可将视觉 token 接入 LLM。应测试遮挡、区域证据和反事实图文配对，避免把语言先验误判为视觉理解。
