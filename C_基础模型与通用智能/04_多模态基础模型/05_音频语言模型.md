# 音频语言模型

## 一句话理解

音频语言模型把语音、环境声音和音乐接入语言或统一生成模型；它必须处理音色、韵律、噪声和流式时延等文本系统不具备的变量。

ASR 提供文本入口但会损失非文字声学信息；原生音频 token 模型可减少 ASR—LLM—TTS 的级联损失，但对数据配对与实时性能要求更高。
