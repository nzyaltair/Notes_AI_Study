# 视觉深度学习任务综述

## 一句话理解

图像分类、检测、分割、跟踪、OCR 与三维理解共享视觉表征，却有不同输出结构、数据标注和评估标准；它们属于任务层知识，应以 [[../../../E_感知与多模态智能/01_视觉表示与视觉理解/00_视觉智能综述\|视觉智能]] 为主入口。

## 本目录的定位

本目录不重复维护任务算法细节，仅保留从 CNN 表征到任务系统的桥接：分类将图像映射为标签；检测预测目标集合和边界；分割输出像素/实例掩码；跟踪维持跨帧身份；OCR 联合文本检测、识别与文档结构；三维视觉从图像、深度或点云推断几何。

## 任务地图

| 任务 | 预测对象 | 核心评估 | 入口 |
|---|---|---|---|
| 图像分类 | 图像级类别 | top-1 / macro-F1 / 校准 | [[01_图像分类]] |
| 目标检测 | 目标集合、类别与框 | AP / IoU / 延迟 | [[02_目标检测]] |
| 语义分割 | 每像素类别 | mIoU / 边界质量 | [[03_语义分割]] |
| 实例分割 | 对象实例掩码 | mask AP | [[04_实例分割]] |
| 姿态估计 | 关键点与骨架 | OKS AP / MPJPE | [[05_姿态估计]] |
| OCR | 文本区域与字符序列 | 检测 F1 / CER | [[06_OCR]] |
| 视觉跟踪 | 跨帧位置与身份 | HOTA / IDF1 | [[07_视觉跟踪]] |
| 三维视觉 | 深度、几何或场景 | 深度误差 / 几何完整度 | [[08_三维视觉]] |

## 学习建议

完成 [[../01_卷积运算与基础组件\|卷积基础]] 与 [[../02_经典CNN架构\|经典 CNN 架构]] 后，先学习分类，再按输出结构扩展至检测、分割、跟踪和三维任务。任务模型的选型应同时考虑标注形式、空间精度、实时性、数据偏移与安全需求，而不是只比较单一榜单指标。
