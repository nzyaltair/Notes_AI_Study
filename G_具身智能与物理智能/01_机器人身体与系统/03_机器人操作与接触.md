# 机器人操作与接触：从抓取到物理交互

操作的目标不是移动末端，而是通过接触改变物体状态。抓取、推拉、插拔、开门和布料操作都涉及不确定摩擦、接触模式切换与力反馈。

## 操作闭环

```text
对象/可供性感知 → 抓取或接触候选 → 可达性与碰撞验证
→ 接近 → 接触检测 → 力/触觉闭环 → 结果核验与恢复
```

## 核心概念

| 主题 | 关键问题 | 典型方法 |
|---|---|---|
| 抓取 | 是否稳定、可达、无碰撞 | 力闭合、抓取质量、学习抓取 |
| 灵巧操作 | 如何在手内重定位物体 | 多指协调、触觉策略、RL |
| 接触建模 | 力如何满足非穿透与摩擦 | 接触雅可比、摩擦锥、顺应模型 |
| 力/阻抗控制 | 如何容忍位姿误差 | 力阈值、阻抗/导纳控制 |
| 操作规划 | 如何组合抓、推、放与工具 | TAMP、接触模式搜索 |

接触力常须满足 \(F_n\ge0\) 及 \(\|F_t\|\le\mu F_n\)。在未知摩擦与柔性物体上，这些模型只能提供边界；视觉、力觉和触觉闭环才决定鲁棒性。

## 设计原则

- 把可供性表示为“对该本体可执行的行动”，而不是物体类别标签。
- 记录接触事件、滑移、实际力和失败恢复，而非只保留成功轨迹。
- 对高风险操作设独立的力、速度与工作空间限制。
