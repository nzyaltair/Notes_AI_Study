# 视觉基础模型路线图

视觉基础模型以大规模视觉预训练获得可迁移表征，而非为单一分类/检测任务训练专用网络。

| 路线 | 核心模型/目标 | 能力接口 |
|---|---|---|
| Transformer 视觉编码器 | ViT、Swin | 全局视觉表征 |
| 对比图文预训练 | CLIP、SigLIP | 开放词汇识别、跨模态对齐 |
| 自监督表征 | DINO、MAE | 少标注迁移、密集视觉任务 |
| 通用分割 | SAM | 可提示视觉接口 |
| 视频基础模型 | VideoMAE、InternVideo | 时间动态理解 |
| 3D 基础模型 | 3D 表征、重建与空间 token | 空间理解与具身感知 |

检测、分割、3D 和视频等感知任务方法详见 [[../../E_感知与多模态智能/01_视觉感知/00_计算机视觉_综述|E 视觉感知]]；视觉语言融合见 [[../04_多模态基础模型/00_多模态基础模型_综述|多模态基础模型]]。
