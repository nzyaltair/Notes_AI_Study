# 智能体理论基础 Overview

## 领域定义

智能体理论基础研究"什么是智能体""理性意味着什么""智能体应该如何组织和决策"等根本性问题。它回答的是哲学与认知科学意义上的"智能体是什么"，而非工程上的"如何实现一个 Agent 系统"。具体来说，它关注：智能体如何定义（Agent 定义与理性）、如何建模信念与目标（BDI 框架）、如何组织认知功能（认知架构）。本领域是 [[../00_智能体与自主系统_综述|D 智能体与自主系统]] 的理论根基，为 [[../02_环境与世界模型/00_环境与世界模型_综述|环境与世界模型]]、[[../03_规划与推理/00_规划与推理_综述|规划与推理]]、[[../04_强化学习/00_强化学习_综述|强化学习]] 等提供概念基础和目标函数定义。

## 为什么会出现

经典人工智能在 1950-1980 年代主要关注"如何让机器推理"（符号主义）和"如何让机器学习"（连接主义），但忽略了"什么是理性的决策者"这一基础问题。1980 年代后期，分布式人工智能（DAI）和机器人学的发展要求研究者为"能自主行动的系统"提供精确的定义——由此诞生了智能体理论的三个核心追问：**Agent 是什么**（区别于纯推理程序）、**理性如何定义**（区别于简单优化）、**智能体如何组织内部认知功能**（区别于端到端黑箱）。

## 发展历史

| 年代 | 里程碑 | 意义 |
|:---|:---|:---|
| 1987 | Bratman 提出 BDI 哲学基础 | 将信念、愿望、意图作为实践推理的核心概念 |
| 1989 | Newell 提出 Soar 认知架构 | 统一认知架构，强调问题空间与块学习 |
| 1995 | Rao & Georgeff 形式化 BDI 逻辑 | 将 BDI 从哲学转化为可计算逻辑 |
| 1995 | Russell & Norvig 定义理性 Agent | 将"理性"定义为"最大化期望性能度量" |
| 2003 | Wooldridge 系统化多 Agent 系统理论 | 智能体理论的完整教科书 |
| 2010s | 深度强化学习 Agent 兴起 | 从"显式推理"转向"端到端学习"，但基本问题（理性、信念、目标）依然存在 |
| 2022- | LLM Agent 时代 | 语言模型作为"隐式推理引擎"，BDI 和认知架构以新的形式重新出现 |

## 核心问题

1. **什么是 Agent**：Agent 与纯程序、纯推理系统的区别是什么？自主性的边界在哪里？
2. **什么是理性**：理性等于效用最大化吗？在约束（信息、计算、安全）下如何定义理性？
3. **如何建模信念与目标**：Agent 如何表示"对世界的认知"和"想要的未来状态"？何时应该坚持目标、何时应该放弃？
4. **如何组织认知功能**：感知、记忆、推理、规划、执行、元认知这些功能如何在架构中协同？

## 重要分支

- **Agent 定义与理性**：Agent 的数学定义、理性决策的形式化、自主性概念（[[01_Agent定义与理性]]）
- **决策理论与 BDI**：信念-愿望-意图框架、承诺管理、意图的稳定性与可修订性（[[02_决策理论与BDI]]）
- **认知架构**：Soar、ACT-R 等经典架构，以及它们在 LLM Agent 时代的新形式（[[03_认知架构]]）

## 概念边界

- **智能体理论 vs. 强化学习**：智能体理论为"理性"提供了哲学和逻辑基础（什么是好的决策）；强化学习（[[../04_强化学习/00_强化学习_综述|D-04 强化学习]]）提供了从经验中学习最优策略的数学框架。两者在"效用最大化"上有交集，但强化学习更关注"如何学"，智能体理论更关注"什么算好"。
- **智能体理论 vs. Agent 工程系统**：智能体理论关注"为什么"——理性、信念、意图的概念基础；Agent 工程系统（[[../06_Agent工程系统/00_Agent工程系统_综述|D-06 Agent工程系统]]）关注"怎么做"——ReAct 循环、LangGraph 状态图、MCP 协议等具体实现。理论是工程设计的指导原则，工程是理论的实际落地。

## 当前发展状态

- **经典理论保持稳定**：Russell & Norvig 的理性 Agent 定义、BDI 框架、Soar/ACT-R 认知架构仍是公认的基础
- **LLM Agent 的重新解释**：LLM 作为"隐式推理引擎"挑战了传统上需要显式推理模块的架构设计，但 BDI 和认知架构的核心思想（信念维护、意图承诺、功能分工）在 LLM Agent 的设计中仍然适用
- **理论工程化程度低**：BDI 框架在工业界应用有限，大多数 Agent 系统采用更实用的 ReAct 循环而非显式的 BDI 架构

## 未来趋势

- **神经符号 BDI**：将深度学习的感知/推理能力与 BDI 的结构化决策逻辑结合
- **可学习的认知架构**：认知架构的各个模块（感知、记忆、决策）从固定设计变为可学习、可自适应
- **LLM 作为认知架构的审议层**：LLM 的推理能力可视为认知架构中的"审议模块"，与记忆、执行等模块协同
