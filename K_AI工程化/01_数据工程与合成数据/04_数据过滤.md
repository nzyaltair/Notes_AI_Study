# 数据过滤

## 一句话理解

数据过滤按质量、相关性、安全性和许可要求选择训练样本——清洗修复格式问题，过滤决定样本是否保留；过滤阈值会改变数据分布，需按群体报告保留率并以固定评测集验证能力与公平性变化。

## 1. 概述

数据过滤是数据清洗之后的环节。清洗修复了格式和一致性问题，过滤则基于内容质量决定哪些样本值得进入训练集。

过滤的核心目标：

- **提升数据质量**：保留高质量样本，丢弃低质量样本
- **控制数据分布**：按领域、难度、语言配比
- **安全保障**：过滤有害、不安全内容
- **合规过滤**：排除许可不允许的数据

## 2. 过滤方法

### 2.1 启发式规则

基于经验的简单规则，速度快、成本低：

| 规则类型 | 说明 | 示例 |
|:---|:---|:---|
| 长度过滤 | 过短/过长文档 | < 50 词或 > 100K 词 |
| 语言识别 | 只保留目标语言 | fastText 语言检测 |
| 字符比例 | 特殊字符占比 | 非字母字符 > 30% → 丢弃 |
| URL 过滤 | 基于域名黑名单 | 成人/垃圾站点黑名单 |
| 广告检测 | 广告模板匹配 | 广告密度 > 50% → 丢弃 |
| 重复行 | 模板页面检测 | 重复行 > 30% → 丢弃 |
| 词频比 | 常见词占比 | 顶级 100 词占比异常 |

### 2.2 分类器过滤

训练专用分类器评估数据质量：

| 分类器 | 目标 | 训练数据 |
|:---|:---|:---|
| 质量分类器 | 区分高质量/低质量文本 | Wikipedia（正）vs 随机网页（负） |
| 毒性分类器 | 检测有害内容 | 有害/无害标注数据 |
| 成人内容分类器 | 检测色情内容 | 成人/非成人标注 |
| 版权风险分类器 | 检测可能侵权内容 | 版权/非版权数据 |
| 领域相关性分类器 | 筛选目标领域 | 领域内/外数据 |

### 2.3 模型评分

用语言模型对数据质量评分：

| 方法 | 说明 | 适用场景 |
|:---|:---|:---|
| 困惑度 (Perplexity) | 用参考模型计算困惑度，高困惑度=低质量 | 预训练数据 |
| 奖励模型评分 | 用 RM 评估回复质量 | SFT/RLHF 数据 |
| 教师模型评分 | 用强模型评估数据质量 | 指令数据 |
| LLM Judge | 用 GPT-4 等评估质量 | 多维质量评估 |

**困惑度过滤的原理**：

```text
高质量文本 → 参考模型对其困惑度低（模型能理解）
低质量文本 → 参考模型对其困惑度高（模型无法理解）

阈值: perplexity > θ → 丢弃
```

> **注意**：困惑度过滤可能偏好与参考模型相似的数据，导致分布偏差。

### 2.4 分桶采样

不简单删除低分数据，而是按分桶设置不同采样率：

```text
质量分桶:
├── 高质量 (0.8-1.0): 100% 保留
├── 中质量 (0.5-0.8): 50% 采样
├── 低质量 (0.2-0.5): 10% 采样（保留长尾）
└── 垃圾 (0.0-0.2): 0% 丢弃
```

分桶采样的优势：

- **保留多样性**：低质量但不完全无用数据仍有少量保留
- **控制分布**：避免过滤后分布过于集中
- **可调节**：采样率可根据实验结果调整

## 3. 安全过滤

### 3.1 有害内容过滤

| 内容类型 | 检测方法 | 处理 |
|:---|:---|:---|
| 暴力/仇恨 | 毒性分类器 | 删除 |
| 色情内容 | 成人分类器 | 删除 |
| 自伤/自杀 | 关键词 + 分类器 | 删除 |
| 违法信息 | 关键词 + 分类器 | 删除 |

### 3.2 PII 过滤

- **检测**：正则规则 + NER 模型
- **处理**：脱敏（替换为占位符）或删除整条
- **验证**：过滤后抽样检查残留 PII

### 3.3 对抗内容过滤

- **注入攻击**：检测 Prompt 注入样本
- **越狱内容**：检测越狱指令
- **模型提取**：检测模型输出反推数据

## 4. 领域过滤

按领域配比筛选数据：

| 领域 | 过滤方法 | 配比（参考） |
|:---|:---|:---|
| 技术/代码 | GitHub 星标 + 语言检测 | 15-20% |
| 科学论文 | arXiv 分类 | 10-15% |
| 百科知识 | Wikipedia | 5-10% |
| 新闻 | 新闻域名白名单 | 10-15% |
| 文学/书籍 | 书籍语料 | 5-10% |
| 对话 | Reddit/论坛 | 5-10% |

领域配比影响模型能力方向，需通过实验优化。

## 5. 过滤的风险控制

### 5.1 分布偏差

过滤阈值会改变数据分布：

```text
原始数据分布: 均匀覆盖各群体
    ↓ 过滤（高质量阈值）
过滤后分布: 偏向高频/主流群体
    → 低资源语言、方言、少数群体数据被过度删除
```

### 5.2 公平性保障

- **按群体报告保留率**：按语言、地域、领域统计过滤前后比例
- **差异化阈值**：对低资源群体使用更宽松的阈值
- **公平性评测**：用固定评测集验证过滤后模型在各群体上的表现

### 5.3 能力回归

过滤后必须验证：

- **核心能力**：过滤是否提升了目标能力
- **辅助能力**：过滤是否意外损害了其他能力
- **安全能力**：过滤是否影响了安全对齐效果

## 6. 过滤管线

```text
原始数据
    ↓ 启发式过滤 (快速、低成本)
    ↓ 质量分类器 (中等成本)
    ↓ 模型评分 (高成本、高精度)
    ↓ 安全过滤 (有害内容/PII)
    ↓ 领域配比采样
    ↓ 过滤后数据集
```

分层过滤策略：先低成本快速过滤大量数据，再高成本精过滤。

## 8. 常见问题

- **过滤过度**：阈值过严导致数据量不足
- **过滤偏差**：偏好主流内容，丢失长尾
- **分类器偏差**：质量分类器偏好特定风格
- **困惑度偏差**：偏好参考模型"熟悉"的文本
- **安全过滤误伤**：正常内容被误判为有害
