# 自主技能获取与终身发现

## 一句话理解

自主技能获取把探索经验打包成可复用选项、程序、工具流程或子目标，并根据新任务进行组合；终身发现进一步要求系统提出可检验的环境假设与能力缺口。

## 核心概念

| 概念 | 定义 |
|---|---|
| 技能（Skill） | 可复用的行动-状态映射或策略片段 |
| 选项（Option） | 带初始条件、终止条件与策略的临时技能（半马尔可夫） |
| 程序化技能 | 以程序/流程形式表示的可执行知识 |
| 子目标发现 | 自动把复杂任务分解为可学的子目标 |
| 能力缺口 | 系统识别"当前无法完成但值得学习"的任务 |

## 技能表示与获取

| 方法 | 表示 | 机制 |
|---|---|---|
| Options（Sutton 等） | 策略片段 | 在 RL 中抽象时间尺度 |
| DIAYN | 隐变量技能 | 最大化技能辨识度（多样行为） |
| 分层强化学习 | 高层子目标 + 低层策略 | 任务分解学习 |
| 程序库学习 | 程序 | 从任务群归纳可复用函数（DreamCoder 范式） |
| 工具流程 | 工具调用序列 | 把成功流程封装为可复用工作流 |

## 可靠流程

```text
发现候选目标 → 在沙箱学习技能 → 定义成功与失败证据 → 评测可迁移性 → 写入带来源和适用条件的记忆
```

- **沙箱学习**：在隔离环境验证技能，避免真实环境风险。
- **证据定义**：明确"什么算学会"（性能阈值、验证集）。
- **可迁移性评测**：技能在新任务/新环境的表现。
- **带来源的记忆**：技能条目记录来源、适用条件与失败模式，防止盲目复用。

## 与终身发现的关系

终身发现（Open-ended Discovery）进一步要求：

- 提出可检验的环境假设（"这个环境的动力学是什么"）。
- 识别能力缺口并驱动技能获取。
- 技能组合产生新能力（组合爆炸 → 能力涌现）。

它与内在动机（[[02_内在动机与好奇心驱动探索]]）形成闭环：内在动机提供探索驱动力，技能获取把探索成果沉淀为长期能力。

## 前沿发展

- **LLM 技能库**：LLM 生成并总结技能描述，检索式复用。
- **开放式技能进化**：技能库作为"基因库"参与进化选择（见 [[../../06_人工生命与进化智能/03_开放式进化与人工生态系统]]）。
- **技能组合的泛化评估**：以未见组合上的成功率评测组合能力（对应 [[../../03_通用推理与抽象智能/02_类比推理与组合泛化]]）。
