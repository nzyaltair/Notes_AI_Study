# 思维链与提示推理

## 一句话理解

思维链（CoT）让模型生成中间步骤以提升部分多步任务的表现；它是可用的推理脚手架和观测窗口，不是模型真实内部因果过程的可靠证明。

## 方法与边界

少样本 CoT 在示例中展示分步解法，zero-shot CoT 用提示诱导分解。错误步骤可能仍碰巧给出正确答案，正确文字也可能只是事后合理化。高风险任务应优先使用可执行程序、形式验证或外部证据。
