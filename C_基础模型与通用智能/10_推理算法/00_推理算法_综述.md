# 推理算法综述

## 一句话理解

推理算法研究已训练模型在运行时如何从概率分布生成 token、减少串行解码、处理长上下文，并在给定时延和成本预算下调度计算；它优化“怎样生成”，不等同于训练模型“怎样推理”。

## 范围与边界

- [[../08_推理与思考/00_推理与思维链_综述|C.08 推理与思考]]：候选、搜索、验证器和推理训练如何提高问题求解正确性。
- **本模块**：解码分布控制、投机解码、长上下文运行时策略、请求级预算调度。
- [[../09_模型压缩与高效推理/00_模型压缩与高效推理_综述|C.09 模型压缩与高效推理]]：量化、KV cache、稀疏化和系统并行等模型/系统效率机制。
- [[../../K_AI工程化/03_推理工程/00_推理工程_综述|K.03 推理工程]]：服务化、容量、框架与运维。

## 核心问题

1. 如何平衡确定性、多样性、事实约束和格式约束？
2. 如何在不改变目标模型分布的条件下减少逐 token 串行瓶颈？
3. 如何在超长上下文中协调位置外推、检索、缓存和注意力预算？
4. 如何按请求难度、验证信号和 SLO 分配有限的测试时计算？

## 方法取舍

| 方法 | 优先优化的目标 | 关键条件/风险 |
|---|---|---|
| 温度与截断采样 | 多样性和退化控制 | 参数需按任务校准，不能保证事实性 |
| 束搜索/约束解码 | 局部概率或格式约束 | 可能降低开放式文本多样性 |
| 标准投机采样 | 降低解码延迟 | 在正确接受/校正机制下才保持目标分布 |
| 多 token 预测 | 减少串行轮数 | 加速比受接受率、硬件和任务影响 |
| 长上下文策略 | 提升可用信息量 | 位置外推不等于有效检索或理解 |
| 动态预算 | 提高单位成本的正确率 | 需要可信难度/验证信号和停止规则 |
