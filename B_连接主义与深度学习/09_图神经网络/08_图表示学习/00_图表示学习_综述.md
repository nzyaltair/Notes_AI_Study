# 图表示学习综述

图表示学习把节点、边和整体图编码为支持预测、检索与推理的向量。它连接传统嵌入、消息传递 GNN、自监督预训练与跨图迁移；学习时应先区分**节点级表示、图级表示与关系推理**，再比较直推与归纳设置。

## 学习路径

1. 从 [[01_节点嵌入]] 理解结构和属性如何形成节点向量。
2. 通过 [[02_图嵌入]] 学习将节点集合汇聚为图级表示。
3. 用 [[03_Node2Vec]] 对比随机游走嵌入与 GNN 的归纳能力。
4. 进入 [[04_图自监督学习]]、[[05_图基础模型]]，审视预训练和跨图迁移的边界。
5. 最后学习 [[06_图推理]]，连接知识图谱补全与神经符号方法。
