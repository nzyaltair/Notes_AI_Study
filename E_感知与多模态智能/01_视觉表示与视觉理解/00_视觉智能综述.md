# 视觉表示与视觉理解 综述

> **定位**：视觉智能研究如何从二维图像信号中提取、组织与维护关于场景的结构化信息——不仅是"识别物体"，更是为后续的时空感知、多模态推理和行动决策提供可查询的视觉证据。

## 领域定义

视觉表示与视觉理解是感知智能的基础模块，研究从像素级信号到语义级视觉状态的全链路转换：

- **视觉表示**：如何将图像编码为可迁移、可组合的向量或特征（手工特征 → 深度特征 → 预训练特征）
- **视觉理解**：如何从图像中提取原子信息（类别、位置、掩码、关系）并组合为场景理解

## 核心问题

1. **表示的可迁移性**：视觉特征如何在不同的任务、数据集和领域中泛化？
2. **从闭集到开放世界**：如何从学习固定类别的分类器，过渡到理解任意视觉概念？
3. **空间关系与结构**：如何从像素级感知上升到物体关系、场景图等结构化理解？
4. **视觉-语言桥接**：视觉表示如何与语言指令对齐，实现可提示的视觉理解？
5. **效率与精度的权衡**：如何在实时性要求下保持高精度的视觉理解？

## 技术演进路线

```text
手工特征 (SIFT/HOG) 
    → 深度 CNN (AlexNet/ResNet) 
    → 自监督预训练 (MAE/DINO) 
    → 视觉-语言对齐 (CLIP) 
    → 视觉基础模型 (SAM/DINOv2) 
    → 视觉语言模型 (LLaVA/InternVL)
```

## 当前发展状态

- **视觉基础模型已成熟**：SAM、DINOv2、CLIP 等提供了通用的视觉表示，可适应多种下游任务
- **开放词汇视觉理解成为主流**：基于 CLIP 的开放词汇检测、分割已取代闭集方法
- **VLM 赋予视觉理解对话能力**：LLaVA、Qwen2-VL 等模型实现了"看图说话"的多轮对话
- **视觉 Transformer 成为默认架构**：ViT 及其变体已全面取代 CNN 作为视觉主干网络

## 前沿方向

- 视觉理解与视觉生成的统一（同一模型既能理解也能生成图像）
- 视频级视觉基础模型（从单帧到视频流）
- 自监督预训练的 Scaling Law（更大数据、更大模型下的收益）
- 视觉表示的可解释性与因果性

## 学习路径

1. 图像处理基础 → 2. 传统特征 → 3. 深度学习视觉 → 4. 分类/检测/分割 → 5. ViT → 6. 自监督学习 → 7. 开放世界视觉
