# 行动表示与具身决策：规划、学习与 VLA

## 一句话理解

具身决策不是“模型输出一个动作”这么简单，而是将语言目标、空间状态、机器人约束与执行反馈统一成可恢复的闭环。高层决定做什么，技能层决定如何组织动作，控制层决定如何稳定做到；经典规划、模仿学习、强化学习和 VLA 分别解决不同难点。

## 1. 行动必须分层

| 层级 | 输入 → 输出 | 时间尺度 | 适用方法 | 成功判据 |
|---|---|---|---|---|
| 任务层 | 指令/目标 → 子任务、技能图 | 秒到分钟 | LLM、PDDL、行为树、状态机 | 子任务条件满足 |
| 技能层 | 对象状态/子目标 → 动作块、末端轨迹 | 100 ms 到数秒 | 规划、IL、RL、扩散策略、VLA | 抓取/开门/放置等技能完成 |
| 控制层 | 参考轨迹 → 关节/力矩命令 | 1–10 ms | PID、MPC、阻抗/WBC | 稳定、约束不违反 |

“收拾桌面”并不是一个原子动作：识别目标 → 判断可抓取 → 选择抓取姿态 → 接近/接触 → 验证抓稳 → 移动/避障 → 放置 → 核验结果。分层的价值是将错误定位到目标理解、感知、几何可达、接触执行或控制，而不是把失败归因给一个端到端模型。

## 2. 经典规划提供约束与可验证性

### 任务、运动与混合规划

- **任务规划**处理对象、关系、顺序和前后置条件，例如“先打开柜门再取杯子”。
- **运动规划**在 \(\mathcal C_{free}\) 中寻找满足碰撞、速度、动力学约束的路径/轨迹。
- **Task and Motion Planning（TAMP）**在符号任务选择与连续可行性之间反复约束传播，是语言 Agent 接入真实机器人的关键桥梁。

A*/PRM/RRT/RRT* 擅长搜索可行路径；CHOMP、TrajOpt 与 MPC 擅长连续优化。它们不擅长从原始图像理解“哪个是用户说的杯子”，但能验证一个候选目标是否碰撞、可达和可执行。

### 行为树与恢复策略

行为树把检查、执行、重试和回退显式化。例如：检测失败 → 调整视角；IK 无解 → 重新选择抓取；滑移 → 调整夹爪力；安全阈值触发 → 停止并撤退。它是把不确定学习模块包裹在确定性安全流程中的常用形式。

## 3. 学习范式：各自解决什么问题

### 行为克隆与交互式模仿学习

行为克隆学习专家条件动作分布：

$$\pi_\theta(a_t\mid o_t,g)\approx\pi_E(a_t\mid o_t,g)$$

它训练稳定、适合遥操作和人类示教，却有**分布偏移**：一旦动作稍偏离演示轨迹，后续观测不再属于训练数据。DAgger 通过让当前策略与专家纠正共同采集数据降低这一问题；实践中还要保留失败/恢复数据，不能只收集“完美演示”。

### 离线与在线强化学习

强化学习优化长期回报：

$$\max_\pi\mathbb E_\pi\left[\sum_{t=0}^{T}\gamma^t r(s_t,a_t)\right]$$

RL 对步态、动态平衡、稠密接触和难以人工示教的行为很有价值。代价是奖励设计、样本效率、探索安全和现实时间。现实可行路线通常是：仿真或离线数据预训练 → 受约束的有限真机微调 → 严格回归测试；不是让真实机器人无约束试错。

### 扩散策略与序列动作

扩散策略在动作序列空间中条件生成 \(a_{t:t+H}\)，可表达多峰选择（例如同一杯子可从不同侧抓取）。动作块减少视觉网络调用频率并改善时序协调，但块太长会放大时延和状态误差。合理做法是短视界生成、滚动执行、每次以新观测重新条件化。

### VLA 与机器人基础模型

VLA 将图像/视频、语言、机器人状态和动作历史映射为离散 token 或连续动作。代表工作体现了三类思路：

| 路线 | 核心贡献 | 应理解的边界 |
|---|---|---|
| RT-1 / RT-2 | 将视觉—语言知识迁移到机器人动作 | 语义泛化不等于可靠接触和精确几何 |
| Open X-Embodiment / RT-X | 跨机器人数据与共同动作表示 | 跨本体、控制频率和标定的异质性仍难统一 |
| OpenVLA | 开源 VLA 训练/微调基线 | 仍需要任务数据、动作适配与真实系统安全层 |
| PaLM-E 等多模态模型 | 语言推理与具身观测结合 | 高层推理不能取代实时控制 |

VLA 的关键不只是参数规模，而是**数据规范与动作接口**：相机视角、语言指令、动作坐标系、夹爪编码、频率、机器人形态、成功标准若不统一，跨数据训练会产生隐性冲突。

## 4. 如何选择技术路线

| 条件 | 优先方案 | 原因 |
|---|---|---|
| 环境/几何已知，安全要求高 | TAMP + MoveIt/MPC + 规则恢复 | 可验证、易调试 |
| 任务是重复操作，少量示教可得 | 行为克隆/扩散策略 + 闭环视觉 | 数据效率较好、实现直接 |
| 动态接触/步态，仿真可信 | RL + 域随机化 + 残差控制 | 能优化长程动态回报 |
| 开放指令与多任务泛化 | VLM/VLA 负责语义与技能选择 | 利用多模态先验，但必须受约束 |
| 长程家居任务 | 语义地图 + 任务规划 + 技能库 | 单一低层策略难承担记忆和恢复 |

这不是静态分类。成熟系统常是混合架构：VLM 提议子任务与对象，语义地图提供状态，规划器验证连续可行性，学习策略处理抓取/接触，控制器和安全监督负责最终执行。

## 5. 数据工程决定上限

每条轨迹应至少包含：任务文本与版本、相机/触觉/本体观测、动作和坐标系、控制频率、标定版本、成功/失败标签、阶段边界、安全事件及环境变化。要特别记录：失败原因、人工干预、重规划和恢复，而不能把它们从训练集清除。

数据集划分应防止泄漏：按物体实例、场景、相机视角、指令模板和时间段切分，而非随机切帧。否则“泛化”常只是记住了同一物体或背景。

## 6. 评测：从演示视频走向可复现实验

| 维度 | 应报告指标 |
|---|---|
| 成功与效率 | 成功率、任务时长、重试次数、能耗 |
| 泛化 | 新物体、新布局、新语言、新初始状态、跨本体成功率 |
| 安全 | 碰撞率、超力/超速、急停触发、近失误（near miss） |
| 鲁棒性 | 遮挡、扰动、传感器延迟/丢帧、对象滑移下的恢复率 |
| 数据效率 | 演示数量、真机交互次数、训练/微调成本 |
| 系统性能 | 推理、通信与控制延迟；动作频率；端到端抖动 |

需报告任务分布、随机种子、评测次数和失败类别。单次成功视频不能说明泛化；仿真排行榜也不能替代真实接触、安全和时延评测。
