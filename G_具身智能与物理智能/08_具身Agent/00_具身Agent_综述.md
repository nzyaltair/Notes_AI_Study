# 具身 Agent 综述

## 一句话理解

具身 Agent 将语言/多模态推理、世界模型、技能、控制和安全运行机制组合为可在物理世界中长期工作的自主体。它不是直接向电机输出 token 的 LLM，而是带有状态、记忆、验证、恢复和权限边界的闭环系统。

## 概述

具身 Agent 是具身智能的"系统级"形态：把感知、记忆、规划、技能、控制与安全组织为一个能够自主完成长程任务的闭环系统。与纯软件 Agent 相比，具身 Agent 必须处理物理世界的不确定性、失败与风险。它综合了本知识体系中所有其他方向的能力。

## 发展历史

- **1966**：SHAKEY——首个集成感知、搜索和规划的自主机器人。
- **1980s-1990s**：行为架构（Subsumption）与分层架构争论；经典规划 Agent。
- **2000s-2010s**：概率机器人学与 SLAM 使移动 Agent 实用化；家用机器人（Roomba, PR2）尝试自主任务。
- **2020s**：LLM 使语言理解与任务分解成为可能（SayCan 2022, Inner Monologue）；VLA 提供技能层；HomeRobot、ALFRED 等基准推动长程家居任务研究。

## 核心问题

1. **长程自主**：几十到几百步任务的可靠完成。
2. **状态与记忆**：环境变化、进度追踪、经验复用。
3. **失败恢复**：检测、归因、恢复的系统化。
4. **安全边界**：物理风险、权限管理、人工接管。
5. **开放世界**：新物体、新指令、新场景的泛化。

## 技术演进路线

| 时期 | Agent 范式 | 代表 |
|---|---|---|
| 经典规划 | 感知-规划-行动 | SHAKEY |
| 行为架构 | 反应式分层 | Subsumption |
| 概率机器人 | 状态估计 + 导航 | PR2 |
| LLM Agent | 语言推理 + 技能库 | SayCan |
| VLA Agent | 语言-视觉-动作闭环 | RT-2, π0 |
| 长程自主 | 记忆 + 恢复 + 治理 | HomeRobot 类 |
