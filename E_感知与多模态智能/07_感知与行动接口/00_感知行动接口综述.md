# 感知与行动接口 综述

> **定位**：感知的终点不是"看见"，而是向决策系统提供可行动、可更新、可验证的状态。感知与行动接口定义感知系统如何与上层的规划、推理、控制模块交互——它是从"感知"到"行动"的桥梁。

## 领域定义

感知与行动接口研究感知系统如何与决策和控制系统交互，包括：

- **主动感知**：感知系统如何根据任务目标主动选择观测（"应该看哪里"）
- **状态表示**：感知输出如何被组织为可供规划器使用的结构化状态（场景图、语义地图、对象中心表示）
- **行动接口**：VLA（视觉语言行动）模型如何将感知输入映射为行动输出
- **闭环反馈**：行动结果如何反馈回感知系统以更新状态估计

## 核心问题

1. **主动感知策略**：系统如何选择最有信息量的观测位置？感知如何受任务目标驱动？
2. **状态表示的可行动性**：感知状态应包含哪些信息才能支持规划与决策？置信度、时间戳、空间关系？
3. **感知-行动闭环**：行动如何改变感知状态？感知状态如何更新以反映行动结果？
4. **VLA 接口契约**：VLM/VLA 的观测输入、指令 grounding 与动作输出应如何设计？
5. **不确定性传播**：感知的不确定性如何传递给规划器和控制器？

## 技术演进路线

```text
被动感知（固定视角） 
    → 交互式感知（主动选择视角） 
    → 对象中心表示（Object-Centric） 
    → 场景图与语义地图 
    → 视觉语言行动模型 (VLA/RT-2) 
    → 感知-行动闭环基础模型
```

## 感知状态契约

感知系统应向上层提供以下信息：

| 维度 | 内容 | 说明 |
|:---|:---|:---|
| 语义 | 类别标签、属性、关系 | 经过分类、检测、分割得到 |
| 空间 | 3D 位置、姿态、尺寸 | 通过深度估计、SLAM、重建得到 |
| 时序 | 时间戳、轨迹、速度 | 通过跟踪、光流、预测得到 |
| 置信度 | 不确定性量化、校准 | 需要校准的模型输出 |
| 可追溯性 | 证据链、原始观测引用 | 支持可解释性和错误分析 |

## 当前发展状态

- **VLA 成为机器人学习的核心范式**：RT-2、OpenVLA 等模型将 VLM 扩展到行动输出，展示了"感知-行动"直接映射的可行性
- **主动感知在特定场景成熟**：Next-Best-View 在 3D 重建、场景探索中已有成熟方法
- **场景图作为状态表示被广泛采用**：场景图提供结构化的场景表示，支持关系推理和查询
- **感知-行动闭环基础模型仍不成熟**：现有 VLA 模型多为"感知→行动"的单向映射，缺乏真正的闭环更新

## 前沿方向

- 感知-行动联合基础模型（同时学习感知表示和行动策略）
- 主动感知与探索的信息理论框架
- 可微分感知-行动环路（端到端优化感知和行动策略）
- 感知状态的不确定性校准与传播
- 长期感知状态维护（持续更新、遗忘与记忆）

## 学习路径

1. 视觉感知基础 → 2. 空间感知基础 → 3. 主动感知 → 4. 状态表示 → 5. VLA 接口 → 6. 闭环感知系统
