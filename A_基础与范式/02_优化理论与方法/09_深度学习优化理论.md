# 深度学习优化理论

> 本文关注非凸深度网络为何能训练、何时不稳定；分布式实现、显存与通信工程请转 [[../../K_AI工程化/02_训练工程/00_训练工程_综述|训练工程]]。

## 核心问题

| 主题 | 要点 | 实践关联 |
|---|---|---|
| 梯度消失与爆炸 | 深层链式相乘导致梯度尺度失衡 | 初始化、残差、归一化、梯度裁剪 |
| 损失景观 | 鞍点、平坦/尖锐极小值、对称性 | 学习率、泛化与优化路径 |
| 优化动力学 | SGD 噪声、batch size、隐式正则化 | 泛化、噪声尺度与训练阶段 |
| 归一化 | BN/LN/RMSNorm 改善尺度与数值条件 | CNN、Transformer 稳定训练 |
| 训练稳定性 | 预热、裁剪、混合精度、损失监控 | 大模型预训练与微调 |
| 优化器比较 | SGD、AdamW、Lion、Shampoo/Muon | 需按模型、规模和预算实证选择 |

## 建议学习顺序

1. 梯度与 Hessian、条件数、随机逼近；
2. 初始化、残差连接、Normalization；
3. SGD 与 AdamW 的状态更新、权重衰减与学习率调度；
4. 研究损失景观、梯度噪声与批量大小；
5. 再进入大规模训练稳定性和分布式优化。
