# 自监督与离线机器人学习

## 一句话理解

自监督学习从无标签交互中提取对控制有用的表征，离线强化学习从固定日志中学习策略而不在线试错——两者共同解决机器人学习最大的瓶颈：真机数据的稀缺与危险。

## 概述

真机交互昂贵且危险，因此机器人学习的两条重要路线是：**自监督学习**（用无标签数据学习表征，如预测未来观测、动作后果）和**离线强化学习**（从已有日志学习策略，不进行在线探索）。它们不直接解决任务，而是提高数据利用率与学习效率，是数据规模化（Open X-Embodiment）的关键技术。

## 发展历史

- **2000s-2010s**：自监督视觉表征（对比学习、预测编码）进入机器人；离线 RL 早期工作（batch RL）出现。
- **2018-2020**：深度离线 RL 突破——CQL（2020）、IQL（2021）解决分布外价值估计；自监督机器人学习（自我模仿、预测模型）兴起。
- **2020s**：离线 RL 与大规模数据集结合（Open X-Embodiment）；自监督预训练表征被 VLA 采用；世界模型（Dreamer）作为自监督学习的高层形式。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 自监督目标 | 无标签数据上的代理任务 | 提取可迁移表征 |
| 对比学习 | 拉近正样本、推开负样本 | 表征一致性 |
| 预测编码 | 预测未来/缺失部分 | 时序表征 |
| 离线 RL | 从固定数据集学策略 | 避免在线危险探索 |
| 分布外动作 | 日志未覆盖的动作 | 离线 RL 核心风险 |
| 保守估计 | 低估未知状态价值 | 缓解 OOD 问题 |
| 行为约束 | 限制策略接近数据集动作 | 离线 RL 安全 |
| 回放评估 | 离线评估策略价值 | 上线前验证 |

## 技术原理

### 自监督学习目标

自监督目标应服务任务：预测对象位姿、接触、可达性或短期潜在状态通常比仅重建像素更利于控制。常见目标：

| 目标 | 学什么 | 用途 |
|---|---|---|
| 未来观测预测 | \(p(o_{t+k}\mid o_{\le t})\) | 世界模型、表征 |
| 动作条件预测 | \(p(o_{t+1}\mid o_t,a_t)\) | 动力学模型 |
| 对比一致性 | 同物体不同视角表征一致 | 视觉表征 |
| 时间对比 | 相邻时刻表征接近 | 时序平滑 |
| 触觉-视觉对应 | 预测接触属性 | 多模态融合 |
| 逆动力学 | \(p(a\mid o_t,o_{t+1})\) | 动作表征 |

### 离线 RL 的挑战与解法

离线 RL 从固定日志 \(\mathcal D\) 学习策略，核心难点是**分布外动作**：策略若选择日志未覆盖的动作，价值估计容易失真（Q 函数外推高估）。

| 方法 | 核心思想 | 代表 |
|---|---|---|
| 行为约束 | 限制策略接近行为策略动作 | BCQ, TD3+BC |
| 保守价值估计 | 惩罚未见状态的价值 | CQL |
| 隐式约束 | 只学习数据集内动作的价值 | IQL |
| 不确定性检测 | 对高不确定区域降权 | Conservative Approaches |

关键工程要求：
- **数据覆盖**：日志需覆盖目标任务的探索状态。
- **行为策略记录**：记录数据来源策略（用于行为约束）。
- **回放评估**：上线前用离线指标（OPE）评估。

### 自监督 + 离线学习的结合

```text
无标签交互数据 → 自监督表征学习 → 表征
已有日志 → 离线 RL/模仿 → 策略
少量真机数据 → 在线微调（RLPD）
```

自监督表征作为策略输入，可显著提升数据效率。

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| CQL | 保守 Q 学习 | 离线 RL 通用 |
| IQL | 隐式 Q 学习 | 离线 RL 稳定 |
| TD3+BC | 确定性策略 + 行为克隆 | 简单高效 |
| R3M | 视频预训练视觉表征 | 机器人视觉 |
| MVP | 掩码视觉预训练 | VLA 编码器 |
| VIP | 价值隐式预训练 | 奖励函数 |
| DreamerV3 | 世界模型自监督 | 想象训练 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 数据效率 | 复用已有数据 | 依赖数据质量与覆盖 |
| 安全性 | 不进行危险在线探索 | OOD 价值失真风险 |
| 可扩展性 | 支持大规模数据集 | 数据异构规范难 |
| 表征泛化 | 跨任务共享表征 | 任务相关目标难定义 |

## 应用场景

- 大规模机器人数据集预训练（Open X-Embodiment）。
- 日志驱动策略改进（旧系统日志）。
- 真机数据不足时的表征预训练。
- 与在线微调结合（RLPD 高效真机适应）。

- **VLA 表征预训练**：R3M/MVP 等视觉表征被 VLA 采用。
- **世界模型离线学习**：Dreamer 类方法从离线数据学习想象模型。
- **语言条件离线 RL**：从语言标注日志学习策略。
- **大规模离线数据集**：Open X-Embodiment、DROID 等规模化。
- **离线-在线混合**：RLPD 类方法统一离线与在线学习。

## 常见问题

- **自监督目标与任务脱节**：仅重建像素不一定利于控制。
- **离线 RL 高估 OOD**：必须行为约束或保守估计。
- **数据泄漏**：同一物体/场景同时出现在训练与评测集。
- **忽略行为策略**：离线数据来自不同策略，需记录元数据。
