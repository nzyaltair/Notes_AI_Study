# 内在动机与好奇心驱动探索

## 一句话理解

内在动机为缺少外部奖励的探索提供信号——用新颖性、预测误差、信息增益或赋能驱动智能体主动学习，是开放式智能的探索引擎。

## 动机信号

| 信号 | 定义 | 优点 | 缺点 |
|---|---|---|---|
| 预测误差 | 模型对未来的预测错误 | 直接、易计算 | 偏好随机噪声 |
| 新颖性 | 状态/行为不在记忆中 | 鼓励覆盖 | 纯新颖性导致漫游 |
| 信息增益 | 降低环境不确定性 | 理论完备 | 高维下难计算 |
| 能力进步 | 技能掌握速度的提升 | 与学习对齐 | 需基线估计 |
| 赋能（Empowerment） | 行动对未来的控制力 | 与目标无关 | 高维下昂贵 |

## 代表性方法

| 方法 | 核心机制 |
|---|---|
| ICM（Intrinsic Curiosity Module） | 预测下一状态的误差作为内在奖励 |
| RND（Random Network Distillation） | 预测随机网络的输出，误差=新颖性 |
| Count-based Exploration | 状态访问计数（哈希/密度估计） |
| Information Gain 方法 | 贝叶斯模型下互信息度量 |
| Go-Explore | 先存档已知状态，再从中探索 |
| DIAYN | 最大化技能辨识度的多样性动机（见 [[03_自主技能获取与终身发现]]） |

## 关键设计问题

预测误差会偏好随机噪声，纯新颖性会导致漫游；因此常需结合：

- **可学习性**：只奖励"可掌握"的新领域（预测误差持续降低的部分）。
- **任务相关性**：把内在动机与任务进展耦合。
- **长期约束**：避免危险或高成本探索。
- **记忆去重**：防止重复访问同一区域。

## 与强化学习的结合

内在动机作为外部奖励的补充信号：`r_total = r_ext + β · r_int`。β 的调度（先探索后利用）是工程关键。对应 D 板块的强化学习与 D 板块的探索机制。

## 前沿发展

- **LLM 驱动好奇心**：用 LLM 生成探索目标（"去尝试什么"）而非仅数值奖励。
- **内在动机与开放式进化结合**：内部驱动 + 外部选择压力双引擎（见 [[../../06_人工生命与进化智能/03_开放式进化与人工生态系统]]）。
- **可学习性驱动的自动课程**：按学习速度安排探索任务顺序。
