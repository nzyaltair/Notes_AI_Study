# 数学速查表

## 一句话理解

本速查表是 AI 学习中最常用数学公式的**最小冗余、最大检索效率**索引，每个公式均标注来源笔记，便于快速查阅与跳转推导。

## 1. 概述

本速查表汇总 AI 学习中最常用的数学公式与概念，作为 [[01_线性代数|线性代数]]、[[02_微积分|微积分]]、[[03_概率与统计|概率与统计]]、[[04_优化方法|优化方法]]、[[05_信息论|信息论]] 的快速参考索引。每个公式标注来源笔记，便于深入查阅。设计目标：**最小冗余、最大检索效率**。

## 2. 发展历史

本表覆盖的公式从经典数学（17-19 世纪微积分、线性代数）到 [[00_大语言模型核心架构_综述|大语言模型]] 时代的特定工具（RoPE、GELU、AdamW），反映了 AI 数学工具栈的持续扩展。详细历史脉络参见各主题笔记。

## 4. 技术原理

### 线性代数（详见 [[01_线性代数|线性代数]]）

| 运算 | 公式 |
|------|------|
| 矩阵乘法 | $C_{ij} = \sum_k A_{ik} B_{kj}$ |
| 点积 | $\mathbf{a} \cdot \mathbf{b} = \sum_i a_i b_i$ |
| 迹 | $\text{tr}(\mathbf{A}) = \sum_i A_{ii}$；$\text{tr}(\mathbf{AB}) = \text{tr}(\mathbf{BA})$ |
| 行列式 | $\det(\mathbf{AB}) = \det(\mathbf{A})\det(\mathbf{B})$ |
| 范数 | L1: $\sum\|x_i\|$；L2: $\sqrt{\sum x_i^2}$；F: $\sqrt{\text{tr}(\mathbf{A}^T\mathbf{A})}$ |

**矩阵分解**：特征分解 $\mathbf{A} = \mathbf{Q}\mathbf{\Lambda}\mathbf{Q}^{-1}$；SVD $\mathbf{A} = \mathbf{U}\mathbf{\Sigma}\mathbf{V}^T$；Cholesky $\mathbf{A} = \mathbf{L}\mathbf{L}^T$

**矩阵微积分**：$\nabla(\mathbf{a}^T\mathbf{x}) = \mathbf{a}$；$\nabla(\mathbf{x}^T\mathbf{A}\mathbf{x}) = 2\mathbf{A}\mathbf{x}$（$\mathbf{A}$ 对称）；$\nabla(\|\mathbf{A}\mathbf{x}-\mathbf{b}\|^2) = 2\mathbf{A}^T(\mathbf{A}\mathbf{x}-\mathbf{b})$

### 微积分（详见 [[02_微积分|微积分]]）

| 概念 | 公式 |
|------|------|
| 链式法则（单变量） | $\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$ |
| 链式法则（多变量） | $\frac{\partial y}{\partial x_j} = \sum_i \frac{\partial y}{\partial u_i} \frac{\partial u_i}{\partial x_j}$ |
| 梯度 | $\nabla f = [\frac{\partial f}{\partial x_1}, \dots, \frac{\partial f}{\partial x_n}]^T$ |
| Taylor 展开 | $f(\mathbf{x}) \approx f(\mathbf{a}) + \nabla f^T\Delta\mathbf{x} + \frac{1}{2}\Delta\mathbf{x}^T \mathbf{H} \Delta\mathbf{x}$ |
| Jacobian | $J_{ij} = \frac{\partial f_i}{\partial x_j}$ |
| Hessian | $H_{ij} = \frac{\partial^2 f}{\partial x_i \partial x_j}$ |

**数值稳定**：Log-Sum-Exp $\log\sum \exp(x_i) = \max(x) + \log\sum \exp(x_i - \max(x))$

### 概率界与重要不等式（详见 [[03_概率与统计|概率与统计]] / [[08_现代AI数学基础|现代AI数学基础]]）

| 不等式/界 | 表达形式 | 成立条件与应用 |
|-----------|---------|---------------|
| **Markov 不等式** | $P(X \ge a) \le \frac{E[X]}{a}$ | $X \ge 0, a > 0$，最基础的概率尾部上界 |
| **Chebyshev 不等式** | $P(\lvert X - \mu \rvert \ge k\sigma) \le \frac{1}{k^2}$ | 已知均值 $\mu$ 与方差 $\sigma^2$ |
| **Chernoff 界** | $P(X \ge a) \le \min_{t>0} \frac{E[e^{tX}]}{e^{ta}}$ | 独立随机变量和的指数衰减尾部界 |
| **Hoeffding 不等式** | $P(\lvert \bar{X} - \mu \rvert \ge \epsilon) \le 2\exp\left(-\frac{2n\epsilon^2}{\sum (b_i-a_i)^2}\right)$ | 有界独立随机变量 $X_i \in [a_i, b_i]$ 的样本均值集中界 |
| **McDiarmid 不等式** | $P(\lvert f(X) - E[f(X)] \rvert \ge \epsilon) \le 2\exp\left(-\frac{2\epsilon^2}{\sum c_i^2}\right)$ | 函数 $f$ 满足 bounded differences 条件（改变单个坐标改变最多 $c_i$） |
| **Jensen 不等式** | $f(E[X]) \le E[f(X)]$ (凸函数 $f$) | 变分推断 ELBO 推导的理论基石 |
| **Cauchy-Schwarz 不等式** | $\lvert \langle \mathbf{u}, \mathbf{v} \rangle \rvert \le \lVert \mathbf{u} \rVert \lVert \mathbf{v} \rVert$ | 内积与范数上界，余弦相似度极值 |
| **Hölder 不等式** | $\lVert f g \rVert_1 \le \lVert f \rVert_p \lVert g \rVert_q$ | $\frac{1}{p} + \frac{1}{q} = 1$，$L_p$ 空间对偶 |
| **Young 不等式** | $a b \le \frac{a^p}{p} + \frac{b^q}{q}$ | $a,b \ge 0, \frac{1}{p}+\frac{1}{q}=1$ |
| **PAC-Bayes 界** | $L(\mathcal{A}) \le \hat{L}_S(\mathcal{A}) + \sqrt{\frac{D_{KL}(P\|P_0) + \ln(2\sqrt{n}/\delta)}{2n}}$ | 学习器后验 $P$ 相对先验 $P_0$ 的泛化界，SAM 理论基础 |

### 概率与统计（详见 [[03_概率与统计|概率与统计]]）

| 概念 | 公式 |
|------|------|
| 贝叶斯定理 | $P(A \mid B) = \frac{P(B \mid A)P(A)}{P(B)}$ |
| 期望 | $E[X] = \sum x\,P(x)$（离散）；$\int x\,f(x)\,dx$（连续） |
| 方差 | $\text{Var}(X) = E[X^2] - (E[X])^2$ |
| MLE | $\hat{\theta} = \arg\max_\theta \sum \log P(x_i \mid \theta)$ |
| MAP | $\hat{\theta} = \arg\max_\theta [\log P(D \mid \theta) + \log P(\theta)]$ |
| 大数法则 | $\bar{X}_n \xrightarrow{P} \mu$ |
| 中心极限定理 | $\sqrt{n}\frac{\bar{X}_n - \mu}{\sigma} \xrightarrow{d} \mathcal{N}(0, 1)$ |

**常用分布**：高斯 $\mathcal{N}(\mu, \sigma^2)$；伯努利 $P(X=1)=p$；均匀 $U(a,b)$

### 信息论（详见 [[05_信息论|信息论]]）

| 概念 | 公式 |
|------|------|
| 熵 | $H(X) = -\sum P(x)\log P(x)$ |
| 交叉熵 | $H(P,Q) = -\sum P(x)\log Q(x) = H(P) + D_{KL}(P\|Q)$ |
| KL 散度 | $D_{KL}(P\|Q) = \sum P(x)\log\frac{P(x)}{Q(x)}$ |
| 互信息 | $I(X;Y) = H(X) - H(X \mid Y)$ |
| JS 散度 | $D_{JS} = \frac{1}{2}D_{KL}(P\|M) + \frac{1}{2}D_{KL}(Q\|M)$，$M=\frac{P+Q}{2}$ |
| ELBO | $\log p(x) \geq E_q[\log p(x,z) - \log q(z)]$ |
| 困惑度 | $\text{PPL} = \exp(-\frac{1}{N}\sum \log P(x_i \mid ctx))$ |

### 优化方法（详见 [[04_优化方法|优化方法]]）

| 方法 | 更新规则 |
|------|---------|
| SGD | $\theta \leftarrow \theta - \eta g_t$ |
| 动量法 | $v \leftarrow \mu v + \eta g_t$；$\theta \leftarrow \theta - v$ |
| RMSProp | $E[g^2]_t = \rho E[g^2]_{t-1} + (1-\rho)g_t^2$；$\theta \leftarrow \theta - \frac{\eta}{\sqrt{E[g^2]_t+\epsilon}} g_t$ |
| Adam | $\hat{m}_t = \frac{m_t}{1-\beta_1^t}$；$\hat{v}_t = \frac{v_t}{1-\beta_2^t}$；$\theta \leftarrow \theta - \eta\frac{\hat{m}_t}{\sqrt{\hat{v}_t}+\epsilon}$ |
| AdamW | $\theta \leftarrow \theta - \eta(\frac{\hat{m}_t}{\sqrt{\hat{v}_t}+\epsilon} + \lambda\theta_t)$ |

**余弦退火**：$\eta_t = \eta_{min} + \frac{1}{2}(\eta_0 - \eta_{min})(1+\cos\frac{t\pi}{T})$

**KKT 条件**：$\nabla f + \sum \lambda_i \nabla g_i + \sum \mu_j \nabla h_j = 0$，$\lambda_i g_i = 0$，$\lambda_i \geq 0$

### 深度学习公式

**激活函数**：

| 函数 | 公式 | 导数 |
|------|------|------|
| Sigmoid | $\sigma(x) = \frac{1}{1+e^{-x}}$ | $\sigma'(x) = \sigma(x)(1-\sigma(x))$ |
| ReLU | $\max(0, x)$ | $\begin{cases}1 & x>0\\0 & x<0\end{cases}$ |
| GELU | $x\Phi(x) \approx x\sigma(1.702x)$ | — |
| SiLU/Swish | $x\sigma(x)$ | $\sigma(x)(1+x(1-\sigma(x)))$ |
| Softmax | $\frac{\exp(x_i-\max)}{\sum_j \exp(x_j-\max)}$ | $J_{ij} = s_i(\delta_{ij}-s_j)$ |

**损失函数**：MSE $L = \frac{1}{n}\sum(y_i - \hat{y}_i)^2$；交叉熵 $L = -\sum y_i \log \hat{y}_i$

**归一化**：$\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}$，$y = \gamma\hat{x} + \beta$；RMSNorm：$\hat{x} = \frac{x}{\sqrt{\frac{1}{d}\sum x_i^2 + \epsilon}}$

**注意力与大模型架构（详见 [[06_大模型相关数学|大模型相关数学]]）**：

- **Standard Attention**: $\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$
- **FlashAttention Online Softmax (分块规约)**: $m^{(i)} = \max(m^{(i-1)}, m^{block})$, $l^{(i)} = e^{m^{(i-1)}-m^{(i)}} l^{(i-1)} + e^{m^{block}-m^{(i)}} l^{block}$, $O^{(i)} = \text{diag}\left(e^{m^{(i-1)}-m^{(i)}}\right) O^{(i-1)} + e^{m^{block}-m^{(i)}} P^{block} V^{block}$
- **DeepSeek MLA (Multi-Head Latent Attention)**: 隐空间低秩压缩 $\mathbf{c}_t^{KV} = \mathbf{W}^{DKV} \mathbf{h}_t$, $\mathbf{k}_t^C = \mathbf{W}^{UK} \mathbf{c}_t^{KV}$, $\mathbf{v}_t^C = \mathbf{W}^{UV} \mathbf{c}_t^{KV}$，显著减少 KV-Cache 显存占用
- **RoPE (旋转位置编码)**: $R_{\Theta, m}^d \mathbf{x}_m = \begin{pmatrix} x_1 \cos m\theta_1 - x_2 \sin m\theta_1 \\ x_1 \sin m\theta_1 + x_2 \cos m\theta_1 \\ \vdots \end{pmatrix}$，满足 $\langle R_m \mathbf{q}, R_n \mathbf{k} \rangle = g(\mathbf{q}, \mathbf{k}, m-n)$
- **RoPE 外推 (YaRN / NTK-aware)**: $\theta_i' = b \cdot a^{\frac{2i}{d}}$，高频高分辨率插值、低频外推

**大模型对齐与强化学习（详见 [[06_大模型相关数学|大模型相关数学]] / [[13_博弈论与机制设计|博弈论与机制设计]]）**：

- **DPO 损失**: $\mathcal{L}_{DPO}(\theta) = -E_{(x, y_w, y_l)} \left[ \log \sigma \left( \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{ref}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{ref}(y_l \mid x)} \right) \right]$
- **GRPO (Group Relative Policy Optimization)**: 组内归一化优势 $A_i = \frac{r_i - \text{mean}(r)}{\text{std}(r)}$，目标 $J_{GRPO}(\theta) = E \left[ \frac{1}{G} \sum_{i=1}^G \min\left( \frac{\pi_\theta(y_i \mid x)}{\pi_{\theta_{old}}(y_i \mid x)} A_i, \text{clip}\left(\cdot\right) A_i \right) - \beta D_{KL}(\pi_\theta \parallel \pi_{ref}) \right]$

**初始化与归一化**：

- Xavier: $\text{Var}(W) = \frac{2}{\text{fan\_in}+\text{fan\_out}}$；He (Kaiming): $\text{Var}(W) = \frac{2}{\text{fan\_in}}$
- LayerNorm: $\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}$，RMSNorm: $\hat{x} = \frac{x}{\text{RMS}(x)} = \frac{x}{\sqrt{\frac{1}{d}\sum x_i^2 + \epsilon}}$
