# 数据工程与采集：具身智能的能力上限

## 一句话理解

具身系统的能力上限不是由模型参数决定的，而是由数据的数量、质量、多样性和规范性决定的。**数据工程不是数据集管理的辅助工作，而是具身智能最核心的工程挑战。**

## 1. 数据从哪里来

### 遥操作（Teleoperation）

人类通过空间鼠标、VR 控制器、主从臂或键盘远程控制机器人执行任务，记录观测—动作对。这是目前获取高质量操作数据的主要方式。

| 方式 | 适用场景 | 优势 | 局限 |
|---|---|---|---|
| 空间鼠标/3D 鼠标 | 桌面操作 | 低成本、易部署 | 自由度有限、精度受限 |
| VR 控制器 | 6DoF 末端控制 | 直觉映射、支持位姿+夹爪 | 需要标定映射和延迟补偿 |
| 主从臂 | 双臂精密操作 | 高精度、力觉反馈 | 硬件成本高 |
| 键盘/游戏手柄 | 简单导航和单一操作 | 门槛最低 | 难以表达 6DoF 操作 |

遥操作数据的质量取决于：操作者一致性、延迟与同步、标定精度、示教策略（是否包含恢复和失败），以及数据记录的完整性。

### 自主采集与探索

机器人用已学策略或内在动机（好奇心、信息增益、预测误差）在环境中自主交互，收集新数据。适合扩展数据分布、覆盖失败场景和长尾状态；但必须加入安全约束、人工监督和失败过滤。

### 仿真数据

仿真可在 GPU 上并行生成海量数据，且自动获得完美标注。代价是 sim-to-real 差距：视觉外观、摩擦、时延和柔性物体的差异可能使仿真训练的策略在真机上失效。域随机化和真机微调是常用的缓解方式。

### 网络视频与人类演示

人类操作视频（如 YouTube）提供了丰富的语义和策略信息，但缺少机器人动作标签、精确位姿和力信息。当前研究方向包括：从视频中提取可供性和操作计划、视频到机器人动作的跨Embodiment迁移、以及用视频预训练视觉编码器。

## 2. 数据规范：一条轨迹应记录什么

| 类别 | 应记录字段 | 常见遗漏 |
|---|---|---|
| 任务 | 文本指令、版本、任务 ID | 指令模板和语言变化未记录 |
| 视觉 | RGB/深度/点云、时间戳、相机参数、曝光 | 深度质量标志、丢帧和延迟 |
| 触觉/力 | 接触力/力矩、滑移信号、传感器 ID | 接触事件与策略动作的时间对齐 |
| 本体 | 关节角/速度/力矩、末端位姿、IMU | 控制器实际执行的动作 vs 策略输出 |
| 动作 | 命令值、坐标系、单位、频率、裁剪范围 | 动作延迟、跟踪误差与饱和 |
| 环境 | 物体 ID/位姿、场景布局、光照 | 动态变化、物体属性和干扰 |
| 元数据 | 标定版本、策略/权重版本、操作者 ID | 失败/恢复/人工干预常被丢弃 |

**最大误区**：只保存成功的完美演示。失败、恢复、人工干预和边缘场景才是系统鲁棒性的关键数据。

## 3. 跨本体数据与统一动作空间

### Open X-Embodiment

Google DeepMind 牵头的 Open X-Embodiment（RT-X）项目汇集了 22 种机器人形态的数据，试图通过统一动作表示实现跨本体迁移。核心挑战包括：

| 维度 | 异质性来源 | 统一策略 |
|---|---|---|
| 动作空间 | 关节角/末端增量/夹爪/力矩 | 归一化到末端 6DoF + 夹爪 |
| 观测 | 不同相机视角、分辨率、有无深度 | 统一图像尺寸 + 本体标记 |
| 控制频率 | 5 Hz–50 Hz | 重采样到统一频率 + 标记原始频率 |
| 成功标准 | 不同任务定义 | 统一成功/失败/部分成功标签 |
| 本体信息 | 不同自由度、工作空间 | 编码本体元数据（DoF、关节限位等） |

跨本体迁移目前仍面临硬约束：不同本体的可达性、接触模式和力控能力差异使得"统一"只在高层语义层面成立，低层动作仍需本体特定适配。

### 数据效率方法

| 方法 | 核心思想 | 适用场景 |
|---|---|---|
| 预训练 + 微调 | 在大规模数据预训练后用少量目标域数据微调 | 目标域数据有限但可获取 |
| 数据增广 | 翻转、裁剪、颜色抖动、物理随机化 | 视觉泛化 |
| 主动学习 | 选择最有信息量的样本采集 | 真机采集成本高 |
| 模仿 + RL 初始化 | IL 初始化后 RL 微调 | 需要超越演示质量 |
| 合成数据 + 真机校正 | 仿真为主 + 少量真机 | 仿真可信但需校正分布 |

## 4. 数据切分、泄漏与评测

常见泄漏源：同一物体实例同时出现在训练和测试集；同一场景不同角度；同一指令模板的不同填充；同一天的连续数据。推荐按物体实例、场景、指令模板和时间切分，而非随机切帧。

评测应区分：训练物体/场景 vs 新物体/场景；见过的指令 vs 新指令组合；短期数据 vs 长期分布漂移。报告泛化能力时必须明确切分方式。

## 5. 关键数据集与基准

| 数据集/项目 | 覆盖范围 | 规模特点 |
|---|---|---|
| Open X-Embodiment | 22 种机器人、多种任务 | 首个大规模跨本体数据集 |
| DROID | 多机器人遥操作 | 开源、多样化操作 |
| Bridge V2 | 单臂桌面操作 | 高质量视觉—动作对 |
| RoboMIND | 多任务、多场景 | 中国开源具身数据集 |
| ManiSkill 演示 | GPU 并行仿真操作 | 可无限生成、带密集奖励 |
| RH20T | 人形/灵巧手 | 触觉和多模态观测 |
