# 连接主义与深度学习：原理、学习机制与通用架构基础

> **定位**：B 板块解释神经网络如何学习表示、从数据中获得监督并形成可扩展的通用架构；它是 C 基础模型、E 感知、F 世界模型、D Agent 与 K 工程体系的共同方法基础，而非这些应用层的替代目录。

## 主线

```text
神经网络基础 → 深度学习理论 → 表示学习 → 自监督学习
                                     ↓
视觉/CNN、序列模型、生成模型、Transformer、图神经网络
                                     ↓
C 基础模型 → E 多模态感知 → F 世界模型 → D Agent
```

## 跨板块边界

- **C_基础模型与通用智能**：预训练系统、模型家族、对齐、推理与高效模型的主体知识。
- **E_感知与多模态智能**：视觉、语音、空间与多模态感知任务及应用。
- **F_世界模型与环境智能**：环境动力学、模拟和交互的主体理论。
- **D_智能体与自主系统**：强化学习、Agent 记忆、规划与行动闭环。
- **K_AI工程化**：数据、分布式训练、部署和评测系统。
