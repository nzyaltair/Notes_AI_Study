# 具身 Agent 世界模型

## 一句话理解

具身 Agent 面对连续控制、接触、延迟和不可逆风险，其世界模型需在高层预测任务进展、对象可供性和路径风险，在低层预测姿态、速度、力和碰撞。

## 概述

具身世界模型是 F 世界模型在物理载体上的落地：它必须同时支撑"做什么"（任务级预测）与"怎么做"（运动级预测），并把预测接入实时、受限、不可逆的控制回路。与仿真/数字环境不同，物理世界没有 reset 按钮。

## 推荐分层架构

```text
语言/任务模型 → 子目标（高层预测）
      ↓
空间世界模型 → 可达目标与约束（中层）
      ↓
MPC / 控制策略 → 短时动作执行（低层）
      ↓
传感器反馈 → 实时校正
```

- 高层：对象可供性、任务进度、风险走廊。
- 中层：位姿、接触图、运动学约束。
- 低层：关节动力学、力/力矩、碰撞检测。

## 关键挑战

- **接触与物理**：抓取、推挤等接触事件是主要误差来源，需物理约束与接触模型。
- **执行延迟与噪声**：预测必须编码动作延迟与执行不确定性。
- **不可逆风险**：危险动作不可撤销，安全层必须独立于生成模型。
- **Sim2Real**：仿真训练的模型需域随机化与现实验证（见 [[../../04_环境模拟与数字孪生/05_Sim2Real|Sim2Real]]）。

## 安全设计原则

安全系统应独立于生成模型，具备速度、力、工作空间和碰撞的**硬约束**：生成模型只提供建议，安全层否决并降级，必要时人工接管。
