# 动作表征与 Robot Transformer

## 一句话理解

动作表示决定模型实际学到的控制语义——关节位置、末端增量、离散 token 或技能参数各有取舍；Robot Transformer 以时序注意力融合视觉、语言、本体和动作历史，是 VLA 的骨干架构。

## 概述

动作表征（Action Representation）是机器人学习中最容易被忽视却决定成败的设计选择：同样一个模型，动作坐标不同、单位不同、频率不同，学到的行为完全不同。Robot Transformer（RT）系列把动作作为序列建模的对象，用 Transformer 架构统一多模态输入与动作输出。本章梳理动作表示的取舍与 Transformer 策略架构的设计。

## 发展历史

- **2016-2020**：端到端视觉运动策略输出连续动作（关节/末端）；动作作为回归目标。
- **2022**：RT-1 引入动作 token（离散化）；动作分块（Action Chunking）用于时序平滑。
- **2023**：ACT 用 CVAE + 动作分块；Diffusion Policy 在动作序列空间生成。
- **2024**：π0 流匹配连续动作；动作分块自回归（π0.5）；统一动作空间的跨本体预训练。

## 核心概念

| 概念 | 定义 | 取舍 |
|---|---|---|
| 关节位置 | 目标关节角 | 直接、硬件相关 |
| 关节速度/力矩 | 速度/力矩指令 | 动态、风险高 |
| 末端位姿增量 | 末端 Δ 位姿 | 任务对齐、跨本体 |
| 动作 token | 离散化动作 | 建模简单、精度损失 |
| 动作分块 | 一次预测多步 | 平滑 vs 时延 |
| 技能参数 | 高层参数 | 抽象、依赖技能库 |

## 技术原理

### 动作表示对比

| 表示 | 优势 | 局限 | 适用 |
|---|---|---|---|
| 关节位置 | 简单、硬件通用 | 任务空间不直观 | 伺服控制 |
| 关节力矩 | 控制力强 | 风险高、需模型 | 动态控制 |
| 末端增量 | 任务对齐、跨本体 | 需 IK 适配 | VLA |
| 离散 token | 复用 VLM 结构 | 精度损失 | RT 系列 |
| 连续回归 | 精度高 | 多模态表达弱 | 简单任务 |
| 流匹配/扩散 | 多模态、平滑 | 推理时延 | 操作 |

### 动作分块

动作分块（Action Chunking）：策略一次预测未来 \(H\) 步动作块 \(a_{t:t+H}\)：

- **优势**：时序协调、降低视觉推理频率、平滑执行。
- **风险**：块太长放大时延与状态误差——执行中环境变化无法响应。
- **标准做法**：短视界生成 + 滚动执行（执行部分块后重新观测）。

### Robot Transformer 架构

```text
图像 token + 语言 token + 本体状态 token + 动作历史
→ 时序注意力（Transformer）
→ 动作 token / 连续动作
```

RT-1 将动作离散化为 256 bin token 与语言联合建模；RT-2 从 VLM 微调；ACT 用 CVAE 生成动作块；π0 用流匹配生成连续动作轨迹。

### 训练-部署一致性

无论架构如何，训练与部署必须一致定义：

- 参考坐标系（世界/基座/末端）。
- 单位（米、弧度）。
- 采样频率与控制频率。
- 归一化（均方差、裁剪）。
- 夹爪编码（开/合语义）。
- 裁剪规则（限幅）。

## 关键方法与模型

| 模型 | 动作表示 | 架构特点 |
|---|---|---|
| RT-1 | 离散 token | 单 Transformer |
| RT-2 | 离散 token | VLM 微调 |
| ACT | 动作分块 + CVAE | 变分生成 |
| Diffusion Policy | 动作序列扩散 | 去噪生成 |
| π0 | 流匹配连续 | 动作 tokenizer + 流模型 |
| π0.5 | 分块自回归 | 长时域生成 |

## 优势与局限

| 表示 | 优势 | 局限 |
|---|---|---|
| token 离散 | 建模统一 | 精度 |
| 连续生成 | 精度、多模态 | 推理成本 |
| 分块 | 平滑 | 时延 |
| 末端增量 | 跨本体 | IK 依赖 |

## 应用场景

- VLA 部署：末端增量 + 分块滚动执行。
- 灵巧操作：连续动作 + 触觉反馈。
- 双臂协调：关节空间联合表示。
- 跨本体：统一末端动作空间。

- **统一动作空间**：跨本体共享动作表示。

## 常见问题

- **忽略坐标系**：相同 Δ 值在不同坐标系行为完全不同。
- **块太长**：放大时延与状态误差。
- **训练部署不一致**：归一化、频率不一致直接失败。
- **夹爪语义混乱**：开/合编码不统一导致抓取错误。
