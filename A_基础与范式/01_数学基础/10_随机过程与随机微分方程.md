# 随机过程与随机微分方程

## 一句话理解

随机过程研究**随时间演化的不确定性**：一个随机变量序列或连续时间函数，每一步的取值都受概率支配。随机微分方程（SDE）则描述"确定性演化 + 噪声驱动"的系统，是连接马尔可夫链、布朗运动、扩散模型去噪过程、强化学习环境与序列建模的核心数学语言。

## 1. 概述

概率论（[[03_概率与统计|概率与统计]]）处理的是"静态"的不确定性——一个随机变量。但在 AI 的几乎所有核心问题中，不确定性是**随时间/序列演化的**：语言模型逐个 token 生成、强化学习 agent 与环境的交互轨迹、扩散模型对图像的逐步去噪、时间序列预测、粒子滤波的状态估计。这些都需要随机过程的框架。

随机过程把"分布"升级为"分布的演化律"：不仅知道 $X_t$ 的边缘分布，还知道 $X_{t+1}$ 如何依赖 $X_t$。随机微分方程则进一步把演化律写成连续时间的形式
$$ dX_t = \mu(X_t, t)\, dt + \sigma(X_t, t)\, dB_t $$
其中 $\mu$ 是漂移（趋势），$\sigma$ 是扩散（噪声强度），$B_t$ 是布朗运动。这个方程统一了确定性 ODE（$\sigma = 0$）与随机扰动，是理解扩散模型"前向加噪 / 反向去噪"、连续时间强化学习、随机梯度下降（SGD）噪声动力学的理论基石。

## 3. 核心概念

### 3.1 随机过程的定义与分类

**随机过程**是一族随机变量 $\{X_t\}_{t \in T}$，其中 $t$ 是时间指标。分类维度：

- **指标集**：离散时间（$t = 0, 1, 2, \dots$，如语言模型的 token 序列）vs 连续时间（$t \in [0, \infty)$，如扩散模型的噪声过程）
- **状态空间**：离散（如词表、状态数有限的 MDP）vs 连续（如向量空间中的 embedding 演化）
- **统计特性**：平稳过程（分布不随时间平移改变）、遍历过程（时间平均等于期望）、鞅（公平博弈）

**马尔可夫性**：未来只依赖现在，不依赖过去：
$$ P(X_{t+1} \mid X_t, X_{t-1}, \dots, X_0) = P(X_{t+1} \mid X_t) $$
这是强化学习中 MDP 的基本假设，也是自回归语言模型"下一个 token 只依赖前文"的随机过程表述。

### 3.2 马尔可夫链

**离散时间马尔可夫链**：转移概率矩阵 $\mathbf{P}$，其中 $P_{ij} = P(X_{t+1} = j \mid X_t = i)$。$n$ 步转移为 $\mathbf{P}^n$。

- **平稳分布** $\boldsymbol{\pi}$：$\boldsymbol{\pi}^T = \boldsymbol{\pi}^T \mathbf{P}$，即经过多次转移后分布不再改变。若链不可约（任意状态可达）且非周期，则从任意初值收敛到唯一的平稳分布。
- **细致平衡（detailed balance）**：$\pi_i P_{ij} = \pi_j P_{ji}$ 蕴含平稳性，是 MCMC 中 Metropolis-Hastings 接受准则的基础。
- **收敛速率**：由 $\mathbf{P}$ 的第二大特征值 $\lambda_2$（谱隙 $1 - \lambda_2$）决定，谱隙越大收敛越快。这与图论中拉普拉斯谱（[[11_图论与组合优化|图论与组合优化]]）直接相关。

> **示例**：两状态链 $\mathbf{P} = \begin{bmatrix} 0.9 & 0.1 \\ 0.3 & 0.7 \end{bmatrix}$。平稳分布满足 $\pi_1 = 0.9\pi_1 + 0.3\pi_2$，$\pi_1 + \pi_2 = 1$，解得 $\boldsymbol{\pi} = [0.75, 0.25]$。特征值 $\lambda_1 = 1, \lambda_2 = 0.6$，谱隙 0.4，约 5 步后收敛。

### 3.3 布朗运动与鞅

**布朗运动（Wiener 过程）** $B_t$ 满足：
1. $B_0 = 0$，轨道连续；
2. 独立增量：$B_t - B_s$ 与 $B_u$（$u < s$）独立；
3. 正态增量：$B_t - B_s \sim \mathcal{N}(0, t - s)$。

关键性质：
- **方差随时间线性增长**：$\text{Var}(B_t) = t$。噪声的能量是时间级的，这与确定性信号（能量随时间平方增长）本质不同。
- **轨道处处不可微**（以概率 1）。这是随机微积分与普通微积分必须分家的根本原因——$\frac{dB_t}{dt}$ 不存在。
- **二次变差非零**：$\sum (\Delta B)^2 \to t$。这一性质决定了 Itô 公式中会出现额外的二阶项。

**鞅（martingale）**：$E[X_{t+1} \mid X_t] = X_t$，即"公平博弈"——未来期望等于现在。鞅在随机分析中的地位类似常数在微积分中的地位，是停时、可选停时定理等核心工具的对象。

### 3.4 泊松过程与跳过程

**泊松过程** $N_t$：计数过程，事件间隔独立且服从指数分布。描述离散事件的随机到达（用户请求、神经元放电）。其广义形式——**莱维过程**（含跳跃的噪声）——是金融建模和某些异步系统模型的基础。

### 3.5 平稳过程与遍历性

**宽平稳**：均值常数，自协方差只依赖时间差。**遍历性**：时间平均 $\frac{1}{T}\int_0^T X_t dt \to E[X_t]$（概率 1）。遍历性保证"长期观察一个样本路径"可以替代"同时观察大量样本"——这是仿真、蒙特卡洛方法（[[03_概率与统计|概率与统计]] 的 MCMC）的合法性与效率依据。

## 4. 技术原理

### 4.1 Itô 积分与 Itô 公式

普通微积分中 $d(t^2) = 2t\,dt$。随机情形下，若 $X_t = f(B_t)$，则
$$ dX_t = f'(B_t)\, dB_t + \frac{1}{2} f''(B_t)\, dt $$
多出的 $\frac{1}{2}f''dt$ 项来自布朗运动的非零二次变差——这是 Itô 公式（随机版的链式法则），也是随机微积分与普通微积分最根本的差异。

> **验证直觉**：$f(x) = x^2$。普通微积分给 $d(B_t^2) = 2B_t dB_t$；Itô 公式给出 $d(B_t^2) = 2B_t dB_t + dt$。取期望得 $dE[B_t^2] = dt$，即 $E[B_t^2] = t$——与 $\text{Var}(B_t) = t$ 吻合。没有 $dt$ 项就会得到错误结论 $E[B_t^2] = 0$。

### 4.2 随机微分方程（SDE）

$$ dX_t = \mu(X_t, t)\, dt + \sigma(X_t, t)\, dB_t $$

- **漂移项** $\mu$：确定性趋势（ODE 部分）
- **扩散项** $\sigma$：噪声强度；$\sigma = 0$ 时退化为 ODE

**Fokker-Planck 方程（前向 Kolmogorov）**：$X_t$ 的概率密度 $p(x, t)$ 满足
$$ \frac{\partial p}{\partial t} = -\frac{\partial}{\partial x}(\mu p) + \frac{1}{2}\frac{\partial^2}{\partial x^2}(\sigma^2 p) $$
这给出了 SDE 的**分布层面的确定性描述**：随机单轨道 $\leftrightarrow$ 确定的密度演化。扩散模型的训练目标（分数匹配）正是让网络学习这个密度演化的反向。

**Ornstein-Uhlenbeck（OU）过程**是最重要的线性 SDE：
$$ dX_t = \theta(\mu - X_t)\, dt + \sigma\, dB_t $$
均值回归性质使其成为扩散模型前向过程、随机利率模型的标准选择。其条件分布封闭：
$$ X_t \mid X_0 \sim \mathcal{N}\left(\mu + (X_0 - \mu)e^{-\theta t},\ \frac{\sigma^2}{2\theta}(1 - e^{-2\theta t})\right) $$

### 4.3 SDE 与扩散模型

扩散模型（DDPM / Score-based）可用 SDE 统一表述（Song et al., 2021）：
- **前向 SDE**（加噪）：$dx = f(x, t)dt + g(t)\, dB$，把数据分布平滑为高斯噪声
- **反向 SDE**（去噪）：$dx = [f(x,t) - g(t)^2 \nabla_x \log p_t(x)]dt + g(t)\, d\bar{B}$，需要分数函数 $\nabla_x \log p_t(x)$——由神经网络（score network）学习

关键结论：**反向过程是随机过程，但去掉噪声项后得到概率流 ODE（PF-ODE）**，可做确定性采样并支持加速（如 DDIM）。噪声注入的强度 $g(t)$ 决定采样路径；确定性 ODE 采样更快，随机 SDE 采样更稳——这是采样器设计的根本权衡。参见 [[../../B_连接主义与深度学习/07_生成模型/00_生成模型_综述|生成模型]] 与 [[../../C_基础模型与通用智能/03_视觉基础模型/04_视觉生成基础模型|图像生成基础模型]]。

### 4.4 SGD 的 SDE 视角

将随机梯度下降（SGD）连续化，权重 $W_t$ 的演化可近似为
$$ dW_t = -\nabla L(W_t)\, dt + \sqrt{\eta \Sigma(W_t)}\, dB_t $$
其中 $\eta$ 是学习率，$\Sigma$ 是梯度噪声协方差。这一视角给出的深刻洞见：
- **噪声是隐式正则**：SGD 的随机性防止陷入尖锐极小点（flat minima 泛化更好的假说），噪声大小与批量大小成反比
- **学习率退火与温度**：学习率衰减等价于降低"随机温度"，引导权重从探索转向收敛
- **批量大小与学习率的匹配**：线性缩放规则（Goyal et al., 2017）可从 SDE 尺度分析导出

### 4.5 滤波与状态估计

**卡尔曼滤波（Kalman filter）**：线性高斯状态空间模型
$$ x_{t+1} = \mathbf{A}x_t + \mathbf{w}_t, \quad y_t = \mathbf{C}x_t + \mathbf{v}_t $$
的精确后验由均值与协方差递推描述，是最优线性估计器。其数学本质是高斯分布的共轭性 + 条件分布的闭式更新，涉及矩阵分析（[[09_矩阵分析与数值线性代数|矩阵分析与数值线性代数]]）中的 Riccati 方程。

**粒子滤波（particle filter）**：非线性非高斯情形用蒙特卡洛近似后验，核心是重要性采样 + 重采样。是机器人定位（粒子滤波 SLAM）、目标跟踪的标准方法。参见 [[../../G_具身智能与物理智能/02_具身感知/00_具身感知_综述|具身感知]]。

## 6. 优势与局限

**优势**：
- 统一框架：随机过程 + SDE 同时覆盖离散/连续、静态/动态、单步/轨迹级不确定性
- 与偏微分方程互通：Fokker-Planck 给出分布层面的确定性演化，可被神经网络逼近
- 提供定量工具：收敛速率（谱隙）、误差界（Itô 公式）、最优性（滤波）

**局限与陷阱**：
- 马尔可夫性在很多真实系统中是近似（长程依赖、记忆效应），强加会引入偏差
- 布朗运动的不可微性使许多直觉失效（如链式法则多出 Itô 项）
- 高维状态空间的显式密度难以处理，只能依赖采样或变分近似
- SDE 理论（漂移/扩散系数的正则性条件）在神经网络参数化的复杂系统中常不满足，理论保证有限

## 10. 常见问题

**Q1: 布朗运动处处不可微，为什么还能定义 $dX_t = \dots dt + \dots dB_t$？**
$dB_t$ 不是普通微商而是**随机积分**（Itô 积分）的记号。Itô 积分通过极限构造（对小区间用左端点值），绕开了"不可微"的障碍，并严格定义了随机微分方程。关键转变：把"微分"理解为"积分方程的简写"。

**Q2: Itô 公式里的 $\frac{1}{2}f''dt$ 项哪来的？**
来自布朗运动二次变差非零：$\sum (\Delta B)^2 \to t$。把 $f(B_{t+\Delta t})$ 做泰勒展开到二阶，二阶项 $f''(\Delta B)^2/2$ 在期望意义下贡献 $f''dt/2$。这是随机微积分与普通微积分的根本分界，也是"随机计算不能照搬普通链式法则"的教训。

**Q3: 马尔可夫链一定会收敛到平稳分布吗？**
不一定。需要**不可约**（所有状态互通）+ **非周期**（返回时间无固定周期）+ 有限状态（或正则性条件）。满足时收敛且收敛速率由谱隙决定。Metropolis-Hastings 等 MCMC 方法正是设计满足这些条件的链来采样任意分布。

**Q4: 扩散模型为什么前向用 SDE、反向也能用 ODE？**
前向 SDE 把数据平滑成噪声（密度演化由 Fokker-Planck 描述）；反向需要分数函数。若去掉反向 SDE 的噪声项，得到概率流 ODE（PF-ODE），其边际分布与 SDE 相同但采样是确定性的——ODE 采样快但可能在数值误差下偏离，SDE 采样噪声大但更稳。这是"随机性换稳健性"的典型权衡。

**Q5: SGD 的噪声真的有正则化作用吗？**
SDE 视角下 SGD 等价于"梯度流 + 协方差 $\propto$ 梯度噪声的布朗扰动"。该噪声推动权重从尖锐极小点逃逸、偏向平坦区域，与显式正则（如权重衰减）作用互补。但这仍是活跃研究领域，具体机制（噪声各向异性、批量大小效应）尚未完全定论。
