# POMDP 与状态估计

## 一句话理解

部分可观测马尔可夫决策过程（POMDP）形式化了"智能体永远无法直接看到真实状态，只能看到含噪声的部分观察"这一现实约束，迫使智能体依据历史观察维护一个概率化的信念（belief），并基于信念而非真实状态做决策。

## 概述

马尔可夫决策过程（MDP，见 [[../04_强化学习/01_强化学习基础与MDP|强化学习基础与 MDP]]）假设智能体在每个时刻都能直接观察到真实状态 $s_t$。这一假设在国际象棋、迷宫求解等完全可观测任务中成立，但在绝大多数现实智能体任务中并不成立：网页 Agent 只能看到 DOM 树或截图，看不到服务器后台状态和用户真实意图；机器人只能看到有限视野的传感器读数，看不到房间全貌；对话 Agent 只能看到文字，看不到用户的真实心理状态。POMDP 正是为这类"观察 ≠ 状态"的场景提供的数学框架，是本方向 [[00_环境与世界模型_综述|环境与世界模型]]中"状态估计"问题的理论基础。

## 发展历史

POMDP 的规划理论由 Åström（1965）在最优控制背景下首先提出，随后在运筹学与人工智能规划领域独立发展。1998 年 Kaelbling、Littman 与 Cassandra 发表的 *Planning and Acting in Partially Observable Stochastic Domains* 系统化了 POMDP 的信念状态表示和精确求解算法，成为该领域的奠基性综述，但精确求解的计算复杂度（信念空间连续且高维）long 期限制了其在大规模问题中的应用。2000 年代后，近似方法（点更新、蒙特卡洛树搜索）使 POMDP 求解具备一定实用性。深度学习时代，RNN/LSTM（Hausknecht & Stone 提出的 DRQN，2015）和后来的 Transformer 被用于隐式地从观察历史中学习信念表示，绕开了显式概率信念更新的计算瓶颈，成为当前处理部分可观测性的主流工程方案。

## 核心概念

- **信念状态（Belief State）** $b_t(s) = P(s_t = s \mid h_t)$：给定观察-动作历史 $h_t$ 后，智能体对真实状态的概率分布估计。信念状态本身是一个（通常无限维的）"元状态"，POMDP 可以被重新表述为在信念空间上的 MDP
- **观察模型（Observation Model）** $P(o_t \mid s_t, a_{t-1})$：真实状态生成观察的概率过程，刻画了传感器/观察通道的噪声和局限性
- **信念更新（Belief Update）**：贝叶斯滤波公式，给定新观察 $o_t$ 后更新信念：
  $$b_t(s') \propto P(o_t \mid s') \sum_{s} P(s' \mid s, a_{t-1}) \, b_{t-1}(s)$$
- **历史依赖策略**：POMDP 中的最优策略一般不能仅依赖当前观察，而必须依赖完整历史（或其充分统计量，如信念状态）

## 技术原理

### POMDP 的形式化定义

POMDP 由七元组 $(\mathcal{S}, \mathcal{A}, \mathcal{O}, P, R, Z, \gamma)$ 定义：状态集 $\mathcal{S}$、动作集 $\mathcal{A}$、观察集 $\mathcal{O}$、状态转移 $P(s'\mid s,a)$、奖励函数 $R(s,a)$、观察函数 $Z(o \mid s', a)$、折扣因子 $\gamma$。与 MDP 相比，POMDP 额外引入了观察集与观察函数，将"真实状态"与"智能体可获得的信息"显式分离。

### 状态估计方法谱系

| 方法 | 适用场景 | 原理 | 局限 |
|:---|:---|:---|:---|
| 精确贝叶斯滤波 | 状态空间小、模型已知 | 解析计算后验分布 | 状态空间大时不可行 |
| 卡尔曼滤波（Kalman Filter） | 线性高斯系统 | 维护均值/协方差的解析更新 | 仅适用于线性高斯假设 |
| 粒子滤波（Particle Filter） | 非线性/非高斯，模型已知 | 用采样粒子集近似信念分布 | 高维状态时粒子退化 |
| RNN/LSTM 隐状态 | 模型未知，端到端学习 | 用循环神经网络隐状态隐式编码历史信息 | 不提供显式概率语义，可解释性差 |
| Transformer 上下文 | 长历史依赖，大规模数据 | 用注意力机制聚合整个历史窗口 | 计算成本随历史长度增长 |
| 外部记忆/状态机 | 结构化、可验证的场景 | 显式维护关键变量（如登录态、任务进度） | 需要人工设计状态变量和更新规则 |

对于状态转移和观察模型已知（或可较好建模）的场景，Bayesian/Kalman/粒子滤波提供有理论保证的解；对于模型未知、观察高维（如像素、自然语言）的场景，深度序列模型（RNN、Transformer）通过端到端训练直接学习"从历史到决策相关信息"的映射，牺牲了显式概率语义换取了可扩展性。

### LLM Agent 中的部分可观测性

在 Web/GUI/企业系统类 Agent 任务中，POMDP 思想体现为：页面截图、API 返回值仅仅是**观察**，而登录状态是否真实有效、后台任务是否已完成、用户的真实意图，都是**隐藏的状态变量**，不能被直接假设为观察内容本身。这要求 Agent 明确区分三类信息：

1. **已验证事实**：通过工具调用明确返回的、可信的信息
2. **推断/假设**：基于观察合理猜测但未验证的信息
3. **未知**：既未观察到也无法可靠推断的信息

对高风险动作（如支付、删除数据），Agent 应在执行前主动检查、询问用户或暂停，而不是将"推断"当作"已验证事实"直接执行，这是 POMDP 理论对 Agent 工程实践的直接指导意义。

## 与强化学习视角的关系

强化学习方向的 [[../../D_智能体与自主系统/04_强化学习/13_POMDP与状态估计|POMDP 与状态估计（RL 视角）]]聚焦"给定部分可观测环境，如何训练策略 $\pi(a_t \mid h_t)$ 本身"，属于策略优化问题；本笔记聚焦"智能体应如何建模、估计和维护对环境状态的信念"，属于表征与建模问题。两者是同一现象的两个侧面：状态估计方法（本笔记）为策略学习（RL 笔记）提供输入表示，策略优化算法决定如何利用这一表示做决策。

## 优势与局限

**优势**：为"观察不完整"这一普遍现实提供了严谨的数学语言；信念状态的引入使得"在不确定性下最优决策"可以被形式化求解或近似求解；驱动了滤波理论、序列建模等一系列实用技术的发展。

**局限**：精确 POMDP 求解的计算复杂度随状态/观察空间呈指数增长，实践中几乎总需要近似；深度学习方法虽然可扩展，但放弃了显式的不确定性量化，可能导致模型对自身的不确定性"过度自信"；如何在高维、语言化的观察空间（如网页、对话）中定义"状态"本身仍是开放问题。

## 应用场景

- **机器人导航与操控**：融合视觉、激光雷达等多传感器信息估计机器人位姿与环境状态
- **Web/GUI Agent**：从截图/DOM 观察推断系统真实状态（登录态、任务完成情况）
- **对话系统**：从对话历史推断用户真实意图与情感状态（对话状态跟踪，DST）
- **金融交易**：从市场公开信息推断难以直接观察的市场情绪与其他参与者的私有信息

## 前沿发展

- **LLM 作为隐式信念维护器**：利用 LLM 的长上下文和推理能力隐式维护复杂信念状态，替代显式的概率图模型
- **不确定性量化与弃权**：让模型在信念置信度不足时主动提示不确定或请求更多信息，而非强行输出确定性答案
- **记忆增强的状态估计**：将 [[../05_记忆与持续学习/02_记忆架构与检索|长期记忆系统]]与状态估计结合，处理跨会话、超长时间跨度的部分可观测性问题

## 常见问题

**Q: 为什么不能直接把网页截图或 API 返回值当作"完整状态"处理？**
因为截图/返回值只反映系统当前可见的一部分信息，可能不包含后台异步任务状态、其他用户的并发操作、权限边界等关键但不可见的变量。将观察误当作完整状态，会导致 Agent 在推断和决策时产生系统性偏差。
