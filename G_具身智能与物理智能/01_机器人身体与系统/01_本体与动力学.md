# 具身基础：本体、运动与接触

## 一句话理解

具身智能并不是把一个通用模型装进任意机器人。**身体决定可观测性、动作空间、能量与接触约束，也改变什么行为最容易学到。**运动学给出“能否到达”，动力学与接触给出“能否稳定、安全地做到”。

## 1. 本体是计算的一部分

机器人本体由结构、关节、执行器、末端执行器与传感器构成。不同本体面对同一指令会形成不同的问题：轮式底盘优先解决导航，机械臂强调可达性与抓取，人形还要同时维持平衡、接触切换与全身协同。

| 维度 | 关键问题 | 对学习/系统的影响 |
|---|---|---|
| 自由度与工作空间 | 能到哪里、姿态是否可达 | 决定动作表示、逆解难度与数据覆盖 |
| 执行器 | 力矩、带宽、回差、柔顺性 | 决定控制频率、接触稳定性与 sim-to-real 差距 |
| 末端执行器 | 夹爪、吸盘、灵巧手 | 决定可抓取物体集合和接触策略 |
| 传感器位置 | 相机视场、触觉覆盖、本体感觉 | 决定遮挡、状态可观测性与闭环能力 |
| 形态与重心 | 稳定域、惯性、可通过性 | 决定步态、全身控制与安全边界 |

**可供性（affordance）**是“物体/环境允许什么行动”，不是物体类别的同义词：把手可拉、按钮可按、平面可放置。有效的具身表征应把视觉语义、几何、可达性和接触条件联合起来，回答“对这个机器人而言，此处现在能做什么”。

## 2. 状态、观测、动作与坐标系

可将真实系统写成部分可观测动力学过程：

$$s_{t+1}\sim p(s_{t+1}\mid s_t,a_t),\qquad o_t\sim p(o_t\mid s_t)$$

- 状态 \(s_t\)：真实但未必完全可见的物体、接触、机器人和环境状态。
- 观测 \(o_t\)：图像、深度、触觉、关节角、速度、IMU 等。
- 动作 \(a_t\)：关节位置/速度/力矩、末端位姿增量或技能参数。

一个常被忽略的事实是：动作 token 本身没有物理意义，必须明确参考坐标系、单位、归一化、控制周期和夹爪语义。相同的 \((\Delta x,\Delta y,\Delta z)\) 在相机系、基座系、末端系下对应完全不同的行为。数据采集、训练和部署三者的定义必须一致。

## 3. 运动学：把意图投影为可执行几何

给定关节构型 \(\mathbf q\)，正运动学得到末端位姿：

$$\mathbf T_{0e}=f(\mathbf q)\in SE(3)$$

逆运动学（IK）在给定目标 \(\mathbf T^*_{0e}\) 时寻找满足关节限位、碰撞与冗余约束的 \(\mathbf q\)。实际系统不要把 IK 当作单一黑盒：它可能无解、多解或接近奇异位形。

雅可比矩阵连接关节速度与末端 twist：

$$\mathbf V_e=J(\mathbf q)\dot{\mathbf q}$$

数值 IK 常解带阻尼和约束的最小二乘问题：

$$\dot{\mathbf q}=J^T(JJ^T+\lambda^2I)^{-1}\mathbf V_e+N(\mathbf q)\dot{\mathbf q}_{null}$$

其中阻尼 \(\lambda\) 缓解奇异性，零空间项 \(N\dot{\mathbf q}_{null}\) 可用于远离关节限位、避障或保持舒适姿态。学习策略输出末端增量时，IK、速度限幅和碰撞检查是必要的执行适配层。

## 4. 动力学、欠驱动与接触

刚体系统的关节动力学可写为：

$$M(\mathbf q)\ddot{\mathbf q}+h(\mathbf q,\dot{\mathbf q})=S^T\boldsymbol\tau+J_c^T\mathbf F_c$$

其中 \(M\) 为惯性矩阵，\(h\) 汇集科氏、离心与重力项，\(S\) 描述被驱动关节，\(J_c^T\mathbf F_c\) 是接触力。浮动基座人形/四足机器人通常欠驱动：脚与地面的接触约束和摩擦决定身体能否平衡。

接触不是噪声，而是操作任务的核心状态。常用约束包括非穿透、法向力非负，以及库仑摩擦锥近似：

$$F_n\ge0,\qquad \|\mathbf F_t\|\le \mu F_n$$

抓取、插拔、开门、布料整理和行走会涉及接触模式切换。纯视觉开环策略容易在对象位姿、摩擦或柔顺性稍有变化时失败，因此接触任务必须引入力/触觉反馈、顺应控制和恢复逻辑。

## 5. 控制层选择

| 控制形式 | 适合问题 | 优点 | 主要风险 |
|---|---|---|---|
| 位置/速度伺服 | 自由空间轨迹跟踪 | 简单、硬件普遍支持 | 硬接触时可能过力 |
| 力控/阻抗控制 | 装配、插拔、打磨、柔性抓取 | 可吸收位姿误差并调节接触 | 需可靠力感知与稳定参数 |
| 操作空间控制 | 末端任务与姿态协同 | 直接表达任务目标 | 需处理冗余与奇异 |
| 全身控制（WBC） | 人形、四足、双臂协作 | 统一处理平衡、接触、多任务 | 模型和实时优化复杂 |
| MPC | 动态约束与前瞻控制 | 可显式处理约束 | 对模型、算力和时延敏感 |

阻抗控制的典型目标是让末端呈现期望的质量—阻尼—刚度关系：

$$M_d\ddot{\mathbf e}+D_d\dot{\mathbf e}+K_d\mathbf e=\mathbf F_{ext}$$

这里的“软”不是降低安全标准，而是用受控顺应性把未知接触误差转成可恢复的位移。

## 6. 模型与学习如何分工

| 场景 | 优先使用 | 学习可补足的部分 |
|---|---|---|
| 碰撞、关节/力矩限制 | 显式几何与控制约束 | 学习可行目标或代价函数 |
| 自由空间到达 | IK、轨迹规划 | 从视觉/语言预测目标位姿 |
| 高频稳定控制 | 伺服、WBC、MPC | 残差控制、动力学参数估计 |
| 复杂接触、柔性物体 | 反馈控制与试探 | 接触模式、抓取/操作策略 |
| 长尾语义任务 | 技能库和约束检查 | VLA/语言模型做泛化与组合 |

结论不是“模型方法过时”或“端到端一定更强”。可靠系统一般让模型承担硬约束、几何和安全边界，让数据驱动方法处理感知歧义、复杂接触和任务泛化。

## 7. 设计与排障清单

1. 明确世界、基座、相机、末端和物体坐标系，并记录外参来源与漂移处理。
2. 明确策略动作的单位、频率、裁剪范围、动作延迟和控制器跟踪误差。
3. 对每个任务先判断可达性、碰撞、抓取稳定性和接触风险，再训练策略。
4. 对接触任务记录力/触觉、滑移、控制模式及失败时刻，不能只保存 RGB 与最终成功标签。
5. 将急停、速度/力矩限制和工作空间约束放在策略之外。
