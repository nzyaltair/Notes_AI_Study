# 长程自主与恢复

## 一句话理解

长程任务将感知漂移、环境变化、技能失败和系统时延累积，因此核心能力是诊断和恢复——恢复策略包括重新观察、重新定位、换技能参数、修改计划、安全撤退、暂停求助与回滚。

## 概述

长程自主（Long-Horizon Autonomy）是具身 Agent 从"演示技能"走向"可靠产品"的关键能力：在数分钟到数小时的运行中，环境变化、传感器漂移、技能失败和系统错误会持续累积。长程自主与恢复研究如何检测失败、归因原因、选择恢复策略，并在无法自主解决时安全降级。

## 发展历史

- **2000s-2010s**：执行监控（Execution Monitoring）与故障诊断进入机器人系统；NASA 深空探测器等高风险系统的故障管理经验。
- **2010s**：行为树结构化恢复进入工程实践；ALFRED 等长程任务基准推动研究。
- **2020s**：LLM 辅助失败诊断与恢复规划（Inner Monologue）；长程家居任务（HomeRobot）与恢复基准成为焦点；VLA 时代"失败-重试-求助"的闭环系统化。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 失败检测 | 识别执行偏离预期 | 恢复的前提 |
| 失败归因 | 确定失败原因 | 选择正确恢复 |
| 恢复策略 | 修复失败的行动 | 系统鲁棒性 |
| 安全降级 | 能力不足时的保守模式 | 安全底线 |
| 人工接管 | 人类介入控制 | 最后手段 |
| 任务预算 | 时间/尝试/资源上限 | 防止无限重试 |
| 回滚 | 撤销有害更新 | 版本治理 |

## 技术原理

### 失败检测

| 失败类型 | 表现 | 检测方法 |
|---|---|---|
| 感知失败 | 位姿错误、目标丢失 | 置信度、重新观察 |
| 规划失败 | IK 无解、无路径 | 规划器返回 |
| 执行失败 | 滑移、卡住、碰撞 | 力/触觉、进度停滞 |
| 环境变化 | 对象被移走、门被关上 | 状态一致性检查 |
| 系统错误 | 节点挂起、通信中断 | 看门狗、健康检查 |

### 失败归因

失败必须归因到正确层级：感知、规划、执行、环境还是任务定义。错误归因导致错误恢复（如把环境变化归因为执行失败，反复重试）。

### 恢复策略分级

```text
轻量恢复：重新观察 → 换抓取姿态 → 调整站位 → 重试
中级恢复：换技能参数 → 修改子任务计划 → 换技能
高级恢复：暂停求助 → 安全撤退 → 回滚版本
终止：中止任务、报告失败、人工接管
```

### 自主运行的治理机制

- **任务预算**：时间、重试次数、能耗上限。
- **重试上限**：防止无限重试死循环。
- **超时**：技能级超时监控。
- **区域权限**：危险区域的动作限制。
- **人类接管**：任意时刻可人工干预。
- **审计**：完整日志与回放。

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| 行为树恢复 | 结构化恢复分支 | 工程部署 |
| 预期-观测比对 | 一致性监控 | 通用 |
| LLM 失败诊断 | 语言归因与恢复建议 | 开放任务 |
| 情景记忆恢复 | 参考过往经验 | 重复任务 |
| 求助策略 | 低置信请求人类 | 能力边界 |
| 安全降级 | 保守模式运行 | 异常状态 |

## 优势与局限

| 方法 | 优势 | 局限 |
|---|---|---|
| 结构化恢复 | 可预测、可验证 | 覆盖不全 |
| LLM 诊断 | 灵活、常识 | 幻觉 |
| 经验复用 | 避免重复错误 | 经验污染 |
| 求助 | 突破能力边界 | 依赖人类 |

## 应用场景

- 家居任务：整理、清洁中持续运行。
- 仓储：长流程拣选-打包。
- 巡检：多站点连续任务。
- 服务机器人：全天候运行。

## 前沿发展

- **自主失败归因**：从日志自动诊断。
- **LLM 恢复规划**：失败上下文 → 恢复方案。
- **恢复技能学习**：从失败数据学习。
- **长期性能监控**：漂移检测与持续改进。
- **自主求助策略**：何时求助的决策模型。

## 常见问题

- **无限重试**：必须有任务预算和重试上限。
- **错误归因**：恢复错误比不恢复更糟。
- **忽略审计**：无日志无法复盘与改进。
- **无安全降级**：能力不足时必须保守运行。
