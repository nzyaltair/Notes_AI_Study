# 世界模型与物理智能综述：行动前的后果预测

## 一句话理解

世界模型回答"如果我采取这个行动，世界将如何变化"，为智能体提供在行动前预测后果、比较方案和规避风险的能力——它是 Agent 的预测基础，也是具身智能的规划前提，但在当前阶段它不是智能上限本身的瓶颈。

## 1. 领域定义

### 世界模型（World Model）

学习环境动力学模型，使智能体能在内部模拟行动后果。广义上包括：状态转移模型、视频预测模型、3D 场景模型和因果动力学模型。

### 物理智能（Physical Intelligence）

对物理世界的规律性理解：物体恒常性、重力、碰撞、材质、因果等。

### 与 AGI 的定位（梁文锋的判断）

> "世界模型和智能还不是现在这个阶段最重要的事情。最重要的是 AI 训练，以及 AI 训练之后怎么解决持续学习。"

世界模型是 AGI 的**组件**，不是**主线**本身——但它是 Agent 和具身智能的必要支撑。

## 2. 核心方法

### 2.1 基于学习的世界模型

| 方法 | 核心思想 | 代表 |
|------|----------|------|
| 潜变量动力学 | 在潜空间预测状态转移 | Dreamer 系列, World Models (Ha & Schmidhuber) |
| 视频预测 | 预测未来帧 | GAIA-1, Sora (生成式) |
| JEPA | 联合嵌入预测 | LeCun V-JEPA |
| 状态空间模型 | 学习系统动力学 | SSM + RL |

### 2.2 基于结构的 3D 理解

| 方法 | 核心思想 | 代表 |
|------|----------|------|
| NeRF | 神经辐射场 | 原始 NeRF + 加速变体 |
| 3D Gaussian Splatting | 高斯泼溅 | 实时 3D 重建 |
| 场景图 | 物体关系图 | 3D Scene Graph |
| 空间记忆 | 语义地图 | NLMap, ConceptGraphs |

### 2.3 因果世界模型

- 因果动力学模型：学习因果图 + 转移函数
- 反事实模拟："如果当时做了另一个动作会怎样"
- 与神经符号融合交叉

## 3. 发展历史

1. 2018：Ha & Schmidhuber 的 World Models
2. 2020：Dreamer 系列（基于世界模型的 RL）
3. 2022：LeCun 提出 JEPA 架构
4. 2024：Sora 引爆视频生成 = 世界模拟器讨论
5. 2025-26：世界模型从 RL 走向通用物理模拟

## 4. 关键争议

| 观点 | 支持方 | 理由 |
|------|--------|------|
| 世界模型是 AGI 核心 | LeCun | 没有世界模型就没有规划能力 |
| 世界模型当前非核心 | DeepSeek 梁文锋 | 当前瓶颈是持续学习，不是世界模型 |
| 视频生成 = 世界模型 | Sora 团队 | 生成即理解 |
| 视频生成 != 世界模型 | 梁文锋 | 视频生成与智能上限无关 |

**统一视角**：世界模型是 Agent 和具身的必要组件，但不是 AGI 主线本身。在持续学习解决后，世界模型的重要性会显著提升。

## 5. 与 AGI 的关系

- Agent 的预测模块（行动前评估后果）
- 具身智能的规划基础（仿真中测试策略）
- 持续学习的环境模型（理解环境以高效学习）
- Sim-to-real 的核心（仿真世界 vs 真实世界）

## 6. 学习路径

1. 学习 Dreamer 系列理解世界模型在 RL 中的作用
2. 理解 JEPA 的联合嵌入预测架构
3. 研究 NeRF/3DGS 的场景重建
4. 分析视频预测与世界模型的关系
5. 探索因果世界模型
