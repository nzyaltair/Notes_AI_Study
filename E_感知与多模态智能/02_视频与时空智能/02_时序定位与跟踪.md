# 时序定位与跟踪

## 一句话理解

时序定位回答事件何时发生，跟踪回答对象在连续观测中是否仍是同一实体——两者共同构成视频理解的时空基础，为世界模型和 Agent 决策提供连续的状态轨迹。

## 概述

时序定位（Temporal Localization）和多目标跟踪（Multi-Object Tracking, MOT）是视频智能的两大核心技术。时序定位在时间维度上确定事件或动作的起止时间；跟踪则在空间维度上维护同一物体在帧间的身份一致性。

## 核心概念

| 概念 | 说明 | 关键方法 |
|:---|:---|:---|
| 检测-关联跟踪 | 逐帧检测后再关联同一目标的检测框 | SORT, DeepSORT, ByteTrack |
| 端到端跟踪 | 直接预测跨帧的轨迹，无需检测+关联两步 | TransTrack, MOTR |
| 时序动作定位 | 在长视频中定位动作的起止时间 | TubeR, ActionFormer |
| 重识别（ReID） | 跨摄像机/跨时间段的身份匹配 | OSNet, TransReID |
| 多目标跟踪（MOT） | 同时跟踪场景中所有目标 | FairMOT, CenterTrack |

## 跟踪范式对比

| 范式 | 代表 | 优势 | 劣势 |
|:---|:---|:---|:---|
| 检测-关联（SORT） | SORT, DeepSORT, ByteTrack | 简单高效，适合实时 | 依赖检测质量，遮挡易丢 |
| 端到端联合 | TransTrack, MOTR | 全局优化，身份一致性更好 | 训练复杂，推理慢 |
| 可变形注意力 | DETR 系列 | 集合预测，无需 NMS | 收敛慢，计算量大 |

## 关键挑战

- **遮挡**：目标被遮挡时如何保持跟踪？
- **身份切换（ID Switch）**：目标重新出现后如何正确恢复身份？
- **长期消失**：目标长时间离开视野后如何重识别？
- **低帧率**：帧率低时运动不连续，关联困难。
- **开放类别**：跟踪未在训练时见过的类别。

## 评测指标

| 指标 | 说明 | 关注点 |
|:---|:---|:---|
| MOTA | 多目标跟踪准确率 | 综合准确率 |
| IDF1 | 身份 F1 分数 | 身份一致性 |
| HOTA | 高阶跟踪准确率 | 平衡检测与关联 |
| mMOTA | 多类 MOTA | 多类别场景 |
