# 风险分类与失效模式

## 核心问题
AI 风险来自偶发故障、设计缺陷、能力失配、恶意攻击和系统性外部性。风险评估应描述“谁会受害、什么资产受损、攻击或故障如何发生、现有控制是否有效”。

## 风险分类

| 层次 | 典型风险 | 示例 |
|---|---|---|
| 数据与模型 | 偏差、投毒、泄露、后门 | 训练语料污染改变输出 |
| 交互与应用 | 注入、越狱、幻觉、误用 | 恶意网页劫持 RAG Agent |
| 自主行动 | 越权、目标漂移、连锁错误 | 自动付款或删库未受限 |
| 社会系统 | 歧视、虚假信息、集中化 | 招聘模型排斥特定群体 |
| 长期能力 | 失控、欺骗、权力寻求 | 高能力系统规避监督 |

## 失效模式分析

使用 FMEA/STPA 思路记录：功能、危险控制动作、触发条件、后果、检测手段、缓解和责任人。AI 特有失效包括：

1. **规范失效**：优化了错误或不完整目标。
2. **泛化失效**：环境、输入分布或交互链与训练假设不同。
3. **感知/知识失效**：错误观测、幻觉、过时知识或置信度失校准。
4. **控制失效**：权限过宽、审批绕过、不可撤销执行。
5. **保障失效**：评测覆盖不足、监控盲区、无事故处置预案。

## 威胁建模模板

```text
资产：数据、模型权重、系统提示、工具权限、用户权益
对手：普通用户、恶意用户、供应商、内部人员、自动化 Agent
入口：训练数据、检索内容、用户输入、插件、模型更新
后果：机密性、完整性、可用性、物理/经济/社会损害
控制：隔离、最小权限、验证、日志、监控、人工接管
```

风险优先级应同时考虑严重度、发生概率、可检测性与影响范围；不能只用单一基准分数替代场景风险判断。
