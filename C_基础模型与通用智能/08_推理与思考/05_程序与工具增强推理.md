# 程序与工具增强推理

## 一句话理解

程序、检索、计算器和形式求解器可将部分推理外包给可验证工具；模型则负责选择工具、构造调用、解释结果和处理失败。

Program-of-Thought 可执行算术/符号程序，检索补足参数知识，SMT/CAS/证明器验证约束。工具使用也引入权限、注入、环境漂移和调用错误风险；协议与治理见 [[../../D_智能体与自主系统/03_Agent工程/01_工具调用与MCP/00_工具调用与MCP_综述|工具调用与 MCP]]。
