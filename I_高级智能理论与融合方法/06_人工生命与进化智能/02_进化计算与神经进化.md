# 进化计算与神经进化

## 一句话理解

进化计算用群体搜索、变异、重组和选择优化解，是不依赖梯度的通用优化范式；神经进化把进化用于搜索网络权重、拓扑、学习规则或身体形态。

## 进化计算算法

| 算法 | 核心机制 | 适用场景 |
|---|---|---|
| 遗传算法（GA） | 二进制/离散编码 + 交叉变异 | 组合优化、特征选择 |
| 遗传编程（GP） | 树形程序进化 | 符号回归、程序生成 |
| 进化策略（ES） | 实数向量 + 高斯变异 | 连续优化、RL 策略搜索 |
| CMA-ES | 自适应协方差矩阵 | 病态条件数下的连续优化 |
| 质量多样性（QD） | 同时优化性能与行为多样性 | 行为空间覆盖 |

### 质量多样性与 MAP-Elites

MAP-Elites 把行为空间网格化，每个格点保存该行为的最高性能解，形成"性能-行为"地图。它同时最大化多样性与性能，是开放式进化的关键工具（见 [[03_开放式进化与人工生态系统]]）。

## 神经进化

| 方向 | 代表工作 | 搜索内容 |
|---|---|---|
| 权重进化 | ES 直接优化权重 | 网络参数 |
| 拓扑进化 | NEAT | 网络结构（节点与边） |
| 间接编码 | HyperNEAT、CPPN | 用紧凑函数生成权重模式 |
| 学习规则进化 | 进化学习规则 | 更新规则本身 |
| 形态进化 | 进化身体 + 控制器 | 形态与行为共同演化 |

## 优势与局限

- **优势**：适合不可微、稀疏奖励、多目标问题；不要求目标函数光滑；天然并行（群体独立评估）。
- **局限**：评估成本高（每个体需完整评估）；早熟收敛（多样性丢失）；仿真到现实差距（Sim2Real 问题）。

## 与深度强化学习的关系

进化策略可作为 RL 的无梯度替代（OpenAI ES），在小规模问题上可与策略梯度互补；但大模型的参数空间远超进化搜索可及范围，进化主要适用于中等规模网络或结构搜索。
