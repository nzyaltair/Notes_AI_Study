# 类比推理与组合泛化

## 一句话理解

类比推理迁移的是关系结构而非表面属性；组合泛化要求系统把已学原子能力重组以处理未见组合——两者共同构成跨任务迁移的核心机制。

## 类比推理

### 结构映射理论（SMT, Gentner）

类比的核心是**关系结构的系统映射**：从"太阳系—原子模型"中迁移中心—环绕关系，比词汇相似度更关键。SMT 三原则：

1. **关系优先**：匹配关系而非对象属性。
2. **系统性**：相互连接的关系结构比孤立关系更重要。
3. **候选推断**：映射后把源域未知性质推断到目标域。

### 关键方法

| 方法 | 核心机制 |
|---|---|
| 结构映射引擎（SME） | 图匹配 + 系统性打分 |
| 类比编码（Analogical encoding） | 用对比帮助抽取共同结构 |
| 神经类比匹配 | 学习关系嵌入，比较图结构 |
| 程序级类比 | 用程序表示关系结构，替换对象槽位 |

## 组合泛化

组合泛化要求系统把已学的概念、关系或技能重组来解决未见组合。

### 评测基准

- **SCAN**：指令→动作序列，测试组合泛化（如"jump twice"组合）。
- **COGS**：语义解析的组合泛化测试。
- **meta-dataset / OOD 组合**：跨组合切分的图像与语言任务。
- **ARC / PCFG 生成任务**：按规则生成训练/测试组合。

### 方法线索

结构映射、关系图匹配、模块化网络、对象中心表征、程序化表示与系统性任务划分都可提供归纳偏置。评测时应切分训练/测试的**组合**，而非仅随机划分样本——随机划分会高估组合泛化能力（对应 [[../../08_研究方法与证据评估/04_基准设计与数据污染]] 的基准设计原则）。

## 与 LLM 的关系

LLM 在表层类比（词面相似）上表现好，但在**结构类比**与**系统组合**上仍有明显短板：改变关系结构而保持表面词汇相似时性能显著下降。评测需分离"记忆的组合"与"新颖的组合"。
