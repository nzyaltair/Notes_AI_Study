# 机器人学基础综述：物理世界中的智能体

## 一句话理解

机器人学是研究物理智能体的设计、制造与控制的学科——运动学和动力学描述机器人如何运动，传感器和执行器是它的感知和行动器官，这是具身智能从"虚拟 Agent"进入"物理世界"的基础。

## 1. 领域定义

机器人学研究机器人的感知、决策、控制和交互。核心子领域：

| 子领域 | 核心问题 | 数学工具 |
|--------|----------|----------|
| 运动学 | 机器人如何运动（几何） | 齐次变换、DH参数 |
| 动力学 | 机器人运动的力和力矩 | 牛顿-欧拉、拉格朗日 |
| 传感 | 如何感知环境和自身状态 | 视觉、力觉、IMU |
| 执行 | 如何产生物理运动 | 电机、液压、气动 |
| 规划 | 如何规划运动轨迹 | 路径规划、避障 |
| 控制 | 如何精确执行规划 | PID、MPC、阻抗控制 |

## 2. 核心概念

### 2.1 运动学

| 概念 | 描述 | 公式 |
|------|------|------|
| 正运动学 | 关节角 → 末端位姿 | T = T₁·T₂·...·Tₙ |
| 逆运动学 | 末端位姿 → 关节角 | 数值解/解析解 |
| DH参数 | 描述连杆关系 | 4 参数/关节 |
| 工作空间 | 末端可达范围 | 位置+姿态空间 |

### 2.2 动力学

| 方法 | 特点 | 适用场景 |
|------|------|----------|
| 牛顿-欧拉 | 递推计算力/力矩 | 实时控制 |
| 拉格朗日 | 基于能量函数 | 分析设计 |
| 关节空间动力学 | 关节力矩驱动 | 操作臂 |
| 笛卡尔空间动力学 | 末端力驱动 | 力控场景 |

### 2.3 传感系统

| 传感器 | 感知内容 | 特点 |
|--------|----------|------|
| 相机 (RGB/RGBD) | 视觉信息 | 信息丰富，受光照影响 |
| LiDAR | 3D点云 | 精确，成本高 |
| IMU | 姿态与加速度 | 高频，有漂移 |
| 力/力矩传感器 | 接触力 | 精确，局部 |
| 关节编码器 | 关节位置 | 基础必需 |
| 触觉传感器 | 接触分布 | 新兴方向 |

### 2.4 执行器

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 电机 (无刷/有刷) | 精确控制 | 关节驱动 |
| 液压 | 大力矩 | 重载/人形 |
| 气动 | 柔顺 | 柔性抓取 |
| 串联弹性 (SEA) | 力控友好 | 人形/协作 |

## 3. 与 AI/AGI 的关系

- **具身智能的物理基础**：AI 算法需要物理载体
- **Sim2Real 的挑战**：仿真与真实物理世界的差距
- **感知-行动循环**：机器人是闭环感知-决策-控制的典型
- **VLA 模型**：视觉-语言-动作模型将 AI 推理与机器人执行结合

```
AGI 阶梯中的位置：

语言模型 → CoT → Agent → 持续学习 → 奇点 → [具身智能]
                                               ↑
                              机器人学是具身智能的
                              物理实现基础
```

## 4. 学习路径

1. 理解运动学（正/逆运动学）
2. 学习动力学建模
3. 理解传感器融合（卡尔曼滤波）
4. 学习机器人控制（MPC、阻抗控制）
5. 探索 VLA 模型与 Learning-based 方法
