# 三维空间智能 综述

> **定位**：空间智能是把视觉观测组织为可定位、可查询、可推理的三维场景状态的能力。它是视觉、多模态、世界模型和具身系统之间的关键桥梁——从 2D 像素到 3D 场景，从"看到"到"理解空间关系"。

## 领域定义

三维空间智能研究如何从二维图像（单目、双目或多目）中恢复、组织和推理三维场景的结构化信息。它解决的根本问题是：**如何将视觉观测转化为可行动的空间知识**——包括物体的三维位置、形状、场景几何、拓扑关系以及可供性。

## 核心问题

1. **从 2D 到 3D 的逆问题**：三维信息到二维投影是多对一的映射，如何从二维恢复三维是病态问题，需要几何约束和先验知识。
2. **尺度模糊性**：单目图像无法区分近处小物体和远处大物体，如何解决深度估计中的尺度模糊？
3. **动态场景**：如何实时更新包含运动物体的场景表示？
4. **场景语义与几何的统一**：如何同时理解"是什么"（语义标签）和"在哪里"（三维位置）？
5. **可行动的空间表示**：空间表示应不仅服务于可视化，还应服务于导航、操作和规划——如何构建这种表示？

## 技术演进路线

```text
经典几何 (相机模型/对极几何/三角化) 
    → 基于特征的重建 (SfM/MVS) 
    → 深度学习和 SLAM (深度估计/ORB-SLAM) 
    → 神经隐式表示 (NeRF/SDF) 
    → 显式可微表示 (3D Gaussian Splatting) 
    → 语义空间智能 (VLM + 3D/场景图)
```

## 场景表示技术对比

| 方法 | 表示形式 | 优势 | 劣势 | 典型应用 |
|:---|:---|:---|:---|:---|
| 点云 | 3D 点集 | 简单直接、传感器原生 | 稀疏、无结构 | 3D 检测/分割 |
| 网格 | 顶点+面 | 紧凑、可渲染 | 拓扑固定、难以优化 | 图形学 |
| 体素 | 3D 网格 | 规则结构、CNN 友好 | 分辨率受限 | 医学影像、3D 重建 |
| NeRF | 隐式神经场 | 高质量、连续 | 训练/推理慢 | 新视角合成 |
| 3DGS | 高斯椭球集合 | 实时、高质量 | 存储大、动态难 | 实时渲染、重建 |
| 场景图 | 节点+边 | 结构化、可推理 | 构建复杂 | 空间推理、语义 |

## 当前发展状态

- **NeRF/3DGS 使新视角合成达到实用水平**：3DGS 实现了实时高质量渲染，已在多个领域应用
- **SLAM 技术成熟**：ORB-SLAM3、VINS-Fusion 等系统在已知场景下可实现稳定定位
- **3D 场景理解仍依赖 2D 基础模型**：多数 3D 检测/分割方法利用 2D 基础模型做预训练
- **3D-LLM 处于早期**：将 3D 空间理解与 LLM 结合的研究刚刚起步
- **大规模 3D 数据集仍匮乏**：与 2D 相比，3D 标注数据获取成本高，规模受限

## 前沿方向

- 动态场景的实时 4D 重建
- 语义与几何的端到端联合学习
- 3D 基础模型（类比 SAM 但用于 3D）
- 语言引导的场景理解与编辑
- 空间记忆与持续学习（长期空间状态维护）

## 学习路径

1. 多视角几何基础 → 2. 深度估计 → 3. SLAM 与重建 → 4. 点云理解 → 5. NeRF/3DGS → 6. 空间推理与语义
