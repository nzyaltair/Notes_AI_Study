# VLA 模型与架构

## 一句话理解

视觉—语言—行动（VLA）模型把视觉观测和语言目标映射为机器人动作；其关键不是简单地把动作接到 LLM 输出端，而是让感知时序、动作表示、数据坐标系和低层执行接口彼此一致。

## 基本结构

```text
图像/状态历史 ─→ 感知编码器 ─┐
语言任务       ─→ 文本编码器 ─┼→ 融合主干 → 动作头 → 控制器
机器人本体信息 ─→ 本体编码器 ─┘
```

- **编码器**：把图像、深度、状态和语言转为 token 或连续特征。
- **融合主干**：可为 VLM、Transformer 或时序策略网络；决定条件信息如何交互。
- **动作头**：输出离散动作 token、连续关节/末端位姿、动作块，或动作分布。
- **执行接口**：将策略输出交给逆运动学、轨迹跟踪和安全控制；这部分不应由 VLA 单独承担。

## 架构取舍

| 设计 | 优势 | 风险 |
|---|---|---|
| 动作 token 自回归 | 可复用语言模型训练接口 | 离散化误差、高频控制困难 |
| 连续回归 | 延迟低、实现直接 | 对多峰示范平均化 |
| 扩散/流匹配动作头 | 能表达多种可行动作 | 采样步数与实时性权衡 |
| 动作 chunk | 降低逐步决策频率 | 观测变化时需及时重规划 |

## 代表案例

- **RT-2**：将视觉—语言知识迁移到离散机器人动作 token，但仍依赖特定机器人数据和执行栈。
- **OpenVLA**：开放 VLA 实现，方便研究动作 token 化和后训练接口。
- **Octo**：通过多数据集预训练探索通用机器人策略；其跨本体泛化仍依赖统一数据协议。
