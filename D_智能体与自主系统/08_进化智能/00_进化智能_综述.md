# 进化智能 Overview Overview

## 领域定义

进化智能研究如何通过**种群、多样性、变异、选择与继承**来搜索策略、结构或程序，使系统在无梯度信息的情况下持续优化和适应。它与群体智能（通过简单个体间局部交互产生全局智能）共同构成 AI 的行为主义范式——不依赖内部知识表示或学习权重，而是通过外部选择压力和交互产生适应性行为。

## 为什么会出现

梯度下降是深度学习的核心优化方法，但它的前提是**目标函数可微**。大量实际问题的目标函数不可微（如组合优化、策略评估、结构设计），或者虽然可微但梯度计算代价过高。进化计算通过"采样→评估→选择→变异"的循环，仅使用目标函数值（适应度）就能搜索优化空间，天然适配黑盒优化问题。此外，进化计算的"种群"特性使其天然适合探索多模态解空间和保持多样性，这在强化学习、神经架构搜索、Agent 技能发现等场景中具有独特价值。

## 发展历史

| 年代 | 里程碑 | 意义 |
|:---|:---|:---|
| 1950s | 进化计算思想萌芽（Fogel, Rechenberg） | 首次提出"模拟进化进行优化" |
| 1975 | 遗传算法（Holland） | 遗传算法的系统化奠基 |
| 1980s | 群体智能方法涌现（PSO, ACO） | 粒子群、蚁群算法 |
| 1990s | 进化计算与机器学习结合 | 进化策略用于神经网络训练 |
| 2002 | NEAT（Stanley & Miikkulainen） | 同时进化网络拓扑和参数 |
| 2008 | Novelty Search（Lehman & Stanley） | 放弃目标函数，搜索新颖性 |
| 2016 | 进化策略用于深度 RL（Salimans et al.） | 进化策略的规模化，大规模并行 RL |
| 2017 | MAP-Elites（Mouret & Clune） | 质量多样性算法，保留多种行为特征 |
| 2020s | 进化 NAS 和 LLM 优化 | 进化计算在 AutoML 和 LLM 中的新应用 |

## 核心问题

1. **探索-利用平衡**：如何在新颖区域探索和已知优区域利用之间平衡？
2. **适应度设计**：如何设计反映真实目标的适应度函数，避免"奖励黑客"？
3. **多样性保持**：如何避免种群过早收敛到局部最优？
4. **评估效率**：进化计算需要大量评估，如何在真实环境中高效评估？
5. **开放性**：如何设计系统使其持续产生新颖且有价值的行为，而非收敛到固定最优？

## 概念边界

- **进化 vs. 强化学习**：进化计算通过种群选择进行搜索，RL 通过值函数估计引导策略优化。进化适合黑盒、不可微目标，RL 适合可微、时序决策。两者可以结合（如 ES-RL 混合）。
- **进化 vs. Multi-Agent**：进化关注跨代选择（时间维度），Multi-Agent 关注同一时刻主体间协调（空间维度）。可用进化优化 Agent 提示、工具策略、工作流和技能。
- **进化 vs. 优化**：进化是优化的一种形式，特别适合不可微、多模态、高维的优化问题。

## 当前发展状态

- **进化策略在 RL 中有实际应用**：ES 作为无梯度 RL 替代方案，在大规模并行中有优势
- **CMA-ES 是连续优化强基线**：在超参数调优、策略搜索中广泛使用
- **神经进化在 NAS 中活跃**：进化 NAS 是神经架构搜索的重要方法
- **开放式进化仍在研究阶段**：如何评价开放式学习的"进步"仍是开放问题

## 未来趋势

- **进化 + 深度学习深度融合**：进化优化网络结构、学习率、损失函数，深度学习提供高效的前向推断
- **大规模分布式进化**：利用云计算资源并行评估种群，突破进化计算的效率瓶颈
- **进化 Agent 技能**：用进化发现和优化 Agent 的工具策略、工作流、提示模板
- **开放式进化与 AGI**：开放式进化被一些研究者视为通向 AGI 的潜在路径之一
