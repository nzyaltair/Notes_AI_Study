# 智能体与自主系统综述

自主智能体是在不完全可观测环境中，围绕目标持续进行感知、状态估计、世界建模、规划、行动、记忆与学习的闭环系统。

```text
目标 → 感知/状态 → 世界模型 → 推理与规划 → 行动 → 环境反馈
                         ↑                         ↓
                    记忆、学习、反思与改进 ←───────┘
```

## 概念边界

- **RAG** 是外部知识增强；**Agent Memory** 是交互经验和技能积累。
- **World Model** 预测“执行动作后会怎样”，不能等同于静态知识库。
- **RL** 是从反馈中优化策略的学习框架；**Runtime** 负责把闭环安全、可观测地运行起来。

## 两条学习路线

工程路线：理论基础 → 工具/MCP → Runtime → RAG 与记忆 → 评测与安全。

自主系统路线：POMDP → 世界模型 → 规划 → RL/HRL → 持续学习 → Multi-Agent → 进化与具身环境。
