# F 世界模型与环境智能：理解、预测、模拟与行动的闭环

> **定位**：F 研究智能体如何从观测中建立可更新的环境内部模型，并用它预测后果、在模拟中评估方案、规划行动、通过交互继续学习。它是连接 `E 感知`、`C 基础模型`、`D Agent` 与 `G 具身智能` 的系统层。

## 一句话理解

世界模型不是"生成一段像真的视频"，而是一个对任务有关状态、环境变化和行动后果进行建模的内部系统。其价值由它能否改善**预测、反事实推演、规划、控制、泛化与安全**决定。

## 领域定义与核心问题

世界模型（World Model）指智能体对环境状态、转移动力学、奖励结构与不确定性建立的**内部表征**，回答两类核心问题：当前发生什么（状态估计），以及采取某个动作后会发生什么（行动条件预测）。由此延伸出 F 方向的完整问题链：

1. **表示**：什么是对任务足够的世界状态？如何把异构观测组织为可预测、可行动的状态？
2. **预测**：如何学习行动条件下的转移分布，并量化其不确定性？
3. **模拟**：如何低成本获得可交互的未来（生成式模拟、物理仿真、数字孪生）？
4. **决策**：预测如何接入规划、搜索与策略学习，并抑制模型偏差？
5. **交互**：如何主动探索、接收反馈并持续更新模型以适配开放世界？
6. **评估**：如何证明模型真正支撑了预测、物理、因果与闭环任务，而非只有表面逼真度？

## 发展历史

| 阶段 | 时间 | 代表工作与贡献 |
|:---|:---|:---|
| 理论奠基 | 1990s | Dyna（Sutton 1991）用"模型生成的经验"连接学习与规划；POMDP（Kaelbling 等 1998）为部分可观测决策提供信念状态形式化 |
| 深度世界模型萌芽 | 2018 | World Models（Ha & Schmidhuber）用 VAE+RNN 学习环境压缩表示并"在梦里训练"；PlaNet 首次在像素观测上用潜在动力学做规划 |
| 想象式强化学习 | 2019–2023 | SimPLe、Dreamer/DreamerV3 在潜在轨迹中训练策略；MuZero 无需规则与观测重建即可用学习模型规划；TD-MPC 系列面向连续控制的短时域 MPC |
| 生成式与基础世界模型 | 2023– | Sora、Genie 等以互联网规模数据学习视频生成与可交互模拟；JEPA 等预测表征路线避免逐像素预测 |
| 系统化与评估 | 2024– | 世界模型进入 Agent 闭环，评估从"画质"转向预测、物理、因果、泛化与任务的证据体系 |

## 技术演进路线

```text
观测与状态估计（E 感知 → belief/latent state）
        ↓
学习型动力学：潜在预测 / 生成式模拟 / 物理与规则仿真
        ↓
规划与控制：MPC / MCTS / 想象式策略 / LLM 高层规划
        ↓
交互与探索：主动学习、安全探索、多智能体环境
        ↓
评估与校准：预测、物理、因果、泛化、任务闭环
```

## 与相邻板块的边界

- **C.05 世界模型基础**：关注作为基础模型能力的潜在动力学、预训练和通用模型接口；F 将这些能力放入环境闭环，强调状态、仿真、决策与部署。
- **D-02 环境与世界模型**：以智能体视角定义环境交互闭环、POMDP 与状态估计、模拟器接口与"心理模拟"；F 聚焦可学习世界模型的建模、生成、规划接入与评估闭环，二者互为前置。
- **E 感知**：将多模态信号转换为可用观测与空间证据；F 负责把证据组织为随时间演化、可供行动查询的状态。
- **D Agent**：负责目标分解、工具使用、记忆与任务编排；F 为 Agent 提供"行动前预测后果"的环境推理层。
- **G 具身智能**：负责机器人感知、控制和物理执行；F 提供训练环境、预测模型和 Sim2Real 桥梁。
- **I 因果智能**：研究因果识别和反事实理论；F 在可交互环境中把因果变量、干预和动力学连接到决策。

## 当前发展状态

- 潜在动力学 + 想象式强化学习在连续控制、游戏与开放世界任务上持续刷新样本效率纪录（DreamerV3 等）。
- 生成式世界模型以互联网视频为数据，开始提供可动作控制的可交互模拟器（Genie 等），但物理一致性与长程稳定性仍是瓶颈。
- LLM 常被当作"软世界模型"用于高层规划，但缺乏对执行后果与环境的校准预测，需与可验证的环境模型结合。
- 评估体系从单一点预测误差扩展到预测、物理、因果、泛化与闭环任务的多元证据。

## 未来趋势

- 长时域一致性、高效推理与高保真生成之间的工程权衡。
- 从视频统计相关性走向可干预的物理与因果机制。
- 多尺度、多模态状态的统一与可更新记忆。
- 世界模型驱动的数据合成、仿真 Agent 训练与数字孪生闭环。
- 安全与对齐：让模型在不确定时降级、请求信息或停止，而不是自信地错误预测。

## 核心原则

1. **任务充分性优先于像素还原**：状态应保留对决策有用的变量。
2. **行动条件不可缺失**：预测必须说明在什么动作、什么控制粒度下成立。
3. **不确定性需要显式处理**：越长的想象轨迹越应反映模型不知道什么。
4. **闭环效用是最终标准**：离线预测高分不保证可提升控制和规划。
5. **仿真不是现实**：任何训练环境都要通过系统辨识、鲁棒优化和现实验证闭环校准。
