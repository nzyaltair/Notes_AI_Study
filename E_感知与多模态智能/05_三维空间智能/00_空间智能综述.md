# 空间智能综述

空间智能是把视觉观测组织为可定位、可查询、可推理的三维场景状态的能力，是视觉、多模态、世界模型和具身系统之间的关键桥梁。

```text
相机与几何 → 深度/多视角 → 定位建图与重建 → 三维场景语义 → 空间推理与记忆
```
