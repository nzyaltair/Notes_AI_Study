# 视觉生成基础模型

## 一句话理解

视觉生成模型学习图像分布或其潜在空间，可用于补全、合成与编辑；单帧逼真不等于拥有面向行动的世界模型。

VAE 提供概率潜变量，GAN 以对抗训练追求保真，扩散学习逆噪声过程，自回归视觉 token 便于与语言统一。若用于世界预测，还需动作条件、长期一致性和闭环控制评测。
