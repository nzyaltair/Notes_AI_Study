# 交互环境与模拟器

| 环境 | 典型观察与动作 | 挑战 |
|---|---|---|
| Web | DOM、截图 / 点击、输入、请求 | 动态页面、认证、注入 |
| Computer Use | 像素、窗口 / 鼠标、键盘 | 定位误差、不可逆操作 |
| 游戏与机器人 | 传感器 / 离散、连续控制 | 稀疏回报、sim-to-real |
| 企业系统 | 消息、数据库 / API | 权限、隐私、审计 |

模拟器支持廉价训练、回归测试和风险预演，但模拟成功不等于真实可靠。环境应提供可验证验收条件、故障注入、动作日志和资源成本；真实执行采用 sandbox、模拟账户和最小权限。
