# Multi-Agent 系统

多智能体研究具有局部观察、目标与行动能力的主体如何通信、协作、竞争和形成制度。LLM 多 Agent 是其中一个实现分支，而非 MAS 全部。

- [[02_协作与评测/01_协作_竞争与任务分配|协作、竞争与任务分配]]：合同网、协同规划、博弈和 MARL。
- [[02_协作与评测/02_LLM_Multi_Agent与评测|LLM Multi-Agent 与评测]]：角色系统、协作收益与失效模式。

拆分 Agent 的前提是信息、工具或评估视角确实互补。通信应有结构、来源、时效、权限、确认和预算；多轮对话不等于协作。
