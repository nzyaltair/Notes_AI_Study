# 机器人运动学：从关节到可执行运动

## 一句话理解

运动学描述几何运动而不讨论力：正运动学回答"当前末端在哪里"，逆运动学回答"怎样到达目标"，Jacobian 回答"关节微动如何转为末端速度"。它是将意图投影为可执行几何的标准桥梁。

## 概述

运动学是机器人学的基础理论层，连接关节空间与任务空间。学习型策略（VLA、扩散策略）常输出末端增量或目标位姿，但末端目标本身没有物理意义——必须经过逆运动学、Jacobian 分析、碰撞检查和限幅才能变成可执行的关节命令。理解运动学是理解"为什么策略输出不能直接驱动电机"的关键。

## 发展历史

- **1950s-1960s**：Denavit-Hartenberg (D-H) 参数法提出，成为关节链建模的标准方法。
- **1970s**：逆运动学数值方法发展（Paul 1981, Whitney 1969 的伪逆方法）；冗余机器人零空间利用被提出。
- **1980s**：螺旋理论与 POE（Product of Exponentials）公式提供了更几何化的运动学表达（Murray, Li, Sastry 1994）。
- **2000s**：随机采样规划（RRT, PRM）将运动规划与逆运动学结合，解决高自由度问题。
- **2020s**：学习型策略输出末端增量，运动学适配层成为策略与硬件之间的标准接口。

## 核心概念

| 概念 | 定义 | 作用 |
|---|---|---|
| 关节空间 | 所有关节角 \(\mathbf{q}\in\mathbb{R}^n\) | 机器人内部状态 |
| 任务空间 | 末端位姿 \(\mathbf{T}\in SE(3)\) | 任务目标定义 |
| 正运动学 | \(\mathbf{q}\to\mathbf{T}\) | 已知关节求位姿 |
| 逆运动学 (IK) | \(\mathbf{T}\to\mathbf{q}\) | 已知位姿求关节 |
| Jacobian | \(\dot{\mathbf{V}}_e=J(\mathbf{q})\dot{\mathbf{q}}\) | 速度映射 |
| 奇异性 | \(J\) 降秩 | 丧失部分方向可控性 |
| 冗余度 | \(n>6\)（任务自由度） | 零空间优化 |

## 技术原理

### 正运动学

以 D-H 参数或 POE 公式表达关节链，输出末端的 \(SE(3)\) 位姿：

$$\mathbf{T}_{0e}=f(\mathbf{q})\in SE(3)$$

D-H 参数法对每个关节定义四个参数 \((a, \alpha, d, \theta)\)，串联齐次变换：

$$\mathbf{T}_{0e} = \prod_{i=1}^{n} \mathbf{T}_{i-1,i}(a_i, \alpha_i, d_i, \theta_i)$$

POE 公式以螺旋运动表达：

$$\mathbf{T}_{0e} = e^{[\mathbf{S}_1]\theta_1} e^{[\mathbf{S}_2]\theta_2} \cdots e^{[\mathbf{S}_n]\theta_n} \mathbf{M}$$

其中 \(\mathbf{S}_i\) 是关节轴的螺旋坐标，\(\mathbf{M}\) 是零位时末端位姿。

### 逆运动学

给定目标 \(\mathbf{T}^*_{0e}\)，求满足关节限位、碰撞与姿态约束的 \(\mathbf{q}\)。IK 有三种情况：

1. **解析解**：特定构型（如 6 轴腕分离机器人）存在闭式解，速度快但适用范围有限。
2. **数值解**：基于 Jacobian 迭代，通用性强但可能收敛到局部最优或无解。
3. **采样/优化**：随机采样 + 碰撞检查，适合高自由度。

数值 IK 常解带阻尼的最小二乘问题（DLS, Damped Least Squares）：

$$\dot{\mathbf{q}}=J^T(JJ^T+\lambda^2 I)^{-1}\mathbf{V}_e + (I-J^\dagger J)\dot{\mathbf{q}}_{null}$$

- 阻尼项 \(\lambda\) 在奇异位形附近降低关节速度放大。
- 零空间项 \((I-J^\dagger J)\dot{\mathbf{q}}_{null}\) 利用冗余度实现避障、远离限位或保持相机视野。

### Jacobian 与奇异性

Jacobian 连接关节速度与末端 twist：

$$\mathbf{V}_e = J(\mathbf{q})\dot{\mathbf{q}}$$

其中 \(\mathbf{V}_e \in \mathbb{R}^6\)（线速度 + 角速度）。当 \(J\) 降秩时进入奇异位形：

- **边界奇异**：关节到达限位。
- **构型奇异**：特定关节组合使末端失去某方向自由度（如手臂伸直时无法径向移动）。

操作度（Manipulability）指标量化各向同性：

$$w = \sqrt{\det(JJ^T)}$$

奇异性处理策略：阻尼伪逆、操作度预警、速度限幅、路径重规划。

### 轨迹规划

轨迹需满足位置、速度、加速度和 jerk 约束，并通过碰撞检查：

- **关节空间轨迹**：插值关节角（五次多项、B-spline），简单但任务空间轨迹不直观。
- **任务空间轨迹**：在末端位姿空间规划（直线、圆弧），需 IK 转换。
- **采样规划**：RRT/RRT\*/PRM 在高维空间搜索无碰撞路径。
- **最优控制**：CHOMP/TrajOpt 将轨迹优化为带约束的优化问题。

## 与学习策略的接口

VLA/扩散策略常输出末端增量（\(\Delta x, \Delta y, \Delta z, \Delta\text{rot}, \text{gripper}\)）而非关节命令。执行层必须：

1. 明确坐标系：增量是相对相机系、基座系还是末端系。
2. IK 求解：将末端增量映射为关节运动，处理无解和奇异。
3. 碰撞检查：验证路径无自碰撞和环境碰撞。
4. 速度/加速度限幅：防止超出硬件能力。
5. 控制周期对齐：策略输出频率（如 10 Hz）与伺服频率（如 500 Hz-1 kHz）的适配。

学习模型预测目标，运动学与规划器负责证明可执行。

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 解析 IK | 实时性好、可解释 | 仅适用特定构型 |
| 数值 IK | 通用、可加约束 | 可能无解或局部最优 |
| D-H 参数 | 标准化、成熟 | 奇异处理不直观 |
| POE | 几何直观、统一 | 教材普及度低 |
| 采样规划 | 通用、可处理高维 | 实时性有限 |

## 应用场景

- 固定基座机械臂：工业装配、拣选、焊接。
- 移动操作：导航 + 臂操作联合规划。
- 人形机器人：全身 IK + 冗余度管理。
- 学习策略部署：策略输出 → IK → 控制器。

## 前沿发展

- **学习辅助 IK**：用神经网络学习 IK 初始猜测或学习热启动，加速数值求解。
- **可微运动学**：将 IK 嵌入可微计算图，支持端到端学习。
- **全身运动规划**：人形机器人的全身 IK + 多接触管理。
- **实时运动规划**：GPU 加速采样规划（cuRobo, MotionBenchMaker）。
