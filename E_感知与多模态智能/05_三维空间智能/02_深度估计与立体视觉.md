# 深度估计与立体视觉

## 一句话理解

深度估计将二维像素映射为三维距离——双目方法利用视差三角测量，多视角方法利用视角一致性，单目方法依赖学习到的尺度先验，共同构成从 2D 到 3D 的核心通道。

## 概述

深度估计（Depth Estimation）和立体视觉（Stereo Vision）是从图像中恢复三维深度信息的关键技术。根据输入类型可分为：

- **单目深度估计**：从单张图像估计深度，依赖学习到的先验
- **双目立体匹配**：利用左右视图视差计算深度
- **多视角立体（MVS）**：利用多视图一致性恢复稠密深度

## 核心方法

| 方法 | 输入 | 原理 | 代表模型 |
|:---|:---|:---|:---|
| 单目深度 | 单张 RGB | 学习先验 + 全局/局部特征 | MiDaS, DPT, Depth Anything |
| 双目立体 | 左右视图 | 视差匹配 + 三角测量 | RAFT-Stereo, IGEV-Stereo |
| MVS | 多视图 | 视角一致性约束 | MVSNet, PatchMatchNet |
| 多传感器 | RGB + LiDAR | 深度补全 | NLSPN, GuideNet |

## 关键挑战

- **相对深度 vs 度量深度**：单目方法通常输出相对深度，需要额外信息转为度量深度
- **遮挡边界**：物体边缘处的深度不连续导致估计模糊
- **弱纹理区域**：缺乏纹理特征的区域难以匹配
- **尺度不确定性**：单目方法无法区分近处小物体和远处大物体
