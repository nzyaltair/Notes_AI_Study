# 持续学习与 Agent 对齐接口

> 本文只说明基础模型训练与长期自主系统的接口；持续学习算法、Agent 架构与安全治理分别归入 D 与 J。

- **持续学习接口**：增量数据、记忆回放、参数/适配器隔离、遗忘监测和版本化评测可减缓能力退化，但不等同于完整终身学习。
- **Agent 对齐接口**：工具权限、目标约束、动作审计、停止条件与异常回退必须在模型后训练之外由 Agent 运行时和安全策略共同实现。
- **边界**：模型偏好优化可以塑造默认行为，却不能单独保证开放环境中的长期目标一致性。
