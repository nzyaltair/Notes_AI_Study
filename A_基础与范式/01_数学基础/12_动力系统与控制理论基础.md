# 动力系统与控制理论基础

## 一句话理解

动力系统研究**系统状态如何随时间演化**（$x_{t+1} = f(x_t, u_t)$），控制理论回答**如何选择输入 $u_t$ 让系统按期望的方式演化**。如果把强化学习看作"用数据学出来的控制"，那么控制理论就是"用模型推导出来的强化学习"——两者的目标函数、稳定性分析与闭环思想完全同源，是理解机器人、世界模型与智能体的数学骨架。

## 1. 概述

AI 的核心命题之一是与物理世界或复杂环境交互：机器人移动、自动驾驶、电网调度、Agent 在环境中决策。这些系统的数学本质是**受控动力系统**——状态随时间演化，输入（控制/动作）影响演化方向。控制理论从 1940 年代起就为这类问题建立了成熟框架：建模、稳定性分析、最优控制、鲁棒性与闭环反馈。

本笔记是数学基础的一部分，为以下主题提供理论底座：
- **强化学习**（[[../../D_智能体与自主系统/04_强化学习/00_强化学习_综述|强化学习]]）：策略 = 控制律，价值函数 = 代价函数的最优性方程，动态规划与最优控制同构
- **世界模型**（[[../../F_世界模型与环境智能/01_世界模型理论/00_世界模型理论_综述|世界模型理论]]）：学习环境动力学 $p(s_{t+1} \mid s_t, a_t)$ 等价于学习动力系统的转移函数
- **机器人控制**（[[../../G_具身智能与物理智能/06_控制与执行/00_控制与执行_综述|控制与执行]]）：PID、LQR、MPC 是控制理论的标准工具
- **优化动力学**（[[../02_优化理论与方法|优化理论与方法]]）：梯度下降、动量法本身就是离散动力系统，其收敛分析借用稳定性理论

核心视角：**AI 智能体 = 数据驱动的控制器**。理解经典控制理论，才能理解强化学习的假设（马尔可夫性、可观测性、稳定性的需求），以及何时应该用模型（MPC）而非纯数据（RL）。

## 3. 核心概念

### 3.1 动力系统

**离散时间**：$x_{t+1} = f(x_t)$（无控制）或 $x_{t+1} = f(x_t, u_t)$（受控）
**连续时间**：$\dot{x} = f(x, u)$

- **状态** $x \in \mathcal{X}$：系统此刻的完整信息（位置、速度、隐藏特征）
- **平衡点**：$x^*$ 满足 $f(x^*) = 0$（或 $x^* = f(x^*)$）。系统停留在平衡点不动
- **轨迹**：从初值出发的状态序列/曲线
- **吸引子**：系统长期演化趋向的集合（平衡点、极限环、混沌吸引子）。训练后的神经网络隐藏状态、训练收敛的损失轨迹都可看作吸引子现象

**性质维度**：线性 vs 非线性、时变 vs 时不变、确定性 vs 随机（随机情形进入 [[10_随机过程与随机微分方程|随机过程与随机微分方程]] 的 SDE 框架）、连续 vs 离散状态。

### 3.2 稳定性

**Lyapunov 稳定性**（1892）给出了不求解方程就判断稳定性的方法：找**能量函数** $V(x) \ge 0$（$V(x^*) = 0$），若沿轨迹 $V$ 单调下降（$\dot{V} \le 0$），则系统稳定；若严格下降则渐近稳定。

> **直觉**：一个球滚进碗底。总能量（势能+动能）单调减少且非负，最终停在碗底——能量函数就是 Lyapunov 函数。不需要知道球的精确轨迹就能断定它会停下来。

**与 AI 的联系**：
- 损失函数 $L(\theta)$ 就是参数空间的 Lyapunov 候选函数：梯度下降保证 $L$ 沿轨迹下降，但非凸情形下"停在鞍点/局部极小"对应"不是全局渐近稳定"
- 神经网络动力学的稳定性分析（如 RNN 的梯度消失 = 平衡点稳定性问题，见 [[../../B_连接主义与深度学习/04_序列模型/00_序列模型_综述|序列模型]]）
- 自回归生成的长程误差积累、世界模型预测误差的传播都可以用稳定/发散来刻画

**常见稳定性判据**：
- 线性系统 $\dot{x} = \mathbf{A}x$：渐近稳定 $\iff$ $\mathbf{A}$ 的所有特征值实部为负（离散：模小于 1）。与特征值（[[01_线性代数|线性代数]]）、谱理论直接连接
- **李雅普诺夫方程**：线性情形下 $V(x) = x^T \mathbf{P}x$，求 $\mathbf{P}$ 满足 $\mathbf{A}^T\mathbf{P} + \mathbf{P}\mathbf{A} = -\mathbf{Q}$
- **不变原理（LaSalle）**：$V$ 不增时，轨迹收敛到 $V$ 不再变化的集合

### 3.3 可控性、可观性与状态估计

- **可控性**：能否用控制输入把系统从任意状态驱动到任意状态。线性系统由可控性矩阵 $\mathcal{C} = [\mathbf{B}, \mathbf{A}\mathbf{B}, \dots, \mathbf{A}^{n-1}\mathbf{B}]$ 的秩判定
- **可观性**：能否从输出序列推断出完整状态。由可观性矩阵秩判定
- **分离原理**：在满足可控可观时，状态估计（Kalman 滤波）与反馈控制（LQR）可以分开设计——观测器 + 状态反馈的组合仍最优。这是现代控制的结构性结果

> **对 RL 的意义**：部分可观测 MDP（POMDP）就是"不可观"情形——agent 需要记忆/信念状态来补偿不可观测性，这与循环神经网络、Transformer 的上下文记忆机制在结构上同构。

### 3.4 反馈控制 vs 开环控制

- **开环**：$u_t = g(t)$，不依赖观测。对环境扰动无抵抗力
- **反馈（闭环）**：$u_t = \pi(x_t)$，依据当前状态调整。负反馈是稳定性的工程基础（传感器误差 → 校正动作 → 误差减小）
- **PID 控制器**是最广泛使用的反馈律：$u(t) = K_p e(t) + K_i \int e + K_d \dot{e}$，比例项立即响应、积分项消除稳态误差、微分项阻尼震荡。神经网络控制器可视为"学出来的非线性 PID"

### 3.5 最优控制问题

给定系统 $\dot{x} = f(x, u)$，最小化
$$ J = \int_0^T c(x_t, u_t)\, dt + \phi(x_T) $$
最优控制通过**动态规划**（贝尔曼方程）或**变分法（庞特里亚金极大值原理）**求解。这与强化学习的价值函数、策略优化完全对应：

| 最优控制 | 强化学习 |
|---------|---------|
| 代价 $c(x,u)$ | 负奖励 $-r(s,a)$ |
| 贝尔曼方程（连续 HJB 方程） | 贝尔曼方程（Q 函数） |
| 策略 = 最优控制律 | 策略 $\pi(a \mid s)$ |
| 模型已知、精确求解 | 模型未知、从数据学习 |
| 庞特里亚金极大值原理 | 策略梯度（对偶结构） |

## 4. 技术原理

### 4.1 线性系统与 LQR

线性时不变系统：$\dot{x} = \mathbf{A}x + \mathbf{B}u$。**线性二次调节器（LQR）**最小化
$$ J = \int_0^\infty (x^T \mathbf{Q}x + u^T \mathbf{R}u)\, dt $$
其最优反馈律为 $u = -\mathbf{K}x$，其中 $\mathbf{K} = \mathbf{R}^{-1}\mathbf{B}^T\mathbf{P}$，$\mathbf{P}$ 由**代数 Riccati 方程**求解：
$$ \mathbf{A}^T\mathbf{P} + \mathbf{P}\mathbf{A} - \mathbf{P}\mathbf{B}\mathbf{R}^{-1}\mathbf{B}^T\mathbf{P} + \mathbf{Q} = 0 $$
LQR 的优美之处：最优解是**线性状态反馈**，闭环系统 $\dot{x} = (\mathbf{A} - \mathbf{B}\mathbf{K})x$ 稳定。这是"反馈律可解析推导"的最佳范例——RL 中学习的策略在局部可看作学出来的 LQR 增益。

### 4.2 模型预测控制（MPC）

MPC 在每个时刻求解一个**有限时域开环最优控制问题**，只执行第一步，然后滚动重算：
1. 用模型预测未来 $N$ 步状态
2. 求解带约束的最优控制问题 $\min_{u_{0:N}} \sum_{k=0}^{N-1} c(x_k, u_k)$，约束 $x_{k+1} = f(x_k, u_k)$，$u_k \in \mathcal{U}$
3. 执行 $u_0$，观测新状态，回到步骤 1

**特点**：显式处理约束（如关节角度限制、安全距离），滚动时域带来鲁棒性。MPC 是自动驾驶、机器人操作、过程工业的标准方法；与 RL 结合（RL-MPC 混合、学习 MPC 的预测模型）是当前热点。参见 [[../../G_具身智能与物理智能/06_控制与执行/00_控制与执行_综述|控制与执行]]。

### 4.3 状态估计：观测器与 Kalman 滤波

状态不可直接观测时，用**观测器**重构状态：
- 确定性系统：Luenberger 观测器 $\dot{\hat{x}} = \mathbf{A}\hat{x} + \mathbf{B}u + \mathbf{L}(y - \mathbf{C}\hat{x})$
- 随机系统：**Kalman 滤波**给出最小方差估计，递推为"预测（动力学）+ 更新（测量）"，见 [[10_随机过程与随机微分方程|随机过程与随机微分方程]]

> **在 AI 中**：Transformer 的因果注意力可以看作"从历史观测中估计潜在状态"的可学习观测器；世界模型的隐状态推断同理。粒子滤波、贝叶斯滤波用于非线性情形。

### 4.4 非线性系统与线性化

- **线性化**：在平衡点附近做一阶泰勒展开，用 Jacobian $\mathbf{A} = \frac{\partial f}{\partial x}$ 判定局部稳定性——这正是神经网络中"局部线性 + 全局非线性"的同一思路
- **LQR 的扩展**：时变线性化 → iLQR/DDP（迭代 LQR / 微分动态规划）——机器人运动规划的标准算法，用一阶/二阶导数信息迭代求解非线性最优控制，是"信赖域牛顿法"在控制中的对应物
- **庞特里亚金极大值原理**：给出最优性的必要条件（伴随方程 + 哈密顿量最大化），与策略梯度中"优势函数"的计算有对偶关系

### 4.5 混沌与复杂动力学

- **混沌**：确定性系统对初值极端敏感（Lorenz 蝴蝶效应），长期预测不可行
- **在 AI 中**：长程预测任务的不可预测性下限、世界模型评估（预测误差必然随 horizon 增长）、扩散模型 ODE 采样轨迹的数值稳定性
- **分岔**：参数连续变化导致系统定性行为突变，是"涌现"（[[../../I_高级智能理论与融合方法/05_复杂系统与涌现智能/00_复杂系统与涌现智能_综述|复杂系统与涌现智能]]）的数学来源之一

| 方法 | 类别 | 在 AI/机器人中的角色 |

| PID | 反馈控制 | 工业与机器人底层控制标准 |
| LQR / Riccati | 线性最优控制 | 稳定控制基准、MPC 的线性变体 |
| MPC | 约束最优控制 | 自动驾驶、操作、安全约束控制 |

| 神经 ODE | 动力系统建模 | 连续深度网络、常微分方程视角的残差连接 |

## 6. 优势与局限

**优势**：
- 理论成熟：稳定性、最优性、鲁棒性有严格保证，可证明而非仅凭实验
- 闭环思想普适：反馈（依据观测调整行为）是智能体与环境交互的本质
- 与 RL 互补：模型已知时 MPC/LQR 优于样本低效的 RL；模型未知时 RL 学模型/策略
- 提供安全语言：约束（$\mathcal{U}$）、不变集、稳定域是安全论证的数学载体

**局限与陷阱**：
- 经典方法依赖精确模型，真实环境（非结构化、高维、不可建模）下失效
- 高维连续状态的最优控制求解成本高（维数灾难）
- 稳定性分析的 Lyapunov 函数构造依赖专家技巧，尚无通用自动化方法（Neural Lyapunov 是探索方向）
- RL 的"数据驱动 + 端到端"绕开了经典建模，但牺牲了可证明性与约束处理能力

## 9. 前沿发展

- **神经李雅普诺夫函数（Neural Lyapunov）**：用神经网络学习稳定性证书，为端到端策略提供安全保证

- **安全强化学习**：约束 RL（CMDP）、屏障函数（barrier function）保证状态不离开安全集——控制理论的安全语言进入 RL
- **神经 ODE 与连续深度模型**：用 ODE 求解器前向传播、伴随方法反向传播，见 [[../../B_连接主义与深度学习/02_深度学习理论/00_深度学习理论_综述|深度学习理论]]
- **涌现与复杂系统**：分岔、混沌与大模型涌现现象的数学刻画

## 10. 常见问题

**Q1: 强化学习和最优控制到底什么关系？**
最优控制是"模型已知的最优决策数学"，RL 是"模型未知、从交互数据学习"的同一问题的求解。连续状态动作的确定性最优控制 = LQR/MPC；带噪声与模型未知时用 RL。现实中常用分层：RL 学高层策略，底层用 PID/MPC 执行——各自发挥"学习"与"可证明性"的优势。

**Q2: 李雅普诺夫稳定性为什么重要？**
它把"判断系统是否稳定"转化为"找一个单调下降的能量函数"，从而**不用解方程**就能证明稳定。这在工程中极其关键（系统规模大、非线性、无法显式求解），也是今天 Neural Lyapunov（让网络学 $V$）能落地的前提。稳定是智能体行为可信、可部署的基础要求。

**Q3: MPC 和普通反馈控制有什么区别？为什么需要模型？**
PID 只依据当前误差给出控制，无约束处理、无前瞻；MPC 用模型预测未来若干步，显式优化带约束的控制序列，能"提前避让"。代价是需要准确模型与在线优化。RL 的世界模型 + 规划（Model-based RL）正是把 MPC 的"模型"换成学出来的动力学。

**Q4: 可控性和可观性对 AI 有什么意义？**
可控性说明"只要策略足够好就能到达目标状态"（决定学习上限）；可观性说明"能否从观测推断决策所需状态"（决定是否需要记忆/信念状态）。POMDP 中的记忆机制、RNN/Transformer 的上下文都是对不可观性的补偿。RL 智能体常常失败，正是因为状态表示不足导致实际不可观。

**Q5: 梯度下降是动力系统吗？稳定性理论能解释深度学习优化吗？**
是。$\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$ 是离散动力系统，损失 $L$ 是 Lyapunov 候选函数。经典分析保证凸情形收敛；非凸情形（鞍点、局部极小、混沌的损失景观）借用动力系统的分岔/吸引子概念理解"训练动力学"。动量法、Adam 都可看作设计更好的"控制系统"，见 [[../02_优化理论与方法/07_大模型训练优化|大模型训练优化]]。
