# 复杂适应系统与自组织

## 一句话理解

复杂适应系统（CAS）由持续适应的主体、环境反馈和规则组成，在无中心控制下通过局部交互涌现全局秩序；自组织是这种秩序的生成机制。

## 核心概念

| 概念 | 定义 | 智能系统启示 |
|---|---|---|
| 复杂适应系统 | 主体适应环境并改变环境的反馈系统 | 学习、交互与生态共演化 |
| 适应性景观 | 主体在"适应度地形"上攀爬 | 局部最优与探索-利用权衡 |
| 正负反馈 | 放大或抑制变化的回路 | 稳定与失稳的机制 |
| 自组织 | 局部规则 → 全局秩序，无中心控制 | 分布式协调与记忆 |
| 涌现 | 宏观模式不能由单元属性直接读出 | 需跨尺度测量与机制解释 |
| 韧性 | 扰动后恢复的能力 | 鲁棒性与对抗干扰 |

## 典型模型

- **Schelling 隔离模型**：个体微小的迁移偏好导致宏观隔离——"微观选择→宏观结果"的经典例证。
- **元胞自动机**：局部规则产生复杂全局图案（生命游戏，见 [[../../06_人工生命与进化智能/01_人工生命理论与数字生命]]）。
- **蚁群模型**：个体简单规则 + 信息素通信 → 群体寻路能力（见 [[03_群体智能与多Agent社会模拟]]）。
- **沙堆模型**：自组织临界性——系统自发到达临界状态，微扰可能触发级联。

## 设计注意

自组织可产生全局秩序，但也可能形成**锁定**（次优状态固化）、**极化**（群体分裂）或**脆弱临界**（微小扰动导致崩溃）。设计智能系统时需显式测量：

- 协调收益与通信成本
- 失效传播路径
- 干预杠杆点（何处施力最有效）

## 与 AI 的关系

- **分布式 Agent 协调**：多 Agent 通过局部交互完成任务，无需中央规划。
- **涌现能力**：LLM 大规模协同中观察到的能力涌现需谨慎归因（见 [[02_涌现智能与多尺度动力学]]）。
- **自我组织的记忆与技能**：开放式智能中技能库的涌现式组织（见 [[../../07_开放式智能/00_开放式智能_综述]]）。
