# 持续学习与终身学习：AGI 的当前最大瓶颈

## 一句话理解

持续学习研究系统如何按任务序列持续适应并尽量保持旧能力，核心难点是灾难性遗忘。它仍缺少可在开放环境中普遍可靠、低成本扩展的通用解法。

## 1. 领域定义

持续学习（Continual / Lifelong Learning）指智能体在时间线上连续学习一系列任务，同时保持对旧任务的能力，不发生**灾难性遗忘**（catastrophic forgetting，神经网络学习新任务时覆盖旧知识，导致旧任务性能骤降）——这是持续学习最根本的挑战。

持续学习改变的是**模型参数**，学习方式为梯度更新，持久性为永久权重变化，计算成本高，目前仍是 AGI 路线图上的瓶颈；与之相对的语言层面经验总结（反思）见 [[06_反思与自我改进|反思与自我改进]]。

## 2. 研究定位与边界

- 持续学习不是单一算法，而是一组关于任务顺序、记忆预算、迁移、遗忘与评测的问题。
- 当前 Agent 可通过 [[06_反思与自我改进|反思与自我改进]]、外部记忆和工作流更新积累经验，但这不等同于权重层持续学习。
- LLM 的 in-context learning 会随上下文结束而消失；参数更新虽更持久，却需要处理回归、数据治理、评测和可回滚性。

## 3. 持续学习核心方法

| 类别 | 核心思想 | 代表方法 | 代价 |
|------|----------|----------|------|
| 正则化方法 | 限制重要参数的更新 | EWC, SI, MAS | 重要性近似有限 |
| 回放方法 | 重放旧数据/特征 | Experience Replay, GEM, A-GEM | 存储、隐私和分布偏差 |
| 架构方法 | 为新任务扩展新模块 | Progressive Nets, PackNet, HAT | 参数膨胀与路由复杂 |
| 动态架构 | 按需增减容量 | DGM, CNDPM | 架构管理复杂 |
| 基于提示/PEFT | 轻量任务适配 | L2P, DualPrompt, prompt pool | 能力与稳定性边界 |

### 评估指标

- 平均准确率（AA）
- 遗忘度（Forgetting Measure）
- 向前迁移（FWT）/ 向后迁移（BWT）
- 样本与存储预算，覆盖未知任务边界的开放世界评测

## 4. 元学习与小样本学习速览

元学习（Learning to Learn）从多个学习经历中提取"如何学习"的元知识，使模型面对新任务时能用少量数据和步数快速适应。持续学习关注**时间维度的积累**（不遗忘），元学习关注**效率维度的适应**（学得快），AGI 需要两者兼备。元学习方法详见 [[05_元学习与自我改进|元学习与自我改进]]；小样本学习（Few-Shot，5-way 1-shot/5-shot）与元学习紧密相关，也与 LLM 的 in-context learning 形成有趣对比。

## 5. 发展历史

1. 1990s：McCloskey & Cohen 发现多层感知机的灾难性遗忘
2. 2017：EWC（Kirkpatrick et al.）开创正则化持续学习
3. 2017：MAML（Finn et al.）开创元学习优化路线
4. 2019：GEM/A-GEM 引入梯度约束
5. 2022：L2P 将 prompt tuning 引入持续学习
6. 2025-26：持续学习成为 AGI 路线图的明确瓶颈

## 6. 与 AGI 的关系

- **Agent 的瓶颈**：当前 Agent 无法持续学习，每次从零开始
- **自我迭代的前提**：AI 必须能从经验中持续改进
- **人脑的参照**：人能持续学习后快速上手新工作，AI 尚不能
- **与 LLM 的关系**：in-context learning 是权重之外的"临时持续学习"

## 7. 未来趋势

- 持续学习 + LLM（权重层面的持续适应）
- 脑启发的持续学习机制
- 持续学习世界模型
- 开放世界持续学习
- 持续学习安全（避免持续学入有害知识）
