# 世界模型与心理模拟

## 一句话理解

世界模型是智能体对"世界如何运作"的内部表征；心理模拟则是利用这个内部模型在"想象"中试演候选行动、评估后果，从而在不触碰真实环境的情况下做出更优决策。

## 概述

真实环境的每一次交互都有成本：时间、资源、风险。**世界模型**让智能体获得一种"内心模拟"的能力——给定当前信念状态和候选动作，世界模型可以预测接下来会发生什么、获得多少奖励、是否终止。基于世界模型的**心理模拟**（Mental Simulation）则让智能体在"想象"中评估多条行动路径，选择最优者执行，然后从真实反馈中学习并更新模型。

世界模型与心理模拟是 [[00_环境与世界模型_综述|环境与世界模型]]方向的顶点：[[01_环境交互与观察行动循环|环境交互闭环]]定义了交互范式，[[02_POMDP与状态估计|POMDP]] 处理了观察的不确定性，[[03_交互环境与模拟器|交互环境]]提供了外部模拟器，[[04_状态表示与环境预测|状态表示与环境预测]]学到了世界模型的核心组件——而本笔记将这些组件整合为完整的"想象-规划-执行"循环，聚焦于"如何用"世界模型做决策。

## 核心概念

- **世界模型（World Model）**：智能体对环境动态的内部表征，通常包含状态表示、前向模型、奖励模型和终止模型。它可以显式（如 Dreamer 的 RSSM + 解码器）或隐式（如 MuZero 的隐式值函数）地预测动作后果
- **心理模拟（Mental Simulation）**：在内部世界模型中"展开"多条行动路径，评估每条路径的累积回报、风险和环境反馈，选择最优路径执行。这是智能体超越"刺激-反应"式短视行为的关键能力
- **想象轨迹（Imagined Trajectory）**：在世界模型中通过 rollout 生成的状态-动作-奖励序列 $(z_0, a_0, r_0, z_1, a_1, r_1, \dots)$，与真实轨迹结构相同但来源不同
- **模型预测控制（Model Predictive Control, MPC）**：一种在线规划方法——每次规划固定视野 $H$，在模型中 rollout 多条候选动作序列，选择最优序列的第一步执行，然后重规划。MPC 的核心优势是每步都利用最新观测修正计划，对模型偏差有一定鲁棒性
- **蒙特卡洛树搜索（MCTS）**：一种在模型中进行树搜索的规划方法，通过选择-扩展-模拟-回传四步迭代，逐步构建搜索树，选择最优动作。AlphaGo/MuZero 是其最成功的实践
- **想象式强化学习（Imagination-Augmented RL）**：在世界模型中生成想象轨迹，用于训练策略或值函数，完全或部分替代真实环境交互。Dreamer 系列是这一范式的最成熟代表
- **模型偏差（Model Bias）**：世界模型在训练分布外的预测误差，导致"在想象中表现完美、在真实环境中失败"的差距。这是基于模型方法的核心挑战

## 技术原理

### 心理模拟的三种范式

**范式一：在线规划（Planning in Latent Space）**

使用学习到的世界模型，在决策时进行潜在空间规划。典型流程：

```text
当前观察 o_t → 编码为 z_t → 在模型中展开多条候选动作序列
  → 用奖励模型评估每条序列 → 选择最优序列的第一步执行
  → 真实环境反馈 o_{t+1} → 重复（重规划）
```

代表：PlaNet、TD-MPC2。优势是每步都利用最新观察修正计划，对模型偏差鲁棒；缺点是每步都需要在线规划，计算开销大。

**范式二：想象式训练（Imagination-Augmented Training）**

先学习世界模型，然后在世界模型中生成大量"想象轨迹"用于训练策略，策略在真实环境中执行时不再需要在线规划：

```text
① 学习世界模型（状态表示 + 前向模型 + 奖励模型）
② 在世界模型中 rollout 生成想象轨迹
③ 用想象轨迹训练策略 π(z_t) 或值函数 V(z_t)
④ 在真实环境中执行 π(o_t)（或 π(z_t)），无需在线规划
```

代表：Dreamer 系列。优势是执行时无额外规划开销；缺点是策略完全依赖世界模型，模型偏差直接影响策略质量。

**范式三：隐式模型 + 搜索（Implicit Model + Search）**

不显式学习环境的前向模型，而是学习一个"隐式模型"（如值函数和策略函数），利用搜索算法在决策时组合这些函数做规划：

```text
当前观察 o_t → 编码为隐状态 s_t → MCTS 使用隐式模型（策略 + 值函数）搜索
  → 搜索汇总的改进策略 π'(s_t)  → 采样子树的动作并执行
  → 真实环境反馈 → 更新隐式模型（训练数据）
```

代表：MuZero、EfficientZero。优势是无需显式预测环境的所有细节（如像素），只需预测对决策关键的值函数和策略，本质上是"学习的模型 + 搜索的结构"的融合。

### 模型偏差的成因与缓解

模型偏差主要有三个来源：

1. **分布外泛化失败**：世界模型只在训练数据分布内可靠，规划可能探索到未见过的状态-动作组合
2. **多步误差累积**：单步预测误差在 rollout 中指数级放大
3. **表示坍塌**：状态表示在训练过程中失去对决策关键信息的编码

**缓解策略**：

| 策略 | 描述 | 代表方法 |
|:---|:---|:---|
| 短视野规划 | 只规划几步，每步重规划，限制误差累积 | MPC（典型视野 5-15 步） |
| 不确定性惩罚 | 对预测不确定性高的路径给予折扣 | PETS 中的集成分歧度惩罚 |
| 集成模型 | 训练多个模型，用分歧度做不确定性估计 | Chua et al. (2018) 的 PETS |
| 模型预测 + 真实验证 | 先在模型中规划，再在真实环境做低成本验证 | 只读检查、沙箱执行 |
| 保守主义 | 在模型置信度低的区域偏好保守/安全的动作 | 悲观模型评估（Pessimistic MBPO） |
| 自适应 horizon | 当预测不确定性高时缩短规划视野 | 动态调整 rollout 长度 |

### 从 Dyna 到 Dreamer：想象式强化学习的演化

Dyna（Sutton, 1991）提出了一个简单而深刻的框架：学习一个环境模型，用它生成额外经验，然后混合真实和模拟经验来训练策略。Dyna 的流程至今仍是许多 Model-Based RL 方法的基础：

```text
① 真实环境交互：收集一批经验 (s, a, r, s')
② 模型学习：用收集的经验更新环境模型
③ 模型生成：从真实经验中随机采样起点，在模型中 rollout 生成想象轨迹
④ 策略学习：用真实 + 想象轨迹更新策略/值函数
⑤ 重复 ①-④
```

Dreamer 将 Dyna 的思想移植到深度学习时代，关键区别在于：Dyna 在原始状态空间建模，Dreamer 在潜在空间建模；Dyna 的模型通常简单（线性/表格），Dreamer 的模型是深度神经网络；Dyna 的想象轨迹在原始状态空间 rollout，Dreamer 的想象轨迹完全在潜在空间进行，无需解码回像素。

### 世界模型与 LLM 的结合

LLM 因训练语料中包含大量关于世界如何运作的常识（物理常识、社会规则、因果关系），被越来越多地用作"软世界模型"——在 Agent 规划时，LLM 被要求"扮演环境"并预测动作后果。这种范式被称作 LLM-as-World-Model 或 World Model 的"语言化"。

典型方法：Agent 生成一个候选计划，然后同一 LLM 或另一个 LLM 被提示"假设你是一个环境模拟器，请评估这个计划的结果"。这种方法的优势是无需训练专用模型、利用 LLM 的广泛常识覆盖；局限是缺乏 grounding、预测可能"看似合理实则错误"（幻觉）、无法量化不确定性，且不能替代需要精确物理建模的场景（如机器人控制）。

## 关键方法与模型

| 方法 | 范式 | 模型类型 | 规划方式 | 特点 |
|:---|:---|:---|:---|:---|
| Dyna (1991) | 想象式训练 | 显式状态空间 | 不滚动规划，模型生成额外经验 | 先驱，简单但局限 |
| PlaNet (2019) | 在线规划 | RSSM 潜在空间 | MPC 规划（CE 交叉熵方法） | 首次在 DMC 上超越无模型 |
| Dreamer (2020) | 想象式训练 | RSSM 潜在空间 | 在潜在空间训练策略 | 完全在"梦境"中训练 |
| DreamerV3 (2023) | 想象式训练 | RSSM 离散潜变量 | 同上，固定超参数 | 通用性最强 |
| MuZero (2020) | 隐式模型 + MCTS | 隐式值函数 + 策略 | MCTS 树搜索 | 无显式模型，搜索驱动 |
| TD-MPC2 (2023) | 在线规划 | 任务导向潜在空间 | MPC 规划 | 样本效率极高 |
| PETS (2018) | 在线规划 | 集成高斯过程/神经网络 | MPC + 不确定性量化 | 强调不确定性处理 |
| MBPO (2019) | 想象式训练 | 集成神经网络 | 模型生成 + 策略优化 | 分支集成，分支策略优化 |
| I2A (2017) | 混合 | 可微分想象路径 | 想象路径嵌入策略网络 | 想象路径作为网络额外的输入 |

## 优势与局限

**优势**：世界模型赋予智能体"在想象中学习"的能力，大幅减少真实环境交互需求（样本效率提升 1-2 个数量级）；心理模拟使智能体能够评估多条行动路径，而非仅依赖当前策略的"贪婪"选择；世界模型学习了一个可迁移的环境表示，可用于多种任务，而非从零开始学习每个任务的策略。

**局限**：模型偏差是根本性问题——基于错误模型的最优规划可能产生灾难性决策；学习高质量的世界模型本身需要大量计算和数据；在复杂高维观察（如真实世界图像、人类行为）中，当前世界模型的质量仍然有限；如何评估世界模型的质量（不依赖真实环境交互）仍是开放问题；LLM 作为世界模型虽然方便，但缺乏对预测准确性的硬约束。

## 应用场景

- **机器人控制**：DreamerV3 在多种机器人操控任务中达到 SOTA 样本效率，在真实机器人上只需少量交互即可学会新技能
- **游戏 AI**：MuZero 在 Atari、围棋、国际象棋、将棋上达到超人类水平，无需任何人类知识或规则
- **自动驾驶规划**：在隐空间中预测未来多条轨迹，评估安全性和舒适性，选择最优路径
- **LLM Agent 内部验证**：Agent 在调用高风险工具前，先用 LLM 模拟可能的后果，辅助决策
- **科学发现**：在生物、化学、物理等领域，世界模型可在模拟中加速新方案搜索

## 前沿发展

- **扩散世界模型**：从扩散模型在视频生成中的成功衍生出"扩散前向模型"，在视觉预测任务中生成更清晰、更多模态的未来帧，但推理速度有待提升
- **世界模型与 LLM 的深度融合**：用 LLM 的世界知识初始化世界模型，或让世界模型输出文本描述而非视觉预测，实现"语言化的心理模拟"
- **分层世界模型**：在多个抽象层级建模（如"宏观目标级"+"微观动作级"），上层规划关注长期目标，下层规划关注具体执行
- **世界模型的自我改进**：智能体通过心理模拟发现知识缺口，主动向真实环境提问以获取关键信息，改进世界模型（"主动学习世界模型"）
- **世界模型对齐**：确保世界模型的预测与人类对世界的认知一致，避免模型学到"技术上正确但人类不认可"的 bias

## 常见问题

**Q: 世界模型和模拟器有什么区别？**
模拟器（如 MuJoCo、Gymnasium）是外部提供的、独立于智能体的环境仿真；世界模型是智能体内部学习的环境表征。模拟器通常更精确但不可微分，世界模型可微分但可能有偏差。两者可以互补：模拟器提供训练数据，世界模型压缩为可微分表示用于端到端学习和快速规划。

**Q: 为什么 Dreamer 在训练中不需要真实环境，而 MuZero 需要？**
Dreamer 需要先学习世界模型（需要真实交互数据），然后完全在模型中训练策略，训练策略时不需要真实环境。MuZero 在每次真实交互后，使用隐式模型 + MCTS 做规划，然后使用真实交互数据更新隐式模型——MuZero 不需要断开式的"模型训练阶段"和"策略训练阶段"，而是 model learning 和 policy search 交替进行。

**Q: 世界模型在 LLM Agent 中有什么特殊价值？**
LLM Agent 面临的环境通常是数字化的（Web 页面、API 响应、用户消息），其动态比物理世界更"语言化"——预测下一步的观察（如"点击这个按钮后会弹出什么"）可以转化为文本预测问题，这正是 LLM 的强项。因此，LLM 本身可以充当"世界模型"，为 Agent 的心理模拟提供低成本的"软预测"。
