# 涌现智能与多尺度动力学

## 一句话理解

涌现研究微观交互与宏观能力之间的关系：宏观模式无法由单元属性直接读出，但也不能被当作"不可解释的神秘跃迁"——它需要通过跨尺度测量与机制解释来验证。

## 核心概念

| 概念 | 含义 |
|---|---|
| 涌现 | 微观规则 → 宏观模式，模式不能还原为单元属性的简单叠加 |
| 相变 | 参数跨越临界点时系统行为突变 |
| 吸引子 | 系统长期收敛的稳定状态 |
| 临界性 | 系统处于有序与混沌的边界，信息传输最大化 |
| 粗粒化 | 把微观状态聚合成宏观描述（对应因果表示学习中的"因果涌现"） |
| 尺度间信息流 | 宏观与微观之间的信息传递 |

## 涌现的度量

要严谨验证"涌现"，需要：

1. **跨尺度测量**：分别度量微观单元属性与宏观集体属性。
2. **粗粒化算子**：明确定义宏观状态如何从微观状态构造。
3. **机制解释**：说明何种局部规则产生何种宏观模式（而非仅观察相关性）。
4. **反事实检验**：扰动微观规则，观察宏观模式是否如预测般变化。

相关概念：**有效复杂度、统计复杂度、因果涌现**（宏观动力学比微观动力学具有更强的因果信息）是量化涌现的候选指标，但均需结合任务定义解释。

## 对基础模型的"涌现能力"主张

LLM 的"涌现能力"主张应同时报告：

- 度量连续性：指标是平滑上升还是阶跃（很多"涌现"是非线性/饱和度量导致的伪影）。
- 基准难度与测试集组成。
- 提示敏感性：是否换提示/解码参数就消失。
- 计算规模与数据规模。

避免将阈值效应或评测伪影误解为不可解释的能力跃迁（对应 [[../../08_研究方法与证据评估/04_基准设计与数据污染]] 与 [[../../08_研究方法与证据评估/03_统计显著性与可靠性]]）。
