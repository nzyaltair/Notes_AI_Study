# 测试时计算与预算分配

## 一句话理解

从能力训练角度看，测试时计算要求模型学会把额外 token、采样、工具和验证用于有价值的候选，而不是机械拉长输出；运行时的请求调度算法见 [[../../10_推理算法/04_推理时扩展与计算分配|C.10 推理时扩展与计算分配]]。

## 训练视角

训练可通过搜索轨迹蒸馏、过程监督、可验证奖励或偏好数据，让模型学习何时分解问题、何时调用工具、何时验证和何时停止。若训练只奖励长答案或表面过程，模型可能产生冗长但无效的轨迹。

## 评估指标

| 指标 | 说明 |
|---|---|
| 正确率—预算曲线 | 每增加单位测试时计算带来多少可靠收益 |
| 校准与停止质量 | 模型能否在简单题早停、在不确定题加算 |
| 验证有效性 | 验证器是否真的降低错误而非偏向特定文风 |
| 总成本 | token、工具、搜索节点和端到端延迟 |
