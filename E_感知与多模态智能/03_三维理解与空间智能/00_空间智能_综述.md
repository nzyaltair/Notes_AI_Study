# 空间智能 综述

## 概述

空间智能（Spatial Intelligence）是 AI 系统理解、推理和操作三维空间信息的能力。它连接计算机视觉、机器人学、世界模型和自动驾驶，是多模态 AI 从"看"到"理解空间"的关键跃迁。

## 核心概念

### 空间智能的定义
- 对三维空间的理解与推理能力
- 从2D图像到3D场景的感知与重建
- 空间关系推理（上、下、前、后、内、外）
- 空间导航与操作规划

### 空间智能的层次
```
2D 感知 → 3D 重建 → 空间理解 → 空间推理 → 空间行动
```

## 主要研究方向

### 三维理解与重建
- 多视角立体视觉（MVS）
- 单目深度估计
- 3D 形状恢复
- 场景流估计

### 神经渲染
- **NeRF (Neural Radiance Fields)**
  - 隐式神经表征
  - 体渲染
  - 动态 NeRF
- **3D Gaussian Splatting**
  - 显式点云表征
  - 实时渲染
  - 大场景重建
- **其他方法**
  - SDF (Signed Distance Functions)
  - Neural Volumes
  - Tri-plane 表征

### 场景理解
- 3D 语义分割
- 场景图生成
- 物体位姿估计
- 空间关系检测

### 空间推理
- 空间关系推理（topological, metric, ordinal）
- 导航推理
- 物理空间推理（支撑、遮挡、碰撞）
- 视觉-语言空间推理（SpatialVQA）

### 3D 基础模型
- Point-E / Shap-E
- LRM (Large Reconstruction Model)
- 3D-LLM
- Point cloud foundation models

## 关键技术

### 3D 表征
- 点云（Point Cloud）
- 体素（Voxel）
- 网格（Mesh）
- 隐式表征（NeRF, SDF）
- 混合表征（3DGS, Tri-plane）

### 多视角几何
- 相机模型与标定
- 极线几何
- 结构恢复（SfM）
- 多视角一致性

### 端到端 3D 学习
- 从单图到3D
- 从视频到3D
- 前馈3D重建网络
- 生成式3D模型

## 与 AGI 的关联

空间智能是 AGI 的空间认知基础：
- **机器人操作**：理解物体空间关系才能正确抓取
- **自动驾驶**：理解道路空间结构才能安全行驶
- **世界模型**：空间理解是构建物理世界模型的前提
- **具身导航**：空间智能是环境导航的核心

## 发展趋势

1. 统一 3D 基础模型：一个模型处理所有3D任务
2. 实时神经渲染：3DGS 实现实时渲染与交互
3. 空间推理与语言结合：3D-LLM
4. 从空间智能到世界模型：3D 理解作为世界模型的基础
