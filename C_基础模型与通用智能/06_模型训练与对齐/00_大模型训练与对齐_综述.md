# 大模型训练与对齐综述

## 一句话理解

训练与对齐把“能预测数据”的预训练模型塑造成“能在约束下完成任务”的系统：前者确定知识和能力先验，后者用高质量任务、偏好和可验证反馈塑造行为；二者都不能替代运行时安全控制。

## 范围与边界

本模块以**数据治理 → 预训练 → 监督微调 → 偏好/推理训练 → 安全评测 → 持续适配**为主线。模型架构见 C.02，推理时搜索见 C.08/C.10，分布式系统与训练运维见 [[../../K_AI工程化/02_训练工程/00_训练工程_综述|K 训练工程]]，社会技术治理见 [[../../J_AGI安全与治理/00_AGI安全与治理_综述|J AGI 安全与治理]]。

## 为什么会出现

自回归或自监督损失只要求模型拟合训练分布，不能直接指定有帮助、诚实、安全、格式稳定或可验证的交互行为。后训练以指令、偏好、过程反馈和可验证奖励为信号，但会引入分布偏移、奖励投机、遗忘与偏好代表性等新风险。

## 生命周期

```text
数据治理与配比 → 预训练（末段退火：混入高质量+指令数据）→ 能力评测
                     ↓
            SFT / 拒绝采样 / 合成数据
                     ↓
偏好优化或可验证奖励的强化学习 → 安全评测与发布
                     ↓
           版本化、监测、持续适配与回归评测
```

## 方法取舍

| 方法 | 主要反馈 | 优势 | 主要风险/成本 |
|---|---|---|---|
| SFT | 示范答案 | 稳定、直接、易实现 | 覆盖外泛化和偏好区分有限 |
| RLHF | 人类偏好 + 奖励模型 + RL | 可优化复杂偏好 | 奖励模型误差、RL 不稳定与高资源成本 |
| DPO 类 | 成对偏好 | 不显式训练在线奖励模型 | 受偏好数据和参考策略假设约束 |
| RLAIF | AI 生成/评判反馈 | 扩大反馈规模 | 可能放大教师偏差 |
| 可验证奖励 RL | 程序/规则可验证结果 | 数学、代码等反馈清晰 | 奖励覆盖窄，可能优化捷径 |
| PEFT | 少量可训练参数 | 低资源、多租户适配 | 容量和组合干扰需验证 |

## 评测与安全边界

训练 loss、偏好胜率和单一基准不足以证明对齐。应同时做能力回归、拒答和过度拒答、事实性、越狱/提示注入、隐私、偏差、工具权限和分布外鲁棒性测试，并记录数据版本、训练配方和模型版本。
