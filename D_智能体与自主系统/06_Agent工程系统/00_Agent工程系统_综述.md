# Agent 工程系统

工程系统将自主闭环变为可运行、可观测、可评测、可治理的产品。工作流适合已知控制流；Agent Loop 根据新观察动态选择下一步，两者应组合而非混淆。

本目录关注**LLM Agent 的工程实现**：系统架构、主流框架、运行时、工具接口、编排、检索增强、评测可观测性与安全治理。Agent 的理论基础（理性主体、BDI、认知架构）见 [[../01_智能体理论基础/00_智能体理论基础_综述|D-01 智能体理论基础]]。
