# 仿真平台与实践路线

## 一句话理解

仿真是具身智能数据、训练和评测的主战场，但"仿真成功"与"真机可用"之间有系统性差距。选择平台和设计实验必须同时考虑物理保真度、渲染质量、并行效率、资产生态和评测基准，而非只看某一指标。

## 1. 主要仿真平台对比

| 平台 | 核心定位 | 物理引擎 | GPU 并行 | 视觉质量 | 适用场景 |
|---|---|---|---|---|---|
| MuJoCo | 接触动力学研究 | MuJoCo | 有限 | 基础 | 步态、接触、低层控制 |
| ManiSkill | 通用操作学习 | PhysX/SAPIEN | GPU 并行仿真+渲染 | 中高 | 桌面操作、RL/IL 基线、大规模数据 |
| Isaac Lab (Isaac Sim) | 高保真人形/工业 | PhysX 5 | GPU 大规模并行 | 高 | 人形、四足、工业、高保真渲染 |
| Habitat 3.0 | 室内导航与交互 | Bullet | GPU 并行 | 中高 | 导航、具身问答、家庭任务 |
| Gazebo | ROS 集成仿真 | ODE/Bullet | CPU | 低中 | ROS 开发与集成测试 |
| PyBullet | 轻量研究 | Bullet | CPU | 低 | 快速原型、教学 |
| RoboCasa / Robosuite | 家庭/桌面操作 | MuJoCo | CPU | 中 | 特定场景操作 |

### 选择原则

- **步态/接触动力学**：MuJoCo、Isaac Lab
- **桌面操作 + 视觉 RL/IL**：ManiSkill（GPU 并行 + 内置基线 + 演示数据）
- **人形全身 + 高保真**：Isaac Lab
- **室内导航/交互**：Habitat
- **ROS 2 集成测试**：Gazebo + ROS 2
- **教学/快速原型**：PyBullet

## 2. 评测基准与排行榜

| 基准 | 任务范围 | 评测维度 | 特点 |
|---|---|---|---|
| ManiSkill | 桌面操作（抓放、插入、堆叠等） | 成功率、泛化、RL/IL 效率 | GPU 并行、有演示数据 |
| RLBench | 100+ 桌面任务 | 多任务成功率 | CPU、任务多样 |
| MetaWorld | 50 ML 操纵任务 | 单任务成功率 | 标准化、适合算法对比 |
| Habitat Challenge | 室内 PointNav/ObjectNav | SPL、成功率 | 大规模场景、导航为主 |
| BEHAVIOR-1K | 1000 家居活动 | 任务完成、物理交互 | 长程、语义丰富 |
| CALVIN | 语言条件长程操作 | 任务链完成率 | 语言 + 多步操作 |
| RoboCasa | 家庭日常任务 | 多任务成功率 | 家庭场景 |

**重要提醒**：仿真排行榜高不等于真机能力强。排行榜通常在固定场景和有限变化下评测，不能替代真机的接触、时延、安全和分布外评测。

## 3. 从零上手实践路线

### 阶段一：仿真入门（1–2 周）

1. 安装 MuJoCo + `gymnasium`，运行经典控制（CartPole、Ant）。
2. 安装 ManiSkill，运行一个视觉抓取任务，用内置 PPO/扩散策略基线训练。
3. 理解观测（RGB/深度/点云/本体状态）、动作空间和奖励函数。

### 阶段二：操作学习（2–4 周）

4. 用 ManiSkill 演示数据训练行为克隆策略。
5. 在仿真中实现视觉闭环：检测 → 位姿估计 → 规划 → 执行。
6. 尝试扩散策略或 RL 微调，比较不同方法的数据效率和泛化能力。

### 阶段三：仿真到现实（4–8 周）

7. 在仿真中实施域随机化（纹理、光照、质量、摩擦、相机位姿）。
8. 加入动作时延、传感器噪声和跟踪误差的模拟。
9. 若有真机：从小范围低速任务开始，记录仿真—真机差异并迭代。

### 阶段四：系统集成（持续）

10. 用 ROS 2 连接仿真/真机、感知、策略和控制。
11. 加入碰撞检查、力阈值和紧急停止。
12. 在真机上持续记录和迭代评测分布。

## 4. 仿真—现实差距的工程管理

| 差距类型 | 检测方法 | 缓解策略 |
|---|---|---|
| 视觉外观 | 对比仿真与真实图像特征分布 | 域随机化、真实图像微调 |
| 动力学 | 在仿真中回放真机轨迹，比较误差 | 系统辨识、残差模型 |
| 时延 | 测量端到端仿真与真机时延差异 | 在仿真中注入对应延迟 |
| 传感器噪声 | 分析真机传感器噪声统计 | 在仿真中添加噪声模型 |
| 执行器非线性 | 记录真机回差、饱和和温漂 | 硬件在环测试、残差控制 |

## 5. 常见误区

1. **仿真排行榜 = 真机能力**：仿真评测缺少真实接触、时延和安全约束。
2. **域随机化万能**：随机化范围太大会降低策略性能，太小则不够泛化。
3. **一次迁移成功 = 系统可用**：新物体、新场景和长期运行都可能暴露新问题。
4. **只看成功率**：忽略恢复率、安全事件、时延和能耗的评测不完整。
