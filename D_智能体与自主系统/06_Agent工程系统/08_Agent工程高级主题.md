# Agent 工程高级主题

## 一句话理解

生产级 Agent 系统需要在运行时语义、权限模型、人类监督、记忆可信度、层级化评测、资源预算和可靠性方面建立工程化保障。

## 状态机与执行语义

### 重试策略

- **指数退避**：失败后等待时间指数增长
- **最大重试次数**：防止无限重试
- **幂等性保证**：同一次工具调用重试不应产生副作用
- **重试隔离**：不同工具的重试策略独立配置

### 幂等设计

- 工具调用需支持幂等（idempotent），即多次调用效果等同于一次
- 实现方式：请求 ID 去重、状态检查前置
- 非幂等操作（如发送邮件）需额外确认机制

### 检查点与恢复

- Agent 执行状态周期性保存
- 中断后从最近检查点恢复
- 支持手动干预和回滚

## 权限模型

### 最小权限原则

- Agent 只获得完成任务所需的最小权限
- 工具权限按需分配，不默认全开
- 敏感操作需要额外授权

### 委托链

- 用户 → Agent → 子 Agent → 工具
- 权限沿调用链传递，不越级
- 审计日志记录完整的调用链

## 人类监督

### 监督模式

| 模式 | 适用场景 | 延迟 |
|------|---------|------|
| 事前审批 | 高风险操作 | 高 |
| 事中监控 | 中等风险 | 中 |
| 事后审计 | 低风险操作 | 低 |

### 高风险动作治理

- 修改/删除数据、执行代码、发送消息、支付等
- 需要人类明确确认
- 可设置风险阈值自动触发监督

## 记忆写入可信度

- 记忆来源可信度评估：直接观察 > 推理 > 用户告知
- 记忆写入前验证：交叉验证、置信度阈值
- 记忆污染检测：检测不一致、异常记忆
- 记忆删除机制：用户可删除特定记忆

## 层级化评测

| 层级 | 评测内容 | 工具 |
|------|---------|------|
| 单元测试 | 单个工具调用 | 模拟工具 |
| 集成测试 | 多工具协作 | 沙箱环境 |
| 场景测试 | 端到端任务 | 基准测试 |
| 在线评测 | 生产环境 | A/B 测试 |
| 安全评测 | 对抗性测试 | 红队测试 |

## 经济学与资源预算

- **Token 预算**：每次对话/任务的 token 上限
- **时间预算**：任务超时控制
- **成本预算**：每次调用或每日限额
- **速率限制**：API 调用频率控制
- **预算告警**：接近预算阈值时触发告警

## 可靠性案例与运行时证据链

- **可靠性案例**：文档化系统在何种条件下可靠
- **运行时证据链**：记录每次决策的完整上下文
- **审计日志**：不可篡改的操作记录
- **故障演练**：定期测试系统的故障恢复能力
