# 记忆系统综述：Agent 的经验积累与知识管理

## 一句话理解

记忆系统是 Agent 突破上下文窗口限制、积累和检索经验的核心组件——从短期的工作记忆到长期的向量数据库，记忆让 Agent 从"每次从零开始"进化为"经验可积累"的智能体。

## 1. 领域定义

Agent 记忆系统是对人类记忆的计算模拟，解决 LLM 上下文窗口有限、无法持久存储信息的问题。

### 记忆层级（类比人脑）

| 层级 | 功能 | 持续时间 | AI 实现 |
|------|------|----------|---------|
| 感觉记忆 | 瞬时感知 | < 1s | 原始观测缓冲 |
| 工作记忆 | 临时加工 | 分钟级 | 上下文窗口 |
| 短期记忆 | 近期交互 | 小时级 | 对话历史 |
| 长期记忆 | 持久知识 | 永久 | 向量数据库/知识库 |
| 情景记忆 | 具体经历 | 永久 | 经验回放存储 |

## 2. 核心架构

### 2.1 记忆类型

| 类型 | 存储 | 检索 | 更新 | 代表 |
|------|------|------|------|------|
| 缓冲记忆 | 队列 | FIFO | 滑动窗口 | 简单对话历史 |
| 向量记忆 | 向量数据库 | 语义搜索 | 增量插入 | Chroma, Pinecone |
| 结构化记忆 | 知识图谱 | 图查询 | 增删改查 | Neo4j |
| 情景记忆 | 经验日志 | 相似度匹配 | 追加 | Reflexion |
| 程序记忆 | 策略库 | 任务匹配 | 训练更新 | Skill Library |

### 2.2 记忆操作

| 操作 | 描述 | 挑战 |
|------|------|------|
| 写入 | 将信息存入记忆 | 什么值得存？信息压缩 |
| 读取 | 从记忆检索信息 | 查询构建、相关性判断 |
| 更新 | 修改已有记忆 | 一致性维护 |
| 遗忘 | 删除过时记忆 | 遗忘策略（有用的遗忘） |
| 整合 | 跨记忆源融合 | 冲突消解 |

### 2.3 记忆增强生成 (RAG)

| RAG 变体 | 特点 | 适用场景 |
|----------|------|----------|
| Naive RAG | 简单检索+生成 | 基础问答 |
| Advanced RAG | 查询改写+重排 | 复杂查询 |
| Modular RAG | 模块化管线 | 生产系统 |
| Graph RAG | 图结构检索 | 关系推理 |
| Agentic RAG | Agent 驱动检索 | 自主决策 |

## 3. 关键技术

### 3.1 向量数据库

| 系统 | 特点 | 适用场景 |
|------|------|----------|
| Chroma | 轻量开源 | 开发原型 |
| Pinecone | 全托管 | 生产部署 |
| Weaviate | 混合搜索 | 多模态 |
| Qdrant | 高性能 Rust | 大规模 |
| Milvus | 分布式 | 企业级 |

### 3.2 嵌入与索引

- 文本嵌入：OpenAI, BGE, E5
- 多模态嵌入：CLIP, ImageBind
- 索引方法：HNSW, IVF, PQ
- 混合搜索：向量 + 关键词 (BM25)

### 3.3 长上下文 vs RAG

| 方案 | 优势 | 劣势 |
|------|------|------|
| 长上下文 | 无需检索，全量输入 | 计算成本高，注意力稀释 |
| RAG | 按需检索，成本低 | 检索质量瓶颈，信息可能遗漏 |
| 混合 | 兼顾成本和覆盖 | 架构复杂 |

## 4. 发展历史

1. 2020：检索增强生成 (RAG) 概念提出
2. 2022：向量数据库生态爆发
3. 2023：Generative Agents 证明记忆系统对 Agent 的重要性
4. 2024：Graph RAG、Agentic RAG
5. 2025-26：记忆系统成为 Agent 的标准组件

## 5. 与 AGI 的关系

- **持续学习的存储层**：记忆系统是持续学习的"存储基础设施"
- **经验积累**：AGI 需要从经验中学习，记忆是基础
- **认知科学对应**：人脑记忆系统是 AI 记忆设计的参照
- **安全挑战**：记忆可能存储有害信息，需要遗忘机制

## 6. 学习路径

1. 理解记忆层级与认知科学对应
2. 学习向量数据库和嵌入方法
3. 实践 RAG 管线构建
4. 研究 Agent 记忆系统设计
5. 探索持续学习的记忆架构
