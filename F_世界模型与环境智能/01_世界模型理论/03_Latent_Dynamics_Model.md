# 潜在动力学模型

潜在动力学模型先从高维观测学习紧凑状态，再在该空间预测未来。目标是把“视觉上像什么”转为“对行动会产生什么后果”。

## 典型结构

```text
观测 o_t → 编码器 → 后验状态 q(z_t|o_≤t)
动作 a_t ─────────────────────────────→ 转移 p(z_t+1|z_t,a_t)
潜状态 z_t → 解码器/奖励头/价值头 → 重建、回报和终止预测
```

RSSM 将循环确定性状态用于记忆，将随机变量用于多模态未来；训练需兼顾观测或特征预测、奖励预测、KL 约束和多步一致性。

## 设计要点

- **连续或离散潜变量**：连续状态平滑，离散 token 更易与 Transformer 和生成模型结合。
- **一步或多步损失**：只优化一步会导致长期漂移；多步训练更贴近规划需求。
- **动作条件与控制频率**：动作语义、延迟和执行噪声必须进入模型。
- **不确定性**：模型集成、概率输出或扩散轨迹可表示多种未来。

## 评判

低重建误差不是充分证据。优先检查潜状态是否能预测奖励、可分辨可控因素、支持长时域想象，并提升真实闭环任务表现。
