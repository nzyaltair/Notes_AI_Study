# RAG 与 Embedding 运行管理

## 一句话理解

RAG 运行管理覆盖文档摄取、解析、切分、Embedding 模型、索引、重排、权限与刷新策略的全生命周期，任何环节变更都需触发检索与端到端回归评测，每个回答必须能关联知识版本和检索证据。

## 1. RAG 运行管理的挑战

RAG 系统不是"一次构建，永久运行"的静态系统。它面临持续的变更压力：

- **知识更新**：业务文档不断变化，索引需要同步
- **模型升级**：Embedding 模型迭代，向量空间不兼容
- **切分策略调整**：chunk 大小、重叠、策略影响检索质量
- **查询分布漂移**：用户提问方式变化，检索策略需适应
- **权限变更**：文档访问权限动态调整

核心原则：**每个回答必须能关联知识版本和检索证据**，实现可追溯。

## 2. RAG 数据管线

### 2.1 管线阶段

```text
文档源 → 摄取(Ingest) → 解析(Parse) → 切分(Chunk) → 嵌入(Embed)
    → 索引(Index) → 检索(Retrieve) → 重排(Rerank) → 生成(Generate)
```

每个阶段都是独立的版本化单元，变更需追踪和评测。

### 2.2 文档摄取

| 维度 | 管理要点 |
|:---|:---|
| 数据源 | API、爬虫、文件系统、数据库 |
| 拉取频率 | 实时 / 定时批量 / 事件触发 |
| 去重 | URL 级、内容 hash 级去重 |
| 增量检测 | 基于 hash、修改时间、版本号 |

### 2.3 解析与切分

- **解析器**：PDF、Word、HTML、Markdown 等格式解析，保留结构信息
- **切分策略**：
  - 固定长度切分（简单但可能截断语义）
  - 按段落/标题切分（保留结构）
  - 语义切分（基于 Embedding 相似度）
- **元数据保留**：来源、标题、页码、权限标签

### 2.4 Embedding 与索引

- **模型版本绑定**：向量索引必须记录 Embedding 模型版本
- **维度管理**：不同模型输出维度不同，索引需对应
- **索引类型**：HNSW、IVF、Flat 等，影响召回速度与精度

## 3. 检索质量监控

### 3.1 核心指标

| 指标 | 说明 | 目标 |
|:---|:---|:---|
| 召回率 (Recall@K) | Top-K 结果中包含正确答案的比例 | ≥ 0.90 |
| NDCG | 排序质量，正确答案排名越前越高 | ≥ 0.85 |
| 无答案率 | 检索结果为空或质量过低的比率 | ≤ 0.05 |
| 检索延迟 | P95 查询延迟 | ≤ 200ms |
| 上下文命中率 | 检索内容被生成模型引用的比例 | ≥ 0.70 |

### 3.2 Embedding 漂移检测

用户查询分布会随时间变化：

- **查询向量分布**：监控查询向量的统计特征（均值、方差）
- **相似度分布**：查询与检索结果的相似度分布变化
- **低置信查询**：相似度低于阈值的查询比例上升时告警

### 3.3 端到端评测

检索指标好不代表端到端质量好，需评测：

- **答案准确性**：生成的答案是否基于检索内容
- **忠实度 (Faithfulness)**：答案是否与检索内容一致，无幻觉
- **答案相关性**：答案是否真正回答了用户问题

## 4. 知识库更新策略

### 4.1 全量重建

- **触发条件**：Embedding 模型升级、切分策略变更
- **流程**：新索引构建 → 双写验证 → 切换流量 → 旧索引保留
- **风险**：构建时间长，需规划资源

### 4.2 增量更新

- **触发条件**：文档新增、修改、删除
- **流程**：检测变更 → 增量嵌入 → 更新索引
- **风险**：碎片化、索引质量下降，需定期全量重建

### 4.3 双写与切换

```text
旧索引 (v1)          新索引 (v2)
    ↑                     ↑
    | 查询流量             | 构建中
    |                     |
    +----- 双写验证 -------+
              ↓
         质量达标 → 切换流量 → 旧索引保留(回滚用)
```

## 5. 权限与安全

- **文档级权限**：检索结果需按用户权限过滤
- **元数据过滤**：在向量检索前/后按权限标签过滤
- **审计日志**：记录谁检索了什么内容
- **敏感数据脱敏**：索引前对敏感信息进行脱敏处理

## 6. 版本管理与回滚

| 版本单元 | 版本内容 | 回滚方式 |
|:---|:---|:---|
| 知识库版本 | 文档集快照 | 切换索引指针 |
| Embedding 模型 | 模型 ID + 维度 | 切换索引 |
| 切分策略 | chunk 参数 + 解析器 | 重建索引 |
| 重排模型 | 模型 ID + 参数 | 配置切换 |
| 检索配置 | Top-K、相似度阈值 | 配置切换 |

## 7. 常见问题

- **索引膨胀**：增量更新导致索引碎片化，需定期全量重建
- **模型不兼容**：Embedding 模型升级后旧向量无法使用，需全量重建
- **权限泄漏**：检索结果未按权限过滤，导致信息泄漏
- **证据缺失**：生成答案未关联检索来源，无法追溯
- **冷启动**：新文档未被及时索引，导致检索遗漏
