# AI 科学家与自动化科学发现

## 一句话理解

AI 科学家系统面向"提出可证伪假设—设计实验—获取/分析证据—修订模型—报告局限"的研究闭环，用自动化提升科学发现的吞吐量，但科研价值取决于证据质量而非论文文本生成。

## 研究闭环

```text
文献与数据 → 假设生成 → 实验规划 → 执行 → 统计分析 → 结果复核 → 报告与溯源
    ↑                                              ↓
    └──────────────── 修订模型与假设 ←──────────────┘
```

## 系统模块

| 模块 | 功能 | 挑战 |
|---|---|---|
| 文献与数据检索 | 获取已有知识与数据 | 时效性、来源可信度 |
| 假设生成 | 提出可证伪假设 | 新颖性 vs 可验证性 |
| 实验规划 | 选择实验设计 | 资源约束、对照控制 |
| 代码/仪器执行 | 运行实验 | 环境隔离、可复现性 |
| 统计分析 | 检验假设 | 多重比较、p 值滥用 |
| 结果复核 | 交叉验证结论 | AI 自评偏差 |
| 溯源记录 | 记录完整过程 | 中间步骤丢失 |

## 代表系统

- **AI Scientist (Sakana AI)**：LLM 驱动假设生成-实验-论文写作闭环，产出研究论文；其价值在于流程自动化示范，论文质量与新颖性仍是开放问题。
- **AlphaFold**：预测蛋白质结构，是"AI 辅助科学发现"的里程碑（自动化机器学习求解具体科学问题）。
- **MLAgentBench**：评估 LLM Agent 在机器学习研究任务（调参、改代码、跑实验）上的表现。
- **AutoML4Science**：把 AutoML 用于科学数据建模。

## 关键原则

- **证据质量 > 论文数量**：AI 生成的论文若不伴随可验证的实验证据与代码，不具有科学价值。
- **AI 不能自评**：AI 生成假设、运行实验、又自我评价，形成闭环偏差——需要独立验证与人类审批（对应 [[../../08_研究方法与证据评估/03_统计显著性与可靠性]] 与 [[../../08_研究方法与证据评估/05_可复现性与负结果]]）。
- **安全边界**：高风险领域（生物、化学）必须遵守实验权限、数据治理和安全规范。

## 前沿发展

- **实验室自动化**：机器人 + AI 的闭环实验（材料、合成生物学）。
- **负结果与失败报告**：自动化系统可系统性记录失败，缓解"文件抽屉效应"。
- **可证伪性与可复现性内置**：把统计检验与复现协议嵌入流水线。
