# 推理与决策机制综述：从内部模型到受约束行动

## 一句话理解

推理把表征、记忆和规则转化为关于世界的结论；决策则在目标、不确定性、成本与风险之间选择行动。AGI 需要的不是无限思考，而是在恰当时刻以可校准的方式推演、查询、行动或求助。

## 推理与决策闭环

```text
观测与记忆 → 状态/假设 → 推演与预测 → 评估效用、风险、信息价值
     ↑                                                  ↓
     └────────────── 执行、反馈、修正与学习 ←─────────────┘
```

## 推理类型与作用

| 类型 | 解决的问题 | AI 对应 |
|---|---|---|
| 演绎推理 | 给定规则推出必然结论 | 约束求解、程序验证、形式推理 |
| 归纳推理 | 从样本概括规律 | 统计学习、模式发现 |
| 溯因推理 | 为证据寻找最佳解释 | 诊断、假设生成、科学发现 |
| 因果推理 | 区分相关、干预与反事实 | 因果模型、世界模型、规划 |
| 概率推理 | 在不确定条件下更新信念 | 贝叶斯更新、校准与风险估计 |

## 决策的关键维度

决策需要明确目标或偏好、可行动作、状态不确定性、行动后果、资源成本和安全约束。人类决策存在启发式与系统性偏差；这既提示 AI 不应把人类行为直接当作最优规范，也提供了研究有限计算条件下策略选择的实验范式。
