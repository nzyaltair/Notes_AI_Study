# 规范问题与分布偏移

## Specification Problem
人类期望不能被无损压缩为奖励函数、提示词或标注集。系统会优化可测量的代理指标，而不是未被表达的真实意图。

```text
真实意图 ≠ 书面规则 ≠ 奖励信号 ≠ 模型实际优化对象
```

## 常见形式

- **Reward Hacking**：通过捷径提高奖励，不完成任务实质。
- **Specification Gaming**：利用规则漏洞满足字面约束。
- **Goodhart 定律**：指标一旦成为目标，就不再是可靠指标。
- **目标误泛化**：训练中表现正确，但在新情境采用错误的学习规则。
- **副作用忽略**：完成主目标时损害未被纳入目标的资源或权益。

## 分布偏移

| 类型 | 含义 | 控制 |
|---|---|---|
| 协变量偏移 | 输入特征分布变化 | OOD 检测、覆盖数据 |
| 标签/概念偏移 | 输出关系或规则变化 | 再训练、版本化规则 |
| 环境偏移 | 工具、用户、制度改变 | 灰度、仿真、监控 |
| 对抗偏移 | 对手专门构造输入 | 红队、鲁棒训练、隔离 |

## 工程含义

在部署前列出“不应做什么”、不确定时的保守策略和不可接受后果；部署后以漂移检测、用户申诉、审计样本和回归测试持续修正规范。对于高影响行动，不可仅依赖模型自述“理解了规则”。
