# 选择性注意与主动感知

## 一句话理解

选择性注意解决“先处理什么”，主动感知进一步解决“下一步该做什么以获得最有价值的信息”；后者使感知成为规划和控制的一部分。

## 从选择到行动

```text
任务目标与不确定性
        ↓
选择当前最有价值的信息源
        ↓
观察 / 移动视角 / 调用工具 / 提问
        ↓
更新状态估计与后续决策
```

## 设计问题

- **注意目标**：显著性、任务相关性、预测误差或信息价值哪一个应主导？
- **行动成本**：获取信息需要时间、算力、工具权限或物理运动，不能无限观察。
- **停止条件**：何时已有足够证据可以行动，何时应继续探索？
- **失败模式**：过度聚焦会漏掉关键线索；无约束探索会浪费资源或造成风险。

## AI 实例

| 场景 | 主动感知动作 | 合理指标 |
|---|---|---|
| 网页 Agent | 搜索、打开页面、请求澄清 | 成功率、调用成本、事实性 |
| 机器人 | 调整视角、触碰、重新定位 | 不确定性下降、任务成功、安全 |
| 科学发现 Agent | 选择实验或查询 | 信息增益、实验预算、可复现性 |
