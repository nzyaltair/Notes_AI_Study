# Foundation Model 定义与统一视角

基础模型是在宽泛数据上以可扩展目标预训练、并可通过提示、上下文、微调或外部工具适应大量下游任务的模型。它不是“大参数量”的同义词；核心是**可迁移的预训练先验与广泛适应能力**。

## 统一视角

\[
\text{数据分布} + \text{预训练目标} + \text{模型归纳偏置} + \text{规模化} \Rightarrow \text{可迁移表示与行为先验}
\]

语言、视觉、多模态、世界与行动基础模型是这一范式在不同观测和输出空间中的实例。模型是否具有通用能力，取决于数据覆盖、目标、评测与适配机制，不仅取决于参数量。
