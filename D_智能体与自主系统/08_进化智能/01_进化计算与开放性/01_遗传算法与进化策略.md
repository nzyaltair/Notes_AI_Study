# 遗传算法与进化策略

## 一句话理解

进化计算通过种群采样估计搜索方向，不要求目标函数可微——遗传算法（GA）重组离散编码，进化策略（ES）在连续参数空间采样扰动，CMA-ES 用协方差自适应处理变量相关性——它们共同构成了"无梯度优化"的核心工具箱。

## 概述

梯度下降是深度学习时代最常用的优化方法，但它的适用范围有限：目标函数必须可微（或至少可有效估计梯度）。在策略搜索、超参数调优、结构设计、组合优化等大量问题中，目标函数要么不可微，要么梯度计算代价过高。进化计算通过**种群采样→评估适应度→选择→变异**的循环，仅使用目标函数值就能搜索优化空间，是梯度方法的天然补充。

[[../00_进化智能_综述|进化智能综述]] 提到"进化适合黑盒与不可微目标，但真实工具评估昂贵"，本笔记聚焦进化计算的核心方法：遗传算法、进化策略和 CMA-ES，以及它们在实际应用中的适应度设计原则。

## 发展历史

| 年代 | 里程碑 | 意义 |
|:---|:---|:---|
| 1960s | 进化策略（Rechenberg） | 首次提出在连续空间用变异+选择优化 |
| 1975 | 遗传算法（Holland） | GA 的系统化奠基，引入交叉和选择算子 |
| 1989 | 遗传编程（Koza） | 用 GA 进化计算机程序 |
| 1996 | CMA-ES（Hansen） | 协方差自适应，处理变量相关性的进化策略 |
| 2000s | 进化多目标优化 | NSGA-II、MOEA/D 等 |
| 2017 | OpenAI ES（Salimans et al.） | 进化策略规模化，可与深度 RL 竞争 |
| 2020s | 进化计算在 LLM 中应用 | 进化提示优化、奖励模型进化 |

## 核心概念

### 进化计算的基本要素

- **种群（Population）**：一组候选解，每个解称为一个个体（individual）
- **适应度（Fitness）**：目标函数值，衡量个体在任务中的表现
- **选择（Selection）**：根据适应度选择"更优"的个体作为父代
- **交叉（Crossover）**：将两个父代个体的编码组合产生子代
- **变异（Mutation）**：随机修改子代个体的部分编码，引入新变化
- **代（Generation）**：一次完整的"评估→选择→交叉→变异→替换"循环

### 遗传算法 vs. 进化策略

| 维度 | 遗传算法（GA） | 进化策略（ES） |
|:---|:---|:---|
| 编码 | 离散（二进制串、排列等） | 连续（实数向量） |
| 核心算子 | 交叉（主要）+ 变异（次要） | 变异（主要）+ 重组（辅助） |
| 选择方式 | 轮盘赌/锦标赛 | (μ+λ) 或 (μ,λ) 截断选择 |
| 适用场景 | 组合优化、离散搜索 | 连续优化、策略搜索 |
| 理论基础 | 模式定理（Schema Theorem） | 自然进化策略（NES） |

### CMA-ES

CMA-ES（Covariance Matrix Adaptation Evolution Strategy）是进化策略中最成功的变体之一，核心思想是**自适应地学习变量之间的相关性**：

- 维护一个**均值向量**（当前最优解的位置估计）和**协方差矩阵**（变量相关性的估计）
- 每代从多元正态分布 $\mathcal{N}(\mu, \sigma^2 C)$ 中采样新个体
- 根据适应度排序更新均值和协方差矩阵
- 协方差矩阵的更新使搜索方向自动适应问题的局部几何结构

CMA-ES 的优势在于：**旋转不变性**（对变量缩放和旋转不敏感）、**自动步长调整**（无需手动调参）、**适用于非凸、非平滑、多模态问题**。

## 技术原理

### 适应度设计原则

适应度函数是进化计算的"目标函数"，设计直接决定搜索方向：

$$ F = \text{task quality} - \lambda_1 \cdot \text{cost} - \lambda_2 \cdot \text{risk} + \lambda_3 \cdot \text{novelty} $$

适应度设计的关键原则：

1. **适应度是规范而非真理**：适应度函数反映的是"我们认为什么好"，不一定是"真正的好"
2. **避免奖励黑客**：若只奖励最终分数，种群可能利用漏洞获得高分而不解决真实问题
3. **多目标权衡**：使用 Pareto 前沿（NSGA-II）或多目标聚合，而非单一加权和
4. **约束处理**：对违反约束的个体给予惩罚，或使用约束支配关系

### 进化策略在 Agent 中的应用

进化策略可用于优化 Agent 的以下组件：

| 组件 | 编码方式 | 评估方式 |
|:---|:---|:---|
| 提示模板 | 离散（文本变异） | 在评测集上执行 Agent |
| 工具策略 | 连续（参数化策略） | 在模拟环境中执行 |
| 工作流 | 离散（DAG 结构） | 端到端任务成功率 |
| 技能组合 | 离散（技能选择） | 组合效果评估 |
| 奖励权重 | 连续（权重向量） | RL 训练效果 |

## 关键方法与模型

| 方法 | 核心思想 | 适用场景 |
|:---|:---|:---|
| Genetic Algorithm (GA) | 二进制编码 + 交叉/变异 | 组合优化、离散搜索 |
| Evolution Strategy (ES) | 连续扰动 + 截断选择 | 连续优化、策略搜索 |
| CMA-ES | 协方差矩阵自适应 | 非凸连续优化，强基线方法 |
| Genetic Programming | 树结构编码 + 进化 | 程序合成、符号回归 |
| NSGA-II | 非支配排序 + 拥挤度 | 多目标优化 |
| OpenAI ES | 动差法 ES + 大规模并行 | 深度 RL 策略优化 |

## 优势与局限

**优势**：不需要梯度信息，适用于任意可评估的目标函数；种群保持多样性，适于多模态优化；天然适合并行化（每代评估可完全并行）；CMA-ES 等方法的稳态性能（最终收敛质量）通常优于梯度方法。

**局限**：评估效率低——需要大量目标函数评估，在真实评估成本高的场景中受限；高维问题中搜索效率下降（维度诅咒）；缺乏理论保证——不像梯度方法有收敛性证明；超参数敏感——种群大小、变异率等对性能影响大。

## 应用场景

- **策略搜索**：用进化策略优化 RL 策略参数，作为无梯度 RL 替代方案
- **神经架构搜索**：用进化方法搜索最优网络结构（NAS）
- **超参数优化**：CMA-ES 在 ML 超参数调优中是最强基线之一
- **Agent 提示优化**：用进化方法自动搜索最优提示模板
- **组合优化**：GA 在旅行商、调度等组合优化问题中的应用

- **大规模分布式进化**：利用云计算并行评估，大幅提升进化计算效率

## 常见问题

**Q: 进化策略和强化学习比，哪个更好？**
不是谁好谁坏，而是各自适用场景不同。进化策略适合：目标函数不可微、评估可完全并行化（如模拟器）、策略空间维度不太高。强化学习适合：有稠密奖励信号、需要在线调整、状态空间和动作空间连续且高维。

**Q: CMA-ES 为什么被称为"最强无梯度优化方法"？**
因为 CMA-ES 的协方差自适应机制使其对问题的局部几何结构有很强的适应性，在大多数标准基准测试（如 COCO/BBOB）中，CMA-ES 的稳态性能优于其他无梯度优化方法。
