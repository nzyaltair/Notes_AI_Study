# 感知行动接口综述

> 感知的终点不是“看见”，而是向决策系统提供可行动、可更新、可验证的状态。

## 接口闭环

```text
任务目标/行动 → 主动选择观测 → 多模态编码与融合 → 状态估计 → 规划/控制 → 环境反馈
```
