# 规划与搜索综述：Agent 如何制定行动策略

## 一句话理解

规划是 Agent 将目标分解为可执行动作序列的核心能力——从简单的前向搜索到蒙特卡洛树搜索，从经典 HTN 规划到 LLM 驱动的推理规划，搜索与规划是"思考后行动"的数学基础。

## 1. 领域定义

规划（Planning）是寻找从初始状态到目标状态的行动序列。搜索（Search）是在状态空间中寻找满足约束的路径。二者是 Agent 决策的核心算法：

```
目标 → 分解 → 子目标 → 搜索行动 → 执行 → 观察反馈 → 修正
```

## 2. 经典规划方法

### 2.1 确定性规划

| 方法 | 核心思想 | 代表 |
|------|----------|------|
| 前向搜索 | 从初始状态向前展开 | BFS, DFS, A* |
| 后向搜索 | 从目标状态回溯 | Goal Regression |
| 状态空间搜索 | 在状态图中搜索 | STRIPS, PDDL |
| 计划空间搜索 | 在计划空间中搜索 | Partial Order Planning |

### 2.2 层次任务网络 (HTN)

- 将高层任务递归分解为低层动作
- 方法（Method）：任务 → 子任务序列
- 与 LLM 规划的天然对应：自然语言指令分解

### 2.3 时序与资源规划

- 时态规划（Temporal Planning）：动作有持续时间
- 资源约束规划：有限资源分配
- 调度问题（Scheduling）

## 3. 搜索算法

### 3.1 无信息搜索

| 算法 | 策略 | 最优性 |
|------|------|--------|
| BFS | 宽度优先 | 是（等代价） |
| DFS | 深度优先 | 否 |
| UCS | 代价优先 | 是 |
| IDS | 迭代加深 | 是 |

### 3.2 有信息搜索

| 算法 | 启发式 | 特点 |
|------|--------|------|
| A* | f(n) = g(n) + h(n) | 最优（启发式可容许） |
| Beam Search | 宽度受限 | 高效但次优 |
| IDA* | 迭代加深 A* | 空间高效 |

### 3.3 蒙特卡洛树搜索 (MCTS)

核心四步循环：选择 → 扩展 → 模拟 → 回溯

| 变体 | 改进 | 应用 |
|------|------|------|
| UCT | UCB1 选择策略 | 通用 |
| AlphaGo MCTS | + 价值网络 + 策略网络 | 围棋 |
| PUCT | 策略引导 UCB | AlphaZero |
| LLM + MCTS | LLM 策略引导 | 推理规划 |

### 3.4 LLM 时代的搜索推理

| 方法 | 搜索结构 | 代表 |
|------|----------|------|
| CoT | 链式 | Wei et al. |
| ToT | 树搜索 | Yao et al. |
| GoT | 图搜索 | Besta et al. |
| Reflexion | 搜索+反思 | Shinn et al. |
| LATS | 语言 Agent 树搜索 | Zhou et al. |

## 4. 与 AGI 的关系

- **Agent 核心能力**：规划是 Agent 从"感知"到"行动"的桥梁
- **推理的延伸**：规划 = 推理在行动空间的应用
- **持续学习的需求**：好的规划需要世界模型来预测行动后果
- **复杂任务的基础**：AGI 需要处理长程、多层次的任务规划

## 5. 学习路径

1. 理解经典搜索算法（A*, BFS/DFS）
2. 学习 MCTS 的四步循环
3. 理解 HTN 层次规划
4. 研究 LLM + 搜索推理（ToT, GoT）
5. 探索规划 + 世界模型的结合
