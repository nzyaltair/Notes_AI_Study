# 认知架构与 AGI 系统架构

## 一句话理解

认知架构研究如何把感知、记忆、推理、规划、行动与学习组织成可持续运行的闭环系统；它不是模块清单，而是关于模块接口、控制权与学习信号的设计理论。

## 架构问题

AGI 架构不是把更多模块拼接在一起，而是定义模块的表示接口、控制权、学习信号及验证闭环。一个最小闭环包括：感知与编码、工作记忆、长期记忆、世界模型、推理规划、执行器、学习器和安全约束。

## 设计原则

1. **分层与可组合**：概念、技能、计划在不同时间尺度工作。
2. **模型化控制**：行动前预测后果，行动后利用误差更新（对应 [[../../F_世界模型与环境智能/00_世界模型综述]] 的模型驱动路线）。
3. **检索、推理、验证分工**：避免将事实记忆、候选生成和正确性判断混为一谈。
4. **持续学习**：保存可复用知识，限制灾难性遗忘与错误累积。
5. **可治理性**：权限、资源、目标修改和自我改进必须受边界约束。

## 代表路线

| 路线 | 核心机制 | 代表系统 | 对 AGI 的启示 |
|---|---|---|---|
| 符号认知架构 | 产生式规则 + 工作记忆 + 学习机制 | SOAR、ACT-R | 可组合、可解释的认知闭环 |
| 全局工作空间理论 | 无意识并行处理竞争进入全局广播 | GWT | 注意与信息整合的架构解释 |
| 预测处理 | 层级预测误差最小化 | 预测编码网络 | 感知与行动统一于预测 |
| 世界模型 Agent | 学习环境模型并想象规划 | Dreamer、MuZero | 用模型压缩经验并模拟后果 |
| LLM+工具+记忆 | 语言模型为核心，外接工具与记忆系统 | ReAct、MemoAgent 等 | 当代 Agent 的工程实现 |

## 优势与局限

- **符号认知架构**：解释性强、组件可替换，但知识获取与感知接口长期未解决。
- **全局工作空间**：为注意与信息整合提供机制假设，但缺乏统一的学习理论。
- **预测处理**：统一感知、行动与学习，但难以处理高层语义与长期规划。
- **世界模型 Agent**：在 RL 与规划任务中实证成功，但模型误差随规划深度累积。
- **LLM 系统**：语言能力强、易部署，但事实幻觉、长程目标保持与自我校正确认不足。

## 前沿发展

- **架构融合**：将世界模型、记忆、反思与工具调用纳入 LLM 为核心的 Agent 框架，形成"生成-执行-验证"闭环。
- **具身化**：把认知架构放入物理环境，验证感知-行动闭环（见 [[../../G_具身智能与物理智能/00_具身智能综述]]）。
- **可评测架构假设**：通过纵向任务与能力矩阵检验不同架构的实证差异，而非停留在理论争论。
