# 视觉 Transformer 与可扩展架构

## 一句话理解

视觉 Transformer（ViT）把图像编码为 patch token 并以注意力建模全局关系；其可扩展性来自统一的序列接口，代价是高分辨率下注意力计算与较弱局部归纳偏置。

## 核心机制

将图像切为 \(N\) 个 patch，并投影为 token：

\[
z_0=[x_1E;\ldots;x_NE]+p.
\]

标准全局注意力随 \(N^2\) 增长，高分辨率图像和视频会迅速增加显存与计算。因此视觉架构通常在全局建模、局部先验和 token 数之间取舍。

## 架构比较

| 架构 | 关键设计 | 优势 | 主要限制 |
|---|---|---|---|
| ViT | 全局 patch 注意力 | 统一、易扩展 | 训练数据需求高，分辨率成本高 |
| DeiT | 蒸馏与训练配方 | 中等数据下更易训练 | 主干仍有全局注意力成本 |
| Swin | 窗口注意力与层级特征 | 密集预测与多尺度效率好 | 全局交互需跨窗口机制 |
| 混合 CNN—Transformer | 卷积局部特征 + 注意力 | 兼顾归纳偏置和全局关系 | 设计与部署复杂度提高 |

## 实践选择

分类和大规模预训练常采用 ViT；检测、分割等多尺度任务常用层级结构；视频模型还需时间 token 压缩或局部时空注意力。架构优劣必须在相同训练数据、分辨率和计算预算下比较。
