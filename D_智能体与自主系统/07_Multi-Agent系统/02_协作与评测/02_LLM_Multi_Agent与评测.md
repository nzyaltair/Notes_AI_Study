# LLM Multi-Agent 与评测

LLM 多智能体常用主管—执行者、辩论、流水线或并行候选架构。其实际价值来自信息、工具或评估视角的互补，而不是让同一模型重复对话。

## 常见失效

- 所有 Agent 共享同一错误先验，形成“多数幻觉”。
- 角色文本很长但没有独立工具、状态或验收标准。
- 讨论无法终止，成本高于单 Agent 搜索或验证。
- 协调者无法归因，导致重复、遗漏或越权。

## 评测

除端到端成功率外，测量协作增益相对单 Agent 基线、通信 token、任务分配正确率、冲突解决、并发效率、鲁棒性和安全违规。消融每个角色、工具和通信边，避免把规模效应误判为协作效应。
