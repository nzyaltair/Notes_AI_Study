# 机器人强化学习

## 一句话理解

强化学习通过最大化长期回报学习策略，特别适合步态、动态平衡、稠密接触和难示范行为；但真机样本昂贵且探索可能危险，工程上以"仿真训练 + 域随机化 + 受限真机微调"为主路线。

## 概述

机器人强化学习（Robot RL）让机器人通过试错与环境交互学习策略，无需人工设计每步动作。它擅长模仿学习难以覆盖的场景：动态平衡（四足、人形）、长程回报任务、复杂接触（在手操作）。核心瓶颈是样本效率与安全——真实交互成本高，危险探索可能损坏硬件或伤害人。

## 发展历史

- **1990s**：经典 RL 机器人应用（Q-learning 倒立摆）；Policy Gradient 方法萌芽。
- **2010s**：深度 RL 突破——DQN（2013）、DDPG（2015）、PPO（2017）、SAC（2018）；端到端视觉运动策略（Levine 2016）出现。
- **2015-2018**：真机 RL 探索（OpenAI 灵巧手解魔方 2019）；仿真训练 + sim-to-real 成为主流（域随机化，OpenAI 抓取 2017）。
- **2020s**：四足/人形运动 RL 成熟（Unitree 步态）；RLPD（RL + 示范数据混合）提升样本效率；世界模型辅助 RL（DreamerV3）。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| MDP | \((S,A,P,R,\gamma)\) 决策过程 | RL 的问题框架 |
| 策略 | \(\pi(a\mid s)\) 状态到动作映射 | 学习目标 |
| 回报 | \(\sum_t \gamma^t r_t\) | 优化目标 |
| 价值函数 | 状态（动作）的期望回报 | 策略评估 |
| 探索-利用 | 尝试未知 vs 利用已知 | RL 核心权衡 |
| 奖励塑造 | 设计中间奖励引导学习 | 双刃剑 |
| 安全约束 | 力/速度/碰撞约束 | 真机部署前提 |

## 技术原理

### 问题形式化

机器人 RL 目标是最大化期望回报：

$$\max_\pi \mathbb E_{\pi}\left[\sum_{t=0}^{T}\gamma^t r_t\right]$$

实际机器人问题常是部分可观测（POMDP）：观测 \(o_t\) 是图像/关节角，状态 \(s_t\) 不完全可见。深度 RL 直接学习观测到动作的映射 \(\pi_\theta(o_t)\)。

### 主要算法族

| 算法 | 类型 | 特点 | 适用 |
|---|---|---|---|
| PPO | on-policy, actor-critic | 稳定、鲁棒、易调 | 运动控制、仿真 RL |
| SAC | off-policy, 最大熵 | 样本高效、探索好 | 操作、需要效率 |
| DDPG/TD3 | off-policy, 确定性 | 连续控制 | 需要平滑动作 |
| DrQ-v2 | 图像输入 off-policy | 视觉 RL 高效 | 图像操作 |
| DreamerV3 | 世界模型 + actor-critic | 想象中训练 | 稀疏奖励、长程 |
| RLPD | 示范 + 离线 + 在线混合 | 样本高效 | 真机微调 |

### 奖励设计

奖励应覆盖任务、能耗、平滑性、碰撞与安全：

$$r_t = r_{task} + \alpha r_{smooth} - \beta r_{collision} - \gamma r_{energy}$$

常见问题：
- **奖励投机（Reward Hacking）**：策略发现未设计的捷径（推倒物体而非抓取）。
- **稀疏奖励**：任务完成才有奖励，探索困难——需要课程、辅助奖励或示范。
- **奖励塑形偏差**：中间奖励引导到次优行为。

### 安全与探索

真机探索可能危险，工程策略：

1. **仿真优先**：在仿真中训练大部分策略。
2. **域随机化**：随机化物理参数（质量、摩擦、延迟）提升泛化。
3. **安全盾**：独立于策略的安全层（力矩限制、急停、碰撞检查）。
4. **受限探索**：动作限幅、速度限制、工作空间约束。
5. **示范初始化**：RLPD 用示范数据引导探索。

### 工程路线

```text
仿真/离线数据/示范初始化
→ 域随机化训练受约束策略
→ 低速受限场景真机验证
→ 安全盾 + 限幅 + 人工接管下的有限微调
→ 回归测试与部署
```

## 关键方法与模型

| 方法 | 核心思想 | 代表性应用 |
|---|---|---|
| PPO | 裁剪目标稳定策略更新 | 四足/人形运动 |
| SAC | 最大熵 + off-policy | 灵巧操作 |
| DrQ-v2 | 图像增强 + off-policy | 视觉操作 |
| DreamerV3 | 世界模型想象训练 | 稀疏奖励任务 |
| Domain Randomization | 物理参数随机化 | Sim2Real |
| RLPD | 示范数据混合 | 真机高效微调 |
| APPO/IMPALA | 大规模并行 | 仿真规模化 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 动态控制 | 超越手工设计 | 需要精准回报 |
| 长程任务 | 优化长期回报 | 信用分配困难 |
| 复杂接触 | 学习力控策略 | 探索危险 |
| 泛化 | 域随机化提升 | 分布外脆弱 |
| 样本效率 | 现代算法提升 | 仍远高于 BC |

## 应用场景

- 四足机器人动态步态（跑、跳、抗扰动）。
- 人形机器人平衡与行走。
- 灵巧操作（在手操作、解魔方）。
- 装配与插拔（接触 RL）。
- 无人机机动飞行。

## 前沿发展

- **世界模型 RL**：DreamerV3 在想象环境中训练，样本效率大幅提升。
- **基础模型辅助 RL**：VLM 提供奖励信号（奖励来自语言反馈）。
- **真机 RL 规模化**：并行真机集群（Google SayCan 后路线、Figure RL）。
- **多机器人并行**：分布式 RL 在仿真中规模化（Isaac Lab）。
- **安全 RL**：约束策略优化（CPO）、安全层（Safety Gym）。

## 常见问题

- **把仿真回报当真机能力**：必须报告真机交互次数、扰动恢复、约束违反率。
- **忽略奖励投机**：评测要防止策略钻奖励空子。
- **探索无边界**：必须受安全约束。
- **不做分布泛化测试**：跨环境泛化才是 RL 的价值。
