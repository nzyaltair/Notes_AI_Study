# 目标检测

## 一句话理解

目标检测（Object Detection）是计算机视觉中结合“定位（Where）”与“分类（What）”的联合任务，通过输出边界框（Bounding Box）与类别置信度，实现对图像中多个特定物体的准确定位与识别。

## 1. 概述

目标检测不仅要识别图像中有哪些物体，还要准确定位它们在图像空间中的几何位置。输出通常为一组 $(bbox, class, confidence)$ 三元组，其中边界框通常用矩形坐标 $(x_1, y_1, x_2, y_2)$ 或 $(x, y, w, h)$ 表示。

作为计算机视觉的核心支撑技术，目标检测广泛应用于自动驾驶（车辆与行人识别）、安防监控（入侵检测与人脸识别）、工业质检（缺陷定位）以及机器人操作等领域。关于底层卷积神经网络（CNN）特征提取架构，参见 [[03_图像分类]]。

## 2. 发展历史（视觉目标检测30年演进）

根据何恺明在 NeurIPS 2025 演讲《视觉目标检测30年 / 视觉目标检测简史》的系统梳理，目标检测的发展历程经历了从**手动特征工程**到**深度卷积表示**，再到**无锚框/集合预测**与**开放词汇大模型**的多次核心范式转移（Paradigm Shifts）：

```
传统特征+滑动窗口 (1990s-2013) 
   ↓ [范式转移：深度卷积表达与候选区域]
两阶段检测 & 区域提议 (2014-2017, R-CNN / Faster R-CNN / Mask R-CNN)
   ↓ [范式转移：单阶段极速回归 & Anchor-Free]
单阶段 & 无锚框检测 (2015-2019, YOLO / SSD / Focal Loss / FCOS)
   ↓ [范式转移：Transformer 集合预测与无 NMS]
Transformer & 端到端匹配 (2020-2023, DETR / Deformable DETR / DINO)
   ↓ [范式转移：开放词汇与多模态 Grounding]
开放词汇 & 基础检测模型 (2022-Present, Grounding DINO / SAM / OWL-ViT)
```

| 发展时期 | 代表方法 | 核心思想 / 机制 | 范式转移意义 |
|:---|:---|:---|:---|
| **第一时期：手工特征与滑动窗口 (1990s-2013)** | Viola-Jones (2001)<br>HOG+SVM (2005)<br>DPM (2008) | Haar 级联 / HOG 梯度直方图 + 空间滑动窗口穷举搜索 + 可变形部件模型 | 确立了“特征提取 + 滑动窗口分类”的早期范式，Viola-Jones 实现了首个实时人脸检测。 |
| **第二时期：两阶段 CNN 与特征表示突破 (2014-2017)** | R-CNN (2014)<br>Fast R-CNN (2015)<br>Faster R-CNN (2015)<br>FPN (2017)<br>Mask R-CNN (2017) | 选择性搜索/RPN 提取区域提议 (Region Proposal) + CNN 深度特征表示 + RoI Pooling/Align | **两阶段范式开创**：将 CNN 表达能力带入检测；RPN 实现候选区域自动生成；RoIAlign 消除像素量化误差，统一检测与实例分割。 |
| **第三时期：单阶段与 Anchor-Free 极速检测 (2015-2019)** | YOLOv1-v3 (2015-2018)<br>SSD (2016)<br>RetinaNet (2017)<br>FCOS / CenterNet (2019) | 密集网格直接回归；Focal Loss 解决正负样本极不平衡；FCOS 逐像素中心性预测 | **从 Proposals 到 Direct Regression**：摒弃候选框提议，实现高帧率实时检测；Anchor-Free 摆脱预定义先验锚框依赖。 |
| **第四时期：Transformer 与集合预测时代 (2020-2023)** | DETR (2020)<br>Deformable DETR (2021)<br>DINO-DETR (2022) | Transformer Cross-Attention + 匈牙利二分图匹配 (Hungarian Matching) + Object Queries | **消除 Anchor 与 NMS**：将检测建模为端到端集合预测 (Set Prediction) 问题，彻底摆脱手工后处理 (NMS)。 |
| **第五时期：开放词汇与基础检测模型 (2022-Present)** | Grounding DINO (2023)<br>OWL-ViT / OWLv2 (2023)<br>SAM (2023)<br>YOLOv10 / RT-DETR (2024) | 文本-图像跨模态特征对齐 (Text-Visual Alignment) + 多模态 Grounding + 零样本迁移 | **从预定义闭集走向 Open-Vocabulary**：打破固定类别限制，实现任意自然语言文本提示的零样本泛化目标检测。 |

## 3. 核心概念

### 3.1 任务定义与数学表述

给定输入图像 $I \in \mathbb{R}^{H \times W \times C}$，目标检测模型需预测包含 $N$ 个物体的集合 $\{(b_i, c_i, s_i)\}_{i=1}^{N}$：
- **边界框坐标 $b_i$**：$(x_1, y_1, x_2, y_2)$ 或归一化中心点与宽高 $(x_c, y_c, w, h)$。
- **类别标签 $c_i$**：$c_i \in \{1, 2, \ldots, K\}$，其中 $K$ 为目标类别数。
- **置信度分数 $s_i \in [0, 1]$**：表示当前预测框包含物体的概率与定位准确度综合得分。

### 3.2 IoU（交并比, Intersection over Union）

IoU 是衡量预测边界框 $B_p$ 与真实标注框 $B_{gt}$ 几何重叠程度的核心指标：

$$\text{IoU}(B_p, B_{gt}) = \frac{\lvert B_p \cap B_{gt} \rvert}{\lvert B_p \cup B_{gt} \rvert}$$

- $\text{IoU} = 1.0$：预测框与真实框完全重合。
- $\text{IoU} \ge 0.5$：通常被视作候选正样本匹配的标准阈值。

### 3.3 mAP（平均精度均值）

mAP（mean Average Precision）是评估检测器综合性能的绝对标准：

1. **查准率（Precision）与查全率（Recall）**：
   $$\text{Precision} = \frac{TP}{TP + FP}, \quad \text{Recall} = \frac{TP}{TP + FN}$$
2. **AP（Average Precision）**：对每个类别，按置信度 $s_i$ 降序排列，绘制 $P-R$ 曲线，计算曲线积分面积。
3. **mAP**：所有 $K$ 个类别的 AP 平均值。

| 评估指标 | 含义与判定条件 |
|:---|:---|
| **mAP@0.5** | 当 IoU 匹配阈值固定为 0.5 时的 mAP（Pascal VOC 标准） |
| **mAP@0.5:0.95** | IoU 阈值从 0.5 到 0.95（步长 0.05）取 10 个 AP 的均值（COCO 评价标准） |
| **$\text{AP}_{small} / \text{AP}_{medium} / \text{AP}_{large}$** | 针对不同像素面积目标的衡量：小目标（$\text{Area} < 32^2$）、中目标、大目标（$\text{Area} > 96^2$） |

### 3.4 锚框（Anchor Boxes）与正负样本匹配

锚框是预先在特征图每个像素点放置的一组具有不同尺度（Scales）和宽高比（Aspect Ratios）的参考框：
- **回归目标**：模型不直接预测绝对坐标，而是预测偏移量 $(\Delta x, \Delta y, \Delta w, \Delta h)$。
- **正负样本指派**：计算 Anchor 与 Ground Truth 的 IoU，IoU 最高的设为正样本，低于阈值的设为负样本。

### 3.5 NMS（非极大值抑制）

由于检测网络会在同一物体周围预测大量重叠框，NMS 用于剔除冗余重复框：

```
所有预测框集合 B，对应得分 S，最终保留集 D = ∅
1. 选择 S 中得分最高的框 m，加入 D，并从 B 中移除
2. 计算 B 中其余所有框与 m 的 IoU
3. 移除 B 中所有与 m 的 IoU > 阈值 N_t 的框
4. 重复上述过程，直到 B 为空
```

**Soft-NMS**：传统 NMS 硬性剔除 IoU 过高框可能导致遮挡物体漏检。Soft-NMS 改为按 IoU 对得分进行连续衰减：$s_i \leftarrow s_i \cdot \exp\left(-\frac{\text{IoU}(m, b_i)^2}{\sigma}\right)$。

## 4. 技术原理深度解析

### 4.1 两阶段检测（Two-Stage）：Proposal + Refinement

#### 经典流程与 Faster R-CNN 架构

两阶段检测将定位任务解耦为“寻找潜在区域”和“精确分类与修正”两个步骤：

```
输入图像 → CNN Backbone → 共享特征图 (Feature Map)
                              │
                              ├──> RPN 网络 → 候选区域 (RoIs)
                              │                   │
                              └───────> RoI Pooling / Align 
                                            │
                                            ▼
                                   全连接层 (FC Heads)
                                   ├──> 分类分支 (Class Head)
                                   └──> 框回归分支 (BBox Regressor)
```

1. **RPN (Region Proposal Network)**：在特征图上滑动 $3 \times 3$ 卷积，每个位置预测 $k$ 个 Anchor 的“是否包含物体”得分（Objectness）和坐标偏移。
2. **RoI Pooling vs RoI Align（何恺明 Mask R-CNN 突破）**：
   - **RoI Pooling**：通过两次浮点数取整量化（Quantization）将不同尺寸的候选区映射到固定大小（如 $7 \times 7$），导致定位偏差（Misalignment），对小目标与像素级分割致命。
   - **RoI Align**：取消所有量化过程，保留浮点数坐标；利用**双线性插值（Bilinear Interpolation）**精确计算采样点特征，消除了映射误差。

$$\text{RoI Pooling (量化两次): } [x / 16] \to \text{RoI Align (无量化插值): } x / 16 \text{ 保持连续浮点数}$$

#### 损失函数设计

两阶段模型的总联合损失定义为：

$$\mathcal{L}_{total} = \mathcal{L}_{rpn\_cls} + \mathcal{L}_{rpn\_reg} + \mathcal{L}_{cls} + \mathcal{L}_{reg}$$

其中回归损失普遍采用 **Smooth L1 Loss**：

$$\text{Smooth}_{L1}(x) = \begin{cases} 0.5 x^2, & \text{if } \lvert x \rvert < 1 \\ \lvert x \rvert - 0.5, & \text{otherwise} \end{cases}$$

### 4.2 特征金字塔网络 (FPN, Feature Pyramid Networks)

针对多尺度目标（尤其是极小目标）检测困难的问题，Lin 和何恺明等提出了 **FPN**：

```
自顶向下的特征增强与侧向连接：

C5 (高层语义) ───1x1 Conv───> P5 ───> 预测头
  │                             │ (上采样 2x)
  ▼                             ▼
C4 (中层特征) ───1x1 Conv───> (+) ──> P4 ───> 预测头
  │                             │ (上采样 2x)
  ▼                             ▼
C3 (低层分辨率) ──1x1 Conv───> (+) ──> P3 ───> 预测头
```

- **高层特征**：包含强语义信息，但空间分辨率低（适合大目标）。
- **低层特征**：空间分辨率高，几何细节丰富，但语义特征较弱（适合小目标）。
- **FPN 机制**：将高层语义通过自顶向下路径（Top-Down Path）上采样，与低层特征通过侧向连接（Lateral Connection, $1 \times 1$ 卷积）相加融合，实现多尺度强语义表达。

### 4.3 单阶段检测与 Focal Loss (RetinaNet)

单阶段检测（One-Stage）直接在特征图网格上预测目标，极具速度优势。但长期以来精度显著落后于两阶段方法，其根本原因在于**极度严重的正负样本不平衡（Class Imbalance）**（候选网格中背景占 99% 以上）。

#### Focal Loss 原理与推导

为了解决极不平衡背景负样本对梯度的统治问题，Lin 等提出了 **Focal Loss**：

传统交叉熵损失 (CE)：$\text{CE}(p_t) = -\log(p_t)$，其中 $p_t$ 为模型预测为真实类别的概率。

Focal Loss 在交叉熵前增加了动态调制因子 $(1 - p_t)^\gamma$：

$$\mathcal{L}_{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t)$$

- **易分样本衰减**：若样本极易区分（如背景 $p_t \to 1$），则 $(1 - p_t)^\gamma \to 0$，损失贡献被指数级抑制。
- **难分样本聚焦**：若样本难以区分（$p_t$ 较小），$(1 - p_t)^\gamma \approx 1$，损失不受影响。
- $\gamma$ 称为聚焦参数（Focusing Parameter，通常设为 2.0），$\alpha_t$ 用于平衡正负样本类别频率。

### 4.4 DETR：基于 Transformer 的端到端集合预测

Carion 等在 2020 年提出的 **DETR (Detection Transformer)** 改变了检测范式，将目标检测改写为无需 Anchor 和 NMS 的**直接集合预测（Direct Set Prediction）**。

```
图像 → Backbone → 特征序列 + 位置编码 → Transformer Encoder
                                                │
                                                ▼
                   Object Queries (N个) → Transformer Decoder
                                                │
                                                ▼
                                    FFN 预测头 (N组 class + bbox)
                                                │
                                      [匈牙利匹配 (Hungarian Matching)]
                                                │
                                                ▼
                                        计算 Set Loss
```

#### 匈牙利二分图匹配算法 (Bipartite Matching)

由于 DETR 输出固定数量 $N$（如 100）个预测框，而真实 Ground Truth 数量 $M < N$（其余用空类别 $\varnothing$ 填充），DETR 采用**匈牙利算法**寻找最优匹配置换 $\hat{\sigma}$：

$$\hat{\sigma} = \arg\min_{\sigma \in \mathfrak{S}_N} \sum_{i=1}^{N} \mathcal{L}_{match}(y_i, \hat{y}_{\sigma(i)})$$

匹配损失包含分类代价与边界框几何损失（GIoU + L1）：

$$\mathcal{L}_{match}(y_i, \hat{y}_{\sigma(i)}) = -\mathbb{1}_{\{c_i \neq \varnothing\}} \hat{p}_{\sigma(i)}(c_i) + \mathbb{1}_{\{c_i \neq \varnothing\}} \mathcal{L}_{box}(b_i, \hat{b}_{\sigma(i)})$$

#### DETR 的瓶颈与进化

- **传统 DETR 的痛点**：全图 Attention 导致训练收敛极慢（需 500 epochs），小目标分辨率下计算复杂度高。
- **Deformable DETR**：引入可变形注意力机制（Deformable Attention），只关注参考点附近的 $K$ 个局部采样点，使收敛速度提升 10 倍。
- **DINO-DETR**：结合去噪训练（Denoising Training）、对比查询选择与双重预测头，刷新 COCO 检测 SOTA。

---

### 4.5 开放词汇目标检测 (Open-Vocabulary Detection, OVD)

传统目标检测模型受限于固定类集的闭集假设（如 COCO 的 80 类）。在基础模型时代，Grounding DINO 和 OWL-ViT 等模型通过将文本编码器（如 CLIP Text Encoder）融合到检测器中：

```
图像 ──> Image Backbone ───> 跨模态融合 Transformer ──> 视觉特征 V
                                     ▲
文本提示 ──> Text Encoder ───> (Cross-Attention) ──────> 文本特征 T
                                     │
                                     ▼
                     预测框 b 与点积相似度 Score = V · T^T
```

- **核心机制**：用文本 Embeddings 矩阵替换传统固定的线性分类头，预测特征与文本特征的余弦相似度，从而实现**对任意自然语言短语**（Prompt）的零样本检测（Open-World Detection）。

## 5. 代表性关键模型与损失演进

### 5.1 YOLO 演进路线

| YOLO 版本 | 发布年份 | 核心技术创新 | 范式变化 |
|:---|:---|:---|:---|
| **YOLOv1** | 2016 | 将图像划分为 $7 \times 7$ 网格，直接预测坐标与类别 | 开创单阶段实时检测先河 |
| **YOLOv2 / v3** | 2017/2018 | 引入 Anchor Boxes、Darknet-53 Backbone、多尺度 FPN 预测 | 大幅提升小目标检测精度 |
| **YOLOv4 / v5** | 2020 | CSPDarknet、Mosaic 数据增强、PANet 特征聚合 | 成为工业界大规模工程落地的基石 |
| **YOLOv7 / v8** | 2022/2023 | Anchor-Free 解耦头 (Decoupled Head)、TaskAlignedAssigner、模型重参数化 | 实时检测在精度与速度上达到新 SOTA |
| **YOLOv10 / RT-DETR** | 2024 | 无 NMS 双重赋值（Dual Assignments）、无延迟实时端到端架构 | 实现高吞吐量无后处理实时端到端检测 |

### 5.2 边界框回归损失（BBox Regression Loss）演进

| 损失函数 | 公式表述 | 解决核心缺陷 / 改进意义 |
|:---|:---|:---|
| **Smooth L1** | $\begin{cases} 0.5 x^2, & \lvert x \rvert < 1 \\ \lvert x \rvert - 0.5, & \text{otherwise} \end{cases}$ | 对异常值不敏感，但孤立回归四个坐标，忽略了矩形整体性。 |
| **IoU Loss** | $\mathcal{L}_{IoU} = 1 - \text{IoU}$ | 具有尺度不变性（Scale Invariance），将四坐标结合为整体。 |
| **GIoU Loss** | $\mathcal{L}_{GIoU} = 1 - \text{IoU} + \frac{\lvert C \setminus (A \cup B) \rvert}{\lvert C \rvert}$ | 引入包含两框的最小闭包 $C$，解决了两框无重叠时 $\text{IoU}=0$ 梯度消失问题。 |
| **DIoU Loss** | $\mathcal{L}_{DIoU} = 1 - \text{IoU} + \frac{\rho^2(b, b^{gt})}{c^2}$ | 直接惩罚两框中心点距离 $\rho$，收敛速度大幅提升。 |
| **CIoU Loss** | $\mathcal{L}_{CIoU} = \mathcal{L}_{DIoU} + \alpha v$ | 进一步增加了宽高比一致性（Aspect Ratio Consistency）的约束。 |

## 6. 优势与局限

### 优势
1. **感知全面**：同时回答“是什么”与“在哪里”，是空间感知与机器人交互的关键环节。
2. **工业生态成熟**：拥有 MMDetection、Detectron2、Ultralytics YOLO 等高度封装且性能卓越的工具链。
3. **评估标准统一**：基于 COCO mAP 的标准测评体系极大促进了算法迭代。

### 局限与挑战
1. **极端遮挡与密集场景**：如密集人群、重叠货架，传统 NMS 容易造成漏检或误剔除。
2. **小目标信息丢失**：极小物体（< $16 \times 16$ 像素）在深层特征图下由于下采样下导致特征淹没。
3. **长尾分布（Long-Tail Distribution）**：常见类别数据丰富，罕见长尾类别检测效果差。

## 7. 与其他技术的关系与 Obsidian 双链

- **与图像分类的关系**：图像分类是目标检测的基石，检测器的 Backbone（如 ResNet、ConvNeXt）通常直接复用图像分类的预训练权重。参见 [[03_图像分类]]。
- **与传统特征提取的关系**：目标检测早期依赖于手动设计的局部梯度与几何特征。参见 [[02_传统视觉特征提取与匹配]]。
- **与图像分割的关系**：Mask R-CNN 证明了检测与实例分割（Instance Segmentation）可通过 RoIAlign 统一在同一多任务网络中。参见 [[05_图像分割]]。
- **与视觉 Transformer 的关系**：ViT 为检测器提供了更强全局上下文 Backbone，DETR 则将 Attention 机制带入检测头。参见 [[06_视觉Transformer]]。
- **与自监督学习的关系**：MAE 等自监督掩码预训练模型大幅提升了检测器在无标注大规模数据上的泛化表现。参见 [[09_自监督视觉学习]]。
- **与视觉语言大模型的关系**：Grounding DINO 等开放词汇检测模型是视觉语言模型（VLM）进行区域级 grounding 的关键模块。参见 [[E_感知与多模态智能/02_多模态感知/01_视觉语言模型|视觉语言模型]] 与 [[C_基础模型与通用智能/03_视觉基础模型/00_视觉基础模型_综述|视觉基础模型]]。
