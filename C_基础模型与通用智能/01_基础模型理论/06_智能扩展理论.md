# 智能扩展理论：能力从何而来

基础模型能力形成可用四个相互作用因素理解：

1. **数据覆盖**：提供语言、视觉、行为和环境规律的统计证据；
2. **目标与归纳偏置**：决定哪些结构被压缩、预测和保留；
3. **规模与优化**：提升可拟合复杂度，但受数据、计算与稳定性约束；
4. **系统脚手架**：检索、验证、搜索、记忆和工具把模型能力组织为更可靠的任务过程。
