# C 基础模型与通用智能：从预训练到能力形成

> **定位**：C 讨论基础模型如何经由大规模预训练、统一表示、后训练与推理时计算形成可迁移能力，并如何向记忆、规划、工具和物理行动提供模型接口。它不是 Agent、认知、因果、具身控制或工程系统的重复目录。

## 一条能力机制链

```text
多模态数据与自监督目标
        ↓
统一表示与可迁移先验
        ↓
预训练规模化 + 后训练/对齐
        ↓
推理、搜索、验证与测试时计算
        ↓
世界状态预测与行动条件建模
        ↓
Agent 的记忆、规划、工具调用与环境交互
```

基础模型回答“如何形成可复用的模型能力”；自主系统回答“如何在长期任务中组织、约束和执行这些能力”。

## 三个正交维度

| 维度 | C 内模块 | 回答的问题 |
|---|---|---|
| 模型与对象 | 语言、视觉、多模态、世界、行动基础模型 | 模型以何种模态、表征和输出作用于世界？ |
| 学习范式 | 基础模型理论、模型训练与对齐 | 数据、目标、规模与后训练如何塑造能力？ |
| 能力与效率 | 推理与思考、模型压缩与高效推理 | 如何在推理时提高正确性、可靠性、效率？ |

## 推荐学习路径

1. 基础模型理论 → 语言/视觉表征 → 多模态对齐；
2. 世界模型 → 推理与测试时计算 → 行动基础模型；
3. 模型训练与对齐 → 高效推理 → D Agent、F 世界模型、G 具身智能的系统闭环。
