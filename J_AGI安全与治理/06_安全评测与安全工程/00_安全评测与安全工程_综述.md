# 安全评测与安全工程

安全工程将安全要求转化为可重复的设计、测试、发布和运营过程。基准分数只能提供证据的一部分，必须结合威胁建模、红队、线上监控与事故响应。

## 目录
- [[01_威胁建模与红队测试]]：攻击树、资产、对手能力、人工与自动红队。
- [[02_安全评测与Agent基准]]：能力/危害评测、动态基准、评判器校准。
- [[03_安全生命周期与Safety Case]]：安全设计、灰度、监控、事件响应和论证。

```text
需求与风险 → 安全设计 → 离线评测/红队 → 发布门禁 → 线上监控 → 复盘与回归测试
```

目标不是宣称“绝对安全”，而是以可审计证据说明已知风险被识别、缓解、监测并有明确责任人。
