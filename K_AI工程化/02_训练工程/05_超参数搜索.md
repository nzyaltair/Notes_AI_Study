# 超参数搜索

## 一句话理解

通过受控实验在学习率、batch size、优化器配置等超参数空间中寻找最优组合，以系统化方法替代手工试错。

## 概述

超参数对模型训练效果的影响巨大——学习率偏差一个数量级就可能导致训练完全失败。大模型训练成本极高，无法像传统 ML 那样进行大规模网格搜索，因此需要更高效的搜索策略。

本笔记回答的核心问题：
- 哪些超参数最关键？影响如何？
- 大模型场景下如何高效搜索？
- 如何保证搜索结果的可复现性和可迁移性？

## 核心概念

### 超参数分类

| 类别 | 超参数 | 敏感度 |
|---|---|---|
| 优化器 | 学习率、weight decay、beta1/beta2 | 极高 |
| 批量 | batch size、梯度累积步数 | 高 |
| 调度 | warmup steps、衰减策略 | 高 |
| 正则 | dropout、label smoothing | 中 |
| 模型结构 | 层数、宽度、注意力头数 | 高（但通常固定） |
| 数据 | 序列长度、采样策略、数据配比 | 中-高 |

### 学习率的重要性

学习率是最关键的超参数。过大导致发散，过小导致收敛缓慢或陷入局部最优。

经验法则（基于 Scaling Laws）：

$$\text{LR}_{\text{opt}} \propto \text{batch\_size}^{0.5} \text{（线性缩放法则，近似）}$$

实际中大 batch 训练使用更大学习率，但缩放并非严格线性。

## 技术原理

### 搜索方法

#### 网格搜索（Grid Search）

穷举所有超参数组合。适用于低维空间（2-3 个超参数），但在高维空间效率极差。

#### 随机搜索（Random Search）

在超参数空间中随机采样。比网格搜索更高效——因为不是所有超参数都同样重要，随机搜索有更高概率探索关键维度。

#### 贝叶斯优化（Bayesian Optimization）

构建超参数到目标值的代理模型（如 Gaussian Process），通过采集函数（如 EI、UCB）选择下一个评估点。每次评估后更新代理模型。

- 优点：样本效率高，适合昂贵评估
- 代价：代理模型在高维空间可能不准确
- 工具：Optuna、Ray Tune、SigOpt

#### Hyperband / ASHA

结合随机搜索和早停机制。先以少量资源训练多个配置，淘汰表现差的，对幸存者分配更多资源继续训练。

- Hyperband：多轮 bracket 调度
- ASHA（Async Successive Halving）：异步版本，更适合分布式

### 大模型搜索策略

大模型不应直接做全局搜索，而采用分阶段策略：

1. **小模型筛选**：在 1/10 参数量的小模型上搜索超参数
2. **Scaling Law 迁移**：利用 Scaling Laws 将超参数从大模型迁移
3. **目标规模复验**：在目标规模做少量验证实验
4. **敏感度分析**：对关键超参数做 ±20% 扰动，确认稳定性

### 优化目标

搜索目标不应仅是最低 loss，而应综合考虑：

| 目标 | 权重 | 说明 |
|---|---|---|
| 验证 loss | 高 | 模型质量 |
| 训练稳定性 | 高 | 无 loss spike、无发散 |
| 训练成本 | 中 | GPU 时 |
| 推理约束 | 中 | 模型大小、延迟限制 |

## 关键方法与模型

### Scaling Laws 指导的超参数迁移

Kaplan et al. (2020) 的 Scaling Laws 表明，最优学习率、batch size 等超参数可按幂律关系从大模型迁移到小模型。这为"小模型搜索 + 大模型复验"提供了理论基础。

### MuP（Maximal Update Parameterization）

Yang & Hu（Tensor Programs V，2022）提出的参数化方案，使超参数（特别是学习率）在不同模型规模间可迁移：小模型上调好的最优学习率可直接用于放大后的模型（零样本迁移），从而避免在大规模上重新搜索。

**两条稳定性不变量**（推导出发点，仅考虑增加宽度）：

1. **初始化激活稳定**：随机初始化 + 随机输入下，各层激活值的量级不随宽度变化（每坐标 $O(1)$，向量范数 $O(\sqrt{n})$）。若激活随宽度爆炸或消失，说明参数化选错了。
2. **特征学习**：单次梯度更新引起的激活值变化量保持 $O(1)$。这与 NTK（神经正切核）极限形成对比——NTK 极限下更新量随宽度趋零，网络退化为固定核上的线性回归。

**推导思路**（深度线性网络 + 单样本 SGD 的量级分析，"物理学式"追踪各项数量级）：

- 用随机高斯矩阵的谱范数（矩阵集中不等式）追踪前向激活量级，反解出每层初始化方差需满足的缩放（矩阵参数含 $\sqrt{f_{\text{out}}/f_{\text{in}}}$ 类因子；标准参数化仅在 $f_{\text{out}} \approx f_{\text{in}}$ 时近似正确）；
- 用"损失单步更新量为 $O(1)$"的假设 + 反向传播的外积结构，追踪单步更新后激活变化各项的量级，反解出每层学习率需满足的缩放：**SGD 下逐层学习率乘子 $\propto f_{\text{out}}/f_{\text{in}}$**；Adam 的逐坐标归一化改变量级关系，对应不同的乘子形式（完整推导见 Tensor Programs V）。

**工程实现要点**（MiniCPM 等采用的操作集）：缩放 embedding 输出；按 $\sqrt{\text{层数}}$ 缩放残差分支；对矩阵参数按 fan-out/fan-in 相关因子缩放初始化方差；按参数类型（embedding/注意力/MLP/输出层）设置不同学习率乘子；缩放 LM 输出头。

**实证与边界**：

- MiniCPM 的学习率扫描显示 μP 下不同宽度模型的最优学习率几乎重合；Cerebras-GPT（Joel Hestness 团队）的 μP 变体训练中，缩放定律拟合更稳定、对大模型的损失预测更准。
- 压力测试（CS336 讲授综述）表明兼容性有边界：SwiGLU、RMSNorm 等常见改动大多兼容；但可学习 RMSNorm 增益、依赖梯度符号的优化器（如 Lion）、较大的解耦权重衰减会使迁移失效。
- μP × Muon × MoE 的组合已验证可行（2026 年工作实现学习率跨宽度迁移与 token 维度外推，$R^2=0.95$）。

### Step Law：超参数缩放定律（StepFun，2025）

StepFun 训练了 3700+ 个从零开始的 LLM（跨 100T token、近百万 H800 GPU 小时），系统验证了超参数缩放规律：

- **超参地形凸且平坦**：固定模型规模 $N$ 与数据量 $D$，学习率 × batch size 平面上的损失地形近似凸、最优区域宽，大幅降低搜索难度。
- **最优学习率随 $N$、$D$ 呈幂律变化**：模型越大最优学习率越低；数据越多最优学习率越高（后者与部分文献结论相反，说明该依赖并不稳固）。
- **最优 batch size 主要由数据量决定**：$B^* \approx \sqrt{cD}$，对模型规模基本不变（与 Kaplan 临界 batch size 随损失降低而增大的逻辑一致）。
- **对架构稳健、对数据敏感**：稠密与 MoE 可统一在同一定律下；但换数据配方后最优值整体偏移——超参规律是数据相关的。
- 拟合最优值与穷举全局最优的偏差仅 0.094%（测试集）。

## 优势与局限

### 优势

- 系统化方法避免人为偏见
- 可量化超参数影响和交互
- 结合早停可控制搜索成本

### 局限

- 大模型搜索成本仍然很高
- 超参数可能与数据分布耦合，换数据需重新搜索
- 搜索结果受随机种子影响，需多次验证

## 应用场景

- 预训练：小模型筛选 + Scaling Law 迁移
- 微调：重点搜索学习率和 LoRA rank
- RLHF/DPO：需搜索的额外超参数包括 β、KL 系数等

## 前沿发展

- **μP 的边界**：可学习 RMSNorm 增益、符号梯度类优化器（Lion）、大解耦权重衰减会破坏迁移；μP × Muon × MoE 组合的迁移已验证可行
- **超参数缩放定律**：Step Law 使"最优学习率/batch size 随规模的幂律"成为可外推工具，但常数依赖数据配方
- **神经配置缩放律**：用 LLM 参数化"训练配置→性能"映射，预测误差比配置无关的 Chinchilla 定律低 20-40%
- **AutoML for LLMs**：自动化搜索模型结构、训练策略和数据配比
- **元学习**：从历史实验中学习超参数先验
- **多目标优化**：同时优化质量、成本和延迟

## 常见问题

- **大模型能直接做随机搜索吗？**：不建议。一次 full-scale training 的成本可能高达数十万美元。应先在小模型上搜索，再在目标规模复验。
- **学习率应该用多少？**：取决于模型大小和 batch size。175B 模型典型值为 1e-4 到 6e-4（BF16 训练），7B 模型约为 3e-4 到 6e-4。
- **batch size 越大越好吗？**：不是。超过临界 batch size 后，训练效率下降。临界 batch size 与模型大小和任务有关，可通过梯度噪声尺度估计。
- **μP 和直接拟合缩放定律，选哪个？**：两条互补路线——μP 追求不变性（小模型调参直接迁移），缩放定律拟合（DeepSeek LLM、Step Law）追求可预测外推。算力落在已发表实验覆盖区间内时可直接用现成规律；自有架构或数据配方差异大时必须重新验证。
