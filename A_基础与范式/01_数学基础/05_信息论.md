# 信息论

## 一句话理解

信息论用**熵**量化随机变量的不确定性，用**KL 散度**度量两个概率分布的差异。在 AI 中，最小化交叉熵等价于最大化似然——这一条等价性将信息论与统计推断、损失函数设计、模型压缩与对齐统一在一个框架之下，是现代深度学习最核心的数学语言之一。

## 1. 概述

信息论量化信息和不确定性。核心概念是熵——衡量随机变量的平均不确定性，以及 KL 散度——衡量两个概率分布的差异。最小化交叉熵等价于最大化似然，这一联系将信息论与统计推断统一起来。在 AI 中，信息论为损失函数设计、模型评估、知识蒸馏和分布对齐提供核心理论工具。

## 3. 核心概念

### 自信息与熵

- **自信息**：$I(x) = -\log P(x)$，概率越小的事件携带信息量越大
- **熵**（离散）：$H(X) = -\sum_{x} P(x) \log P(x) = -E[\log P(X)]$
- **微分熵**（连续）：$H(X) = -\int p(x) \log p(x)\,dx$
- 性质：$H(X) \geq 0$（离散）；均匀分布熵最大；确定性分布熵为 0
- **单位**：以 2 为底 → bit；以 $e$ 为底 → nat；以 10 为底 → dit

### 条件熵与联合熵

- **条件熵**：$H(Y|X) = -\sum_{x,y} P(x,y) \log P(y|x)$，已知 X 时 Y 的剩余不确定性
- **联合熵**：$H(X,Y) = -\sum_{x,y} P(x,y) \log P(x,y)$
- **链式法则**：$H(X,Y) = H(X) + H(Y|X)$

### 互信息

$$I(X;Y) = H(X) - H(X|Y) = D_{KL}(P(X,Y) \| P(X)P(Y))$$

- 性质：$I(X;Y) \geq 0$；$I(X;Y) = 0$ 当且仅当 $X$ 与 $Y$ 独立；对称性 $I(X;Y) = I(Y;X)$
- 度量两个随机变量共享的信息量
- **与熵的恒等式**：$I(X;Y) = H(X) + H(Y) - H(X,Y)$，即互信息等于两个边际熵之和减去联合熵。
- **条件互信息**：$I(X;Y|Z) = H(X|Z) - H(X|Y,Z)$，在因果发现与特征选择中用于衡量在给定 $Z$ 时 $X$ 与 $Y$ 的剩余依赖。

### KL 散度

$$D_{KL}(P\|Q) = \sum_{x} P(x) \log\frac{P(x)}{Q(x)} = E_P\left[\log \frac{P(x)}{Q(x)}\right]$$

- **非负**：$D_{KL}(P\|Q) \geq 0$（Gibbs 不等式），当且仅当 $P=Q$ 时为 0
- **不对称**：$D_{KL}(P\|Q) \neq D_{KL}(Q\|P)$
- **前向 KL**（$D_{KL}(P\|Q)$，mean-seeking）：使 Q 覆盖 P 的所有支持域
- **后向 KL**（$D_{KL}(Q\|P)$，mode-seeking）：使 Q 集中在 P 的高概率区域
- **非对称性的数学根源**：前向 KL 中 $P(x)\to 0$ 项贡献为 0（无惩罚），但 $P(x) > 0$ 而 $Q(x)\to 0$ 时发散，迫使 $Q$ 覆盖所有 $P$ 的支持域；后向 KL 则相反，迫使 $Q$ 集中在 $P$ 的高概率区。这决定了变分推断中 ELBO 使用后向 KL $D_{KL}(q\|p)$，产生 mode-seeking 行为。

### 交叉熵

$$H(P,Q) = -\sum_{x} P(x) \log Q(x) = H(P) + D_{KL}(P\|Q)$$

最小化交叉熵等价于最大化似然：$\min H(P,Q) \iff \max \log P(\text{data}\mid\theta)$

**推导**：设经验分布 $\hat{P}(x) = \frac{1}{N}\sum_i \mathbb{1}[x_i = x]$，模型分布 $Q_\theta(x)$。交叉熵 $H(\hat{P}, Q_\theta) = -\sum_x \hat{P}(x)\log Q_\theta(x) = -\frac{1}{N}\sum_i \log Q_\theta(x_i)$，即负对数似然 (NLL)。因此 $\min_\theta H(\hat{P}, Q_\theta) \iff \max_\theta \sum_i \log Q_\theta(x_i)$。这解释了为何分类任务用交叉熵、语言模型用 NLL——本质上都是最大似然估计。

## 4. 技术原理

### 重要不等式

- **吉布斯不等式**：$D_{KL}(P\|Q) \geq 0$
- **Jensen 不等式**：对凸函数 $f$，$f(E[X]) \leq E[f(X)]$，KL 散度非负性的证明基础
- **数据处理不等式**：对马尔可夫链 $X \to Y \to Z$，$I(X;Z) \leq I(X;Y)$（信息处理后不会增加）
- **最大熵原理**：在给定约束下，熵最大的分布是最无偏的分布（如已知均值方差时，最大熵分布为高斯分布）

### 信道容量

$$C = \max_{P(X)} I(X;Y)$$

信道容量是通信信道无差错传输信息的最大速率。虽源自通信理论，但其思想影响了 AI 中的信息瓶颈方法。

### 信息瓶颈（Information Bottleneck）

- **Tishby et al. (1999)**: *The Information Bottleneck Method*
- 目标：找到表示 $T$，最大化 $I(T;Y)$（保留标签信息），同时最小化 $I(T;X)$（压缩输入信息）
- 用于解释深度学习：网络逐层压缩输入中的冗余信息

### 率失真理论（Rate-Distortion Theory）

- **定义**：给定失真函数 $d(x, \hat{x})$，在允许最大平均失真 $E[d(X, \hat{X})] \le D$ 的条件下，对源 $X$ 进行有损压缩所需的最小比特率 $R(D)$：
  $$R(D) = \min_{p(\hat{x} \mid x): E[d(X,\hat{X})] \le D} I(X; \hat{X})$$
- **AI 应用**：为 LLM 模型量化 (Quantization, 如 FP8/INT4)、有损权重剪枝以及变分自编码器 (VAE) 的码本速率-重建失真权衡提供了严格的信息论极限边界。

### 互信息估计（MINE 与 InfoNCE 界）

直接计算高维连续变量之间的互信息 $I(X; Y) = \int p(x, y) \log \frac{p(x, y)}{p(x)p(y)} dx dy$ 极难且不可积。现代自监督表示学习通过神经网络构造互信息的变分下界：

1. **MINE (Mutual Information Neural Estimator)**：利用 Donsker-Varadhan 变分表示：
   $$I(X; Y) \ge \sup_{T \in \mathcal{F}} \mathbb{E}_{P_{XY}}[T(X, Y)] - \log\left( \mathbb{E}_{P_X \otimes P_Y}[e^{T(X, Y)}] \right)$$
2. **InfoNCE 下界（对比学习）**：
   $$I(X; Y) \ge \mathbb{E} \left[ \log \frac{\exp(f(x, y)/\tau)}{\sum_{j=1}^K \exp(f(x, y_j)/\tau)} \right] + \log K$$
   其中 $f$ 为相似度打分网络，$K$ 为负样本数。该界表明增加对比学习负样本数 $K$ 能直接提升互信息下界的紧致度（CPC, SimCLR, CLIP 的数学根基）。

### 扩展散度度量与最优传输（Wasserstein 距离）

- **JS 散度**（Jensen-Shannon）：对称化的 KL 散度
  $$D_{JS}(P\|Q) = \frac{1}{2}D_{KL}(P\|M) + \frac{1}{2}D_{KL}(Q\|M), \quad M = \frac{P+Q}{2}$$
  - 对称、有界、有定义（即使 $Q$ 支持域不覆盖 $P$）。原始 GAN 的损失函数等价于最小化 JS 散度。但当两个分布的支撑集（Support）互不重叠时，JS 散度恒为常数 $\log 2$，导致梯度消失。

- **Wasserstein 距离（Earth Mover's Distance / 最优传输）**：
  $$W_1(P, Q) = \inf_{\gamma \in \Pi(P, Q)} \mathbb{E}_{(x, y) \sim \gamma} [\|x - y\|]$$
  - 由 Kantorovich-Rubinstein 对偶性，一阶 Wasserstein 距离写为 1-Lipschitz 连续函数上的最大化问题：
    $$W_1(P, Q) = \sup_{\|f\|_L \le 1} \mathbb{E}_{x \sim P}[f(x)] - \mathbb{E}_{y \sim Q}[f(y)]$$
  - **优势**：即使分布无重叠，Wasserstein 距离仍能提供平滑有界的连续梯度，彻底解决了 GAN 训练不稳定的难题（WGAN）。

- **证据下界（ELBO）**：

$$\log p(x) \geq \mathbb{E}_{q(z)}[\log p(x,z) - \log q(z)] = \mathbb{E}_{q(z)}[\log p(x\mid z)] - D_{KL}(q(z)\|p(z)) = \text{ELBO}$$

  - 变分推断的核心，VAE 的优化目标
  - **分解**：$\log p(x) = \text{ELBO} + D_{KL}(q(z) \| p(z\mid x))$，因此最大化 ELBO 等价于最小化变分后验 $q(z)$ 与真实后验 $p(z\mid x)$ 的 KL 散度。
  - **重构-正则权衡**：ELBO 的两项分别对应重构项 $\mathbb{E}_{q}[\log p(x\mid z)]$（似然）与先验正则项 $D_{KL}(q\|p)$，体现了 VAE 中重构质量与潜在空间规则化的平衡。

## 5. 关键方法/模型

### 交叉熵损失

- 分类任务的标准损失函数：$L = -\sum_i y_i \log \hat{y}_i$
- 与最大似然估计等价

### 困惑度（Perplexity）

$$\text{PPL} = 2^{H(p,q)} = \exp\left(-\frac{1}{N}\sum_{i=1}^N \log P(x_i|context)\right)$$

- 语言模型评估的核心指标
- 困惑度越低，模型对数据拟合越好

### 知识蒸馏

- **Hinton et al. (2015)**: *Distilling the Knowledge in a Neural Network*
- 使用 KL 散度让学生模型逼近教师模型的软标签分布
- 温度参数 $T$ 控制软标签的平滑程度

### DPO 中的 KL 约束

- **Rafailov et al. (2023)**: *Direct Preference Optimization*
- 在偏好对齐中，用 KL 散度约束策略模型不偏离参考模型太远

### ELBO 与 VAE

- **Kingma & Welling (2013)**: *Auto-Encoding Variational Bayes*
- 最大化 ELBO 等价于最小化 $D_{KL}(q_\phi(z|x) \| p(z|x))$

## 6. 优势与局限

**信息论的优势**：
- 提供分布间差异的统一度量框架
- 交叉熵损失有明确的概率解释（最大似然）
- 困惑度为语言模型提供可解释的评估指标
- 信息瓶颈等为深度学习提供理论分析工具

**局限**：
- KL 散度不对称，不同方向的散度有不同的行为特性
- KL 散度要求两个分布支持域一致（否则无定义），Wasserstein 距离无此限制
- 高维空间中互信息估计困难
- 熵和互信息的实际计算依赖分布已知或可精确估计

## 9. 前沿发展

- **信息瓶颈与深度学习**：Tishby 的"深度学习中的信息瓶颈"理论认为网络逐层压缩 $I(T;X)$ 同时保留 $I(T;Y)$，引发对泛化机制的热烈讨论；后续工作 (Saxe et al., 2018) 指出该解释在 ReLU 网络中的适用性存在争议。
- **互信息估计**：MINE（Belghazi et al., 2018）、InfoNCE (Oord et al., 2018) 为对比学习提供互信息下界；CLUB (Cheng et al., 2020) 给出互信息上界用于互信息最小化任务（如解耦表示）。
- **最小描述长度 (MDL)**：将模型复杂度与信息编码代价联系，用于模型选择与压缩感知。
- **大模型校准**：温度缩放、弹性校准等信息论方法改善模型置信度估计，缓解过度自信。
- **压缩与智能的关系**：Hutter 奖推动数据压缩与通用智能的理论关联（压缩 ≈ 预测 ≈ 智能）。
- **速率-失真理论在生成模型中的应用**：扩散模型的速率-失真解释 (Kingma et al., 2023)，VAE 的码率-失真权衡。
- **f-散度统一框架**：GAN 中的 f-GAN、变分散度最小化 (VDM) 将 KL、JS、Chi-squared 等纳入统一 $D_f$ 框架。
- **传输不确定性**：神经网络的预测不确定性传播（MC Dropout、Deep Ensemble）与信息论的结合，用于 OOD 检测。

## 10. 常见问题

- **为什么交叉熵等价于最大似然？** 经验分布 $\hat{P}$ 下 $H(\hat{P}, Q_\theta) = -\frac{1}{N}\sum_i \log Q_\theta(x_i)$，即 NLL；最小化 NLL 等价于最大化似然。
- **KL 散度为什么不对称？** $D_{KL}(P\|Q)$ 中权重为 $P(x)$，强调 $P$ 高概率区；交换 $P, Q$ 后权重变为 $Q(x)$，强调区不同，故数值与优化行为均不同。
- **为什么 ELBO 用后向 KL $D_{KL}(q\|p)$？** 后向 KL 使 $q$ 在 $p$ 低概率处也趋零（mode-seeking），避免 $q$ 覆盖不存在的模式，保证变分推断稳定。
- **困惑度与交叉熵的关系？** $\text{PPL} = \exp(H)$，即交叉熵的指数；困惑度可理解为模型在每个位置上的等效选择数。
- **Wasserstein 与 KL 的本质差别？** KL 只比较概率密度比值，不考虑支撑集几何距离；Wasserstein 考虑样本空间度量 $\lVert x-y\rVert$，即使分布不重叠仍能给出连续梯度。
- **互信息为什么难以估计？** 高维下需估计 $\log\frac{p(x,y)}{p(x)p(y)}$，涉及密度比估计，样本指数增长才能覆盖高维空间；MINE/InfoNCE 通过判别式估计绕过显式密度估计。
- **InfoNCE 的 $\log K$ 项含义？** 它是对比学习互信息下界的对齐项，表明负样本数 $K$ 越大下界越紧，但受计算与偏差-方差权衡限制。
