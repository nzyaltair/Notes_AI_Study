# 具身基础模型综述

## 一句话理解

具身基础模型以大规模多任务、多形态机器人数据预训练视觉、语言、状态与动作的联合表征，目标是在新任务、新对象和新平台上以少量适配获得可行动能力。VLA 是核心路线，但必须与世界模型、规划、控制和安全层协同。

## 概述

具身基础模型（Embodied Foundation Models）借鉴大语言模型的"预训练-适配"范式：用大规模异构数据训练通用表征，再以少量数据适配到具体任务、对象和平台。它与 LLM 的关键区别：输出必须落地为物理动作，必须处理本体差异、动作坐标系和控制约束。

## 发展历史

- **2021-2022**：语言条件策略（LCBC）、SayCan；RT-1 首次用 Transformer 统一视觉-语言-动作。
- **2023**：RT-2 迁移 VLM 知识到动作；PaLM-E 多模态 LLM 具身化；Open X-Embodiment 推动跨本体数据；Diffusion Policy 提出生成式动作。
- **2024**：OpenVLA 开源基线；π0 流匹配连续动作；GR-1 人形 VLA；跨本体与数据规模化成为焦点。
- **2025-**：VLA 与世界模型融合、大规模真机评测、灵巧手操作、长程家居 Agent 成为竞争焦点。

## 核心问题

1. **动作表示**：关节/末端/token/连续——如何统一。
2. **数据规范**：跨本体、跨平台的动作与观测标准。
3. **物理泛化**：语义知识如何转化为可靠物理行动。
4. **适配效率**：新任务/新平台需要多少数据。
5. **安全部署**：基础模型输出的验证与约束。

## 技术演进路线

| 时期 | 路线 | 代表 |
|---|---|---|
| 语言条件 | LLM + 技能库 | SayCan |
| 动作 token | Transformer 统一建模 | RT-1, RT-2 |
| 多模态 LLM | 具身观测进 LLM | PaLM-E |
| 开源基线 | 可复现微调 | OpenVLA |
| 生成式动作 | 流匹配/扩散 | π0, Diffusion Policy |
| 跨本体规模化 | 数据统一 | RT-X |
