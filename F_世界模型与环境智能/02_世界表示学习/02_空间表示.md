# 空间表示

空间表示让模型维持“物体在哪里、彼此如何关联、从不同视角看是否仍是同一世界”。它是导航、抓取、碰撞规避与空间问答的共同基础。

## 表示族

| 表示 | 优点 | 局限 |
|---|---|---|
| 栅格/占据图 | 规划直接、可表达空闲空间 | 大范围高分辨率成本高 |
| 点云/网格 | 几何显式 | 更新与语义融合复杂 |
| NeRF/3D Gaussian Splatting | 新视角渲染强 | 不天然提供物理和对象语义 |
| 场景图 | 对象关系与语言接口好 | 几何精度有限 |
| 语义/拓扑地图 | 长程导航高效 | 需与度量地图协同 |

关键不是选择唯一表示，而是将度量几何、对象身份、可供性和不确定性连接起来。详见 [[../../04_环境模拟与数字孪生/03_神经模拟器|神经模拟器]]。
