# 数学、代码与科学推理评测

## 一句话理解

可验证领域提供高质量推理反馈，但不同领域测量不同能力；单一数学或代码榜单不能外推为普遍推理或科学发现能力。

数学可检查答案/证明，代码可执行测试，科学任务需评估预测、实验设计和证据引用。应报告 pass@k、预算、工具可用性、污染检查和失败类别。
