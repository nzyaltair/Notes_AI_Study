# 具身认知理论与感知—行动耦合

## 一句话理解

具身智能不是工程领域的凭空发明，而是认知科学、发展心理学和神经科学长期积累的共识：**智能不是离身大脑的计算，而是身体与环境持续交互中涌现的适应性行为。**理解这些理论有助于避免"给大模型装个身体就行"的简化误判。

## 1. 具身认知：为什么身体不是外设

传统认知主义将心智类比为符号处理器：感知输入 → 内部表征计算 → 行动输出。具身认知（Embodied Cognition）对此提出三重挑战：

| 假设 | 具身认知的反驳 | 对工程的影响 |
|---|---|---|
| 认知可以脱离身体 | 身体形态决定可学到的行为空间 | 不同本体需要不同策略，不存在通用策略 |
| 感知是被动接收 | 感知服务于行动，行动改变感知 | 主动感知优于被动分类 |
| 内部表征是核心 | 表征与行动不可分割，"知"即"能做" | 不应把感知与行动割裂训练 |

核心论断：**认知是为行动服务的，而行动能力受身体和环境共同约束。**同一种"智能"在不同身体上的表现完全不同：蛇、鱼、鸟和人面对同一障碍会采取根本不同的策略。

## 2. 感知—行动循环与可供性

### Gibson 的生态光学

James Gibson 提出：感知不是重建内部 3D 模型，而是直接"拾取"环境中的可供性（affordance）——环境相对于观察者行动能力的行动机会。地面可站立、把手可抓取、缺口可穿过。

- 可供性是**关系性的**：同一台阶对成人"可跨"对幼儿"不可跨"。
- 可供性是**相对于行动能力的**：它不是物体的固有属性，而是身体与环境的关系。
- 对工程的启示：感知表征应优先编码"能做什么"，而非仅编码"是什么"。

### 感知—行动耦合

感知与行动不是串行流水线，而是闭环耦合：

```text
行动 → 改变环境/视角 → 新感知 → 更新状态与意图 → 新行动
```

视觉不是每帧独立识别，而是在运动中不断获取互补信息：头转动消除遮挡、手移动产生视差、接近目标获得更高分辨率。工程上这意味着：策略应主动选择观测，而不是被动等待固定视角的输入。

## 3. 发展机器人学：从婴儿学习到机器人学习

发展机器人学（Developmental Robotics / Cognitive Developmental Robotics）试图让机器人像婴儿一样，通过渐进式的感觉运动经验学习世界模型和行动策略。

### 感觉运动阶段（参考 Piaget）

| 阶段 | 婴儿行为 | 机器人对应 | 关键学习机制 |
|---|---|---|---|
| 反射阶段 | 抓握反射、吸吮 | 预设基本反射/安全行为 | 固定模式 + 反馈修正 |
| 初级循环反应 | 重复偶然有趣动作 | 探索性动作 + 内在奖励 | 好奇心驱动、预测误差 |
| 次级循环反应 | 手段—目的分离 | 技能学习 + 目标条件化 | 分层策略、技能库 |
| 三级循环反应 | 主动实验 | 系统化探索 + 假设检验 | 主动学习、模型预测 |
| 心理表征 | 延迟模仿、客体永久性 | 内部模型 + 想象规划 | 世界模型、心理模拟 |

### 关键原则

1. **渐进式复杂性**：先学简单的感觉运动映射，再组合为复杂技能。不要一开始就训练长程任务策略。
2. **内在动机**：好奇心、预测误差和信息增益可作为探索奖励，而非仅依赖任务成功信号。
3. **社会学习**：模仿和指示学习是高效获取技能的方式；在机器人中对应行为克隆和语言条件策略。
4. **身体图式**：机器人需学习自身运动能力与约束（可达性、碰撞、抓取稳定性），而非假设它已知。

## 4. 预测编码与主动推断

### 预测编码（Predictive Coding）

大脑不是被动处理输入，而是持续生成预测并只处理预测误差：

$$\text{感知信号} - \text{预测} = \text{预测误差} \rightarrow \text{更新内部模型}$$

这给出了一种统一的感知—学习—行动框架：感知是自上而下的预测与自下而上的误差的融合；学习是最小化长期预测误差；行动是改变感知以匹配预测。

### 主动推断（Active Inference, Friston）

自由能原理将生物系统的目标定义为最小化变分自由能：

$$\mathcal F = \underbrace{\mathbb E_q[\ln q(s)-\ln p(o,s)]}_{\text{变分自由能}} \ge -\ln p(o)$$

- 感知：优化内部后验 \(q(s)\) 减小自由能（感知推断）。
- 行动：选择行动使未来观测与预测一致（主动推断）。
- 学习：更新生成模型 \(p(o,s)\) 减小长期预测误差。

主动推断的独特之处在于：**行动的目的是让感知符合预测（即预期），而不是最大化外部奖励。**这解释了为什么生物体倾向于留在熟悉的、可预测的状态空间中，以及为什么好奇心（降低不确定性）和习惯（保持可预测性）可以共存。

### 对具身系统的工程启示

| 原则 | 工程体现 |
|---|---|
| 预测先于感知 | 用世界模型预测下一观测，只在误差大时更新 |
| 行动服务于预测 | 选择让未来更可预测的行动（安全、可控） |
| 不确定性驱动探索 | 对高不确定性区域主动感知或试探 |
| 分层预测 | 高层预测任务进度，低层预测接触和运动 |
| 最小化意外 | 安全行为偏好可预测状态，避免未知风险 |

## 5. 从理论到工程的转化

| 理论概念 | 工程对应 | 已在系统中体现的例子 |
|---|---|---|
| 可供性 | 对象级行动属性 | 6D 位姿 + 可抓取区域 + 操作方向 |
| 感知—行动循环 | 闭环视觉伺服 + 主动感知 | 移动相机消除遮挡、试探性接触 |
| 渐进式发展 | 技能库 + 分层学习 | 先学到达再学抓取再学放置 |
| 内在动机 | 好奇心奖励 + 信息增益 | 预测误差驱动的探索 |
| 预测编码 | 世界模型 + 预测误差 | DreamerV3 的世界模型学习 |
| 主动推断 | 安全行动偏好 + OOD 检测 | 偏好已知状态、触发人工接管 |
