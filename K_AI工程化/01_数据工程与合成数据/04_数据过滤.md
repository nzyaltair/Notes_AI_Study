# 数据过滤

## 一句话理解

数据过滤按质量、相关性、安全性和许可要求选择训练样本——统一框架是「从原始池 R 中挑出与目标分布 T 相似的子集」，用轻量评分器（规则/生成式 LM/线性分类器）按阈值筛选；过滤阈值会改变数据分布且最优阈值与训练 token 预算耦合，需按群体报告保留率并以固定评测集验证能力与公平性变化。

## 1. 概述

数据过滤是数据清洗之后的环节。清洗修复了格式和一致性问题，过滤则基于内容质量决定哪些样本值得进入训练集。

过滤的核心目标：

- **提升数据质量**：保留高质量样本，丢弃低质量样本
- **控制数据分布**：按领域、难度、语言配比
- **安全保障**：过滤有害、不安全内容
- **合规过滤**：排除许可不允许的数据

## 2. 过滤方法

### 2.1 启发式规则

基于经验的简单规则，速度快、成本低：

| 规则类型 | 说明 | 示例 |
|:---|:---|:---|
| 长度过滤 | 过短/过长文档 | < 50 词或 > 100K 词 |
| 语言识别 | 只保留目标语言 | fastText 语言检测 |
| 字符比例 | 特殊字符占比 | 非字母字符 > 30% → 丢弃 |
| URL 过滤 | 基于域名黑名单 | 成人/垃圾站点黑名单 |
| 广告检测 | 广告模板匹配 | 广告密度 > 50% → 丢弃 |
| 重复行 | 模板页面检测 | 重复行 > 30% → 丢弃 |
| 词频比 | 常见词占比 | 顶级 100 词占比异常 |

### 2.2 分类器过滤

训练专用分类器评估数据质量：

| 分类器 | 目标 | 训练数据 |
|:---|:---|:---|
| 质量分类器 | 区分高质量/低质量文本 | Wikipedia（正）vs 随机网页（负） |
| 毒性分类器 | 检测有害内容 | 有害/无害标注数据 |
| 成人内容分类器 | 检测色情内容 | 成人/非成人标注 |
| 版权风险分类器 | 检测可能侵权内容 | 版权/非版权数据 |
| 领域相关性分类器 | 筛选目标领域 | 领域内/外数据 |

### 2.3 模型评分

用语言模型对数据质量评分：

| 方法 | 说明 | 适用场景 |
|:---|:---|:---|
| 困惑度 (Perplexity) | 用参考模型计算困惑度，高困惑度=低质量 | 预训练数据 |
| 奖励模型评分 | 用 RM 评估回复质量 | SFT/RLHF 数据 |
| 教师模型评分 | 用强模型评估数据质量 | 指令数据 |
| LLM Judge | 用 GPT-4 等评估质量 | 多维质量评估 |

**困惑度过滤的原理**：

```text
高质量文本 → 参考模型对其困惑度低（模型能理解）
低质量文本 → 参考模型对其困惑度高（模型无法理解）

阈值: perplexity > θ → 丢弃
```

> **注意**：困惑度过滤可能偏好与参考模型相似的数据，导致分布偏差。

### 2.4 分桶采样

不简单删除低分数据，而是按分桶设置不同采样率：

```text
质量分桶:
├── 高质量 (0.8-1.0): 100% 保留
├── 中质量 (0.5-0.8): 50% 采样
├── 低质量 (0.2-0.5): 10% 采样（保留长尾）
└── 垃圾 (0.0-0.2): 0% 丢弃
```

分桶采样的优势：

- **保留多样性**：低质量但不完全无用数据仍有少量保留
- **控制分布**：避免过滤后分布过于集中
- **可调节**：采样率可根据实验结果调整

### 2.5 统一框架：原始池 R → 目标分布 T

几乎所有过滤方法都套用同一框架：给定原始数据 R（如 240T token 的 CommonCrawl 池）和目标数据 T（少量高质量样本），从 R 中挑出与 T 相似的子集。落地方式是先在 R∪T 上训练一个廉价模型建立评分，再按阈值筛选 R：

| 评分器类型 | 做法 | 代表 |
|:---|:---|:---|
| 生成式 | 在 T 上训练小型语言模型（如 KenLM 五元语法），文档困惑度低于阈值则保留 | CCNet（在 Wikipedia 上训练 LM，“像维基百科”的文档得分高） |
| 判别式 | T 为正样本、R 中随机采样为负样本，训练线性分类器（fastText），分数超阈值保留 | GPT-3（WebText 正 vs 随机 CC 负）、DCLM（OpenHermes 正 vs RefinedWeb 负） |

关键工程约束：评分器必须能在全量原始数据（数十万亿 token）上跑一遍，因此用五元语法模型或 fastText 级别的线性分类器，而非大模型。

**目标分布 T 的选择定义了“质量”——质量没有统一定义**：

| 案例 | 目标 T | 评分器 | 备注 |
|:---|:---|:---|:---|
| GPT-3 | WebText（Reddit 高分外链页面） | 线性分类器 | 早期质量过滤范式 |
| Llama 1 | 被 Wikipedia 引用的页面 | CCNet LM | 引用源比 Wikipedia 本身更泛在、规模更大 |
| OpenMathText | ProofPile（已知数学语料） | LaTeX 规则 + CCNet 困惑度 + fastText 数学分类器 | ~15B token 数学语料，训练效果超过 20 倍大的未过滤语料 |
| Phi-1 | GPT-4 判定“有教育价值”的 10 万样本 | 随机森林 | 教科书质量代码数据 |
| DCLM | OpenHermes（GPT-4 指令 + ELI5 问答） | fastText 线性分类器 | 一度是开源质量过滤黄金标准 |
| Nemotron | LLM 按“教育价值”打分的样本 | fastText + DCLM 分类器 | 认为 DCLM 过于激进（仅留 3.8T），扩大保留至 6T |

**教师→学生分类器蒸馏**：当目标本身难以定义时，先用强模型 + prompt 对子集（如 10 万条）打标，再训练轻量分类器推广到全量——Phi-1 与 Nemotron 均为此模式。历史脉络上，早期数据集（RefinedWeb/Gopher）刻意避开模型过滤以避免偏差；如今基于模型的过滤已成标配——除非算力无限，否则必须想清楚过滤策略，否则就是在低质量内容上白白浪费算力。

## 3. 安全过滤

### 3.1 有害内容过滤

| 内容类型 | 检测方法 | 处理 |
|:---|:---|:---|
| 暴力/仇恨 | 毒性分类器 | 删除 |
| 色情内容 | 成人分类器 | 删除 |
| 自伤/自杀 | 关键词 + 分类器 | 删除 |
| 违法信息 | 关键词 + 分类器 | 删除 |

### 3.2 PII 过滤

- **检测**：正则规则 + NER 模型
- **处理**：脱敏（替换为占位符）或删除整条
- **验证**：过滤后抽样检查残留 PII

### 3.3 对抗内容过滤

- **注入攻击**：检测 Prompt 注入样本
- **越狱内容**：检测越狱指令
- **模型提取**：检测模型输出反推数据

## 4. 领域过滤

按领域配比筛选数据：

| 领域 | 过滤方法 | 配比（参考） |
|:---|:---|:---|
| 技术/代码 | GitHub 星标 + 语言检测 | 15-20% |
| 科学论文 | arXiv 分类 | 10-15% |
| 百科知识 | Wikipedia | 5-10% |
| 新闻 | 新闻域名白名单 | 10-15% |
| 文学/书籍 | 书籍语料 | 5-10% |
| 对话 | Reddit/论坛 | 5-10% |

领域配比影响模型能力方向，需通过实验优化。

## 5. 过滤的风险控制

### 5.1 分布偏差

过滤阈值会改变数据分布：

```text
原始数据分布: 均匀覆盖各群体
    ↓ 过滤（高质量阈值）
过滤后分布: 偏向高频/主流群体
    → 低资源语言、方言、少数群体数据被过度删除
```

### 5.2 公平性保障

- **按群体报告保留率**：按语言、地域、领域统计过滤前后比例
- **差异化阈值**：对低资源群体使用更宽松的阈值
- **公平性评测**：用固定评测集验证过滤后模型在各群体上的表现

### 5.3 能力回归

过滤后必须验证：

- **核心能力**：过滤是否提升了目标能力
- **辅助能力**：过滤是否意外损害了其他能力
- **安全能力**：过滤是否影响了安全对齐效果

### 5.4 阈值与训练预算耦合

不存在全局最优的过滤阈值——**最优保留率取决于训练 token 预算**：

- **短预算**：高质量小数据胜出——低质量数据在有限步数内来不及发挥作用
- **长预算**：低质量大数据可能反超——高质量小数据集会被重复训练多个 epoch 而过拟合，损失在临界点后回升；未过滤数据前期损失高但下降持续更久（DataComp-LM 风格小规模实验：~1.5 亿参数模型 × 小数据池的多 epoch 训练曲线）
- **过滤是算力约束下的必需品**：理论上无限算力可不过滤直接全量训练；现实中过滤后数据量通常只有原始池的个位数百分比（DCLM：240T → 3.8T，约 1.6%）

> 实操建议：报告过滤结果时同时报告训练 token 数与每个数据点的 epoch 数；在固定评测集上验证不同阈值的下游表现（见 [[06_数据质量评估]]、[[11_数据配比]]）。

## 6. 过滤管线

```text
原始数据
    ↓ 启发式过滤 (快速、低成本)
    ↓ 质量分类器 (中等成本)
    ↓ 模型评分 (高成本、高精度)
    ↓ 安全过滤 (有害内容/PII)
    ↓ 领域配比采样
    ↓ 过滤后数据集
```

分层过滤策略：先低成本快速过滤大量数据，再高成本精过滤。

## 8. 常见问题

- **过滤过度**：阈值过严导致数据量不足
- **过滤偏差**：偏好主流内容，丢失长尾
- **分类器偏差**：质量分类器偏好特定风格
- **困惑度偏差**：偏好参考模型"熟悉"的文本
- **安全过滤误伤**：正常内容被误判为有害
