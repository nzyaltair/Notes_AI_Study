# 视觉语言动作模型

## 一句话理解

VLA 统一视觉、语言、机器人状态和动作，代表路线包括 RT-1/RT-2 的动作 token、OpenVLA 的开源微调基线，以及 π 系列的生成式动作建模。关键问题不是仅增大参数，而是统一数据规范与物理落地。

## 概述

视觉语言动作模型（Vision-Language-Action, VLA）是具身基础模型的核心路线：一个模型同时理解视觉、语言、机器人状态，并输出动作。它把大语言/视觉模型的语义能力与机器人动作统一，目标是在新任务、新对象上以零样本或少样本泛化。VLA 已成为 2023 年以来机器人学习研究的主流方向。

## 发展历史

- **2022**：RT-1 首次用单 Transformer 统一视觉-语言-动作 token。
- **2023**：RT-2 从 VLM 微调出动作模型（Web 知识迁移）；PaLM-E 多模态 LLM。
- **2024**：OpenVLA 开源 7B VLA 与微调流程；π0 用流匹配生成连续动作（Physical Intelligence）。
- **2025-**：VLA 规模化（更大数据）、人形 VLA（GR-1, HumanPlus）、VLA + 世界模型、跨本体 VLA 评测。

## 核心概念

| 概念 | 定义 | 关键点 |
|---|---|---|
| 动作 token | 动作离散化为 token | RT 系列 |
| 视觉语言迁移 | VLM 知识→动作 | RT-2 价值 |
| 流匹配 | 连续动作生成 | π 系列 |
| 开源基线 | 公开权重 + 微调 | OpenVLA |
| 跨本体 | 多平台共享 | 动作空间统一 |
| 分块自回归 | 分段生成动作 | 长时域 |

## 技术原理

### 三条代表性路线

| 路线 | 核心思想 | 代表 | 特点 |
|---|---|---|---|
| 离散动作 token | 动作离散化为 token 与语言联合建模 | RT-1, RT-2 | 复用 VLM 结构 |
| 开源微调基线 | 公开 VLA + 微调流程 | OpenVLA | 可复现 |
| 生成式动作 | 流匹配/扩散生成连续动作 | π0, π0.5 | 高精度、多模态 |

### RT 系列架构

RT-1 架构：

```text
图像 token + 语言 token + 状态 token
→ Transformer（动作 token 预测）
→ 离散动作（8 bin × 11 维）
```

RT-2 从 VLM（PaLI-X/PaLM-E）微调，把动作作为语言 token 混合训练。核心价值：VLM 预训练的语义知识迁移到动作预测；核心局限：离散化精度有限。

### π（pi-zero）的流匹配

π0 用流匹配（Flow Matching）生成动作轨迹：

```text
观测（视觉+语言+状态）→ 动作 tokenizer → 流匹配模型 → 连续动作轨迹
```

- 支持多模态动作分布（同一任务多种方式）。
- 精度高于离散 token。
- π0.5 引入分块自回归实现长时域生成。

### 统一动作空间与数据规范

VLA 训练的关键不是参数，而是数据规范统一：

| 维度 | 必须统一 |
|---|---|
| 动作坐标 | 世界/基座/末端系 |
| 夹爪语义 | 开/合编码 |
| 控制频率 | 采样与执行频率 |
| 相机视角 | 视角一致性 |
| 成功定义 | 任务标签 |
| 本体元数据 | 自由度、限位 |

## 关键方法与模型

| 模型 | 年份 | 核心贡献 | 边界 |
|---|---|---|---|
| RT-1 | 2022 | 动作 token Transformer | 数据规模 |
| RT-2 | 2023 | VLM 知识迁移 | 精度、安全 |
| PaLM-E | 2023 | 多模态 LLM 具身化 | 推理-控制鸿沟 |
| OpenVLA | 2024 | 开源 VLA 基线 | 需适配 |
| π0 | 2024 | 流匹配连续动作 | 推理成本 |
| GR-1 | 2024 | 人形 VLA | 本体适配 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 语义泛化 | 开放指令 | 物理精度 |
| 多任务 | 共享表征 | 任务冲突 |
| 数据利用 | 大规模预训练 | 数据规范难 |
| 端到端 | 免中间层 | 安全验证缺失 |

## 应用场景

- 家居任务：语言指令操作。
- 多任务操作：一套模型多技能。
- 人形操作：全身 VLA。
- 交互式任务：持续指令调整。

## 常见问题

- **参数规模当精度**：VLA 需要验证层。
- **忽略动作坐标语义**：动作 token 不自带坐标系。
- **跳过安全层**：VLA 输出必须可被拒绝/裁剪。
- **用演示视频评测**：需覆盖新物体、布局、指令、跨本体。
