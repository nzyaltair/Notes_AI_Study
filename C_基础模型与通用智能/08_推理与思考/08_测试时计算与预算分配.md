# 测试时计算与预算分配

## 一句话理解

测试时计算是在单个问题上额外投入采样、搜索、工具执行和验证；重点是在固定成本与时延下把预算分给最有价值的步骤，而不是无限延长思考。

\[
B=B_{generate}+B_{search}+B_{verify}+B_{tool}
\]

难题、低置信度或可验证任务可使用更多预算，简单题应早停。训练扩展改善候选分布，测试时扩展改善具体实例的候选选择，二者互补。
