# 经典与混合认知架构：从产生式规则到神经符号协作

## 一句话理解

经典认知架构将感知、记忆、规则、目标和行动显式组织，适合研究长期控制与可解释行为；混合架构尝试保留这种结构，同时以神经网络处理高维感知与模糊模式。

## 代表架构

| 架构 | 关键机制 | 强项 | 局限 |
|---|---|---|---|
| ACT-R | 陈述性记忆、产生式规则、模块缓冲区 | 与人类实验数据的细粒度建模 | 知识工程与感知扩展成本高 |
| SOAR | 问题空间搜索、子目标、组块学习 | 通用问题求解和任务分解 | 表征与学习规模受限 |
| CLARION | 显式规则与隐式子符号知识双表征 | 描述显隐知识协作 | 工程生态较小 |
| 神经符号 Agent | 神经模型 + 程序/工具/验证器 | 处理开放语言和感知输入 | 接口、可靠性和可学习性仍是难点 |

## 对现代系统的启发

可将现代 LLM Agent 看作混合架构候选：LLM 提供语言表征与启发式生成；结构化状态、工具调用、规划器、验证器和记忆系统提供外部约束。关键问题不是模块越多越好，而是接口是否可观测、状态是否可复现、失败是否可恢复。
