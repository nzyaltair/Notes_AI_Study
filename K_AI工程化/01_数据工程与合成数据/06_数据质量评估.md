# 数据质量评估

## 一句话理解

数据质量评估用可量化证据判断数据是否适合特定模型和任务——从完整性、正确性、一致性、多样性、新鲜度和安全性六个维度评估，质量门禁应同时包含自动统计、人工抽检和下游任务回归测试。

## 1. 概述

数据质量是模型性能的基础。与软件工程中"代码质量"类似，数据质量需要系统化的评估框架，而非依赖经验直觉。

数据质量评估的核心目标：

- **量化**：用指标而非感觉判断数据质量
- **可比**：不同数据集间可横向对比
- **可追踪**：质量变化可追踪到具体原因
- **可门控**：质量不达标时阻断下游使用

## 2. 质量维度

### 2.1 六大质量维度

| 维度 | 问题 | 示例指标 | 评估方法 |
|:---|:---|:---|:---|
| 完整性 | 是否缺字段、缺模态 | 缺失率、空值率 | 自动统计 |
| 正确性 | 标签和事实是否可靠 | 抽检准确率、错误率 | 人工抽检 |
| 一致性 | 格式和标注标准是否统一 | Schema 通过率、一致性分数 | 自动校验 |
| 多样性 | 是否覆盖目标分布和长尾 | 熵、覆盖率、类别分布 | 统计分析 |
| 新鲜度 | 是否反映当前世界 | 数据时延、更新频率 | 时间分析 |
| 安全性 | 是否含风险内容 | PII 命中率、毒性命中率 | 分类器检测 |

### 2.2 完整性

```text
完整性 = (非空字段数 / 总字段数) × 100%

检查项:
├── 必填字段是否为空
├── 多模态数据是否配对（图文、音视频）
├── 元数据是否完整（来源、时间、许可）
└── 嵌套结构是否完整
```

### 2.3 正确性

- **标签正确性**：人工抽检标注是否正确
- **事实正确性**：内容中的事实是否准确
- **数值合理性**：数值是否在合理范围内
- **逻辑一致性**：字段间逻辑是否自洽

### 2.4 一致性

- **Schema 一致性**：所有样本是否符合统一 Schema
- **标注一致性**：不同标注者对同一样本的标注是否一致
- **格式一致性**：日期、单位、编码是否统一
- **分布一致性**：不同批次数据的分布是否一致

### 2.5 多样性

```text
多样性指标:
├── 类别熵: H = -Σ p(i) × log(p(i))
├── 覆盖率: 目标维度覆盖比例
├── 长尾比例: 低频类别占比
├── 主题分布: LDA/聚类分析主题分布
└── 语言/领域/难度分布
```

### 2.6 新鲜度

| 指标 | 说明 | 重要性 |
|:---|:---|:---|
| 数据时延 | 数据产生到入库的时间差 | 实时场景关键 |
| 更新频率 | 数据更新的周期 | 影响时效性 |
| 过期比例 | 超过有效期的数据比例 | 影响准确性 |
| 版本年龄 | 数据版本距今天数 | 影响可复现性 |

### 2.7 安全性

- **PII 命中率**：含个人信息的样本比例
- **毒性命中率**：含有害内容的样本比例
- **版权风险**：可能侵权的内容比例
- **敏感数据**：涉密/受限内容比例

## 3. 质量门禁

### 3.1 门禁设计

质量门禁是数据进入下游使用前的检查点：

```text
数据集 → 质量评估 → 门禁检查 → 通过 → 可用于训练/推理
                        ↓
                     不通过 → 阻断 + 通知 + 修复
```

### 3.2 三层门禁

| 层级 | 内容 | 频率 |
|:---|:---|:---|
| 自动统计 | 完整性、一致性、分布指标 | 每次数据更新 |
| 人工抽检 | 正确性、质量主观评估 | 每批次抽样 |
| 下游回归 | 固定评测集上的模型表现 | 每次重大更新 |

### 3.3 门禁规则示例

```yaml
quality_gates:
  completeness:
    missing_rate: { max: 0.02, action: block }
  correctness:
    label_accuracy: { min: 0.95, action: review }
  consistency:
    schema_pass_rate: { min: 0.99, action: block }
  diversity:
    category_entropy: { min: 3.5, action: warn }
  safety:
    pii_rate: { max: 0.001, action: block }
    toxicity_rate: { max: 0.005, action: block }
```

## 4. 质量评估方法

### 4.1 统计分析

| 方法 | 说明 | 工具 |
|:---|:---|:---|
| 描述性统计 | 均值、方差、分位数 | Pandas, Spark |
| 分布分析 | 直方图、密度图 | Matplotlib, Seaborn |
| 相关性分析 | 字段间相关性 | Pandas |
| 异常检测 | 离群点检测 | Scikit-learn |

### 4.2 人工抽检

- **随机抽样**：从数据集中随机抽取 N 条
- **分层抽样**：按类别/领域分层抽样
- **边界抽样**：重点检查阈值边界数据
- **金标准对比**：与人工标注金标准对比

### 4.3 下游任务回归

在固定评测集上测试模型表现：

```text
新数据集 → 训练模型 → 固定评测集 → 分数对比
                                    ↓
                              分数下降 → 质量问题
                              分数提升 → 质量改善
```

## 5. 数据价值评估

高分数据不必然对任务最有价值。需要区分质量与价值：

| 维度 | 质量 | 价值 |
|:---|:---|:---|
| 含义 | 数据本身的优质程度 | 数据对特定任务的帮助程度 |
| 评估 | 通用质量指标 | 下游任务表现提升 |
| 关系 | 高质量是高价值的必要条件 | 高质量不一定高价值 |

### 5.1 难例价值

- **难例 (Hard Examples)**：模型当前表现差的样本
- **反馈样本**：从生产环境中收集的失败案例
- **价值加权**：难例和反馈样本应单独加权

### 5.2 数据影响分析

- **数据删除实验**：删除某类数据后观察模型表现变化
- **数据影响函数**：量化单条数据对模型的影响
- **Shapley 值**：基于博弈论的数据贡献评估

## 7. 常见问题

- **只看数量不看质量**：追求数据规模而忽视质量
- **质量与价值混淆**：高质量数据不一定对任务有价值
- **无门禁**：数据质量无检查直接使用
- **门禁过严**：质量标准过高导致数据量不足
- **无人工抽检**：仅依赖自动指标，遗漏语义质量问题
