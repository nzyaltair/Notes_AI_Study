# 环境与世界模型 Overview

## 领域定义

环境（Environment）是智能体行动所处的外部系统，向智能体提供观察（observation）、接受动作（action）、并按自身动力学产生反馈（reward/next state）；世界模型（World Model）则是智能体对环境状态、转移动力学、奖励结构与不确定性的**内部表征**，回答"当前发生了什么"（状态估计）以及"如果这样做，接下来会怎样"（动态预测）两个核心问题。

环境与世界模型共同构成智能体感知-决策闭环中"理解外部世界"的一环：环境交互定义了智能体能获得什么信息、能执行什么动作；世界模型决定智能体能在多大程度上脱离真实试错，在"想象"中评估候选行动的后果。二者是 [[../00_智能体与自主系统_综述|D 智能体与自主系统]]闭环图中"感知/状态 → 世界模型"这一环节的具体内容，上承 [[../01_智能体理论基础/00_智能体理论基础_综述|智能体理论基础]]中对"理性"的定义，下接 [[../03_规划与推理/00_规划与推理_综述|规划与推理]]与 [[../04_强化学习/00_强化学习_综述|强化学习]]中对"如何决策"的展开。

## 为什么会出现

经典人工智能规划最初假设环境是**完全可观测**且**确定性**的（如国际象棋），智能体可以直接访问真实状态 $s_t$。但绝大多数现实任务——网页操作、对话、机器人控制、金融决策——智能体只能获得部分、带噪声的观察 $o_t$，真实状态（用户真实意图、系统后台状态、物理世界的完整构型）永远无法完全确定。1998 年 Kaelbling 等人将这一问题形式化为部分可观测马尔可夫决策过程（POMDP），指出智能体必须依赖历史观察维护一个**信念（belief）**而非直接使用真实状态做决策。

与此同时，纯"无模型"（model-free）的强化学习虽然理论优雅，却需要海量真实环境交互才能收敛，这在机器人、自动驾驶等试错代价高昂的场景中不可接受。这催生了**世界模型**方向：与其在真实环境中反复试错，不如学习一个可微分或可采样的环境近似模型，让智能体在"内部模拟"中进行低成本的规划与策略改进（Sutton 1991 年提出的 Dyna 架构是这一思想的早期代表，2018 年后的 World Models、PlaNet、Dreamer、MuZero 系列将其推向深度学习时代）。进入 LLM Agent 时代后，"环境"进一步扩展为网页、操作系统、企业软件等数字环境，状态估计与世界建模的问题以新的形式（如网页 DOM 是否反映真实系统状态）重新出现。

## 核心问题

1. **部分可观测性**：智能体如何从有限、含噪声的观察中估计并维护对真实状态的信念？
2. **环境多样性与工程实现**：如何为不同类型的任务（Web、GUI、游戏、机器人、企业系统）构建统一、可复现、安全的交互接口？
3. **状态表示**：应该保留观察中的哪些信息、过滤哪些噪声，才能支撑后续决策？
4. **动态预测**：如何学习"执行动作后环境将如何变化"的模型，并量化预测的不确定性？
5. **想象与现实的鸿沟**：基于内部模型的"心理模拟"何时可信、何时会产生模型偏差导致的灾难性决策？

## 技术演进路线

```
完全可观测假设（经典规划/游戏 AI）
  → POMDP 形式化（Kaelbling et al., 1998）：显式建模部分可观测性
    → Bayesian 滤波 / 粒子滤波 / Kalman 滤波：概率状态估计
      → 深度序列模型做隐式信念状态（RNN/LSTM/Transformer 编码历史）
        → 模拟器与交互环境标准化（OpenAI Gym → Gymnasium，Web/GUI/机器人 sandbox）
          → 学习型世界模型（World Models 2018 → PlaNet/Dreamer 潜在空间规划）
            → 基于模型的规划与搜索融合（MuZero：隐式模型 + MCTS）
              → LLM 作为世界模型 / 世界知识源（LLM 模拟环境反馈，用于 Agent 规划）
```

## 重要分支

- **环境交互闭环**：观察-行动-反馈的基本范式，及其与纯推理范式（无反馈闭环）的区别
- **POMDP 与状态估计**：信念状态的数学建模与近似方法
- **交互环境与模拟器**：Web、Computer Use、游戏、机器人、企业系统等具体环境类型与工程实现
- **状态表示与环境预测**：状态抽象方法与环境动态模型（前向模型）的学习
- **世界模型与心理模拟**：基于内部模型的规划、MPC、MCTS 与想象式强化学习

## 概念边界

- **世界模型 vs. 知识库/RAG**：知识库（见 [[../06_Agent工程系统/03_RAG与检索增强/00_RAG系统|RAG系统]]）回答"世界通常是什么样"的静态事实性问题；世界模型回答"在当前状态下执行某个动作，世界会变成什么样"的动态转移问题。两者可以结合（如用 RAG 检索的事实约束世界模型的预测），但不能相互替代。
- **世界模型 vs. 强化学习**：世界模型是对环境动力学 $p(s_{t+1}, r_t \mid s_t, a_t)$ 的显式或隐式建模；强化学习（见 [[../04_强化学习/00_强化学习_综述|强化学习综述]]）是利用（可能包含世界模型的）反馈信号优化策略的学习框架。基于模型的强化学习（Model-Based RL）正是二者的交集。
- **状态估计 vs. 感知**：感知（Perception）是从原始传感器信号（像素、文本、声音）提取特征的过程；状态估计是在感知基础上，结合历史与先验知识，推断出对决策有用的（通常是部分隐藏的）状态变量。

## 学习路径

1. 理解 [[01_环境交互与观察行动循环|环境交互闭环]]的基本范式，明确环境提供什么、智能体能做什么
2. 学习 [[02_POMDP与状态估计|POMDP 与状态估计]]，掌握部分可观测性的数学形式化与信念维护方法
3. 了解 [[03_交互环境与模拟器|交互环境与模拟器]]中不同任务类型的环境设计与工程实践
4. 学习 [[04_状态表示与环境预测|状态表示与环境预测]]，理解如何构建可用于规划的环境动态模型
5. 掌握 [[05_世界模型与心理模拟|世界模型与心理模拟]]，理解如何用内部模型支撑规划与强化学习

## 当前发展状态

- **深度学习驱动的世界模型进展迅速**：Dreamer 系列、TD-MPC2 等在连续控制任务上持续刷新样本效率纪录，MuZero 证明了"无需已知规则、仅学习隐式模型"也能达到超人类水平
- **LLM 承担部分世界模型职能**：LLM 因训练语料中包含大量关于世界如何运作的常识，被越来越多地用作"软世界模型"，为 Agent 的行动后果提供粗粒度预测，但其预测缺乏 grounding、可能产生"看似合理实则错误"的幻觉
- **数字环境标准化程度低**：相比游戏/机器人仿真环境（Gym/MuJoCo）的成熟标准，Web/GUI/企业系统等数字环境的接口、评测基准仍在快速演化（如 WebArena、OSWorld）

## 未来趋势

- **模型偏差的鲁棒处理**：短视野规划、不确定性惩罚、真实世界验证等机制将持续发展，以缓解"想象中成功、现实中失败"的模型偏差问题
- **世界模型与 LLM 融合**：用 LLM 的世界知识初始化或约束可学习的世界模型，兼顾常识覆盖面与预测精度
- **可验证的数字环境**：面向 Agent 评测的标准化交互环境（含可验证的验收条件、故障注入能力）将逐渐成为 Agent 能力评估的基础设施
