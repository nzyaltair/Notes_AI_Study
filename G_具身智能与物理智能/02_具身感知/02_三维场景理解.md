# 三维场景理解

## 一句话理解

机器人需要从多视角观测恢复可操作的 3D 状态——实例、6D 位姿、尺寸、支撑关系、遮挡、可抓取区域以及不确定性——而不是仅做"逼真的重建"。

## 概述

三维场景理解是具身感知的几何基础。导航需要地图，抓取需要物体位姿，装配需要接触面法向，操作需要支撑关系。与三维重建（追求外观逼真）不同，具身三维场景理解追求的是**可查询、可更新、带不确定性的任务相关几何状态**。

## 发展历史

- **1970s-1990s**：立体视觉与点云配准（ICP）建立几何感知基础。
- **2000s**：Kinect 时代深度相机普及；TSDF 与 Voxel Hashing 实现实时重建（KinectFusion）。
- **2010s**：点云深度学习（PointNet, PointNet++, VoxelNet）带来语义理解；6D 位姿估计（PoseCNN）服务抓取。
- **2020s**：NeRF（2020）与 3DGS（2023）实现高质量新视角合成；开放词汇 3D 感知（CLIP 特征嵌入 3D 场）；SAM 实现开放词汇分割。

## 核心概念

| 概念 | 定义 | 用途 |
|---|---|---|
| 点云 | 3D 点集合 | 几何表示、配准 |
| 网格 | 顶点-边-面结构 | 渲染、碰撞查询 |
| TSDF | 符号距离场 | 实时重建、隐式表面 |
| 语义地图 | 几何 + 语义标签 | 语言查询、任务规划 |
| 6D 位姿 | 3D 位置 + 3D 旋转 | 抓取、放置 |
| 场景图 | 节点(对象)+边(关系) | 关系推理、语言查询 |
| NeRF | 隐式神经辐射场 | 新视角合成 |
| 3DGS | 3D 高斯泼溅 | 实时渲染、稠密重建 |

## 技术原理

### 点云处理基础

- **配准**：ICP 及其变体，通过最近邻匹配最小化点对距离。
- **特征**：FPFH、3D 描述子用于匹配与识别。
- **分割**：区域生长、欧式聚类；语义分割网络（PointNet++）输出逐点类别。

### 3D 重建

- **实时重建**：TSDF 融合（KinectFusion）逐帧更新体素符号距离。
- **稀疏重建**：COLMAP 从多视角图像恢复相机与稀疏点云。
- **隐式神经场**：NeRF 学习辐射场，可生成新视角但训练/推理慢。
- **3D 高斯泼溅**：3DGS 以高斯函数表达场景，实时渲染且重建质量高，正成为机器人场景表示的新宠。

### 对象状态估计

操作所需的对象级状态应写成：

$$z_i=(\text{id},{}^B\!T_i,\Sigma_i,\text{attributes},\text{relations},\text{affordance})$$

- \({}^B\!T_i\)：相对机器人基座的 6D 位姿。
- \(\Sigma_i\)：位姿不确定性（决定是否重新观察）。
- affordance：可抓取区域、操作方向。

方法路线：直接回归（PoseCNN）→ 逐点投票（PVN3D）→ 视觉特征匹配（FoundationPose）→ 大模型辅助（语言条件位姿）。

### 语义地图构建

将语义标签与几何地图结合，支持"去厨房拿红色杯子"式语言查询。条目包含几何、语义、关系、时间与置信度：

$$m_i=(\text{instance},{}^W\!T_i,\Sigma_i,\text{attributes},\text{relations},t_{last})$$

开放词汇 3D 特征场（如 ConceptFusion、OpenScene）将 CLIP 特征嵌入 3D 空间，可按语言检索未知类别。

## 关键方法与模型

| 方法 | 核心思想 | 优势 | 局限 |
|---|---|---|---|
| PointNet/PointNet++ | 点集深度学习 | 直接处理点云 | 全局结构弱 |
| VoxelNet | 体素 3D CNN | 3D 检测 | 分辨率受限 |
| PoseCNN | 中心回归+方向回归 | 6D 位姿端到端 | 遮挡脆弱 |
| FoundationPose | 特征匹配+渲染对齐 | 开放物体位姿 | 计算量大 |
| ORB-SLAM | 特征 SLAM | 成熟稳定 | 语义弱 |
| NeRF | 隐式辐射场 | 新视角合成 | 慢、物理弱 |
| 3DGS | 高斯泼溅 | 实时、高质量 | 动态更新成本 |
| 3D Scene Graph | 场景图表示 | 关系+语言查询 | 依赖数据关联 |

## 优势与局限

| 表示 | 优势 | 局限 |
|---|---|---|
| 点云/TSDF/网格 | 距离和碰撞查询直接 | 动态更新成本高 |
| 3D 检测与位姿 | 面向抓取与放置 | 遮挡和类别外对象困难 |
| 场景图 | 支持关系与语言查询 | 依赖稳定数据关联 |
| NeRF/3DGS | 外观稠密、视图新颖 | 不天然提供物理可操作性 |

## 应用场景

- 导航：占用地图、语义地图、拓扑导航。
- 抓取：6D 位姿 + 可抓取区域。
- 装配：接触面、法向、对齐约束。
- 长程任务：对象级地图 + 场景图支撑语言查询。

## 前沿发展

- **开放词汇 3D 感知**：SAM + CLIP 嵌入 3D 场景，支持任意语言查询。
- **3DGS 用于机器人**：实时场景更新、动态物体建模、与 SLAM 结合（GS-SLAM）。
- **FoundationPose 类基座位姿模型**：无需训练即可估计新物体位姿。
- **场景图 + LLM**：场景图作为 LLM 的空间推理接口。
- **动态场景理解**：可移动物体、被挪动对象的跟踪与重定位。

## 常见问题

- **逼真重建 ≠ 可操作状态**：NeRF 渲染漂亮但不可碰撞查询，需要几何层。
- **位姿精度 vs 识别率**：识别 95% 但位姿误差大，抓取仍会失败。
- **静态 vs 动态**：家居场景物体常被移动，地图必须支持更新与遗忘。
