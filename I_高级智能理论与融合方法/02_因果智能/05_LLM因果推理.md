# LLM 因果推理

## 一句话理解

LLM 可以处理因果概念、抽取变量、生成分析代码或规划实验，但语言中的因果陈述和基准答对并不构成可识别的因果结论——因果必须通过机制假设与识别策略来确立。

## LLM 能做什么

- **概念与解释**：解释因果阶梯、混杂、反事实等概念，辅助学习。
- **信息抽取**：从文本中抽取变量、事件与因果陈述，构建因果图草稿。
- **代码生成**：根据问题生成因果推断分析代码（估计量、敏感性分析）。
- **实验设计辅助**：提出可能的混杂、设计干预方案。

## LLM 不能做什么

- **不能仅凭语言确定因果**：训练语料反映的是文本中的相关性，不是干预证据。
- **不能替代识别假设**：基准答对可能是记忆或模式匹配（见 [[../../08_研究方法与证据评估/04_基准设计与数据污染]]）。
- **幻觉风险**：可能生成看似合理但错误的因果结构或数值结论。

## 可靠工作流

```text
自然语言问题 → 明确处理/结果/总体 → 绘制或审查因果图
→ 选择识别策略 → 执行估计与敏感性分析 → 用证据校验叙述
```

该流程中，LLM 承担理解与生成，因果推断方法（见 [[02_因果发现与因果推断]]）承担识别与估计，两者职责分离。

## 评测注意

评估 LLM 因果能力时应区分：

- 记忆因果概念 vs 实际执行因果推断
- 相关模式匹配 vs 反事实推理
- 语言流畅 vs 结论可验证
