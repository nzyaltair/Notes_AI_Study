# 多模态评测

## 一句话理解

多模态评测衡量模型在图文、音频、视频等多种模态输入下的理解、推理和生成能力，需要同时评估跨模态对齐质量、模态特有错误（如视觉幻觉）和真实场景的鲁棒性。

## 1. 多模态理解评测

### 1.1 图文理解

| 基准 | 测量能力 | 特点 |
|:---|:---|:---|
| **MMMU** | 大学水平多模态理解 | 11.5K 题，30 学科 |
| **MMBench** | 综合多模态能力 | 20 维度能力评估 |
| **MMMU-Pro** | 增强版 MMMU | 减少猜测，更重推理 |
| **SEED-Bench** | 图文+视频理解 | 19K 题 |
| **MM-Vet** | 综合能力集成评估 | 6 核心能力 |
| **MathVista** | 视觉数学推理 | 图表/几何/函数 |

### 1.2 视觉问答（VQA）

| 基准 | 测量能力 | 评测方式 |
|:---|:---|:---|
| **VQAv2** | 基础视觉问答 | 人工标注一致性 |
| **OK-VQA** | 需外部知识的 VQA | 需常识/百科知识 |
| **TextVQA** | 图中文字阅读 | OCR + 推理 |
| **DocVQA** | 文档理解 | 表单/发票/文档 |
| **ChartQA** | 图表理解 | 柱状/折线/饼图 |

### 1.3 视频理解

| 基准 | 测量能力 | 特点 |
|:---|:---|:---|
| **Video-MME** | 视频多模态理解 | 多时长、多类型 |
| **MVBench** | 视频时序理解 | 20 个时序任务 |
| **VideoChat** | 视频对话 | 开放式问答 |
| **EgoSchema** | 第一人称视频理解 | 长视频因果推理 |

### 1.4 OCR 与文档

| 基准 | 测量能力 |
|:---|:---|
| **OCRBench** | 文字识别能力 |
| **FUNSD** | 表单理解 |
| **AI2D** | 科学图表理解 |
| **InfographicVQA** | 信息图理解 |

## 2. 多模态生成评测

### 2.1 图像生成

| 指标 | 类型 | 说明 |
|:---|:---|:---|
| **FID (Fréchet Inception Distance)** | 分布 | 生成图与真实图特征分布距离，越低越好 |
| **IS (Inception Score)** | 分布 | 衡量生成质量和多样性 |
| **CLIP Score** | 对齐 | 图像与文本提示的 CLIP 相似度 |
| **LPIPS** | 感知 | 感知相似度，用于图像复原 |
| **SSIM / PSNR** | 像素 | 像素级结构相似性 |
| **CMMD** | 分布 | CLIP 特征空间最大均值差异 |

### 2.2 文生图 Benchmark

| 基准 | 评测维度 | 特点 |
|:---|:---|:---|
| **T2I-CompBench** | 组合泛化 | 颜色/空间/数量绑定 |
| ** PartiPrompts** | 文本-图像对齐 | 1600+ 提示 |
| **HEIM** | 整体性文生图 | 12 维度评估 |
| **GenAI-Bench** | 指令遵循 | 复杂指令理解 |

### 2.3 视频生成

| 指标 | 评测维度 |
|:---|:---|
| **FVD** | 视频质量（FID 的视频版） |
| **VBench** | 综合：时序一致性、运动质量 |
| **EvalCrafter** | 文生视频开放评估 |
| **运动一致性** | 物体运动物理合理性 |

## 3. 多模态特有问题

### 3.1 视觉幻觉

模型"看到"图中不存在的内容：

| 类型 | 说明 | 检测方法 |
|:---|:---|:---|
| **对象幻觉** | 描述不存在的物体 | POPE（二选一判断） |
| **属性幻觉** | 错误描述颜色/大小 | 属性绑定测试 |
| **关系幻觉** | 错误描述空间关系 | 关系推理测试 |
| **计数幻觉** | 数量错误 | 数量问答 |

### 3.2 跨模态对齐

```text
┌──────────────┐     ┌──────────────┐
│  文本理解    │ ←→ │  视觉理解    │
│  "红苹果"    │     │  红色圆形    │
└──────────────┘     └──────────────┘
        ↑                   ↑
        └─── 对齐质量 ──────┘
        
评测方法：
1. 跨模态检索（图文匹配）
2. 组合推理（颜色+对象+位置绑定）
3. 否定理解（"不是红色的车"）
```

### 3.3 模态缺失与降级

- **部分模态缺失**：只有图像没有文本时的表现
- **低质量输入**：模糊图片、噪声音频
- **模态冲突**：文字说"猫"，图片是"狗"
- **评测建议**：分模态单独测试 + 多模态联合测试

### 3.4 时序理解

- **短期时序**：几秒内的动作识别
- **长期时序**：分钟级视频的因果理解
- **时序定位**：视频中"第几秒发生了什么"
- **时序一致性**：长视频中物体身份保持

## 4. 评测方法

### 4.1 自动化评测

| 方法 | 适用任务 | 优势/局限 |
|:---|:---|:---|
| **CLIP Score** | 文图对齐 | 自动但语义粗糙 |
| **FID/IS** | 图像质量 | 自动但与人类感知有差距 |
| **LLM-as-Judge** | 开放式回答 | 可扩展但需校准 |
| **执行器** | 图表→代码 | 客观但覆盖有限 |

### 4.2 人工评测维度

```text
多模态人工评估 rubric：
├── 正确性：信息是否准确
├── 完整性：是否遗漏关键信息
├── 对齐性：文本与图像是否匹配
├── 细节度：是否注意到细微元素
├── 推理性：跨模态推理是否正确
└── 安全性：是否产生有害输出
```

### 4.3 对抗鲁棒性

- **图像扰动**：添加微小噪声测试视觉鲁棒性
- **OCR 错误**：模糊/变形文字的识别能力
- **对抗样本**：对抗性图像攻击
- **分布偏移**：不同设备/光照/风格

## 5. 评测数据集构建

### 5.1 覆盖维度

```text
多模态评测集应覆盖：
├── 图像类型：自然图/文档/图表/截图/医学图像
├── 文本类型：中/英/多语言/专业术语
├── 任务类型：识别/推理/计数/空间/时序
├── 难度层次：简单识别 → 复杂推理
├── 模态组合：图+文/图+表/视频+文/音频+文
└── 真实场景：光照/遮挡/模糊/长尾分布
```

### 5.2 质量保障

- **标注一致性**：多标注者一致性（Cohen's Kappa > 0.7）
- **反偏见设计**：平衡文化、地域、语言
- **对抗案例**：人工构造易错场景
- **版本管理**：记录数据来源和标注协议

## 7. 前沿挑战

- **视频生成评测**：运动一致性、物理合理性、叙事连贯性
- **3D 理解评测**：点云/深度/3D 场景理解
- **音频理解评测**：语音识别、声学场景分类、音乐理解
- **具身智能评测**：在虚拟环境中的多模态交互
- **实时多模态**：流式视频/音频的实时理解
