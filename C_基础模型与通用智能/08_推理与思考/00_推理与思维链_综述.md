# 推理与思维链综述：从语言生成到自主推理

## 一句话理解

推理（Reasoning）是从已知前提得出新结论的认知过程，思维链（CoT）让 LLM 展示中间推理步骤——推理 ≠ 语言生成，o 系列、AlphaGeometry、搜索式推理证明：真正的智能在于"想清楚"而非"说出来"，这是 AGI 阶梯从语言模型迈向 Agent 的关键能力。

## 1. 领域定义

### 推理 (Reasoning)

从已知信息出发，通过逻辑规则或搜索过程，得出新结论的认知能力。包括：
- **演绎推理**：从一般到特殊（所有 A 是 B，C 是 A → C 是 B）
- **归纳推理**：从特殊到一般（观察多个实例 → 总结规律）
- **溯因推理**：从结果推测原因（观察到 Y → 最可能的原因 X）
- **类比推理**：从相似情境迁移知识

### 思维链 (Chain-of-Thought)

Wei et al. (2022) 发现，让 LLM 逐步输出推理过程，可显著提升复杂推理任务的表现。CoT 不是"教模型推理"，而是"让模型展示推理过程"。

### 推理 ≠ 生成

这是当前最关键的认知：

| 维度 | 语言生成 | 推理 |
|------|----------|------|
| 本质 | 模式匹配 + 采样 | 搜索 + 验证 |
| 约束 | 流畅性优先 | 正确性优先 |
| 过程 | 自回归逐 token | 搜索树 + 剪枝 + 回溯 |
| 评估 | 流畅度、相关性 | 正确性、可验证性 |
| 代表 | GPT-4 日常对话 | o 系列、AlphaGeometry |

## 2. AGI 阶梯定位

```
语言模型 → [CoT思维链] → Agent → 持续学习 → 奇点 → 具身智能
              ↑
         推理是语言模型到Agent的
         关键能力跃升
```

- 语言模型会"说话"，但不一定会"思考"
- CoT 让语言模型"展示思考过程"——这是 AGI 阶梯的第二步
- Agent 需要推理来规划、决策、反思——推理是 Agent 的核心能力

## 3. 核心方法

### 3.1 思维链 (CoT) 及其变体

| 方法 | 核心思想 | 代表 |
|------|----------|------|
| CoT | 逐步推理 | Wei et al. 2022 |
| Zero-shot CoT | "Let's think step by step" | Kojima et al. |
| Self-Consistency | 多条推理路径投票 | Wang et al. |
| Tree-of-Thought | 树搜索推理 | Yao et al. 2023 |
| Graph-of-Thought | 图结构推理 | Besta et al. |
| Multimodal CoT | 多模态思维链 | Zhang et al. |

### 3.2 搜索式推理

| 方法 | 搜索策略 | 特点 |
|------|----------|------|
| MCTS | 蒙特卡洛树搜索 | AlphaGo 路线 |
| Beam Search | 宽度受限搜索 | 高效但不保证最优 |
| Best-First Search | 启发式最优优先 | 结合价值函数 |
| A* Search | 启发式最优路径 | 可证明最优性 |
| Branch-and-Bound | 剪枝搜索 | 组合优化 |

### 3.3 Test-time Compute

核心发现：**推理时投入更多计算，模型表现更好**。

| 策略 | 方法 | 效果 |
|------|------|------|
| 多次采样 + 验证 | Self-Consistency, Verifier | 线性提升 |
| 搜索 | MCTS, ToT | 超线性提升（有时） |
| 迭代修正 | Self-Correction, Critic | 逐步提升 |
| 深度思考 | o 系列 style | 质变提升 |

关键洞察：Test-time Compute 可能重新定义 Scaling Laws——不一定需要更大的模型，而是需要更多的推理时间。

### 3.4 形式推理与验证

| 领域 | 方法 | 代表 |
|------|------|------|
| 数学推理 | 形式化证明 + LLM | AlphaGeometry, LeanDojo |
| 代码推理 | 程序执行验证 | PAL, Code-as-Reasoning |
| 逻辑推理 | 符号推理引擎 + LLM | LLM + Z3, LLM + Coq |
| 科学推理 | 假设生成 + 实验验证 | AI Scientist |

### 3.5 过程奖励模型 (PRM)

| 方法 | 思路 | 代表 |
|------|------|------|
| ORM | 只评估最终答案 | Cobbe et al. |
| PRM | 评估每一步推理 | Lightman et al. |
| MCTS + PRM | 搜索 + 步级奖励 | o 系列（推测） |
| 自我验证 | 模型验证自身推理 | Self-Verify |

## 4. 发展历史

1. 2022：CoT (Wei et al.) 发现思维链推理
2. 2023：ToT/GoT 树/图搜索推理；Self-Consistency
3. 2024：o 系列证明 Test-time Compute 的巨大价值；AlphaGeometry 数学推理
4. 2024：PRM (过程奖励模型) 成为训练推理能力的关键
5. 2025-26：推理能力成为基础模型的核心差异化能力

## 5. 与 AGI 的关系

- **AGI 阶梯2**：推理是语言模型之上的关键能力跃升
- **Agent 的核心**：Agent 需要推理来规划、决策、反思
- **自我迭代的前提**：AI 必须能推理才能改进自身
- **安全的保障**：可验证推理是可靠 AI 的基础

## 6. 学习路径

1. 理解 CoT 的基本原理和变体
2. 学习 Tree-of-Thought 搜索推理
3. 理解 Test-time Compute 的 Scaling 效应
4. 研究 PRM（过程奖励模型）的训练方法
5. 探索形式验证 + LLM 的混合推理
6. 思考推理与生成的本质区别

## 7. 未来趋势

- Test-time Compute 重新定义 Scaling
- 长推理链 (Long CoT) 的训练与优化
- 搜索 + 学习的深度融合
- 形式验证 + 神经推理
- 推理效率优化（减少推理计算浪费）
- 推理安全（防止推理被对抗攻击劫持）
