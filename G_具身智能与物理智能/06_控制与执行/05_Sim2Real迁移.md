# Sim2Real 迁移

## 一句话理解

Sim2Real 的目标不是让仿真看起来真实，而是让部署策略对真实系统的关键差异保持鲁棒——差距来自物理、视觉、时延与任务分布四个层面，必须系统化地度量与弥合。

## 概述

Sim2Real（仿真到现实）是学习型具身策略部署的核心方法论。仿真可以大规模训练，但仿真与真机存在系统性差距（sim-to-real gap）：真实摩擦、执行器回差、视觉外观、传感噪声、控制时延和柔性接触。Sim2Real 研究如何在仿真中训练出能在真机可靠工作的策略。

## 发展历史

- **2016-2017**：域随机化（Domain Randomization）提出——训练时随机化物理/视觉参数，策略学会鲁棒（OpenAI 抓取、Tobin 2017）。
- **2018-2019**：系统辨识 + 域随机化结合（把真机日志校准仿真参数）；RL 四足步态迁移成功（Hwangbo 2019）。
- **2020s**：视觉 Sim2Real（真实图像微调、神经渲染）；硬件在环（HIL）；大规模仿真训练 + 有限真机微调成为标准路线。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| sim-to-real gap | 仿真与真机的行为差异 | 核心工程挑战 |
| 域随机化 | 训练时随机化环境参数 | 提升鲁棒性 |
| 系统辨识 | 从真机日志估计参数 | 缩小差距 |
| 视觉迁移 | 处理外观差异 | 感知对齐 |
| 硬件在环 | 真实硬件 + 虚拟环境 | 中间验证 |
| 课程迁移 | 难度递进的真机部署 | 平稳过渡 |
| 验收阶梯 | 分步验证的部署流程 | 风险控制 |

## 技术原理

### 主要差距来源

| 差距 | 典型表现 | 缓解措施 |
|---|---|---|
| 质量/摩擦 | 抓取滑移、接触反弹 | 系统辨识、参数随机化 |
| 执行器回差 | 轨迹误差、抖动 | 残差控制、限幅 |
| 视觉外观 | 仿真策略看不懂真物 | 域随机化、真实图像微调 |
| 传感噪声 | 状态估计漂移 | 噪声建模 |
| 控制时延 | 超调、错过接触时机 | 显式注入延迟 |
| 柔性接触 | 布料、柔性体差异 | 更真实物理模型 |

### 域随机化

训练时从分布中随机采样环境参数：

$$p(\phi): \phi \sim \mathcal U(\phi_{min}, \phi_{max})$$

随机化范围：质量、摩擦、刚度、阻尼、纹理、光照、相机位姿、动作延迟、观测噪声。

系统辨识用真机日志缩小随机范围：先估计真机参数分布，再在该分布上随机化——避免范围过大导致策略保守（过度随机化）。

### 视觉 Sim2Real

- **域随机化渲染**：随机纹理/光照训练。
- **真实图像微调**：少量真机数据微调视觉编码器。
- **神经渲染**：NeRF/3DGS 生成真实感仿真场景。
- **特征对齐**：仿真与真机图像在特征空间对齐。

### 验收阶梯

推荐验收阶梯：

```text
日志回放 → 单元仿真 → 集成仿真 → 硬件在环
→ 限速空载 → 受限真机 → 扩大场景
```

每步应量化成功率、超力/碰撞、时延、恢复率和可回滚性。每一步都定义可以回退的验收门槛，而非一次性把新模型接到完整功率的真机。

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| Domain Randomization | 参数随机化 | 通用 |
| 系统辨识 | 日志估计参数 | 物理差距 |
| 真实数据微调 | 少量真机数据 | 视觉、策略 |
| 残差控制 | 经典 + 学习残差 | 执行器差异 |
| 硬件在环 | 真硬件 + 仿真 | 中间验证 |
| 课程迁移 | 难度递进 | 平稳部署 |
| 神经渲染 | 真实感仿真 | 视觉对齐 |

## 优势与局限

| 方法 | 优势 | 局限 |
|---|---|---|
| 域随机化 | 通用、无真机数据 | 过度随机化保守 |
| 系统辨识 | 缩小物理差距 | 参数估计偏差 |
| 真机微调 | 直接对齐 | 数据量少、风险 |
| HIL | 接近真实 | 成本高 |

## 应用场景

- 四足/人形步态迁移。
- 操作策略部署（抓取、装配）。
- 无人机机动迁移。
- 导航策略（仿真地图 → 真实地图）。

## 常见问题

- **只做仿真评测**：必须真机验收。
- **域随机化万能**：范围要由系统辨识校准。
- **一次迁移当系统可用**：需扩大场景分布验证。
- **忽略时延建模**：仿真需显式注入延迟。
