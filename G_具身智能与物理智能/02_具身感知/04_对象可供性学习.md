# 对象可供性学习

## 一句话理解

可供性（affordance）描述对象、环境与机器人身体之间允许的行动关系：杯子可抓取、把手可拉、平面可放置。它是行动导向表征，不是静态类别属性。

## 概述

可供性概念源自 Gibson 的生态心理学：感知的直接对象不是"物体类别"，而是"环境允许我做什么"。对机器人而言，可供性是把感知（这是什么）转化为行动（我能做什么）的关键中间表征。可供性学习研究如何从数据中学习、表达和泛化这种行动导向的知识。

## 发展历史

- **1979**：Gibson 提出可供性概念，强调感知与行动的不可分割。
- **2000s-2010s**：可供性进入机器人学——Affordance-based grasping（抓取可达性）、Affordance detection 成为独立任务。
- **2010s**：深度学习实现可供性检测（热图、关键点）；交互感知（Interactive Perception）通过学习行动结果推断可供性。
- **2020s**：VLM/LLM 带来可供性的开放词汇推理（"这个杯子可以倒水吗"）；可供性与世界模型、技能库结合。

## 核心概念

| 概念 | 定义 | 说明 |
|---|---|---|
| 可供性 | 环境-身体关系的行动机会 | 关系性：同一把手对成人/幼儿/机器人不同 |
| 行动表征 | 从"是什么"到"能做什么" | 抓、推、倒、插、开等技能标签 |
| 部件级可供性 | 物体部件的行动属性 | 把手可拉、按钮可按、边缘可放 |
| 本体相关性 | 同一物体对不同本体的可供性不同 | 夹爪 vs 灵巧手 |
| 交互感知 | 通过行动推断可供性 | 推一下才知道是否可动 |

## 技术原理

### 表征层次

| 层次 | 内容 | 形式 |
|---|---|---|
| 对象级 | 技能标签与前置条件 | "可抓取""可倒水""可打开" |
| 部件级 | 把手、按钮、边缘、接触面 | 部件检测 + 操作方向 |
| 像素/点级 | 可抓取热图、接触点、法向 | 热图、关键点、场 |
| 状态级 | 当前物体状态与可用动作 | "门开着→可关闭" |

### 学习来源

1. **人类示范**：从演示中提取"做什么、接触哪里"。
2. **交互试探**：机器人自己推、拉、抓，观察结果学习（交互感知）。
3. **视频先验**：从人类操作视频学习可供性（跨本体迁移的中间表征）。
4. **视觉语言模型**：VLM 提供开放词汇可供性推理（"能装水的容器"）。
5. **物理仿真**：仿真中大量试探学习接触与操作结果。

### 可供性与操作闭环

部署时必须由几何可达、碰撞与力约束复核：

```text
可供性提议（"可抓取"）
→ 抓取候选生成（哪里抓）
→ IK 可达性验证
→ 碰撞检查
→ 力/接触验证
→ 执行
```

VLM 说"可以抓"不等于真的能抓——机器人必须用几何和物理层验证。

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| AffordanceNet | 像素级可供性检测 | 抓取、放置 |
| GraspNet/GG-CNN | 抓取质量热图 | 抓取 |
| 交互感知 | 行动结果学习 | 未知物体 |
| VLM 提示 | 语言可供性推理 | 开放词汇 |
| 功能网络 | 功能几何联合表示 | 工具使用 |
| 图网络 | 部件-关系可供性 | 装配、使用 |

## 优势与局限

| 方面 | 优势 | 局限 |
|---|---|---|
| 行动导向 | 直接服务规划 | 依赖本体与场景 |
| 开放词汇 | 泛化到新物体 | 几何验证缺失 |
| 交互学习 | 获取视觉不可得信息 | 试错成本与风险 |
| 热图表征 | 简单、可部署 | 缺少关系信息 |

## 应用场景

- 抓取：可抓取区域预测。
- 工具使用：功能属性（"这个可以拧螺丝吗"）。
- 家居任务：开门、放物、倒水。
- 长程任务：物体状态与可用动作的组合推理。

## 前沿发展

- **VLM 可供性推理**：开放词汇 + 世界知识。
- **可供性-世界模型联合**：预测"若推这个物体会怎样"。
- **跨本体可供性**：同一可供性在不同机器人上的迁移。
- **动态可供性**：物体状态变化后的可供性更新。

## 常见问题

- **把可供性当类别属性**：可供性是关系性的（身体-环境）。
- **忽略本体差异**：同一物体对夹爪和灵巧手的可供性不同。
- **语义不验证**：VLM 说"可抓"但几何不可达，必须物理层验证。
