# 神经进化、开放式学习与人工生命

神经进化用进化方法优化网络参数或拓扑；开放式学习不只追求固定目标最优，而持续产生新颖、可行且有价值的行为；人工生命研究简单规则、生态互动与进化如何形成复杂性。

## 关键思想

- **NEAT/拓扑进化**：同时发展网络结构和参数。
- **Novelty Search**：奖励行为新颖性，避免稀疏奖励下的局部最优。
- **Quality Diversity（MAP-Elites）**：保留多种行为特征下的高质量解，形成技能多样性。
- **开放式演化**：要求不断产生复杂性，而非收敛到单一最优解；评价标准仍是开放难题。

这些方法可用于发现多样化 Agent 技能和环境课程，但开放性也会产生不可预期行为，因此必须在隔离环境中评估并施加能力边界。
