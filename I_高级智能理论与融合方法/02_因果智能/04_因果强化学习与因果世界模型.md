# 因果强化学习与因果世界模型

## 一句话理解

因果强化学习利用机制知识区分行动、状态、混杂与奖励生成，从而提升探索效率、迁移可靠性与离线决策安全性；因果世界模型进一步预测不同干预下的环境演化。

## 为什么需要因果

标准 RL 假设马尔可夫状态满足干预语义，但现实中：

- **行为策略选择偏差**：离线数据由旧策略产生，次优区域无数据。
- **混杂行动**：状态中存在同时影响决策与奖励的混淆变量。
- **不可执行干预**：模型学到的"因果"可能只是相关性，无法用于反事实规划。
- **环境变化**：干预改变机制后，纯关联模型失效。

## 核心方法

| 方向 | 代表工作 | 核心机制 |
|---|---|---|
| 因果策略学习 | CaRLO、CASL | 在因果图中优化可干预变量的策略 |
| 反事实回归 | CF-RL | 用反事实推断纠正行为策略偏差 |
| 因果世界模型 | CWM、Causal MBRL | 学习可分解转移，支持干预模拟 |
| 离线因果评估 | Causal OPE | 在未观测混杂下做无偏策略评估 |
| 探索利用因果 | 因果驱动的 intrinsic reward | 优先探索因果信息增益大的状态 |

## 因果世界模型 vs 一般世界模型

一般世界模型（见 [[../../F_世界模型与环境智能/00_世界模型综述]]）学习观测序列的预测分布，适合模拟但与机制解耦；因果世界模型显式建模变量间的干预关系，可以在想象中回答"如果我改变 X 会怎样"，为规划提供可检验的反事实模拟。代价是需要更强的结构假设。

## 难点

- 因果结构从部分可观测、高维状态中学习困难。
- 行为策略造成的数据分布偏差难以完全修正。
- 模型失配与长期误差累积使反事实规划失真。
