# 物理与接触预测

## 一句话理解

物理世界模型学习状态如何随动作演化——\(p(s_{t+1}\mid s_t,a_t)\) 或潜在状态转移 \(p(z_{t+1}\mid z_t,a_t)\)——并显式处理摩擦、碰撞、接触模式切换和部分可观测性。

## 概述

物理预测是具身世界模型的核心科学问题：机器人行动后世界会怎样变化？解析物理可以在受控场景精确预测，但真实世界的接触、摩擦和柔性物体超出解析范围；学习式模型可以逼近复杂动力学，但长时域误差累积。物理与接触预测研究如何组合两者，在决策时域内给出可靠预测。

## 发展历史

- **1970s-1990s**：刚体动力学算法成熟（Featherstone 1983）；接触力学（Mason 1986）建立理论。
- **2000s**：物理引擎（Bullet, ODE, PhysX）进入机器人仿真；系统辨识方法成熟。
- **2010s**：可微物理引擎（Differentiable Physics）出现——可把接触与碰撞嵌入反向传播（DiffTaichi, Brax）。
- **2020s**：学习式动力学模型（GNN 粒子系统、神经接触模型）用于机器人操作；接触预测与触觉结合。

## 核心概念

| 概念 | 定义 | 意义 |
|---|---|---|
| 状态转移 | \(p(s_{t+1}\mid s_t,a_t)\) | 世界模型的基本形式 |
| 接触动力学 | 接触力满足非穿透与摩擦 | 预测能否抓稳/放稳 |
| 摩擦锥 | \(\lVert F_t\rVert\le\mu F_n\) | 接触的可行力域 |
| 接触模式 | 分离/滑动/固定/滚动 | 模式切换是难点 |
| 系统辨识 | 从数据估计模型参数 | 缩小 sim-to-real 差距 |
| 可微物理 | 物理仿真可反向传播 | 学习物理参数 |
| 神经接触模型 | 学习接触结果 | 处理未知摩擦与柔性 |

## 技术原理

### 解析动力学

刚体关节动力学：

$$M(\mathbf q)\ddot{\mathbf q}+h(\mathbf q,\dot{\mathbf q})=S^T\boldsymbol\tau+J_c^T\mathbf F_c$$

接触约束（库仑摩擦锥）：

$$F_n\ge0,\qquad \lVert\mathbf F_t\rVert\le\mu F_n$$

解析方法精确但需要准确模型参数；对柔性物体、未知摩擦、布料等难以建模。

### 学习式动力学

| 路线 | 学什么 | 优势 | 局限 |
|---|---|---|---|
| 神经网络回归 | 状态转移残差 | 灵活 | 数据需求、误差累积 |
| GNN 粒子系统 | 粒子间作用力 | 可表达柔性体 | 粒子数计算成本 |
| 神经 ODE | 连续动力学 | 可微、时序精确 | 训练复杂 |
| 潜空间模型 | 压缩观测转移 | 从图像学习 | 语义遗漏 |
| 混合模型 | 解析约束 + 学习残差 | 安全 + 适应 | 接口复杂 |

### 接触预测

接触预测是机器人操作最困难的预测问题：

- **何时接触**：接近阶段的接触时刻预测。
- **接触结果**：是否会滑移、倾倒、卡住。
- **柔性物体**：布料折叠后的接触状态。

方法：物理引擎 + 参数辨识、学习式接触模型、触觉辅助验证。

### 评测

评测应按对象位姿、接触事件、可达性、风险预测和控制收益衡量；仅用像素误差会奖励模糊但不可控的预测。

## 关键方法与模型

| 方法 | 核心思想 | 适用 |
|---|---|---|
| Featherstone 算法 | 刚体递归动力学 | 精确刚体 |
| MuJoCo 解析导数 | 可微接触 | 接触 RL |
| Brax | JAX 可微物理 | 大规模并行 |
| DiffTaichi | 可微物理编程 | 自定义物理 |
| GNN 粒子动力学 | 学习粒子交互 | 柔性体 |
| Dreamer 潜模型 | 潜空间转移 | 图像域 |
| 混合模型 | 解析+学习残差 | 工业部署 |

## 优势与局限

| 路线 | 优点 | 局限 |
|---|---|---|
| 解析动力学/系统辨识 | 可解释、适配 MPC | 难覆盖柔性与复杂接触 |
| 神经动力学 | 可从高维数据学习 | 长时域误差累积 |
| 视频预测 | 利用大规模视觉数据 | 视觉逼真不等于物理正确 |
| 混合模型 | 约束保证 + 学习残差 | 接口和验证复杂 |

## 应用场景

- 抓取稳定性预测：预测抓取后是否滑移。
- 放置规划：预测物体倾倒风险。
- 推操作：预测推动后物体的位移。
- 布料/柔性物体操作：预测形变。
- MPC 中的动力学模型：滚动预测。

## 常见问题

- **像素误差当物理正确**：逼真视频 ≠ 力/接触预测可靠。
- **长时域盲信**：预测误差随时间累积，需滚动重规划。
- **忽略不确定性**：单一预测当事实，必须输出分布或置信度。
