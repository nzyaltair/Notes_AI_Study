# 多模态基础模型综述

## 一句话理解

多模态基础模型把文本、图像、音频、视频或动作映射到可对齐、可交互或可共同生成的表示与 token 空间，使模型能根据一种模态理解、生成或约束另一种模态。

## 领域定义与边界

多模态不是由“模型接入了多种输入”决定，而是由跨模态对齐、融合和任务适配能力决定。本模块研究模型层的接口、架构、训练与评测；单模态视觉预训练见 C.03，感知任务、传感器和数据基准见 E，动作策略见 C.07，环境模拟见 C.05。

## 核心问题

1. 不同采样率、维度和噪声特性的模态如何 token 化与编码？
2. 如何在配对不足、错配和弱监督条件下获得语义对齐？
3. 何时使用双塔检索、连接器接入 LLM、跨注意力融合或原生统一建模？
4. 如何评测跨模态感知、定位、推理、生成与安全性，而不把语言先验误判为视觉理解？

## 技术演进

| 阶段 | 代表路线 | 主要能力 |
|---|---|---|
| 2019–2021 | 图文预训练与双塔对比（CLIP/ALIGN） | 检索、零样本分类、开放词汇接口 |
| 2022–2023 | Q-Former、视觉连接器、指令微调 | 图像条件的对话、问答和推理 |
| 2024–当前 | 原生多模态、实时音视频、统一生成 | 输入输出模态扩展与低延迟交互 |

这不是严格线性替代关系：双塔、组合式 VLM 和原生统一模型在成本、数据和任务上可并存。

## 架构取舍

| 路线 | 优势 | 局限与适用边界 |
|---|---|---|
| 双塔对比 | 检索高效、可大规模训练 | 细粒度交互和生成能力有限 |
| 编码器 + 连接器 + LLM | 能复用强语言模型，工程灵活 | 接口瓶颈、视觉 token 压缩与幻觉风险 |
| 跨注意力融合 | 条件生成和细粒度交互较强 | 训练和推理成本较高 |
| 原生统一建模 | 理论上支持任意模态 I/O | 数据、评测和安全约束更难统一 |

## 评测与局限

必须分别检查感知是否正确、语言是否忠实于输入、跨模态推理是否可验证、生成是否满足条件及系统是否对错配/对抗输入稳健。多模态基准分数也可能受语言数据污染、选项偏置和文本捷径影响；应结合人工审查、定位任务和受控反事实样本。
