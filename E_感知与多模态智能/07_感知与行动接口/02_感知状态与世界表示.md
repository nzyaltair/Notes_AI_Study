# 感知状态与世界表示

## 一句话理解

感知状态与世界表示研究感知系统如何将原始观测组织为可供决策系统使用的结构化状态——它定义了"感知输出了什么"这一核心问题，是连接感知与行动的关键接口。

## 概述

感知状态（Perception State）和世界表示（World Representation）关注感知系统的输出格式：感知不仅仅是"识别"物体，而是向上层系统（规划器、控制器、世界模型）提供可查询、可更新、带置信度的结构化状态。

## 核心表示方法

| 表示 | 描述 | 优点 | 缺点 |
|:---|:---|:---|:---|
| 对象中心表示 | 以物体实例为单位的表示 | 直观，可操作 | 对象分割困难 |
| 语义地图 | 语义标签+几何地图 | 可导航 | 更新成本高 |
| 场景图 | 节点(物体)+边(关系) | 结构化，可推理 | 构建复杂 |
| BEV | 鸟瞰图统一表示 | 多任务共享 | 3D 信息损失 |
| 占据栅格 | 每个格子是否被占据 | 简单，通用 | 分辨率受限 |
| 隐式表示 | 神经场/特征网格 | 连续，紧凑 | 不可解释 |

## 感知状态契约

感知系统输出应包含：

```python
{
    "timestamp": 1234567890,          # 观测时间
    "objects": [                       # 物体列表
        {
            "id": "obj_001",
            "class": "chair",
            "bbox_3d": [x, y, z, w, h, d],
            "confidence": 0.95,
            "attributes": {"color": "red", "material": "wood"}
        }
    ],
    "scene_graph": {                   # 场景图
        "nodes": [...],
        "edges": [{"subject": "obj_001", "predicate": "on", "object": "obj_002"}]
    },
    "uncertainty": {                   # 不确定性
        "epistemic": ...,
        "aleatoric": ...
    }
}
```

## 关键挑战

- **置信度校准**：感知置信度应准确反映实际准确率
- **时间一致性**：帧间状态变化应平滑
- **动态更新**：场景变化时高效更新状态
- **不确定性量化**：区分认知不确定性和偶然不确定性
