# 仿真 Agent

## 一句话理解

仿真 Agent 在软件、游戏、网页、城市或机器人环境中完成训练、回放和压力测试，是安全试错与规模化数据收集的执行载体。

## 概述

仿真是世界模型价值兑现的舞台：Agent 在仿真中大规模试错、收集数据、验证策略，再迁移到真实环境。仿真 Agent 既可由规则/物理模拟器驱动，也可由生成式环境扩展长尾场景（见 [[../../04_环境模拟与数字孪生/06_大规模环境生成|大规模环境生成]]）。

## 运行要求

- **高吞吐交互**：并行环境（数千实例）、快速 reset、稳定的 step 语义。
- **数据记录**：环境版本、随机种子、动作轨迹、观测、奖励、失败原因。
- **可回放**：同一状态可重放以复现 bug 与回归测试。
- **注入能力**：可注入故障、扰动与对抗对手进行压力测试。

## 用途

- **训练**：RL/模仿学习的经验来源；生成式数据增强。
- **评测**：在固定测试切片上标准化对比（避免训练-评测泄漏）。
- **压力测试**：对抗扰动、极端参数、罕见故障注入。
- **人类行为模拟**：LLM 驱动的用户/对手 Agent 模拟（社会与市场场景）。

## 常见误区

- 仅在单一模拟器中的成功被当作现实泛化：应做跨环境、扰动和反事实测试。
- 训练数据与评测数据同源：会高估泛化，需划分环境版本与种子。
