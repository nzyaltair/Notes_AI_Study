# C 基础模型与通用智能：能力形成层

## 领域定位

C 讨论基础模型如何由宽泛数据、统一表征、后训练和推理时计算形成可迁移能力，并如何向记忆、规划、工具与物理行动提供模型接口。它不是 Agent、认知、因果、具身控制或工程系统的重复目录。

## 能力形成链

```text
多模态数据与预测目标
        ↓
通用表征与世界知识先验
        ↓
规模化预训练 + 后训练/对齐
        ↓
候选生成 + 搜索/验证 + 测试时计算
        ↓
世界状态预测与行动条件建模
        ↓
Agent 的记忆、规划、工具调用与环境交互
```

C 回答“可复用模型能力如何形成”；自主系统回答“如何在长期任务中组织、约束和执行这些能力”。

## 评测与能力边界

能力提升应同时检查任务正确率、校准与鲁棒性、数据污染、跨域迁移、推理成本和安全行为。语言、多模态、推理、世界预测与行动条件模型的共用方法论入口是 [[../K_AI工程化/06_评测体系/00_AI评测体系_综述|K AI 评测体系]]。单个排行榜、输出流畅性或展示案例都不足以证明通用智能。

## 推荐学习路径

1. 理论 → 语言/视觉表征 → 多模态对齐。
2. 训练与对齐 → 推理时计算 → 世界模型与行动基础模型。
3. 进入 [[../D_智能体与自主系统/02_Agent理论/00_Agent理论_综述|D Agent]]、[[../F_世界模型与环境智能/01_世界模型理论/00_世界模型理论_综述|F 世界模型]]、[[../G_具身智能与物理智能/09_具身基础模型/00_具身基础模型_综述|G 具身基础模型]] 构成系统闭环。
